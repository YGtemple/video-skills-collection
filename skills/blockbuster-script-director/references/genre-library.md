# 类型库与作品发动机拆解（genre-library）

确定类型打法时读取。学的是"故事发动机"（观众为什么继续看、人物为什么必须行动、冲突为什么升级、结尾为什么勾人），**不是复制具体情节**。

## 一、中国网络小说类型谱系

| 类型 | 核心发动机 | 关键机制 |
|---|---|---|
| 仙侠 | 修炼—升级—换地图—更高层级敌人 | 境界体系、宗门势力、资源争夺、师徒关系、宿命、长期伏笔、大篇章推进；靠"不断进入更高层级世界"维持长期动力 |
| 玄幻 | 力量成长与世界观逐层展开 | 等级成长、血脉/天赋、势力战争、逆袭 |
| 奇幻 | 世界规则与冒险使命 | 规则谜题、种族与阵营、史诗任务 |
| 武侠 | 江湖恩怨与价值选择 | 江湖、人物关系、恩怨、身份秘密、高手对决、人物成长 |
| 都市 | 现实社会中的身份/财富/关系跃迁 | 现实代入、身份差、财富差、权力差、打脸、逆袭、隐藏身份、情感冲突、快速情绪释放；可融合商业、爱情、武力、超自然元素 |
| 历史 | 时代洪流中的改命与立足 | 现代认知差、阵营博弈、家国选择 |
| 权谋 | 权力争夺与计谋反制 | 阵营、利益、立场、表面事件背后的真正目的、信息差 |
| 军事 | 战争任务与军人成长 | 任务压力、团队、牺牲、战术博弈 |
| 科幻 | 世界规则与未知危机 | 规则设定、技术逻辑、生存压力、世界观逐层展开 |
| 悬疑 | 问题—线索—推理—信息差 | 未知感、误导、谜题、身份反转、层层揭露、"答案带来更大问题" |
| 灵异 | 未知恐惧与规则求生 | 环境恐惧、诡异氛围、规则谜题、秘密 |
| 盗墓 | 险境探索与谜题破解 | 未知环境、团队关系、死亡风险、传统推理+惊悚+冒险+灵异的混合结构（尤其适合漫剧与短视频） |
| 现实题材 | 人物处境与现实矛盾 | 真实人物、生活压力、家庭关系、职业冲突、社会环境、时代变化；**不能靠简单反派推动，要靠处境和现实矛盾推动** |
| 系统流 | 任务—奖励—升级循环 | 任务机制、规则限制、阶段目标 |
| 无限流 | 副本/任务世界连续闯关 | 未知环境、任务机制、团队关系、死亡风险、规则谜题、世界观逐层展开 |
| 末世 | 资源极限下的生存 | 生存压力、资源限制、人性选择、团队关系 |
| 重生 | 带着记忆重来改命 | 信息差优势、弥补遗憾、蝴蝶效应、宿敌仍在 |
| 穿越 | 异环境适应与认知差 | 身份错位、认知差、规则学习、改变世界 |
| 复仇 | 向施害者追讨 | 压制→积累→反击→释放；仇人层级递进、背后还有更大敌人 |
| 宫斗 | 后宫权力生存 | 阵营、利益、信息差、计谋反制、身份隐藏 |
| 宅斗 | 家族内部利益与名分 | 礼法规则、亲缘伪装、算计与反制 |
| 商战 | 商业利益争夺 | 商业博弈、资源与权力差、现实代入 |
| 娱乐圈 | 名气、作品与身份沉浮 | 打脸、逆袭、舆论反转、职业成长 |
| 年代文 | 时代变迁中的个人/家庭奋斗 | 时代细节、资源匮乏、家庭关系、政策变化 |
| 职场 | 职业目标与组织博弈 | 现实代入、利益冲突、晋升、职业伦理 |
| 刑侦 | 案件侦破 | 线索、误导、推理、警匪博弈、社会议题 |
| 探案 | 谜题与真相 | 问题、线索、信息差、反转 |
| 言情（古言/现代言情） | 关系的拉扯与确认 | 误会、秘密、占有、牺牲、选择、失去、重逢、关系反转、情绪高潮 |
| 群像 | 多人物命运交织 | 多目标、立场冲突、关系网、主题合唱 |
| 成长 | 人物内在转变 | 弱点、代价、认知更新、与世界和解/对抗 |
| 热血 | 以弱胜强的信念之战 | 升级流、团队、信念、高燃对决 |
| 升级流 | 等级持续成长 | 修炼—升级—换地图—更高层级敌人 |
| 无敌流 | 绝对力量下的新问题 | 反差、隐藏实力、更高层级世界 |
| 凡人流 | 普通人在残酷世界求生 | 资源匮乏、步步为营、真实代价、智斗 |

类型可杂交（如都市+悬疑、末世+无限流、古言+权谋），杂交时必须说清**主发动机是哪个类型**，副类型提供什么元素。

## 二、经典作品类型拆解

### 武侠 / 江湖

- 金庸：《射雕英雄传》《神雕侠侣》《倚天屠龙记》《天龙八部》《笑傲江湖》
- 古龙：《多情剑客无情剑》《楚留香》《绝代双骄》
- 梁羽生作品

**学习点：** 人物恩怨、宿命关系、身份秘密、江湖势力、价值选择、高手对决、人物成长。

### 仙侠 / 玄幻

- 《凡人修仙传》《诛仙》《仙逆》《我欲封天》《斗破苍穹》《斗罗大陆》《完美世界》《雪中悍刀行》

**学习点：** 世界观、力量体系、等级成长、地图升级、宗门势力、资源争夺、师徒关系、宿命、逆袭、长期伏笔、大篇章推进；尤其擅长用"不断进入更高层级世界"保持长期故事动力。

### 悬疑 / 探案 / 灵异

- 《盗墓笔记》《鬼吹灯》及侦探、刑侦、心理悬疑类作品

**学习点：** 未知感、线索、误导、信息差、环境恐惧、秘密、谜题、身份反转、层层揭露、"答案带来更大问题"；中国网络悬疑常把传统推理与惊悚、冒险、灵异、诡异氛围结合，这种混合结构尤其适合漫剧和短视频叙事。

### 历史 / 权谋

- 《庆余年》《琅琊榜》《雪中悍刀行》及历史、宫廷、战争、权谋类作品

**学习点：** 阵营、利益、权力关系、政治博弈、身份隐藏、人物立场、计谋、反制、信息差、"表面事件背后的真正目的"。

### 都市 / 逆袭

- 都市商战、职场、豪门、复仇、重生、身份反转类作品

**学习点：** 现实代入、身份差、财富差、权力差、打脸、逆袭、隐藏身份、情感冲突、快速情绪释放；以现代社会为背景，可融合商业、爱情、武力、超自然元素。

### 言情 / 情感

- 现代言情、古言、虐恋、甜宠、婚恋、豪门、宫斗、女性成长类作品

**学习点：** 人物关系、情感拉扯、误会、秘密、占有、牺牲、选择、失去、重逢、关系反转、情绪高潮。

### 科幻 / 末世 / 无限流

**学习点：** 世界规则、生存压力、资源限制、未知环境、任务机制、团队关系、死亡风险、规则谜题、阶段性目标、世界观逐层展开。

### 现实题材

**学习点：** 真实人物、生活压力、家庭关系、职业冲突、社会环境、时代变化、人物选择。现实题材的动力来自人物处境和现实矛盾，而非简单反派。

## 三、影视叙事类型

重点掌握：商业大片、动作片、犯罪片、悬疑片、惊悚片、恐怖片、爱情片、喜剧、黑色喜剧、家庭剧、都市剧、历史剧、权谋剧、战争剧、科幻剧、奇幻剧、成长剧、群像剧、短剧、连续剧、动画、动漫、漫剧。

提取的不是桥段，而是五个"故事发动机"问题：

1. 观众为什么会继续看？
2. 人物为什么必须行动？
3. 冲突为什么会不断升级？
4. 观众为什么会关心人物？
5. 结尾为什么让人想看下一集？

**形态适配提示：**

- 短剧/短视频：开场钩子前置到前几秒；单集闭环更短；情绪释放更密；视觉记忆点优先。
- 漫剧/动画：强化画面奇观、人物造型记忆点、动作与反转的视觉冲击；可用旁白但信息仍要靠冲突给出。
- 连续剧：四层结构（整部/篇章/单集/场景）+ ABC 三线；伏笔系统与篇章高潮是长线动力核心。

## 四、类型使用原则

1. 先定主类型发动机，再谈杂糅元素；杂糅不得让发动机失焦。
2. 拆解作品只提取机制（因果结构、升级方式、信息差布局、情绪波形），**不得照搬具体情节、人物与设定**。
3. 类型期待必须兑现：观众选择某类型是为满足特定情绪契约（如复仇要等到清算、悬疑要得到公平推理的真相、甜宠要兑现关系确认），可以反套路，但要先满足核心契约再颠覆。
4. 每个类型的名场面模板都要过本 Skill 的因果与自检：爽点/反转/高潮必须由人物选择和代价支撑，不允许靠降智与巧合解决核心问题。
