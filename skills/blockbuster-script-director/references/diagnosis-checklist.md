## 阶段一：12 项诊断模板

对用户剧本逐项输出，每项给出"现状判断 + 问题定位 + 改造方向提示"。

| # | 诊断项 | 必须回答的问题 |
|---|---|---|
| ① | 一句话故事 | 用一句话讲清"谁，在什么处境下，想要什么，被什么阻挡，最终不得不面对什么"。讲不清 = 发动机不明确。 |
| ② | 故事核心卖点 | 这部剧最独特、最可营销的设定/关系/情境是什么？一句话能卖出去吗？ |
| ③ | 最强优势 | 原作最有价值、必须保留的东西（创意/人物/设定/关系/名场面）是什么？ |
| ④ | 最大问题 | 最致命的一个结构性问题是什么？（只挑最影响追剧动力的那个） |
| ⑤ | 主角问题 | 主角是否主动？外部目标与内部需求是否清晰？错误是否源于性格而非降智？ |
| ⑥ | 反派问题 | 反派有无自己的目标、逻辑、资源、恐惧与过去？能否持续威胁主角？是否靠变蠢输？ |
| ⑦ | 人物关系问题 | 主要关系有无欲望错位、秘密、博弈和变化？B 线能否影响 A 线？ |
| ⑧ | 冲突问题 | 冲突是目标互相阻碍，还是仅停留在吵架打架？外部/关系/内部/利益/价值观冲突是否齐备？ |
| ⑨ | 节奏问题 | 有无大段解释背景、聊天、重复冲突？每集是否都有阶段性变化？哪里会弃剧（标出具体集/场）？ |
| ⑩ | 悬念问题 | 观众此刻最想知道什么？问题被回答后是否产生更大问题？信息差是否被利用？ |
| ⑪ | 伏笔问题 | 重大转折前有无铺垫？伏笔是否回收并产生影响？有无为复杂而复杂的废伏笔？ |
| ⑫ | 最有潜力的爆点 | 现有素材里哪个情境/关系/反转具备成为名场面或传播点的潜力？如何放大？ |

诊断输出后，明确标注**弃剧风险点**（具体到集与场）。

## 阶段二：《整体升级方案》模板

11 个模块逐项给出，经用户确认后才进入改写：

1. **核心卖点**：一句话卖点 + 卖点在剧情中的承载方式（哪条线、哪些场面持续兑现卖点）。
2. **主线重构**：故事发动机（可持续产生剧情的核心问题）；A 线目标链；关键因果链（因为……所以……）。
3. **人物升级**：主角外部目标 / 内部需求 / 弱点 / 恐惧 / 主动选择链；主要配角各自的目标与功能。
4. **反派升级**：十项设定（目标、能力、资源、弱点、恐惧、过去、价值观、策略、底线、与主角关系）；反派的自我合理性。
5. **关系线（B 线）**：核心关系的初始状态 → 关键博弈 → 关系反转 → 终局；B 线如何影响 A 线。
6. **副线**：副线人物与目标；副线与主线的交汇点；删除/合并的人物清单及理由。
7. **伏笔系统**：伏笔表——伏笔内容 / 埋设位置 / 误导方式 / 回收位置 / 回收产生的影响。
8. **反转系统**：每个反转的四条件自检（意外/合理/必然/有效）；反转后改变了什么。
9. **情绪曲线**：全篇与每个篇章的主情绪；"积累→爆发→释放→新危机"波形；每集主情绪标注。
10. **篇章结构**：分篇章（每篇一个阶段性目标、敌人、高潮）；四层结构（整部/篇章/单集/场景）对齐表。
11. **单集钩子**：每集开场钩子问题 + 结尾钩子问题清单；每集小故事闭环（目标→阻碍→行动→变化→代价→阶段结果→新问题）。

## 单集八拍表与小故事闭环

每集开写前先填本表：

| 节拍 | 内容 | 观众心理 |
|---|---|---|
| 1. 开场钩子 | 冷开场画面/事件，尽快抛出一个问题 | 发生了什么？这个人是谁？为什么？ |
| 2. 本集目标 | 主角本集明确想得到什么 | 建立期待 |
| 3. 核心冲突 | 谁/什么阻挡，双方目标如何互斥 | 紧张站队 |
| 4. 冲突升级 | 阻力加大、代价提高或时间压迫 | 紧张升级 |
| 5. 中段变化 | 新信息/新敌人/新关系/新风险，原问题变质 | 预测被改变 |
| 6. 情绪高潮 | 本集主情绪的爆发点（名场面优先） | 情绪释放峰值 |
| 7. 反转/重大信息 | 选择、代价、关键情报或失去 | 震撼/恍然 |
| 8. 结尾钩子 | 明确的下一集问题，卡在答案揭晓前 | 然后呢？立刻点下一集 |

**小故事闭环**（即使主线未解决，本集也必须完成）：

```
目标 → 阻碍 → 行动 → 变化 → 代价 → 阶段结果 → 新问题
```

废集判定：整集只剩"聊天 → 解释背景 → 再聊天 → 发生一点小事 → 结束"，必须重写。

## 场景检查表

每场戏写前写后各过一遍：

**写前：**

- 人物进入这个场景时想要什么（场景目标）？
- 谁阻止他？双方如何博弈？
- 可能发生什么意外？

**写后（任一项答"无"即删除或合并）：**

- 人物状态是否发生变化？
- 人物关系是否发生变化？
- 观众是否获得新信息？
- 冲突是否升级？
- 情绪是否变化？
- 是否有视觉价值（值得拍的画面/声音记忆点）？

**视觉化追问：** 能否不用对白表达？动作是否比台词更有力量？信息能否通过行为、环境、道具给出？

## 阶段四：爆款自检十维清单

改写完成后逐项检查；不通过的直接改成品，不向用户解释原因。

| 维度 | 自检问题 |
|---|---|
| 故事 | 核心卖点是否明确？故事发动机能否持续产生新目标、新阻力、新选择？ |
| 人物 | 主角是否主动？反派是否有逻辑且不靠变蠢输？配角是否各有目标？ |
| 剧情 | 有无因果链？有无升级？有无中点变化？有无低谷？有无高潮？ |
| 单集 | 开头有钩子？中段有升级？后段有高潮？结尾有下一集钩子？本集闭环是否完成？ |
| 场景 | 每场戏是否都发生了变化？废戏是否已删并？ |
| 悬念 | 观众此刻最想知道的是什么？问题回答后是否引出更大问题？ |
| 情绪 | 本集让观众产生了什么主情绪？波形是否有积累与释放，而非全程平或全程炸？ |
| 视觉 | 有没有值得记住的画面（人物/场景/动作/反转/高潮记忆点）？ |
| 节奏 | 有无废戏、废对白、重复冲突？说明式对白是否已改为事件呈现？ |
| 追剧 | 本集结束后，观众为什么必须点下一集？钩子是"信息差带来的期待"还是"故意拖延"？ |

**总收束标准**：观众看完一集后不是觉得"这一集结束了"，而是自然产生"下一集我要继续看"。

## 下游成片 / 资产交付自检门（A/B/C · 进入分镜 / 资产 / 视频环节后必过）

> 本技能为剧本 / 前期层，本身不生成成片；但剧本一旦流入下游资产与视频制作，每张定稿资产、每个成片交付用户前必须过此门，发现任一问题即改 / 重生成、不带病交付（真人 / 漫剧同样查）。

- [ ] **A. 意外文字类（应为无）**：资产成图与成片是否意外出现 字幕 / 台词字幕 / 花字 / 标题字 / 屏幕文字 / 招牌或纸张上的可读文字 / 水印 / logo / 平台 UI / 进度条 / 时间码 / 按钮图标等。除黑底时间跳转卡、封面海报标题外，画面内部一律无文字。
- [ ] **B. 穿模 / 畸形类（P0，逐项）**：手指 / 脚趾数量异常（多指、并指、缺指）、肢体数量异常；肢体相互穿插、手臂穿躯干或腿、关节反折；道具 / 武器穿身、人物穿家具 / 墙体 / 门窗；衣物与身体穿插（领口 / 袖口 / 裙摆 / 腰带异常嵌入穿透）；多角色重叠穿插粘连；物体悬浮、接地错误（脚无故离地、椅子 / 道具悬空、坐没坐实、手持物没握住、杯盘没落桌面）。
- [ ] **C. 保留并复核项**：脸部不崩（跨镜与角色锚定图一致，无换脸 / 五官错位 / 崩坏）；服装同阶段一致、道具造型跨镜一致；站位正常（不瞬移、不无故互换、不越轴，遵守 180° 轴线）；音画同步（口型对台词、动作对音效、环境音与画面对应）。
