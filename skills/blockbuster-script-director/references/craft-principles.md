## 一、十大核心能力

### 1. 设计故事发动机

任何长篇故事都必须有一个能持续产生剧情的问题：复仇、寻找真相、逃亡、权力争夺、身份秘密、成长升级、生存、爱情选择、家族冲突、世界危机等。

检验标准：该发动机必须能**持续产生新的目标、新的阻力和新的选择**。一次性的问题撑不起长篇。

### 2. 设计人物发动机

人物不能只为剧情存在。每个主要角色都应有：欲望、目标、恐惧、弱点、秘密、过去、价值观、底线、无法轻易解决的问题。剧情必须尽可能由人物的选择推动。

### 3. 设计冲突

冲突不是吵架或打架，而是**人物目标互相阻碍**。同时建立：

- 外部冲突、关系冲突、内部冲突
- 利益冲突、权力冲突、信息冲突、价值观冲突

### 4. 渐进式升级

- 第一次危机解决后不应恢复平静，而应产生更大的问题。
- 第一次敌人解决后，发现背后还有更大的敌人。
- 第一次得到答案后，答案又产生新问题。

剧情必须越来越复杂，但逻辑必须越来越清楚。

### 5. 制造信息差

让观众、主角、反派、配角掌握不同信息：

- 观众知道而人物不知道（戏剧反讽 → 紧张）
- 人物知道而观众不知道（悬念 → 好奇）
- 不同人物掌握不同秘密（博弈 → 反转空间）

### 6. 制造合理反转

反转必须"第一次看意外，回头看合理"。反转前必须存在伏笔、线索或逻辑基础。优秀反转不仅揭露真相，还改变人物关系、目标、危险程度，或观众对前面剧情的理解。详见[第六节](#六反转机制四个条件)。

### 7. 伏笔与回收

重大伏笔提前出现，通过误导隐藏真实意义，后续回收，并让回收产生实际影响。不要大量埋没有意义的伏笔。详见[第七节](#七伏笔机制五步回收)。

### 8. 情绪积累与释放

先让观众产生期待、愤怒、委屈、心疼、紧张、恐惧或好奇，再通过高潮释放。不要一上来就把所有情绪全部释放。

### 9. 视觉化

剧本不是小说说明书。每场都要考虑"拍出来是什么"。用动作、表情、环境、声音、镜头和人物行为表现信息，而不是让人物站着解释剧情。

### 10. 潜台词

人物说出口的内容不一定是真正想表达的。优秀对白包含目的、隐藏信息、试探、攻击、防御、欺骗、妥协和情绪。

## 二、主角设计

- 主角必须**尽量主动做选择**，而不是一直等待别人推动剧情。
- 不断经历循环：想要 → 行动 → 遇阻 → 选择 → 后果 → 再选择。
- 主角可以犯错，但错误必须来自人物性格、信息不足、价值观冲突或现实压力，**不得为推进剧情强行降智**。
- 必须拥有清晰的**外部目标**，同时拥有一个更深层的**内部需求**（Truby 的欲望 vs. 需求）。

---

## 三、反派设计

反派不能只有"坏"。必须设计十项：目标、能力、资源、弱点、恐惧、过去、价值观、策略、底线、与主角之间的关系。

- 反派最好有自己的逻辑：他为什么认为自己这样做合理？他真正想得到什么？
- 他为什么能**持续**威胁主角（资源、智谋、权力差或信息优势）？
- **禁止反派靠突然变蠢让主角获胜。**

---

## 四、剧情升级机制

每次冲突解决后，检查是否产生更大后果。推荐链条：

```
问题出现 → 主角行动 → 问题升级 → 主角付出代价 → 暂时解决 → 发现更大的问题
```

不要让剧情重复同一种冲突。升级的八个杠杆：

1. 提高危险程度
2. 提高人物代价
3. 扩大冲突范围
4. 增加时间压力
5. 增加信息差
6. 增加关系风险
7. 增加道德选择难度
8. 增加权力差

---

## 五、悬念机制

悬念不是"不告诉观众答案"。真正的悬念 = **明确的问题 + 不完整的信息 + 观众预测 + 新信息不断改变预测**。

每回答一个问题，最好再产生一个更大的问题。范式示例：

> 谁杀了他？→ 找到凶器 → 凶器属于主角 → 主角发现自己当天失去一段记忆 → 监控证明主角出现过 → 但监控时间不对 → 真正的问题变成："那天晚上到底发生了什么？"

---

## 六、反转机制：四个条件

1. **意外**：观众第一时间没想到。
2. **合理**：回头看能找到依据。
3. **必然**：所有线索组合后结果唯一成立。
4. **有效**：反转之后真正改变剧情（关系、目标、危险等级或对前文的理解）。

禁止为了"炸"而炸；禁止突然抛出前面毫无铺垫的新事实。

---

## 七、伏笔机制：五步回收

```
埋下 → 隐藏 → 误导 → 回收 → 产生影响
```

- 伏笔第一次出现时可以不引起注意。
- 回收后观众回头看应能发现："原来这里早就出现过。"
- 回收必须产生实际剧情影响，而非仅作"彩蛋"。

---

## 八、导演思维

写任何重要场景时，依次回答：

1. 观众现在看到了什么？
2. 观众现在知道什么？
3. 人物现在知道什么？
4. 观众误以为什么？
5. 这一幕最值得拍的画面是什么？
6. 能不能不用对白表达？
7. 有没有视觉记忆点？有没有声音记忆点？
8. 人物的动作是否比台词更有力量？

针对漫剧、AI 视频和短视频改编，主动寻找五类记忆点：**人物视觉记忆点、场景视觉记忆点、动作视觉记忆点、反转视觉记忆点、高潮视觉记忆点**。

---

## 九、对白原则

对白不能只解释剧情。每句重要台词都应有目的：试探、欺骗、威胁、保护、攻击、掩饰、求助、拒绝、诱导、谈判、告白、羞辱、试图获得某物。

- 让人物说话具有潜台词。
- 禁止大量说明式对白："事情是这样的……""原来你不知道……""其实我当年……"
- 重要背景尽量通过事件、行为、冲突和信息逐渐揭露。

---

## 十、情绪设计

- 每集明确**一个主要情绪**：爽、愤怒、心疼、紧张、恐惧、好奇、震撼、甜蜜、虐、遗憾、感动、解气、期待。
- 情绪不能从头到尾同一强度。标准波形：

```
平静 → 异常 → 紧张 → 希望 → 危机 → 爆发 → 释放 → 新危机
```

---

## 十一、爽点设计

适用于短剧、爽文、逆袭、复仇、都市、权谋等类型：

```
压制 → 积累 → 反击 → 爆发 → 情绪释放 → 更大危机
```

硬约束：

- 爽点必须来自人物和剧情，不能凭空出现。
- 不能为了爽让反派突然降智。
- 不能让主角无代价获得能力。
- 不能让所有问题都轻松解决。

---

## 十二、主线与副线：ABC 三线

长篇必须建立：

- **A 线**：主线（外部目标/案件/任务）
- **B 线**：人物关系（情感、同盟、背叛）
- **C 线**：秘密 / 世界观（隐藏真相，重新解释一切）

三线不得独立运行，交织规则：

```
A 线推动 B 线 → B 线影响 A 线 → C 线重新解释 A 线
```

---

## 十三、剧情因果检查六问

所有重大事件必须回答：

1. 为什么发生？
2. 为什么**现在**发生？
3. 谁导致的？
4. 如果不发生会怎样？
5. 产生了什么后果？
6. 后果如何影响后面的剧情？

六问答不上来，即为"作者强行推动"，必须重写。

- 优先用**人物选择**推动剧情，而非巧合。
- 巧合可以用来**制造问题**，但不要让巧合直接**解决核心问题**。
