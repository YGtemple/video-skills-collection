# 视频全能大师（Video Master Suite）

## 🏷️ 技能分类标识

> **归属类别**：【通用跨类型】（路由总控层，横跨真人/漫剧/工具；内部按任务类型分派到各子技能，本技能本身不决定画风）
>
> - **🎬 典型任务场景**：用户只有一个想法/已有剧本/要分镜/要提示词/要生成视频/要审核/要剪辑/要处理素材/要下载在线视频——识别阶段并路由到对应子技能（⛔ 以阶段门控总则为准：识别后逐门暂停、给下一步选项、等用户确认再路由，**不自动跑完全流程**）；从 0 到 1 做短剧或商业视频（同样逐门确认，非自动端到端）。
> - **🚫 不适用场景**：本技能是总控入口，不亲自写死剧本细节/不亲自出逐镜头资产卡/不亲自逐帧剪辑——这些按路由表下沉到 `blockbuster-script-director`、`script-asset-master`、`byted-mediakit-*`/`jianying-editor` 等子技能执行。
> - **🔗 上下游 / 推荐搭配**：上游〔`ai-story-vault` 选题 / `blockbuster-script-director` 剧本〕 → **本技能**（总控分派） → 下游〔全流程各子技能直至成片交付〕。
> - **🧭 与相邻技能的边界**：所有视频类任务先到本技能做识别与路由；本子技能内部再按"真人/漫剧/工具"选择对应执行技能（见下方分支表）。
> - **📦 标准三件套产出职责**：本技能为**总控，按任务分派三件套**——①立项大纲派给 `blockbuster-script-director`（主导）/`doubao-creative-drama`（规划）；②通用模型资产提示词派给 `script-asset-master`（主导，可派生③）；③MJ提示词由 `script-asset-master`/`video-prompt-master` 派生；本技能负责串起①→②→③→成片的交付顺序与分批确认。
> - **⚠️ 本用户固定规范**：成片无字幕、无 BGM、禁用 TTS（台词由视频模型直接生成）；视频直接生成（不设生成前阻断），生成后随成片一起把完整脚本/分镜 + 完整视频提示词（@ 已审核资产）给用户看，用户认可才生成下一个；人物图必须 @ 引用、强制图片参考不纯文字生成人物。

|---|---|---|

| **任务C 视频素材处理/后期/剪辑/增强** | **后期工具向（不决定画风）** | `byted-mediakit-editing`/`byted-mediakit-video`/`jianying-editor`；作用于已有素材。 |

## ⛔ 阶段门控总则（选项驱动 · 用户确认 · 资产 AI 生成必审 + 视频成片必看）

> 本技能是**统一路由总控**，默认**不再自动端到端链式跑完整制作**。标准范式全文见 `/home/user/Doubao/chats/38436370915409154/_工作规范/阶段门控总则（标准范式）.md`；以下为本技能落地要点，**优先级高于下文任何「自动路由跑完全流程 / 自动串联 / 自动识别后直通」的旧表述**。

### 0. 最高原则（不可违反）

1. **禁止一次性自动跑完整制作**：不得在用户只给一句话想法后，就自动把剧本→资产→分镜→视频→后期全部做完。
2. **路由即暂停点**：本技能把任务分派给某子技能/阶段后，**该子技能/阶段一结束就立即 ⛔ 暂停 → 给下一步选项（每个附一句话亮点 + 利弊 + ⭐推荐项）→ 等用户明确回复**，之后才路由到下一个子技能/阶段。**用户未确认，绝不擅自往下路由、不擅自批量出片。**
3. 用户在每个门控点都可以：**回复编号选定 / 混搭多个选项 / 回复「再发散」换一批 / 直接写修改意见**；需求不清时只围绕当前阶段问必要的问题。
4. **【美术资产 AI 可直接生成、但出图必审 · 强约束】**：角色、场景、道具、关键画面 / 分镜参考图等**所有进入成片的图像资产**，AI 可以直接调用文生图（`image_gen` / T2I / `doubao-creative-design` / `seedream-50`）生成；但每一张 / 每一批生成完，必须立即把「成图 + 该图所用提示词（通用版 / MJ 版）+ 三维参数」给用户审核——可 ✅ 直接通过 / 提修改意见 / 要求重生成——**通过后才定稿、才在分镜 / 视频提示词中以 `@ 引用`、强制图片参考**。未通过则按意见改提示词 / 重生成，再审。「用户自制」为可选路径：用户想自己出图时，AI 仍给两套提示词 + 三维 + 资产清单/顺序 + 制作建议，用户回传后同样审核确认。
   - **视频生成仍由被路由的下游/AI 执行**（`seedance-25` / I2V·T2V）：**视频不设生成前阻断**，脚本/分镜与视频提示词备好后直接生成（提示词仍须完整、透明，不省略、不事后补）；每个视频生成后，必须把「成片（内嵌预览播放器）+ 该视频完整脚本/分镜 + 完整视频提示词（@ 已审核资产）」一起给用户看，用户认可才生成下一个，**逐个生成、逐个审核，禁止未经用户认可连续批量自动生成全部片段**；不合适则按意见改提示词 / 重生成，再审通过才往下。
5. **示意图 / 资产辅助沟通**：AI 生成的每一张 / 批资产图都按上条立即交付用户审核；示意图不得未经审核直接当作定稿资产进入成片。

### 3. 故事发散 · 钩子画面化 + 因果链（两条硬性创作要求）

- **故事发散**：用户只有一个想法 / 题材 / 一句话故事时，先产出 **3–5 个彼此差异化方向**填入《故事发散选项表》，差异化硬要求＝题材、核心设定、主角原型、主要矛盾、开头钩子明显不同；**用户确认故事之后**，才路由去定稿①立项大纲——故事没确认前不写大纲、不定资产。
- **① 钩子结合画面（看得见，不靠「说」）**：开头钩子必须是**看得见的具体画面 / 动作 / 场景**，靠第一帧 / 前几秒视觉冲击或视觉悬念抓人，**不靠旁白、台词、字幕、标题去「说」**；钩子画面必须直接关联核心矛盾 / 悬念。发散表「开头钩子」栏一律填**具体钩子画面**（谁在干什么 / 出现什么异常画面），不填抽象概念。
- **② 因果关系（A→B→C，消灭流水账）**：剧情按因果链推进，不是「然后…然后…」的事件罗列；钩子抛出的异常 / 悬念必须有成因（可后置揭示）；人物每个行动都要有动机、有后果；**伏笔是「因」、回收是「果」**，反转意料之外、情理之中。每个场景追问「**它因什么发生、又导致了什么**」，删除与主线无因果关系的段落。

### 4. 资产阶段 · 路由层职责边界（严格限定为四件事）

1. **资产提示词两套**：通用模型版（中文，适配 Seedream / 即梦 / 可灵）＋ MJ 版（英文，含 `--ar` / `--niji` / `--cref` / `--sref`）；
2. **三大控制维度参数 + 取值理由**：风格化 `--stylize`、怪异度 `--weird`、多样性 `--chaos` + 固定 `--seed`；🎥 真人写实＝**低 / 低 / 低 + 固定 seed**；🎴 漫剧强风格＝**风格化中~高、怪异低、多样低~中 + 固定 seed**；
3. **资产清单与制作顺序**（建议顺序：角色锚点 → 场景空镜 → 道具 → 关键画面 / 分镜参考图）；
4. **制作建议**：景别 / 光线 / 姿态、四宫格 / 三视图 / 空镜 / 固定 seed 与 `--cref`·`--sref` 锁一致等。

> ⛔ 上述提示词 / 参数 / 清单 / 建议即路由层在资产阶段的**提示词包产出**；AI 可据此**直接调用 `doubao-creative-design` / `seedream-50` / `image_gen` 等文生图工具出图，但每一张 / 每一批出图后必须立即把「成图 + 所用提示词 + 三维参数」交付用户审核**。用户审核——可 ✅ 直接通过 / 提修改意见 / 要求重生成——通过后，才在分镜 / 视频提示词中以 **@ 引用、强制图片参考**；逐类一确认、不重复分配。用户选自制路径时，AI 只给料、用户回传后同样审核确认。记录于《资产审核确认表》（状态口径：AI 生成待审核 / 用户自制 / 需返工 / 已审核可 @）。

### 5. 三件套按门控节奏分批产出（不要一股脑全给）

- **① 立项大纲**：在「故事确认」之后才产出 / 定稿；
- **② 通用模型资产提示词**、**③ MJ 提示词**：按**用户生成进度分批提供**——角色确认给角色的、场景确认给场景的、道具 / 关键画面同理，不提前一次性全给。

2. 资产与视频门控：由「全部定稿资产由用户自制、路由层不代出图」改为「**美术资产 AI 可直接生成，但每张/批出图必交付用户审核（成图+提示词+三维），通过才定稿 @（用户自制为可选）**」；由「生成前展示完整提示词、用户确认后才生成视频」改为「**视频不设生成前阻断、直接生成，生成后把成片+完整脚本/分镜+完整视频提示词一起给用户看，用户认可才生成下一个**」。

其余能力零删除；**视频生成仍由被路由的下游 / AI 执行**。

## 二、全局铁律（所有任务类型必须遵守）

### 铁律0：Seedance 2.5 为最高优先级视频生成引擎
所有视频生成默认使用 Seedance 2.5 引擎，优先级高于即梦/MiniMax等其他引擎。
- 调用视频生成工具时，`model_version` 固定为 `seedance_2.5`
- 用户认可的最终视频提示词**逐字原文透传**，不得改写、润色、精简、翻译、纠错、重排
- **视频不设生成前阻断**：脚本/分镜与提示词备好后直接生成；生成后把成片 + 完整确认信息（模型/原始prompt/时长/比例/参考素材）一起给用户看，用户认可才生成下一个
- 时长支持5-30秒整数；比例仅支持16:9/4:3/1:1/3:4/9:16/21:9
- 若用户明确指定使用其他引擎（如即梦），按用户指定执行，但Seedance 2.5仍为默认推荐

### 铁律1：视频直接生成，生成后透明展示完整提示词，强制图片参考并@艾特人物
视频不设「生成前阻断」：脚本/分镜与完整提示词备好后直接生成；每个视频生成后，必须把**成片（内嵌预览播放器）+ 完整脚本/分镜 + 完整视频提示词**一起给用户看，用户认可才生成下一个。
- **强制使用图片参考**：每次生成必须使用图生视频模式（带参考图），不允许纯文字生成
- **人物必须@艾特**：提示词中出现用户提供的人物时，必须用`@图片N`格式艾特对应的参考图
- **用户提供的人物图片一人一角色**：每张图只对应一个角色，多余角色纯文字描述
- 提示词必须完整、透明，不得省略或事后补；禁止未经用户认可连续批量自动出片

### 铁律2：视频必须以内嵌预览播放器形式交付，用户预览确认后再继续
每生成完一个视频，必须以内嵌预览播放器形式展示在聊天对话中，用户可直接点击播放。
- 内嵌预览播放器是首选交付形式，公共访问链接作为补充同时提供
- 每条视频生成后，停下等待用户预览并明确确认后，再生成下一条
- 用户未确认前，不得继续批量生成后续镜头

### 铁律3：有台词必须写进提示词，不使用TTS单独合成
角色对话、内心独白、画外音、旁白等所有台词，必须直接写进视频生成提示词中，让AI视频模型直接生成带语音的视频。
- 提示词中写台词的格式：`角色A说："台词内容"`
- 如果生成的视频没有语音，检查提示词中台词是否写清楚，调整后重新生成

### 铁律4：分步执行，每幕自检后用户确认再继续
每个模块/阶段完成后必须停下，做完整自检（角色是否合适/脸崩/信息密度/节奏），把自检结果展示给用户，用户说"可以"后才进入下一阶段。严禁一次性输出全部内容。严禁空镜拖时间：每3-4秒必须有信息点（对话/物品/镜头变化），一个镜头超过5秒中间必须有说话声或画面变化。

### 铁律5：合规安全
- 所有涉及伤害/死亡/暴力的画面描述必须经过合规替换，仅改画面描述不改台词
- 不出现血腥特写、喷溅血液、断肢、尸体、利器刺穿身体、暴力慢放
- 即使Prompt已合规，AI生成仍可能"脑补"违规内容，必须逐镜人工审核

### 铁律6：物理可行性优先
物理可行性 > 叙事情绪 > 多样性指标。所有景别/焦段/机位/运镜必须先匹配场景物理空间。

### 铁律7：不含任何去水印内容
全技能不包含、不推荐、不指导任何去水印操作。涉及水印时，建议用户使用平台官方无水印导出。

## 三、任务A：短剧/剧情片标准九步工作流

这是最完整的工作流，适用于短剧、微电影、剧情片、动态漫、动画短片。根据用户已有素材，自动从对应步骤开始。

### 总览

```
Step 1 需求澄清与规划  →  Step 2 剧本创作  →  Step 3 分镜设计
                                                          ↓
Step 9 成片交付  ←  Step 8 后期合成  ←  Step 7 质量审核与一致性
                                                          ↓
Step 4 资产与参考图准备  ←  Step 5 提示词生成  ←  Step 6 视频生成执行
```

### Step 1：需求澄清与规划　⛔ 确认点①
**调用子技能**：`doubao-creative-drama`（planner阶段）
**输入**：用户的想法/题材/一句话故事
**输出**：短篇短剧生产规划报告（项目信息、完成度检查、执行规划）
**关键动作**：
- 确认单集总时长（短篇默认5-10分钟，90秒短剧默认90秒）
- 确认比例（9:16竖屏 / 16:9横屏 / 21:9超宽）
- 确认剧作基调（微电影三幕式 / 短视频钩子驱动）
- 确认已有素材，判断从哪个阶段开始
- 输出规划报告后停下，等待用户确认

### Step 2：剧本创作　⛔ 确认点②（先故事发散，确认后才写剧本）
**调用子技能**：`ai-drama-master-suite`（模块1）+ `jimeng-studio`（阶段1，即梦平台适配）
**输入**：想法/题材/一句话故事
**输出**：完整剧本（90秒四幕结构 或 5分钟五阶段工作流）
**关键动作**：
- ⛔ **先故事发散、再写剧本**：路由去写剧本前，先给 **3–5 个彼此差异化方向**（题材 / 核心设定 / 主角原型 / 主要矛盾 / **开头钩子画面**各不相同），按统一门控格式给亮点 + 利弊 + ⭐推荐，**给完即暂停**；用户选定 / 混搭 / 再发散并**确认故事**后，才路由去写剧本、才定稿①立项大纲。
- ⛔ **钩子必须画面化**：开头钩子填具体画面（谁在干什么 / 出现什么异常画面），不靠旁白/台词/字幕/标题；**剧情按因果链 A→B→C 推进**，每场景能答「因什么发生、导致什么」。
- 90秒短剧：四幕时间锁（开场10-15秒强冲击 → 核心冲突40-50秒 → 反转爆发15-20秒 → 结尾悬念5-10秒）
- 5分钟短剧：五阶段工作流
- 五大赛道：都市日常/都市玄幻脑洞/古风仙侠/悬疑科幻末日/开放赛道
- 九大结构原型可选
- 交付"剧情梗概 → 人物小传 → 主要故事场景 → 完整剧本"四段产物
- 输出后停下，等待用户确认

### Step 3：分镜设计　⛔ 确认点③
**调用子技能**：`ai-drama-master-suite`（模块2）+ `jimeng-studio`（阶段2-4）
**输入**：剧本
**输出**：标准化分镜脚本（中文画面规格书 + 结构化分镜组）
**关键动作**：
- 专业电影级镜头语言约束：光源动机铁律、纵深主层机制、五层色彩思维、物理可行性铁律
- 通用分镜组格式（V2.0 PLUS）：分镜组4-15秒，@人物@标注，XMB运镜规范
- 双输出格式：中文【标签】块画面规格书（给人看）+ 结构化分镜组（给AI用）
- 章节切分（3-5个叙事章节），每章节15s片段数量规划
- 输出后停下，等待用户确认

### Step 4：资产与参考图准备　⛔ 确认点④（资产 AI 生成必审 · 用户自制可选）

### 10.3 串联顺序原则

1. **创作在前，制作在后**：剧本→分镜→资产→提示词→生成→审核→后期→交付
2. **图片在前，视频在后**：先生成角色/场景图片资产，再用图生视频
3. **单镜在前，多镜在后**：先逐镜生成确认，再做跨镜一致性和剪辑
4. **内容在前，形式在后**：先确定画面内容，再加滤镜/调色/字幕/音效
5. **生成在前，处理在后**：先用AI生成原始素材，再用MediaKit/剪映做后期处理

## 十一、常见决策树

### 11.1 用户说"帮我做个视频"
```
1. 澄清：什么类型的视频？（短剧/广告/宣传/其他）
2. 澄清：多长时间？什么比例？
3. 澄清：有没有已有素材（剧本/图片/视频）？
4. 根据回答路由到任务A或任务B
5. 从对应工作流的第一步开始
```

### 11.2 用户提供了人物图片要求生成视频
```
1. 进入任务A或任务B
2. Step 4：建立参考图资产表，一人一角色
3. Step 5：提示词中必须@艾特对应图片
4. Step 6：强制图生视频，不用纯文字
5. 直接生成，生成后把成片+完整脚本/分镜+完整提示词一起给用户看，用户认可才生成下一个
```

### 11.3 用户要求剪辑已有视频
```
1. 进入任务C
2. 判断具体操作：剪辑合成→mediakit-editing；智能处理→mediakit-video；复杂多轨→jianying-editor
3. 读取对应子技能SKILL.md
4. 执行处理，交付结果
```

### 11.4 用户给了一个视频链接
```
1. 进入任务D
2. 判断目标：下载/转写/画面分析
3. 调用doubao-video-extract
4. 如需二次创作，串联任务B或任务C
```

### 11.5 视频生成后质量不好
```
1. 进入任务A Step 7（质量审核）
2. 七维审核定位问题
3. 轻度问题→后期修复（mediakit-editing/mediakit-video）
4. 中度问题→调Prompt重生成（回到Step 5）
5. 重度问题→重新设计镜头（回到Step 3）
```

- [ ] **C 复核**：脸不崩（跨镜与锚定图一致）；服装同阶段一致、道具跨镜一致；站位不越轴；音画同步（口型对台词、动作对音效）？

### 后期合成自检
- [ ] 总时长是否严格符合？
- [ ] 剪辑节奏是否匹配情绪曲线？
- [ ] 转场是否克制（默认硬切）？
- [ ] 角色对话语音是否清晰可辨？
- [ ] 音效四层音量层级是否正确（台词>动效>环境>BGM）？
- [ ] 字幕是否与台词完全同步？
- [ ] 全片调色是否统一？

### 交付自检
- [ ] 成片终审清单是否逐项检查过？
- [ ] 交付规格是否匹配目标平台？
- [ ] 最终成片是否以内嵌预览播放器形式交付？
- [ ] 最终成片是否同时附了公共访问链接？
- [ ] 封面图是否设计完成？
