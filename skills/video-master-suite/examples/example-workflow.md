# 完整工作流示例：90秒都市悬疑短剧

> ⛔ **本示例为流程示意，实际执行以 SKILL.md「阶段门控总则」为准**：①每一步结束即 ⛔ 暂停、给下一步选项、等用户确认后再路由下一步（示例中「用户确认后进入下一步」即对应此门控）；②**Step 4 的角色 / 场景设定图由 AI 直接调用文生图生成，但每张/批出图必须立即把「成图 + 所用提示词 + 三维」交付用户审核，通过才定稿 @**（用户自制为可选路径）；封面图同样 AI 生成必审。下文「AI 生成某图」的措辞，即「AI 直接出图 → 成图+提示词+三维交付审核 → 通过才定稿」。③**视频不设生成前阻断**：Step 6 凭已备好的完整提示词直接生成，生成后把「成片（内嵌播放器）+ 完整脚本/分镜 + 完整视频提示词」一起给用户看，用户认可才生成下一个。

本文档通过一个完整示例，展示 `video-master-suite` 从想法到成片的全流程。

## 项目背景

**用户需求**："帮我做一个90秒的都市悬疑短剧，主角是一个女程序员，发现自己的代码被人篡改了"

**比例**：9:16 竖屏
**风格**：都市悬疑，冷色调
**时长**：90秒

---

## Step 1：需求澄清与规划

**调用子技能**：`doubao-creative-drama`

AI 输出规划报告：

```
## 短篇短剧生产规划报告

### 项目信息
- 项目名称：《代码裂痕》
- 类型：都市悬疑短剧
- 风格：冷色调，赛博都市感
- 默认比例：9:16
- 单集总时长：90秒
- 剧作基调：短视频钩子驱动
- 单段视频时长：15秒（约6个片段）

### 当前完成度检查
| 阶段 | 是否完成 | 缺失内容 |
|---|---|---|
| 1. 剧本创作 | 否 | 全部 |
| 2. 分镜切分 | 否 | 全部 |
| 3. 资产设定 | 否 | 全部 |
| 4. 关键帧 | 否 | 全部 |
| 5. 视频提示词 | 否 | 全部 |

### 执行规划

```

用户确认后进入下一步。

## Step 2：剧本创作

**调用子技能**：`ai-drama-master-suite`（模块1）

AI 输出 90 秒四幕结构剧本：

```
【剧名】《代码裂痕》
【题材】都市悬疑
【时长】90秒（第1集）

【人物设定】
- 林晚｜28岁，女程序员，短发，戴眼镜，性格冷静细致｜核心立场：追查真相
- 陈默｜30岁，男，技术总监，西装革履，表面温和｜核心立场：掩盖秘密

【第一幕：开场强冲击】（0-12秒）
镜头01（0-5秒）：深夜办公室，林晚盯着屏幕，脸色骤变
【台词】林晚："这不是我写的代码……"
镜头02（5-12秒）：屏幕上代码逐行变红，鼠标自己在移动
【音效】键盘敲击声突然停止，心跳声

【第二幕：核心冲突推进】（12-55秒）
...（完整四幕剧本）

【结尾悬念钩子】（80-90秒）
林晚转身，发现办公室的门不知何时被锁上了，门缝下渗进红色的光……
```

用户确认剧本后进入下一步。

## Step 3：分镜设计

**调用子技能**：`ai-drama-master-suite`（模块2）

AI 输出标准化分镜脚本（6个15秒片段）：

| 镜号 | 时长 | 景别 | 画面 | 台词 | 运镜 |
|---|---|---|---|---|---|
| 01 | 12s | 近景→特写 | 林晚盯着屏幕，脸色骤变 | "这不是我写的代码" | 慢推 |
| 02 | 15s | 特写 | 屏幕代码逐行变红，鼠标自己移动 | （无台词） | 固定 |
| 03 | 15s | 中景 | 林晚起身查看服务器机房 | "有人在远程登录我的账号" | 跟拍 |
| 04 | 15s | 正反打 | 林晚质问陈默，陈默表情微妙 | 对话2轮 | 正反打固定 |
| 05 | 18s | 全景→特写 | 林晚发现监控被删除，U盘里有隐藏文件 | "这是什么……" | 手持晃动 |
| 06 | 15s | 全景 | 林晚转身，门被锁上，红光渗入 | （无台词） | 缓慢拉远 |

用户确认分镜后进入下一步。

---

## Step 4：资产与参考图准备

**调用子技能**：`script-asset-master`（提示词包）+ `image-reference`
> ⛔ 以阶段门控总则为准：下面各「设定图」由 AI 直接调用文生图生成，每生成一张/批，立即把「成图 + 所用提示词 + 三维」交付用户审核；用户通过（或提意见/要求重生成）后，才登记资产表、才 @ 引用。

**4.1 主角设定图生成**

AI 直接生成林晚的角色设定图（左侧正脸特写 + 三视图）：
- 28岁女性，黑色齐耳短发，戴黑框眼镜，穿灰色连帽卫衣
- 冷色调，办公室背景

生成后立即把成图 + 所用提示词 + 三维参数交付用户审核，用户通过才定稿。

**4.2 配角设定图生成**

AI 直接生成陈默的角色设定图，成图+提示词+三维交付用户审核通过后定稿。

**4.3 角色总体确认**

AI 询问："所有角色资产是否审核通过、OK？" 用户确认。

**4.4 场景全景图生成**

- 场景1：深夜办公室（冷蓝光，电脑屏幕发光）
- 场景2：服务器机房（蓝色指示灯，金属质感）

每个场景生成后成图+提示词+三维交付用户审核，通过后定稿。

**4.5 建立参考图资产表**

| 编号 | 图片内容 | 类型 | 用途 |
|---|---|---|---|
| 图1 | 林晚角色设定图 | 角色 | 面部/发型/服装 |
| 图2 | 陈默角色设定图 | 角色 | 面部/发型/服装 |
| 图3 | 深夜办公室全景 | 场景 | 空间/光线/陈设 |
| 图4 | 服务器机房全景 | 场景 | 空间/光线/陈设 |

## Step 5：提示词生成

**调用子技能**：`ai-drama-master-suite`（模块3）+ `image-reference` + `seedance-25`

AI 为每个镜头生成详细提示词，以镜头01为例：

```
参考@图片1的林晚面部五官（28岁女性、黑色齐耳短发、黑框眼镜、清冷表情）和服装（灰色连帽卫衣），参考@图片3的深夜办公室场景空间布局（开放式工位、多台显示器、冷蓝色环境光）。

连贯性锚点：开篇场景建立，深夜11点，办公室只剩林晚一人，冷蓝色屏幕光照在她脸上。

画面内容：画面中仅有一人：林晚（@图片1）。近景，林晚坐在工位前盯着电脑屏幕，瞳孔微微收缩，脸色从平静转为震惊，手指悬停在键盘上。屏幕上的代码发出蓝白色光芒映照在她的眼镜片上。

镜头运动：近景缓慢推近到面部特写。

光影：冷蓝色环境光，电脑屏幕蓝白色主光源从正面照亮面部，背景昏暗，浅景深。

构图安全区：人物面部严格位于画面中心55%区域内，头顶距离上边缘至少18%，左右各预留160px安全边距。

台词：林晚（冷静但带一丝颤抖的女声）说："这不是我写的代码……"

声音设计：深夜办公室安静环境音，键盘敲击声突然停止，轻微心跳声。无BGM。

禁止项：无字幕，无画面文字。画面中仅有林晚一人，不得出现第三个角色。每个人物仅有两只手五根手指。角色面部五官、发型、服装必须与参考图一致。
```

AI 用代码块完整、透明备好全部6个镜头的提示词（@ 已审核资产，不省略），用户确认分镜文字方案后进入下一步。

---

## Step 6：视频生成执行

**调用子技能**：`ai-drama-master-suite`（模块4）+ `seedance-25`

**6.1 直接生成（不设生成前阻断）**

AI 备好生成参数（提示词原文透传）：
- 模型：seedance_2.5
- 比例：9:16
- 参考图：图1-图4（均为已审核通过资产）
- 提示词：已完整备好（原文透传）

凭以上直接调用生成；不生成前阻断等确认。

**6.2 逐镜生成、成片必看**

- 镜头01：调用 `image_to_video`，model_version=seedance_2.5，duration=12，ratio=9:16
- 生成完成后，把**成片（内嵌预览播放器）+ 该镜完整脚本/分镜 + 完整视频提示词**一起给用户看，附公共访问链接
- 用户认可该成片后，才继续生成镜头02；不合适则按意见改提示词/重生成再审
- 逐个生成、逐个审核，不未经认可连续批量自动出片，直到全部6个镜头完成

**6.3 重试与版本管理**

如果某个镜头质量不合格（如角色变脸），调整提示词后重新生成，最多重试3次。

## Step 7：质量审核与一致性

**调用子技能**：`ai-drama-master-suite`（模块5）+ `byted-mediakit-video`

AI 执行七维审核：

| 镜头 | 画面质量 | 角色一致 | 动作自然 | 场景还原 | 镜头语言 | 合规安全 | 时长节奏 | 结果 |
|---|---|---|---|---|---|---|---|---|
| 01 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 通过 |
| 02 | ✓ | — | ✓ | ✓ | ✓ | ✓ | ✓ | 通过 |
| 03 | ✓ | ✓ | △ | ✓ | ✓ | ✓ | ✓ | 轻度问题（动作略卡顿） |
| 04 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 通过 |
| 05 | ✗ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 中度问题（场景跑偏）→ 重生成 |
| 06 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 通过 |

**四维一致性检查**：
- 角色一致性：林晚的发型/眼镜/卫衣在全镜一致 ✓
- 场景连续性：办公室的工位布局在镜头01/03一致 ✓
- 光影衔接：相邻镜头的冷蓝色调一致 ✓
- 道具追踪：U盘在镜头05出现，位置合理 ✓

镜头05调整提示词后重新生成，全部通过后进入下一步。

---

## Step 8：后期合成

**调用子技能**：`byted-mediakit-editing` + `seed-audio`

**8.1 剪辑拼接**
- 按分镜顺序拼接6个片段
- 调整入点/出点，总时长控制在90秒±2秒
- 工具：`concat-video`（默认硬切，场景切换处用淡入淡出）

**8.2 音效混音**
- 台词：视频自带，最优先
- 动效音：键盘声、心跳声、门铃声（用 `seed-audio` 生成或从素材库选取）
- 环境音：办公室空调声、机房风扇声
- BGM：悬疑感低频电子乐，台词出现时自动压低
- 工具：`mix-audio` + `mux-audio-video`

**8.3 字幕压制**
- 台词字幕居中下方，白色黑体，带黑色描边
- 工具：`add-subtitle-to-video`

**8.4 调色统一**
- 全片统一冷色调LUT
- 工具：`apply-video-filter`

**8.5 片头片尾**
- 片头2秒：剧名《代码裂痕》
- 片尾3秒：悬念卡 + "未完待续"

合成完成后交付预览，用户确认后进入最终交付。

---

## Step 9：成片交付

**调用子技能**：`byted-mediakit-video` + `doubao-creative-design`

**9.1 成片终审**
- 总时长：90秒 ✓
- 画面质量：全部通过 ✓
- 音频：台词清晰，混音平衡 ✓
- 字幕：完全同步 ✓
- 合规：无违规内容 ✓

**9.2 多平台适配**
- 抖音/快手版：9:16，1080×1920，H.264
- 工具：`transcode-video`

**9.3 封面图生成**（⛔ 封面图 AI 可直接生成，但出图必审：AI 给提示词+三维+建议并直接出图，成图+提示词交付用户审核通过才定稿；用户自制为可选）
- 路由层给出 `doubao-creative-design` 提示词并直接生成9:16封面，成图+提示词交付用户审核
- 画面：林晚盯着发光屏幕，红色代码映照在脸上
- 文字："代码裂痕" + "她发现了不该发现的东西"（封面为海报，可含标题文字）

**9.4 最终交付**
- 以内嵌预览播放器形式交付最终成片
- 附公共访问链接
- 附封面图
- 附多平台版本下载链接
