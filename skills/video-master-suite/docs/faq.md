# 常见问题（FAQ）

## 安装与使用

### Q1: 如何安装这个技能包？
A: 将 `SKILL.md` 复制到豆包用户技能目录即可：
- Windows: `%USERPROFILE%\AppData\Local\Doubao\User Data\Profile 2\.doubao\agent_mode\workspace\.user_skills\video-master-suite\`
- macOS: `~/.doubao/agent_mode/workspace/.user_skills/video-master-suite/`

复制后重启豆包或刷新技能列表即可生效。

### Q2: 安装后如何触发？
A: 不需要手动触发。直接用自然语言描述视频需求即可，例如：
- "帮我做一个90秒悬疑短剧"
- "生成一条15秒产品广告"
- "把这几段视频剪辑到一起"

技能会自动识别任务类型并启动对应工作流。

### Q3: 这个技能包依赖其他技能吗？
A: 是的。本技能包是**统一调度入口**，实际执行时会调用 20+ 个子技能。这些子技能通常已随豆包预装，如果某个子技能缺失，技能会提示你安装对应技能。

## 工作流相关

### Q4: 为什么每一步都要停下来等我确认？
A: 这是**分步执行协议**。视频制作涉及多个不可逆决策（剧本方向、角色形象、提示词等），每步确认可以避免后期大规模返工。如果你确认当前阶段没问题，回复"继续"即可进入下一步。

### Q5: 我已经有剧本了，可以跳过前面的步骤吗？
A: 可以。技能会自动识别你已有素材的阶段，从对应步骤开始。例如你提供了剧本，会直接从 Step 3 分镜设计开始；你提供了提示词，会直接从 Step 6 视频生成开始。

### Q6: 一次可以生成多少个视频片段？
A: **逐个生成、逐个审核**——每个视频生成后立即把成片（内嵌播放器）+ 完整脚本/分镜 + 完整提示词一起给你看，你认可才生成下一个；**禁止未经你认可连续批量自动出片**。同场景相邻镜头可排在一起，但不攒批自动跑。不合适可按你的意见改提示词 / 重生成该镜再审。

## 视频生成相关

### Q7: 为什么必须使用图生视频，不能用纯文字生成？
A: 纯文字生成（文生视频）容易导致角色变脸、场景漂移。使用参考图 + @艾特可以显著提升角色和场景的一致性。这是经过大量实测验证的最佳实践。

### Q8: 我没有人物参考图怎么办？
A: 有两种方式：
1. 先用 `doubao-creative-design` 生成角色设定图（Step 4 会自动处理）
2. 多余角色用纯文字描述外貌，但主要角色建议有参考图

### Q9: 为什么生成后要把完整脚本/分镜和完整提示词一起给你看？
A: 提示词是视频生成的核心输入，一个小改动可能导致结果完全不同。视频不设生成前阻断、直接生成，但生成后必须把「成片 + 该视频完整脚本/分镜 + 完整视频提示词（@ 已审核资产）」一起给你看；你看完成片觉得合适，才生成下一个。不合适可按你的意见改提示词 / 重生成再审，从而避免因理解偏差导致的批量返工。

### Q10: Seedance 2.5 和即梦有什么区别？
A: 
- **Seedance 2.5** 是豆包内置的视频生成引擎，支持5-30秒，6种比例，是默认推荐
- **即梦** 是字节跳动的独立AI视频平台，有自己的提示词语法和批量生成工具
- 本技能包默认使用 Seedance 2.5，如果你明确要求即梦平台，会切换到 jimeng-studio + jimeng-director 工作流

### Q11: 生成的视频没有语音怎么办？
A: 检查提示词中是否明确写出了角色台词。正确格式是 `角色A说："台词内容"`。如果台词已写但仍无语音，可能是语速过快或台词过长，建议精简台词后重新生成。不使用 TTS 单独合成语音。

## 后期处理相关

### Q12: 剪辑用 mediakit 还是剪映？
A: 
- **简单操作**（拼接、裁剪、调速、加字幕、混音）→ 用 `byted-mediakit-editing`，快速无需GUI
- **复杂操作**（多轨编辑、关键帧动画、模板、录屏、影视解说）→ 用 `jianying-editor` 剪映 Python API

### Q13: 可以去除视频水印吗？
A: 本技能包**不包含、不推荐、不指导任何去水印操作**。建议使用平台官方无水印导出，或在生成时选择无水印版本。

### Q14: 如何提升视频画质？
A: 
1. 生成时使用 Seedance 2.5（画质优于 2.0_fast）
2. 后期用 `byted-mediakit-video` 的 `enhance-video` 做画质增强
3. 提示词中加入画质描述（如"8K, cinematic lighting, detailed skin texture"）

## 音频相关

### Q15: 如何给视频配音？
A: 有两种方式：
1. **推荐方式**：把台词直接写进视频生成提示词，AI视频模型会直接生成带语音的视频
2. **后期配音**：用 `seed-audio` 生成音频，再用 `byted-mediakit-editing` 的 `mux-audio-video` 合流

### Q16: 如何分离视频中的人声和背景音乐？
A: 使用 `byted-mediakit-audio` 的 `separate-voice` 工具，可以将人声和背景声分离为两个独立音频文件。

## 其他

### Q17: 支持哪些视频平台的下载？
A: 快手、B站、AcFun、CCTV、芒果TV、梨视频、搜狐视频、腾讯视频、微博视频、X.com、Facebook、Instagram、TikTok、Twitch、YouTube，以及视频直链和本地视频。

### Q18: 生成的视频版权归谁？
A: AI生成内容的版权归属因地区而异。建议查看豆包平台的用户协议和相关法律法规。本技能包仅提供创作工具，不承担版权责任。

A: 欢迎 Fork 本仓库，在 `SKILL.md` 中添加新技能的映射关系，然后提交 Pull Request。具体规范见 README 的贡献指南。
