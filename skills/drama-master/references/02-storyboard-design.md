# 分镜设计规范

## 概述

将剧本/小说片段转化为标准化分镜脚本。支持两种输出格式：**中文画面规格书**（给人看，电影级镜头语言约束）和**结构化分镜组**（给AI用，4-15秒分组格式）。根据用户需求自动选择，未指定时默认中文画面规格书。

**优先级铁律**：物理可行性 > 叙事情绪 > 多样性指标。三者冲突时，前者压倒后者。

---

## 一、核心设计约束（分镜前必须遵守）

### 1.1 光源动机铁律

**画面中每一处亮度都必须有明确来源、方向与真实衰减。**

- 室内光源必须绑定锚点：窗户/灯具/火源/屏幕/霓虹，不允许"无来源的侧光"
- 室外光源必须明确动机：太阳（黄金时刻/正午/阴天）、月光、街灯、霓虹、车灯、火光
- 光的衰减必须真实：近处亮远处暗、有方向有落点、有明暗交界，不允许"全局均匀补光"
- 光必须参与叙事：侧逆光=神秘，剪影=孤独，正面柔光=温情，顶光=压迫，钠灯脏橙=衰败
- 同一场戏内光线物理方向必须一致，只能变化强度/色温

### 1.2 纵深主层机制

**纵深必须保留主体与背景结构。禁止用fog/haze/blur当万能纵深捷径。**

每个纵深镜头必须从以下三种主层机制中**只选一种**（不堆叠）：

1. **光/曝光分离**：主体通过有来源的轮廓光或明暗关系与背景分离，近中远景保持不同受光与对比
2. **随距离衰减的大气透视**（仅外景/大尺度远景）：远景随距离降低对比、轻微去饱和偏冷，结构与边缘仍然清楚可辨
3. **遮挡/尺度递退**：场景已有重复建筑/地形/人群时，描述重叠与尺度递减

**铁律**：
- 场景里没有雾/烟/尘/蒸汽/风雪时，**禁止写体积雾或可见光束**
- 真空太空永不加大气雾
- 浅景深时降低物理雾——避免背景被抹糊
- 主体始终是最高优先信号

### 1.3 五层色彩思维

**每个镜头的色调方案由五层联动决定，不能只给palette：**

| 层 | 含义 | 取值 |
|---|---|---|
| palette | 主色调 | 青橙/蓝紫/暖棕/墨绿金/冷中性/病态青绿/霓虹对比/血红/创伤蓝/闪回暖金 |
| saturation | 饱和度 | 极低/低/适度/中高 |
| film_stock | 胶片模拟 | Kodak 500T/Kodak 250D/Fuji Eterna/Kodachrome/无 |
| grain | 颗粒 | 无/细腻/中等/粗重 |
| halation | 高光溢出 | 无/微弱光晕/暖调光晕 |

**软化预算铁律**：grain、halation、物理雾、diffusion、bloom不能同时全开。最多保留两种全开软化信号，其余降为subtle或省略。

**全片统一色调**：先出全局色调总表（情绪节点→色调→色温→五层参数），全片严格遵守，不允许中途换调。关键情绪转折允许"局部反差色"短暂出现（不超过总镜头数15%）。

## 二、物理可行性约束（核心）

### 2.1 场景空间类型分类（7类）

每个场景必须先判定类型，标注面积、层高、可放置机位区域。

| 类型 | 代号 | 物理特征 | 最大景别 | 鸟瞰 | 升降 |
|---|---|---|---|---|---|
| 室内封闭小空间 | S1 | ≤20㎡，≤2.8m | 全景 | ❌ | ❌ |
| 室内中型空间 | S2 | 20-60㎡，≤3m | 全景 | ❌ | ❌ |
| 室内大型空间 | S3 | 60-200㎡，3-6m | 远景 | ⚠️ | ⚠️ |
| 室内超大型空间 | S4 | >200㎡，>6m | 大远景 | ✅ | ✅ |
| 室外开阔场景 | O1 | 无顶部遮挡 | 大远景 | ✅ | ✅ |
| 室外半封闭/狭窄 | O2 | 围墙/建筑夹持 | 远景 | ⚠️ | ⚠️ |
| 特殊封闭场景 | X | 极端狭窄/几何特殊 | 中全景 | ❌ | ❌ |

### 2.2 物理可行性红线（不可违反）

以下视为严重错误，必须改写：
1. ❌ S1/S2室内使用大远景/远景
2. ❌ 室内层高<5m使用鸟瞰/上帝视角
3. ❌ S1/S2室内使用升降/摇臂
4. ❌ S1室内使用长焦>135mm
5. ❌ X特殊封闭场景使用大远景/横移/拉镜/轨道/升降/环绕
6. ❌ 任何场景使用物理上不可能的运镜组合（如固定镜头同时描述"镜头环绕"）
7. ❌ 室内场景出现"无来源光线"
8. ❌ 拉镜/横移/环绕未确认机位背后有退让空间

### 2.3 室内场景特别指引

- 定场不用大远景，用全景/中全景+缓慢横移
- 空间压迫感用"高角度俯拍（30°-60°）"代替鸟瞰
- 室内想"宏大"用低角度仰拍+广角，不要用大远景
- 室内动线有限，运镜优先推/拉/摇/手持
- 层高<3m禁止任何形式的"从上方俯视"超过60°俯角

## 三、镜头语言约束

### 3.1 景别

- 可用景别：大远景→远景→全景→中全景→中景→近景→特写→大特写
- 基础规则：情绪越强景别越紧，动作越大景别越松
- 每组至少包含：1个大景别（定场）、1个特写（情绪锚点）、1个中景（信息交代）
- 禁止连着三个近景
- 对话开场必须是中景或全景（禁止对话开场直接给特写）
- 人物特写比例上限40%（仅限人物特写，物件/局部肢体特写不计入）

**景别反规则**（重锤情绪反着用更有力）：
- 悲伤/绝望爆发→反而拉远（人物在环境中渺小）
- 震撼/认知崩塌→反而固定大特写（观众无处可逃）
- 暴力/冲击瞬间→反而切空镜或拉远（留白让观众脑补）
- 孤独/被遗弃→反而用大景别人物居中

### 3.2 焦段

| 焦段 | 等效焦距 | 适用 |
|---|---|---|
| 超广角 | 14-24mm | 史诗场景/建立镜头（室内小空间慎用） |
| 广角 | 24-35mm | 环境交代/室内全景/运动场景 |
| 标准 | 35-50mm | 日常叙事/中景对话 |
| 中长焦 | 85-100mm | 人物特写/肖像/情绪逼近 |
| 长焦 | 135-200mm+ | 远距离观察/偷窥/跟踪（室内禁用） |
| 微距 | 1:1 | 物件细节/泪滴/纹理/关键道具 |

**规则**：大景别优先广角/超广角；人物特写优先中长焦85mm；禁止用广角拍人物近景（除非刻意扭曲）；全片至少使用4种不同焦段。

### 3.3 机位角度

| 角度 | 情绪表达 |
|---|---|
| 平视 | 中性、平等、客观 |
| 仰视角 | 力量、威严、压迫、英雄感 |
| 俯拍 | 弱小、孤独、无助 |
| 鸟瞰/上帝视角 | 全知、宿命（室内层高<5m禁止） |
| 荷兰角 | 不安、失衡、疯狂（全片≤4次） |
| 过肩 | 对话经典，建立空间关系 |
| 主观视角POV | 沉浸代入（全片≤3次） |

**角度反规则**：
- 阴险反派→平视或微仰（不用大仰拍，"近在咫尺的威胁"更阴险）
- 受害者恐惧→仰拍施暴者（代入受害者视角）
- 失败者尊严→平视（保留人格）
- 英雄脆弱瞬间→俯拍（立体化）

### 3.4 运镜

**固定镜头比例上限30%**，禁止连续3个固定镜头。全片至少使用6种不同运镜。

**重技法频率上限**（稀缺资源，只用于重锤瞬间）：

| 重技法 | 全片上限 | 单场上限 |
|---|---|---|
| 滑动变焦Dolly Zoom | ≤1次 | ≤1次 |
| 环绕/弧形Orbit | ≤3次 | ≤1次 |
| Snorricam | ≤1次 | ≤1次 |
| 长镜头Long Take | ≤2次 | ≤1次 |
| 鱼眼Fisheye | ≤2次 | ≤1次 |
| 荷兰角Dutch Angle | ≤4次 | ≤1次 |
| 升降Crane | ≤2次 | ≤1次 |
| 摇臂Jib | ≤2次 | ≤1次 |
| POV主观视角 | ≤3次 | ≤1次 |

**运镜速度=情绪强度**：
- 平静（1-3分）：慢/静止，稳定器般平稳
- 紧张上升（4-6分）：中速，微晃
- 爆发混乱（7-9分）：快/突变，手持晃动
- 沉默留白：静止/极慢，极稳
- 震撼凝固（10分）：静止或滑动变焦

## 四、情绪与镜头匹配

### 4.1 情绪节奏曲线（分镜前必画）

分镜前必须先识别本场戏的情绪节奏曲线：
1. 标记每个情绪节点（类型+强度1-10分+持续度）
2. 画出情绪曲线（如：平静(2)→紧张上升(5)→爆发(9)→沉默(3)→二次爆发(10)→释然(4)）
3. 镜头节奏必须跟随情绪曲线：上升段→镜头变紧运镜变快；爆发点→重锤镜头；平复段→镜头变松留白

### 4.2 留白镜头（情绪重锤后必加）

情绪重锤瞬间（爆发/真相/离别/震撼）之后，必须至少1个留白镜头：
- 环境空镜（窗外风景/桌上物品/墙上光影）
- 反应镜头（无台词，捕捉沉默中的微表情）
- 动作细节空镜（手颤抖/茶杯微颤/烟灰掉落）
- 长固定镜头（人物静默，时间凝固）

### 4.3 人物出现节制

**非人物镜头占比必须在30%-50%区间**（下限防人脸接力，上限防叙事碎片化）。

| 段落类型 | 非人物镜头占比 |
|---|---|
| 长对话（>5个来回） | 35%-50% |
| 中等对话（3-5个来回） | 30%-45% |
| 短对话（1-2个来回） | 20%-40% |
| 情绪爆点对话 | 25%-45% |
| 内敛压抑戏 | 35%-50% |
| 纯动作段落 | 15%-35% |

**5类非人物镜头**（长对话穿插用）：
1. 环境空镜（窗外/天空/街道，氛围铺垫）
2. 物件特写（茶杯/信件/挂钟/烛火，情绪承载）
3. 局部肢体（手颤抖/拳头紧握/脚步后撤，情绪外化不露脸）
4. 光影变化（阳光移动/阴影拉长/烛火摇曳，时间流逝）
5. 反应局部（不拍整脸，拍手紧握/肩膀绷紧/背影微颤）

**铁律**：连续4个人脸镜头=人脸接力=不合格，必须插入非人物镜头。

## 五、输出格式

### 5.1 中文画面规格书格式（默认）

每个镜头用【标签】块组织，纯中文，干净利落：

```
【全局色调方案】
情绪节点 → 主色调 → 色温 → 五层参数（palette/saturation/film_stock/grain/halation）

【导演备注】
本场情绪节奏曲线：XXX
本场场景空间类型：S1/S2/S3/S4/O1/O2/X
反规则运用点：XXX（如有）

【镜头01】
【画面内容】XXX
【焦段】XXXmm
【机位角度】XXX
【景深】浅/深/焦点转换
【运镜方式】XXX（速度：慢/中/快）
【光影设计】光源来源+方向+衰减
【色调色彩】XXX
【纵深构图层次】光/曝光分离 或 大气透视 或 遮挡递退
【画面质感与锐度】XXX
【皮肤质感】XXX
【焦外与虚化】XXX
【物理与视觉限制】XXX（场景空间适配确认）
【台词与音效】XXX
```

### 5.2 结构化分镜组格式（V2.0 PLUS，给AI用）

按分镜组输出，每组4-15秒，包含3-8个单镜头：

```
分镜组 N：[分镜组标题，一句话概括核心内容]
（@人物1@）（@人物2@）
场景：@场景名｜时间，场景详细描述
道具：@道具1、@道具2
主体与站位：@人物1｜位置，@人物2｜位置
摄影：设备+基准焦段
无字幕无文字，环境音：XXX

【镜头1】景别：XX；角度：XX；运镜：XX；动作/台词/音效：XXX
【镜头2】景别：XX；角度：XX；运镜：XX；动作/台词/音效：XXX
...

影片时长：Xs。画面呈现照片级真实感，光影追踪。
```

**分镜组规则**：
- 每组总时长严格4-15秒
- 每组包含1-8个单镜头（最多5个为佳）
- 同场景内人物站位必须锁定，人物移动后在新分组重新锁定
- 所有出场人物用`@人物名@`标注，道具有`@道具名`，场景用`@场景名｜时间`
- 衣服描述直接省略（不需要在分镜里描述衣服细节）

### 5.3 长台词拆分规则

单句台词超过5秒（平常语速25字以上/快语速35字以上），必须拆分：
- 镜头1：说话人近景/特写，说前半段
- 镜头2-3：听众微表情反应/手部肢体特写/相关道具特写
- 最后镜头：说话人收尾表情/动作特写，说后半段

语速规则：平常语速每秒5字/4单词；情绪激动/快语速每秒7字/5单词。

## 六、分镜自检门（输出前必过）

- [ ] 每个镜头是否标注景别/焦段/机位角度/运镜/景深？
- [ ] 光源是否有明确来源、方向、真实衰减？
- [ ] 纵深是否使用了主层机制（非万能雾）？
- [ ] 色调是否由五层联动决定？全片是否统一？
- [ ] 场景空间类型是否判定？景别/焦段/机位/运镜是否匹配物理空间？
- [ ] 是否有物理可行性红线违规？
- [ ] 情绪节奏曲线是否识别？镜头是否跟随情绪？
- [ ] 是否至少识别1-2个反规则机会点？
- [ ] 非人物镜头占比是否在30%-50%区间？
- [ ] 固定镜头是否≤30%？是否有连续3个固定？
- [ ] 重技法使用是否在频率上限内？每个重技法是否有叙事理由？
- [ ] 对话开场是否为中景/全景（非特写）？
- [ ] 人物特写是否≤40%？
- [ ] 长台词是否拆分？
- [ ] 全片焦段是否≥4种？机位角度是否≥4种？运镜是否≥6种？
