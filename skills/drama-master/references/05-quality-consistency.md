# 质量审核与一致性管理规范

## 概述

对已生成的AI视频片段进行逐镜质量审核和跨镜一致性检查。本模块是AI短剧制作的"质检关"——不合格的镜头必须修复或重生成，不能带病进入后期合成。

---

## 第一部分：逐镜质量审核

### 1.1 七维审核标准

每个生成的镜头必须从以下七个维度审核，每个维度评级为：✅合格 / ⚠️轻度问题 / ❌中度问题 / ❌❌重度问题。

| 维度 | 审核要点 | 合格标准 |
|---|---|---|
| 1.画面质量 | 清晰度、噪点、AI拼贴感、模糊 | 清晰无明显噪点，无AI拼贴感，主体锐利 |
| 2.角色一致性 | 面部、服装、发型、年龄、异化特征 | 与锚定图和前镜一致，无换脸 |
| 3.动作自然度 | 动作流畅度、物理合理性、肢体结构 | 动作流畅无卡顿，符合物理规律，无多余手指/肢体扭曲 |
| 4.场景还原度 | 场景与Prompt描述的匹配度、空间布局 | 场景与描述一致，空间布局合理，无明显跑偏 |
| 5.镜头语言 | 景别、运镜、光影、构图是否符合分镜 | 符合分镜标注的景别/运镜/光影，构图合理 |
| 6.合规安全 | 血腥/暴力/死亡/敏感符号/违规文字 | 无违规内容，伤害画面已合规替换 |
| 7.时长节奏 | 生成时长与目标时长的偏差、节奏 | 时长偏差≤10%，节奏符合情绪设计 |

### 1.2 审核评级与处理

| 评级 | 定义 | 处理方式 |
|---|---|---|
| ✅ 合格 | 所有维度均合格，或仅有不影响观看的极轻微问题 | 标记final，进入后期 |
| ⚠️ 轻度问题 | 1-2个维度有轻微问题，不影响观看和叙事 | 标记final，后期修复（调色/裁切/加音效掩盖） |
| ❌ 中度问题 | 1个维度有明显问题，或2-3个维度有轻度问题 | 重试生成（调Prompt），最多重试对应优先级的次数 |
| ❌❌ 重度问题 | 任何维度有严重问题（换脸/肢体崩坏/合规问题/场景完全跑偏） | 立即废弃，重试生成；超过重试上限则导演决策 |

**一票否决项**（出现即重度问题，必须重生成）：
- 面部崩坏/换脸
- 多余手指/肢体严重扭曲
- 出现血液/断肢/尸体等违规内容
- 场景完全跑偏（与Prompt描述的场景完全不同）
- 全黑/全白/花屏

### 1.3 AI问题诊断库（20+常见问题）

| 问题类型 | 表现 | 严重度 | 原因 | 修复方案 |
|---|---|---|---|---|
| 面部崩坏 | 五官扭曲、五官位置错误、面部融化 | 重度 | AI对面部细节生成能力不足，特写时放大 | 换景别（特写→中景）、换角度（正侧面→3/4侧面）、增加参考图权重 |
| 换脸 | 同一角色在不同镜头中面部不同 | 重度 | 角色锚定不足，参考图权重不够 | 提高参考图权重、使用同一锚定图、增加面部描述细节 |
| 多余手指 | 手指数量>5，手指融合/分叉 | 重度 | AI对手部细节生成能力不足 | 避免手部特写、用道具遮挡手部、裁切画面去掉手部 |
| 肢体扭曲 | 手臂/腿角度异常，关节反向 | 重度 | 复杂动作AI生成困难 | 简化动作、拆分镜头、用反应镜代替动作展示 |
| 场景跑偏 | 生成的场景与Prompt描述完全不同 | 重度 | Prompt场景描述不够具体，或参考图缺失 | 增加场景描述细节、使用场景参考图、明确空间布局 |
| 光影异常 | 无来源光、过曝、全黑、光源方向跳变 | 中度 | Prompt中光线描述不明确 | 增加光源描述（来源/方向/色温/强度）、统一同场景光线 |
| 动作卡顿 | 动作不流畅，有跳帧/停顿 | 轻度-中度 | 复杂连续动作AI生成困难 | 简化动作、拆分镜头、加速播放掩盖卡顿 |
| 动作错误 | 生成的动作与Prompt描述不符 | 中度 | Prompt动作描述不够明确 | 增加动作细节描述、使用首帧参考图控制起始状态 |
| 背景模糊 | 背景细节模糊/涂抹感 | 轻度 | 浅景深或AI对背景细节生成不足 | 可接受（后期加锐化），或降低景深要求 |
| 色彩偏差 | 色调与全片不一致，偏色 | 轻度 | AI生成的随机性 | 后期调色统一，或在Prompt中增加色调描述 |
| 文字乱码 | 画面中出现无意义的文字/符号 | 中度 | AI对文字生成能力差 | Prompt中加"无文字无字幕"、裁切去掉文字区域 |
| 道具消失/变形 | 关键道具在镜头中消失或变形 | 中度 | AI对道具追踪能力不足 | 增加道具描述、使用道具参考图、道具放在中心安全区 |
| 空间跳变 | 同场景中空间布局/道具位置无故变化 | 中度 | 连续镜头之间缺乏空间锚定 | 使用前一镜末帧作为首帧参考、统一空间描述 |
| 越轴 | 角色左右位置在相邻镜头中互换 | 中度 | 分镜中未明确轴线，或Prompt中站位描述不一致 | 统一Prompt中人物站位描述、分镜中标注轴线 |
| 服装变化 | 同一角色服装在不同镜头中不同 | 中度 | 角色资产描述不统一 | 统一角色服装描述、使用同一锚定图 |
| 年龄变化 | 同一角色年龄感在不同镜头中不同 | 轻度-中度 | AI生成的随机性 | 统一年龄描述、使用同一锚定图 |
| 异化特征缺失 | 竖屏引擎中角色的鳞片/触须/鱼尾等缺失 | 中度 | 异化特征描述不够具体，或参考图中未体现 | 增加异化特征描述、使用包含异化特征的锚定图 |
| 时长不符 | 生成时长与目标时长偏差>20% | 轻度-中度 | 平台生成时长设置错误 | 重新设置时长参数、后期裁切/加速 |
| 合规问题 | 出现血液/暴力/死亡/敏感内容 | 重度 | Prompt合规替换不彻底，或AI"脑补"违规内容 | 立即废弃，加强Prompt合规替换，增加负面提示词 |
| 音画不同步 | 角色口型与台词不匹配 | 轻度-中度 | AI对口型生成能力有限 | 可接受（短剧对口型要求不高），或用反应镜/特写掩盖 |

### 1.4 分级修复策略

#### 轻度问题（后期修复）
- 适用：背景模糊、色彩偏差、轻微动作卡顿、轻微光影差异
- 修复方式：后期调色统一、加锐化、裁切、加音效掩盖、加速播放
- 不需要重生成

#### 中度问题（调Prompt重生成）
- 适用：光影异常、动作错误、道具消失、空间跳变、越轴、服装变化、文字乱码
- 修复方式：调整Prompt（增加细节/明确描述/统一参数），重新生成
- 重试次数按优先级限制（P0≤3次，P1≤2次，P2≤1次）

#### 重度问题（重新设计镜头）
- 适用：面部崩坏、换脸、多余手指、肢体扭曲、场景跑偏、合规问题
- 修复方式：先尝试调Prompt重生成；超过重试上限后，进入导演决策流程（见模块7），重新设计镜头（拆分/换景别/用替代镜头/用剪影遮挡）

## 第二部分：跨镜一致性管理

### 2.1 四维跨镜追踪

全片所有镜头必须在以下四个维度保持一致：

| 维度 | 追踪内容 | 检查方法 |
|---|---|---|
| 1.角色一致性 | 面部、服装、发型、年龄、异化特征、身材 | 并排对比相邻镜头的角色截图，重点看面部和服装 |
| 2.场景连续性 | 空间布局、道具位置、建筑结构、环境细节 | 同场景镜头并排对比，检查空间布局和道具位置是否连续 |
| 3.光影衔接 | 光源方向、色温、强度、阴影位置 | 相邻镜头对比，检查光源方向和色温是否一致（允许强度变化） |
| 4.道具追踪 | 关键道具的位置、状态、持有者 | 建立道具出场追踪表，逐镜检查道具是否连续 |

### 2.2 角色一致性检查

**检查时机**：
- 每个镜头生成后，立即与锚定图对比
- 同一场景的所有镜头生成后，并排对比
- 全片生成完成后，整体检查

**检查要点**：
- 面部：五官形状、脸型、肤色、年龄感是否一致
- 发型：发色、发型、长度是否一致
- 服装：款式、颜色、材质、配件是否一致
- 异化特征（竖屏引擎）：鳞片位置/数量、触须、鱼尾、义眼等是否一致
- 身材：体型、身高比例是否一致

**常见问题与修复**：
| 问题 | 修复方式 |
|---|---|
| 面部略有差异 | 可接受（观众对面部差异有一定容忍度），或后期用调色统一肤色 |
| 面部明显不同（换脸） | 必须重生成，提高参考图权重，使用同一锚定图 |
| 服装颜色偏差 | 后期调色统一，或重生成时统一服装描述 |
| 服装款式不同 | 必须重生成，统一角色资产描述 |
| 异化特征缺失 | 重生成，增加异化特征描述，使用包含异化特征的锚定图 |

### 2.3 场景连续性检查

**检查时机**：同一场景的所有镜头生成后。

**检查要点**：
- 空间布局：家具/建筑/道具的相对位置是否一致
- 道具位置：关键道具在场景中的位置是否连续
- 环境细节：墙面/地面/窗户等环境细节是否一致
- 空间方向：角色的左右位置是否一致（无越轴）

**常见问题与修复**：
| 问题 | 修复方式 |
|---|---|
| 道具位置小差异 | 可接受，或用剪辑掩盖（不连续展示道具位置） |
| 空间布局明显不同 | 重生成，使用前一镜末帧作为首帧参考，统一空间描述 |
| 越轴 | 重生成，统一Prompt中人物站位描述，分镜中标注轴线 |
| 环境细节差异 | 后期调色统一，或可接受（观众对背景细节关注度低） |

### 2.4 光影衔接检查

**检查时机**：相邻镜头生成后，以及同场景所有镜头完成后。

**检查要点**：
- 光源方向：主光源的方向是否一致（如都是从左侧窗户射入）
- 色温：整体色调是否一致（如都是暖黄色调）
- 强度：允许有合理变化（如角色走到阴影区变暗），但不能无故跳变
- 阴影位置：阴影的方向和长度是否与光源一致

**常见问题与修复**：
| 问题 | 修复方式 |
|---|---|
| 色温小差异 | 后期调色统一 |
| 光源方向不同 | 重生成，统一Prompt中光源描述 |
| 强度无故跳变 | 后期调整亮度，或重生成 |
| 阴影位置不一致 | 可接受（观众对阴影关注度低），或重生成 |

### 2.5 道具追踪表

对于关键道具（如信件、武器、信物、手机等），建立出场追踪表：

```
【道具追踪表：XX道具】
出场镜头 | 持有者 | 位置 | 状态 | 备注
镜01     | 角色A  | 手中 | 完整 | 首次出场
镜02     | 角色A  | 桌上 | 完整 | 放下
镜03     | 角色B  | 手中 | 破损 | 角色B拿起，已破损
镜04     | 角色B  | 口袋 | 破损 | 收起来
...
```

**追踪要点**：
- 道具的持有者是否连续（不能凭空从A手中到B手中，中间要有传递动作）
- 道具的状态是否连续（完整→破损，不能破损→完整）
- 道具的位置是否合理（在桌上→在手中，要有拿起动作）

## 第三部分：剪辑掩盖技巧

当一致性问题无法通过重生成完全解决时，用后期剪辑技巧掩盖：

### 3.1 插入过渡镜
- 在两个不一致的镜头之间插入一个过渡镜（空镜/反应镜/细节特写）
- 观众的注意力被过渡镜分散，不会注意到前后镜头的不一致

### 3.2 快切蒙太奇
- 将不一致的镜头放在快切蒙太奇中（每个镜头0.5-1秒）
- 快节奏下观众不会注意到细节不一致

### 3.3 音效桥接
- 用音效（动作声/环境音/BGM）连接两个不一致的镜头
- 听觉上的连续性可以掩盖视觉上的不连续

### 3.4 调色统一
- 用后期调色将不一致的镜头统一到同一色调
- 色彩统一后，观众对其他差异的敏感度降低

### 3.5 裁切与缩放
- 裁切掉不一致的区域（如背景差异、道具位置差异）
- 用缩放将视觉重心引导到一致的区域（如角色面部）

### 3.6 闪白/闪黑转场
- 在不一致的镜头之间加闪白/闪黑转场
- 转场的视觉冲击可以掩盖前后镜头的不一致

**原则**：剪辑掩盖是"最后手段"，不是"首选方案"。能重生成解决的问题优先重生成，实在无法解决才用剪辑掩盖。掩盖后要确保观众在正常观看速度下不会察觉问题。

## 四、质量审核+一致性自检门

- [ ] 每个镜头是否都过了七维审核？
- [ ] 每个维度是否都有评级（✅/⚠️/❌/❌❌）？
- [ ] 一票否决项是否检查（换脸/多余手指/合规问题/场景跑偏/花屏）？
- [ ] 不合格项是否都有诊断（问题类型+原因+修复方案）？
- [ ] 轻度问题是否标记后期修复？
- [ ] 中度问题是否进入重试流程？
- [ ] 重度问题是否立即废弃并重生成？
- [ ] 重试次数是否在限制内？
- [ ] 超过重试上限的镜头是否进入导演决策流程？
- [ ] 角色四维（面部/服装/发型/异化特征）是否全镜追踪？
- [ ] 同场景镜头是否并排对比了空间布局和道具位置？
- [ ] 相邻镜头光影是否检查了衔接（光源方向/色温/强度）？
- [ ] 关键道具是否建立了出场追踪表？
- [ ] 道具持有者/状态/位置是否连续？
- [ ] 是否有越轴问题？
- [ ] 无法重生成解决的问题是否用了剪辑掩盖？
- [ ] 掩盖后是否在正常观看速度下不可察觉？
- [ ] 合规安全是否逐镜检查（无血液/暴力/死亡/敏感内容）？
- [ ] 所有终选镜头是否都有公共访问链接？
