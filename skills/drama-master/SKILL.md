**3+. 钩子画面化与因果链 · 两条硬性创作要求**

根据用户输入，自动判断起始模块，不需要用户手动选择。如果用户需求不明确，用一个简短问题确认即可，不要抛出复杂的多选项菜单。

    │
    ├─ 已有剧本/小说片段，要求分镜 ───────────→ 模块2 分镜设计
    │
    ├─ 已有分镜，要求生成视频提示词 ──────────→ 模块3 提示词生成
    │
    ├─ 已有提示词，要求批量生成视频 ──────────→ 模块4 视频生成执行
    │
    ├─ 已有视频片段，要求审核/修复 ───────────→ 模块5 质量审核+一致性
    │
    ├─ 有多段素材，要求剪辑合成 ──────────────→ 模块6 后期合成
    │
    ├─ 要求输出成片/交付/发布 ────────────────→ 模块7 交付与导演决策

## 全局铁律（所有模块必须遵守）

### 铁律0：Seedance 2.5 为最高优先级视频生成引擎
**所有视频生成默认使用 Seedance 2.5 引擎，优先级高于即梦/MiniMax等其他引擎。** 具体规则：
- 调用视频生成工具时，`model_version` 固定为 `seedance_2.5`，不得因画质判断/速度/成本/时长或其他偏好切换到其他模型
- 用户确认的最终视频提示词**逐字原文透传**，不得改写、润色、精简、翻译、纠错、重排，不得增加前缀/后缀/负面提示词/风格词/质量词
- 生成前必须向用户展示完整确认信息（模型/原始prompt/时长/比例/参考素材），等待用户明确确认后才生成
- 时长支持5-30秒整数；比例仅支持16:9/4:3/1:1/3:4/9:16/21:9，不支持的比例必须让用户重新选择，不得擅自替换
- 若用户明确指定使用其他引擎（如即梦），按用户指定执行，但Seedance 2.5仍为默认推荐

### 铁律1：视频必须以内嵌预览播放器形式交付，用户预览确认后再继续
**每生成完一个视频（包括单镜片段、九宫格成图、最终成片），必须以内嵌预览播放器形式展示在聊天对话中**（用户可直接点击播放按钮预览播放，类似视频消息卡片），而不是只给一个文件链接或本地路径。
- 内嵌预览播放器是**首选交付形式**，公共访问链接作为补充同时提供
- 每条视频生成后，停下等待用户预览并明确确认（"可以/继续/通过"）后，再生成下一条
- 用户未确认前，不得继续批量生成后续镜头
- 不允许只说"已生成"而不给预览，不允许只给本地文件路径
- 用户需要能直接在聊天界面中点击播放，无需跳转到外部页面

### 铁律2：不含任何去水印内容
**全技能不包含、不推荐、不指导任何去水印操作。** 涉及水印时，建议用户使用平台官方无水印导出，或在生成时选择无水印版本。不提供去除他人水印的方法或工具。

### 铁律3：合规安全
- 所有涉及伤害/死亡/暴力的画面描述必须经过合规替换，仅改画面描述不改台词
- 不出现血腥特写、喷溅血液、断肢、尸体、利器刺穿身体、暴力慢放
- 即使Prompt已合规，AI生成仍可能"脑补"违规内容，必须逐镜人工审核
- 发现违规内容立即标记并重生成

### 铁律4：物理可行性优先
**优先级铁律：物理可行性 > 叙事情绪 > 多样性指标。** 所有景别/焦段/机位/运镜必须先匹配场景物理空间，再谈情绪与多样性。室内小空间禁止大远景/鸟瞰/升降，特殊封闭场景禁止横移/拉镜/环绕。

### 铁律5：分步执行，不跳步
- 每个模块完成后必须停下，等待用户确认后再进入下一模块
- 严禁一次性输出全部内容（从剧本直接跳到成片）
- 每阶段输出后必须询问用户确认
- 视频生成时，每条生成后必须等待用户预览确认再继续下一条

### 铁律6：不编造，不猜测
- 缺少关键信息时（主角是谁/对白语言/特定结局），补问一个简短问题
- 其他细节自行做合理决定，不把用户拦在连续的选择题前
- 所有数字、时长、规格必须有依据，不编造

### 铁律7：有台词必须在提示词中写清楚，不使用TTS语音合成
**角色对话、内心独白、画外音、旁白等所有台词，必须直接写进视频生成提示词中**，让AI视频模型直接生成带语音的视频。不使用TTS（文本转语音）单独合成语音，不在后期单独做语音合成。
- 提示词中写台词的格式：`角色A说："台词内容"`、`角色A内心独白："..."`、`画外音："..."`
- 台词必须完整写入提示词，不能省略、不能只写"角色A说话"
- 生成的视频应自带角色语音，后期只需调整音量和混音，不需要额外合成语音
- 如果生成的视频没有语音或语音不清，检查提示词中台词是否写清楚，调整后重新生成，而不是用TTS补救

### 铁律8：生成前必须展示完整提示词，强制图片参考并@艾特人物
**每次生成视频前，必须把完整详细的提示词展示给用户看**，让用户确认后再生成。同时：
- **强制使用图片参考**：每次生成必须使用图生视频模式（带参考图），不允许纯文字生成（文生视频）。用户提供的人物图片必须作为参考图传入
- **人物必须@艾特**：提示词中出现用户提供的人物时，必须用`@图片N`格式艾特对应的参考图，紧跟在角色名后面，如`李明（@图片1）说："..."`
- **提示词完整展示**：生成前用代码块展示完整提示词，包含所有参数（画面描述/人物@艾特/台词/运镜/光影/时长/比例），用户确认后才调用生成工具
- 不允许跳过提示词展示直接生成，不允许只展示摘要不展示完整提示词

### 铁律9：用户提供的人物图片一人一角色，不得重复使用
**用户提供的每个人物图片只对应剧中一个角色，不得复用同一张图片扮演多个角色。**
- 用户提供N张人物图片，就锁定N个角色的形象，每张图只对应一个角色
- 如果剧中角色数量超过用户提供的图片数量，多余的角色**只用纯文字描述外貌**（如"中年男性，短发，戴眼镜，穿灰色西装"），不使用任何参考图
- 禁止用同一张参考图扮演两个不同角色（会导致"一人分饰两角"或角色重复）
- 禁止把用户提供的角色图片用于描述其他角色
- 角色与参考图的对应关系在全剧中保持一致，不中途更换

## 全流程自检门（每个模块输出前必过）

### 模块1 剧本创作自检
- [ ] 时长是否符合（90秒四幕时间锁 或 5分钟四幕节拍）？
- [ ] 开场3秒内是否有强冲击？
- [ ] 反转是否有前期伏笔？是否直指核心立意？
- [ ] 人物是否性格立场鲜明？
- [ ] 每句台词是否服务于冲突/反转/爽点？
- [ ] 结尾是否有强悬念钩子或一击致命的余味？

#### 脚本自检质量门 · 六大项（源自《短剧脚本创作自检清单》更新版，剧本产出后、进入资产/分镜/生成前强制逐项勾选）
- [ ] **① 矛盾设计（核心）**：矛盾能让观众代入并做**视觉化**呈现（看得见，非旁白交代）；每个矛盾配具体伏笔（前期埋、后期收）；矛盾 **≥2 个**；矛盾承担「塑造主角 / 推动剧情 / 升华主题」三重作用
- [ ] **② 人物侧写**：基于故事情境分析人物而非贴标签；写清性格特点与面临的问题；用神态、动作、习惯等细节立人
- [ ] **③ 场景与转场**：设计专门转场避免硬切；区分/交代背景让观众看懂时空；掌握同一场景、不同时间的转场（用光影/道具/状态变化体现时间流逝）
- [ ] **④ 叙事结构（多线 + 因果链）**：故事含主线 + 亲情线 + 社会关系线至少三条线，各线有交汇、相互推动而非平行堆砌；**剧情按因果链 A→B→C 推进（A 导致 B、B 导致 C），不是「然后…然后…」的流水账**；对每个场景追问「**它因什么发生、又导致了什么**」，删除与主线无因果关系的段落；人物行动有动机、有后果，**伏笔是因、回收是果**，反转意料之外情理之中；钩子抛出的异常 / 悬念必须有成因（可后置揭示）
- [ ] **⑤ 开头钩子（画面化）与互动**：钩子必须是**看得见的具体画面 / 动作 / 场景**，靠第一帧 / 前几秒视觉冲击或视觉悬念抓人，**不靠旁白 / 台词 / 字幕 / 标题去「说」钩子**，且直接关联核心矛盾 / 悬念、不用与正片无关的唬头；开头用热点 / 焦点 / 强冲突抓住观众；全片设置讨论点（留争议 / 悬念 / 共鸣），引发留言互动
- [ ] **⑥ 观众视角自检**：切换为普通观众（角色扮演）重看一遍；自问「哪里可以优化？整体是否吸引我继续看？」

> 源文件：`/home/user/Doubao/chats/38436370915409154/短剧脚本创作自检清单.md`。此门为**强制勾选门**——六大项全过才允许进入模块 2 分镜 / 资产 / 生成；不通过则改剧本后重过。一句话流程：先立人物与背景 → 布置 ≥2 个矛盾并埋好伏笔 → 用主线串起亲情线/社会关系线 → 设计转场与开头钩子 → 埋讨论点 → 最后以观众视角逐项挑刺。
