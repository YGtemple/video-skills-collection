# 导演决策手册

## 概述

本文件是导演视角的创作决策指南。在AI短剧制作中，不是所有问题都能靠"调Prompt重生成"解决——当技术手段遇到瓶颈时，需要以导演的创作思维做决策：重新设计镜头、用剪辑技巧掩盖、调整节奏、统一风格。

**核心原则**：AI是工具，导演是决策者。不要被AI的能力边界限制创作——当AI做不到时，换一种创作方式，而不是降低标准。

---

## 一、镜头生成失败时的重新设计

### 1.1 什么时候判定"生成失败"

- 同一镜头重试3次，仍有中重度问题
- 问题反复出现（如每次都面部融化、每次都动作卡顿）
- Prompt已经调整到极限，问题依然存在
- 生成质量远低于可接受线

### 1.2 重新设计的五种方法

#### 方法一：拆分镜头

**适用**：复杂连续动作AI无法流畅生成（如"从椅子上站起并走向门口同时说话"）

**做法**：将一个复杂镜头拆成2-3个简单镜头：
- 镜A：中景，角色从椅子上站起（2秒）
- 镜B：特写，角色的手拿起桌上的文件（1.5秒）
- 镜C：中景，角色走向门口（2秒）

**原理**：AI生成简单动作的成功率远高于复杂动作。拆分后每个镜头只有一个核心动作，生成质量大幅提升。

#### 方法二：换景别

**适用**：全景/远景中AI需要生成太多细节导致崩坏；或大角度面部持续融化

**做法**：
- 全景→中景：减少背景细节，聚焦人物上半身
- 中景→近景/特写：进一步聚焦，减少AI需要生成的区域
- 正侧面→3/4侧面：AI对3/4侧面的面部生成能力最强
- 俯视/仰视→平视：AI对视平角度生成最稳定

**原理**：AI生成的细节越少，出错概率越低。特写镜头虽然对细节要求高，但区域小，AI更容易控制。

#### 方法三：用替代镜头

**适用**：某个动作/场景AI完全无法生成（如复杂打斗、手部精细操作、多人互动）

**做法**：用其他镜头替代直接展示：
- 打斗→用反应镜（对手的表情）+ 动效音（击打声）+ 快速剪辑暗示
- 手部精细操作→用道具特写（结果展示）+ 音效（操作声）代替操作过程
- 多人互动→用单人特写+对话剪辑（正反打）代替同框互动
- 无法生成的场景→用空镜（场景细节）+ 角色画外音 + 音效暗示

**原理**：电影百年历史中，导演经常用"不直接展示"的手法——观众的想象力比AI生成的画面更有冲击力。希区柯克的"炸弹理论"：让观众知道桌子下有炸弹，比直接展示爆炸更紧张。

#### 方法四：用剪影/遮挡

**适用**：AI生成的人物/动作有明显瑕疵，但剧情需要这个镜头

**做法**：
- 剪影：强背光，人物全黑，只看轮廓（AI生成剪影的成功率极高）
- 遮挡：用前景物体（门框/窗帘/其他人）遮挡瑕疵部分
- 景深虚化：大光圈浅景深，瑕疵区域在焦外虚化
- 运动模糊：快速运动时的自然模糊，掩盖细节瑕疵

**原理**：遮挡和虚化是电影语言的常规手法，不是"偷工减料"——它们可以引导视觉重心，增强氛围感。

#### 方法五：改变调度

**适用**：当前的镜头调度（人物位置/运动方向/动作设计）导致AI生成困难

**做法**：
- 改变人物站位：从面对面改为肩并肩（减少面部同时生成的难度）
- 改变运动方向：从横向运动改为纵向运动（AI对纵深运动生成更稳定）
- 改变动作设计：从大幅度动作改为小幅度动作（如从"拍桌子"改为"握紧拳头"）
- 增加静止帧：动作之间加0.5秒静止，让AI有"锚点"

**原理**：AI生成有自己的"舒适区"——静态/小幅度/纵深运动比动态/大幅度/横向运动更容易生成。导演要了解工具的特性，在创作中扬长避短。

## 二、情绪强化技巧

### 2.1 单镜情绪不到位时

AI生成的镜头有时"技术上合格但情绪不到位"——画面清晰、动作正确，但就是没有感染力。用以下后期技巧强化：

**运镜速度调整**：
- 紧张/爆发场景：将镜头加速1.1-1.3x（但不要过度，否则会不自然）
- 压抑/悲伤场景：将镜头减速0.85-0.95x，增加沉重感
- 反转时刻：先减速0.5x（慢动作）→ 骤停0.3秒 → 恢复正常速度

**光影强化**：
- 紧张场景：增加对比度（+15%），压暗阴影，制造压迫感
- 温暖场景：加暖色调（色温+500K），降低对比度，增加柔光感
- 恐怖/悬疑：加冷色调（色温-500K），增加暗角，降低曝光

**音效强化**：
- 加心跳声（紧张场景，逐渐加速）
- 加呼吸声（情绪爆发前，急促呼吸）
- 加低频嗡鸣（悬疑场景，持续的不安感）
- 加静音（反转前0.5秒，所有声音骤停）

### 2.2 全片情绪曲线调整

如果全片情绪"平"——没有起伏，观众看到一半就走神——用以下方法调整：

**节奏重剪**：
- 找出全片的"情绪峰值"（反转/高潮），确保它在65-80秒区间
- 峰值前的镜头逐镜缩短（加速铺垫），峰值后的镜头逐镜拉长（释放情绪）
- 在峰值前加一个"假平静"（突然放慢节奏），然后爆发（对比增强冲击）

**BGM重构**：
- 确保BGM有明确的"起承转合"——不是全程一个调子
- 在情绪升级段，BGM逐层叠加乐器（钢琴→弦乐→打击乐→全奏）
- 在反转时刻，BGM骤停→爆发（不要让BGM"预测"反转，反转要意外）

**特写插入**：
- 在情绪关键节点插入角色特写（眼神/表情/手部动作），特写是情绪的"放大器"
- 每个主要角色至少有一个情绪特写（让观众"看到"角色的内心）

## 三、跨镜不一致的剪辑掩盖

当跨镜不一致无法通过重生成解决时（如时间/资源限制），用剪辑技巧掩盖。这不是"作弊"——专业电影也经常用剪辑技巧掩盖拍摄中的问题。

### 3.1 插入中性镜头

在两个不一致的镜头之间插入一个"中性镜头"，转移观众注意力：

**可用的中性镜头**：
- 角色反应特写（表情变化，与剧情相关）
- 道具特写（关键道具的细节，推动剧情）
- 空镜（场景细节，如时钟/窗外/摆件）
- 手部动作特写（握拳/拿东西/敲门）
- 环境音+黑场（0.3-0.5秒黑场，用音效过渡）

**插入时机**：
- 角色换脸：在两个面部镜头之间插入道具/空镜，观众不会连续对比面部
- 场景跳变：在两个场景镜头之间插入角色特写（特写不展示背景）
- 光影断裂：在两个光影差异大的镜头之间加0.3秒闪白/闪黑

### 3.2 快切蒙太奇

将不一致的镜头用快切（每镜0.5-1.5秒）组合成蒙太奇段落：

**适用场景**：
- 打斗段落（快切本身就是打斗的常规手法）
- 情绪爆发段落（快切增强混乱感/冲击感）
- 回忆/闪回段落（碎片化的记忆本身就不需要完全连贯）
- 时间流逝段落（蒙太奇展示时间跨度）

**技巧**：
- 快切时加动效音（每个切换配一个音效），音效可以"桥接"视觉上的不连贯
- 快切段落的BGM要有强烈的节奏感，让观众的注意力在节奏上而不是细节上
- 快切段落不要超过5-8秒（太长会让观众疲劳）

### 3.3 音效桥接

用音效掩盖视觉上的不连贯：

**技巧**：
- 前一镜的动效音延续到后一镜（如前镜关门声，后镜开头还有关门的余音）
- 用一个"过渡音效"（whoosh/上升音/低音boom）覆盖切换瞬间
- 场景切换时，环境音先变（前镜结尾已经是新场景的环境音），画面后变——观众的听觉先接受了新场景，视觉上的跳变就不明显了
- 用角色画外音覆盖切换（前镜结尾角色开始说话，后镜画面变了但声音继续）

### 3.4 调色统一

全片加较强的统一调色，降低各镜之间的差异感知：

**技巧**：
- 加统一LUT（色彩查找表），将所有镜头的色彩"拉"到同一个基调
- 加颗粒/噪点（模拟胶片质感），颗粒可以掩盖AI生成的平滑感和细节差异
- 加暗角（-15%~-20%），暗角引导视觉重心到画面中心，边缘的差异不被注意
- 降低饱和度（-10%~-15%），低饱和度下色彩差异不明显

**注意**：调色统一是"最后手段"，不要过度——如果调色太重，会影响画质和观感。优先用重生成解决，调色只是辅助。

## 四、节奏调整决策

### 4.1 节奏拖沓时

**表现**：观众看到一半走神，觉得"进度慢"，总时长虽然90秒但感觉像3分钟。

**诊断**：
- 单个镜头过长（超过6秒且无明确叙事目的）
- 过渡镜头太多（不必要的反应镜/空镜）
- 台词冗长（每句台词都完整说完，没有剪辑）
- BGM太平（没有起伏，全程一个调子）

**解决方案**：
1. **压缩镜头时长**：每个镜头问"这个镜头需要这么久吗？"——能3秒说完的不要用5秒
2. **删减过渡镜头**：去掉不推动剧情/不展示情绪的镜头
3. **台词剪辑**：长台词中间插入反应镜/动作镜，不要让一个角色连续说超过5秒
4. **加速铺垫段**：开场和推进段可以略加速（1.05-1.1x），把时间留给反转和结尾
5. **提前冲突**：如果开场10秒还没进入冲突，把冲突提前（删掉铺垫，直接进冲突）

### 4.2 节奏仓促时

**表现**：观众看不懂剧情，"太快了没反应过来"，反转没有冲击力。

**诊断**：
- 镜头太短（大量0.5-1秒的快切，观众来不及理解）
- 关键信息没有给够时间（反转的揭示只有1秒，观众没看懂）
- 缺少"呼吸点"（全程快节奏，没有停顿）
- 台词被裁切（关键台词没说完就切了）

**解决方案**：
1. **关键镜头给够时间**：反转揭示镜、情绪爆发镜、关键台词镜，至少给3-5秒
2. **加呼吸点**：在连续快切后加一个1-2秒的停顿镜（角色喘息/空镜/表情特写）
3. **放慢反转前的节奏**：反转前5秒开始减速，制造"暴风雨前的宁静"，然后反转爆发
4. **关键台词完整保留**：推动剧情的关键台词不要裁切，给完整的说话时间
5. **加反应镜**：在关键信息后加角色反应镜（0.5-1秒），给观众消化时间，同时展示角色的情绪

### 4.3 节奏决策检查表

- [ ] 开场3秒内有冲突/悬念吗？
- [ ] 前15秒内观众能看懂"谁在什么地方遇到了什么问题"吗？
- [ ] 反转在65-80秒区间吗？反转前有足够的铺垫吗？
- [ ] 反转后有足够的"释放时间"吗（不要反转后立刻结尾）？
- [ ] 结尾悬念有冲击力吗？卡点准确吗？
- [ ] 全片有至少2个"呼吸点"吗（停顿/慢镜头/留白）？
- [ ] 有没有哪个镜头让你觉得"这段可以快进"？如果有，压缩或删掉
- [ ] 有没有哪个镜头让你觉得"没看懂"？如果有，给更多时间或加解释

## 五、视觉风格统一决策

### 5.1 建立全片视觉基调

在开始后期之前，先确定全片的视觉基调，所有镜头向基调对齐：

**基调要素**：
- **色调**：冷色调（悬疑/恐怖/科幻）/暖色调（温情/甜宠/复古）/中性色调（都市/现实）
- **对比度**：高对比（戏剧化/冲击）/中对比（自然/叙事）/低对比（柔和/梦幻）
- **饱和度**：高饱和（活力/漫画感）/中饱和（自然）/低饱和（压抑/写实/胶片感）
- **光影**：硬光（戏剧化/ noir）/柔光（自然/温馨）/混合光
- **颗粒感**：无颗粒（数字感）/轻微颗粒（胶片感）/重颗粒（复古/lo-fi）

**决策方法**：
- 根据题材和情绪选择基调（悬疑=冷色+高对比+低饱和；甜宠=暖色+中对比+中饱和）
- 选一个"参考片"（电影/短剧/广告），以它的视觉风格为基准
- 在全片中选1-2个"基准镜头"（质量最高、风格最明确的镜头），其他镜头向基准镜头对齐

### 5.2 偏差镜头的风格统一

当个别镜头的视觉风格与全片基调不一致时（AI生成的随机性导致），用以下方法统一：

**调色统一**（最常用）：
- 将基准镜头的调色参数（色温/色调/对比度/饱和度/曲线）复制到偏差镜头
- 如果偏差较大，用"颜色匹配"功能（后期软件的自动颜色匹配）
- 加统一LUT，将所有镜头拉到同一色彩空间

**光影统一**：
- 如果偏差镜头的光影方向与全片不同，用后期调整（加光源/减光源/改变光影方向）
- 如果偏差太大，重生成（光影是AI生成的核心参数，后期难以根本改变）

**质感统一**：
- 加统一颗粒/噪点，掩盖不同镜头的质感差异
- 加统一锐化/模糊，统一清晰度感
- 加统一暗角，统一画面氛围

### 5.3 风格统一的"度"

- **不要为了统一而牺牲质量**：如果基准镜头质量高，偏差镜头向它对齐；如果基准镜头质量一般，不要把好镜头"拉低"
- **允许合理的风格变化**：不同情绪段可以有不同的色调（如回忆段用暖色调，现实段用冷色调），这是叙事需要，不是"不一致"
- **统一是"基调统一"，不是"逐像素统一"**：观众感知的是整体氛围，不是每个像素的色彩。小差异可以接受

## 六、常见创作困境与解决方案

### 困境一：AI生成的角色"没有灵魂"

**表现**：角色面部清晰、动作正确，但表情木然，感觉像"人偶"，没有感染力。

**解决方案**：
1. **用特写放大微表情**：AI在特写中生成的微表情（眼神微动/嘴角微颤）比中景更有感染力
2. **用BGM和音效"注入"情绪**：同样的画面，配悲伤的BGM和音效，观众会"觉得"角色在悲伤
3. **用反应镜代替正面展示**：不直接展示角色的表情，而是展示其他角色对他的反应——观众会通过反应"推断"角色的情绪
4. **用画外音/内心独白**：角色不说话，但加内心独白（画外音），观众通过声音理解角色的内心
5. **Prompt中加更具体的表情描述**：不是"sad"，而是"tears in eyes, trembling lips, looking down with grief"——越具体，AI生成的表情越有细节

### 困境二：反转没有冲击力

**表现**：反转剧情设计得很好，但生成后观众"没感觉"，反转像普通剧情推进。

**解决方案**：
1. **反转前加"假平静"**：反转前3-5秒突然放慢节奏，BGM减弱，制造"一切正常"的假象——然后反转爆发，对比增强冲击
2. **反转时刻骤停**：反转揭示前0.5秒，所有画面运动和声音骤停——然后反转镜硬切切入，BGM和动效音爆发
3. **用闪白/闪黑**：反转帧加0.2-0.3秒闪白（视觉冲击）或闪黑（悬念感）
4. **加低音boom**：反转时刻加一个30-60Hz的低音冲击（身体能感受到的震动）
5. **给反转足够的"释放时间"**：反转后不要立刻切走，给3-5秒展示角色反应和情绪释放
6. **用慢动作**：反转的关键动作（如转身/揭露/掉落）用慢动作（0.3-0.5x），增强仪式感

### 困境三：90秒讲不完故事

**表现**：剧本写得很好，但90秒内塞不下——要么节奏仓促，要么砍掉关键剧情。

**解决方案**：
1. **"展示，不要讲述"**：用画面和动作代替台词解释（如角色看了一眼照片，比说"这是我去世的妻子"更有效）
2. **删减次要角色**：90秒短剧最多2-3个主要角色，多余的角色合并或删除
3. **合并场景**：如果剧情在3个场景发生，考虑合并到1-2个场景（场景切换消耗时间）
4. **用蒙太奇压缩时间**：需要展示时间流逝/多个事件时，用快切蒙太奇（5秒可以展示5个事件）
5. **开头直接进冲突**：不要用5秒"介绍背景"——直接从冲突开始，背景信息在冲突中自然展示
6. **结尾留白**：不要把所有事情都解释清楚——结尾留悬念，让观众自己脑补，同时为下集铺垫

### 困境四：全片"AI感"太重

**表现**：每个镜头单独看都OK，但拼在一起后，观众一眼就能看出"这是AI生成的"——太完美、太光滑、没有"人味"。

**解决方案**：
1. **加颗粒/噪点**：模拟胶片质感，颗粒可以打破AI生成的"过于光滑"
2. **加轻微运动抖动**：AI生成的镜头太稳，加轻微的手持抖动（模拟手持摄影），增加"实拍感"
3. **加镜头光晕/漏光**：模拟镜头眩光和胶片漏光，增加"摄影感"
4. **加呼吸式对焦**：模拟真实镜头的轻微对焦呼吸（焦点微移），打破AI的"全画面清晰"
5. **故意保留一些"不完美"**：不要把每个镜头都修到完美——真实拍摄也有小瑕疵，保留一些自然的不完美
6. **用剪辑打破"完美"**：AI生成的镜头节奏太均匀，用剪辑制造一些"不均匀"——有的镜头长，有的短，有的硬切，有的叠化
7. **加环境音的"不完美"**：AI生成的视频没有环境音，后期加真实的环境音（空调声/远处人声/电流声），增加"在场感"

## 七、导演决策检查清单

在每个关键决策点，问自己以下问题：

**创作决策**：
- [ ] 这个决策是为了"更好的叙事"，还是为了"掩盖AI的缺陷"？如果是后者，有没有更好的创作方式？
- [ ] 如果这是真人拍摄，我会这么做吗？如果不会，为什么AI生成就要降低标准？
- [ ] 观众会注意到这个问题吗？如果不会，不要过度修复（把精力放在观众会注意的地方）
- [ ] 这个决策会影响全片的节奏/情绪/风格吗？如果会，确保它是"有意为之"，不是"无奈之举"

**技术决策**：
- [ ] 已经重试3次了吗？如果没有，再试一次（不要轻易放弃）
- [ ] 换了Prompt/参考图/生成模式了吗？如果只调了一种参数，试试其他参数
- [ ] 这个问题是"这一个镜头"的问题，还是"这类镜头"的问题？如果是后者，在后续镜头中主动规避
- [ ] 后期能修复吗？如果能，标记后期修复，不要浪费生成资源

**最终决策**：
- [ ] 这个决策后的结果，我愿意署上自己的名字吗？
- [ ] 如果观众问"为什么这里这样处理"，我能给出一个创作上的解释吗？
- [ ] 全片看完后，整体感好吗？（不要只看单个镜头，要看全片的整体效果）
