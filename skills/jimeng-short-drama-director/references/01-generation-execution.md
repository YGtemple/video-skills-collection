# 生成执行管理规范

## 概述

本文件指导如何将 Studio 产出的单镜 Prompt 转化为有序、可控、可追溯的批量视频生成执行。核心目标：**用最小的重生成次数拿到最高质量的成片素材**。

---

## 一、生成任务卡模板

每个镜头在生成前必须建立任务卡，所有字段填齐后才进入生成队列。

```
【生成任务卡】
镜号：03
所属幕：第二幕（核心冲突推进）
场景：室内-办公室夜景
预期时长：5秒
生成模式：图生视频（首帧参考）
参考图：角色A锚定图_v2 + 场景首帧图
Prompt摘要：中景，角色A从椅子上站起，怒视前方，冷色调侧光，慢推
优先级：P1（关键剧情镜）
依赖：无（可独立生成）
批次：第2批（同场景镜头组）
版本：v1（首次生成）
状态：待生成
```

### 字段说明

- **优先级**：
  - P0：反转镜、高潮镜、结尾悬念镜——必须最先生成并严格审核
  - P1：关键剧情镜、人物特写、情绪爆发镜——优先生成
  - P2：过渡镜、反应镜、空镜——正常生成
  - P3：补镜、备用镜——最后生成
- **生成模式**：
  - 图生视频：有角色锚定图或首帧参考时优先使用，一致性更好
  - 文生视频：无参考图的空镜、远景、过渡镜使用
- **依赖关系**：标注是否需要前一镜的末帧作为首帧参考

## 二、批次策略与生成顺序

### 2.1 按场景分组

同一场景的镜头必须同批生成，原因：
- AI生成的光影/色调在同批内更一致
- 同场景道具/空间布局在同批内更稳定
- 批量审核时同场景镜头可并排对比

**批次划分规则**：
- 每个场景为一个批次
- 单批次镜头数≤6个（超过则拆分为子批次）
- 跨场景的连续动作镜（如从室内跑到室外）单独成批

### 2.2 生成顺序

在每个批次内，按以下顺序生成：

1. **P0镜头先出**：反转/高潮/悬念镜先生成2-3个版本，确认质量基线
2. **角色出场镜第二**：每个角色在该场景的第一个镜头优先生成（建立该场景下的角色视觉基准）
3. **P1镜头跟进**：关键剧情镜按剧情顺序生成
4. **P2/P3镜头最后**：过渡镜、空镜、补镜

### 2.3 连续镜头的首帧处理

动作连续的镜头（如角色从站起→走到门口→开门），必须：
- 前一镜生成完成后，截取末帧作为后一镜的首帧参考图
- 后一镜使用图生视频模式，首帧=前一镜末帧
- 这样确保动作连贯、角色位置连续、光影不跳

**注意**：如果前一镜末帧质量差（模糊/畸变），不要直接用作首帧，先用锚定图+Prompt描述重新生成一个合格首帧。

## 三、重试与版本管理

### 3.1 每镜版本策略

- **默认每镜生成2个版本**（v1、v2），择优选用
- P0镜头生成3个版本（v1、v2、v3），增加选择空间
- P3镜头可只生成1个版本

### 3.2 不合格重试流程

```
镜头生成 → 七维审核
    │
    ├─ 合格 → 标记"终选"，进入一致性检查
    │
    └─ 不合格 → 诊断问题等级
                    │
                    ├─ 轻度（可后期修复）→ 标记"后期修复"，记录修复方案
                    │
                    ├─ 中度（调Prompt重生成）→ v2：微调Prompt（动作/光影/参考图）
                    │                              │
                    │                              ├─ 合格 → 终选
                    │                              └─ 仍不合格 → v3：换参考图/换生成模式
                    │                                                    │
                    │                                                    ├─ 合格 → 终选
                    │                                                    └─ 仍不合格 → 导演决策
                    │
                    └─ 重度（需重新设计）→ 直接进入导演决策（换景别/拆镜头/改调度）
```

### 3.3 重试次数上限

- **最多重试3次**（v1→v2→v3）
- 3次仍不合格，不再机械重试，进入导演决策：
  - 评估是否镜头设计本身有问题（AI难以生成的动作/场景）
  - 考虑拆分镜头（一个复杂动作拆成2-3个简单镜头）
  - 考虑换景别（全景改中景，减少AI需要生成的细节）
  - 考虑用剪辑技巧替代（用反应镜/特写/空镜掩盖无法生成的镜头）

### 3.4 版本命名规范

```
镜号_v1          — 首次生成
镜号_v2          — 第二次生成（微调Prompt）
镜号_v2_修复     — v2基础上做了后期修复
镜号_v3_终选     — 第三次生成，标记为最终选用
镜号_v3_备用     — 第三次生成，标记为备用
```

**禁止**：覆盖旧版本、不标注版本号、文件名混乱。所有版本保留，终选版本单独标记。

## 四、即梦平台批量操作指南

### 4.1 生成前检查清单

- [ ] 所有角色锚定图已上传至即梦素材库
- [ ] 所有场景首帧参考图已准备好
- [ ] 每个镜头的Prompt已复制到任务卡（避免生成时临时找）
- [ ] 风格引擎参数已确认（画幅/帧率/画质）
- [ ] 负面提示词已准备好（全镜通用+单镜特定）

### 4.2 批量生成操作流程

1. 按批次顺序，逐镜在 Prompt 框粘贴对应文本
2. 上传参考图（角色锚定图+首帧图）
3. 设置生成参数（时长/画幅/帧率）
4. 生成后立即下载，按版本命名规范保存
5. 同批全部生成完后，统一进入逐镜审核
6. 审核不合格的镜头，记录修复方案，进入下一轮重试

### 4.3 常见生成问题预防

| 问题 | 预防措施 |
|---|---|
| 角色换脸 | 必须用锚定图做图生视频，Prompt中重复角色面部特征描述 |
| 动作不自然 | Prompt中动作描述要具体（"缓慢站起"而非"站起"），避免复杂连续动作 |
| 场景跑偏 | Prompt中场景描述要详细（空间布局/光线/道具），首帧参考图锁定场景 |
| 光影突变 | 同场景镜头同批生成，Prompt中光影描述保持一致 |
| 多余手指/肢体 | 负面提示词加入"extra fingers, deformed hands, missing limbs"，特写手部镜头避免 |
| 口型不匹配 | 台词镜头优先用中近景（肩部以上），Prompt标注"speaking, lips moving" |

## 五、生成进度追踪表

整个生成过程用追踪表管理，实时更新状态。

```
【生成进度追踪表】
批次1（场景：办公室夜景）
├─ 镜01 P2  v1合格✅  v2备用
├─ 镜02 P1  v1不合格（动作卡顿）→ v2重生成中...
├─ 镜03 P1  v1合格✅（终选）
├─ 镜04 P0  v1/v2/v3全部生成，审核中...
└─ 镜05 P2  待生成

批次2（场景：走廊）
└─ 全部待生成

统计：已生成8/20镜，合格5镜，重试2镜，待生成7镜
```

**状态定义**：
- 待生成：已建任务卡，未开始
- 生成中：正在即梦平台生成
- 已生成待审核：视频已下载，未过七维审核
- 合格：审核通过，标记终选
- 不合格-重试中：审核未过，正在重生成
- 不合格-导演决策：3次重试仍不合格，待导演决策
- 后期修复：轻度问题，待后期处理
