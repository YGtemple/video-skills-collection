# C 类 · 道具资产生成规范（小资产卡 · 纯静物）

> 适用：所有武器、法宝、工具、信物、载具、科技装备、生活器物与关键剧情物件。道具卡为纯静物，默认四视图，次要道具可降级单图。

## C.1 道具分类（万能题材）

- **武器类**：刀 / 剑 / 枪 / 弓 / 弩 / 法器 / 激光枪 / 能量剑 / 改装猎枪
- **法宝/超凡类**：丹炉 / 符箓 / 灵石 / 魔杖 / 魔典 / 符咒 / 水晶球
- **工具类**：算盘 / 罗盘 / 相机 / 手术器械 / 工程工具 / 黑客笔电
- **信物/证物类**：玉佩 / 家书 / 戒指 / 钥匙 / U 盘 / 身份证件 / 老照片
- **载具类**：马车 / 轿子 / 老式轿车 / 摩托车 / 飞行器 / 机甲 / 义肢
- **科技装备类**：通讯器 / AR 眼镜 / 义体接口 / 无人机 / 全息投影器
- **生活器物类**：茶具 / 酒器 / 烟斗 / 打火机 / 医疗包 / 旅行箱
- **关键剧情物件**：毒药瓶 / 血书 / 半枚虎符 / 录音磁带 / 加密硬盘

## C.2 道具必填字段

**【道具名】**

**【所属分类】**（见 C.1）

**【所属角色或场景】**

**【剧情功能】**（一句话说明用途）

**【时代/世界观】**

**【尺寸与体量】**（实际可比对的尺寸描述，如：长约 80 厘米，单手可握）

**【整体形制】** 结构 / 部件 / 比例

**【材质构成】**（必须达到「可触摸」标准，参照 `scene-assets.md` A.3）

- 主体材质 ＋ 颜色 ＋ 工艺
- 次要部件材质
- 装饰镶嵌

**【工艺与年代痕迹】**

- 制造工艺（锻打 / 铸造 / CNC / 手工编织 / 3D 打印）
- 使用痕迹（磨损 / 划痕 / 血迹 / 包浆 / 氧化 / 烧灼）
- 修复痕迹（缠绳 / 补丁 / 焊点 / 胶带）

**【装饰与纹样】**

- 雕刻 / 铭文 / 符文 / LOGO / 电路纹路
- 文字内容（如有）

**【功能细节】** 机关 / 开关 / 弹匣 / 卡槽 / 指示灯 / 按钮

**【特殊状态】**（如适用）发光 / 损坏 / 沾血 / 缺失部件 / 待激活

## C.3 道具构图规范（默认四视图，可降级为单图）

**默认四视图（推荐用于关键道具）**：

- 左上：正面完整视图
- 右上：背面或反面视图
- 左下：侧视图（展示厚度与层叠）
- 右下：细节特写（展示纹样 / 铭文 / 机关 / 磨损）

**可降级单图模式（用于次要道具）**：

- 单一 45° 俯视或正面置中，纯白/浅灰背景，柔和顶光
- 仍需写明材质、工艺、年代痕迹

## C.4 道具提示词组织顺序（200-400 字）

```
[时代/世界观] ＋ [道具类别] ＋ [整体形制] ＋ [主体材质与颜色]
＋ [工艺与年代痕迹] ＋ [装饰纹样与文字] ＋ [功能细节] ＋ [特殊状态]
＋ [构图：四视图或单图]
＋ [画质：白色/浅灰背景，柔和顶光，材质纹理清晰可触，8K超精细，电影级静物摄影]
```

## C.5 道具禁止事项

- 禁止出现人物或人手（道具卡为纯静物）。
- 禁止与角色卡混用。
- 禁止空泛形容词（"精美""华丽""炫酷"必须转为具体材质工艺）。
- 禁止与世界观脱节的材质（古代道具不得出现塑料 / LED，除非剧情设定）。
- 禁止违禁色（参照 `scene-assets.md` A.4）。
