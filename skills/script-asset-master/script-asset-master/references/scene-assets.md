# A 类 · 场景资产生成规范（空镜 · 七层递进）

> 适用：所有场景/空镜资产。每条场景提示词必须由七层组成，并以第八层全局尾缀结尾，全程无人物。

## A.1 强制全局尾缀（所有场景提示词必须以此结尾，原文照用）

```
空镜，无人物，没有任何人影或人形轮廓。全场景色彩统一协调，禁止使用高饱和紫色、荧光色、霓虹色（除非题材本身为赛博朋克等强霓虹世界观，且需符合统一主色调），禁止出现与场景主色调冲突的刺眼配色。整体色调必须符合自然环境或建筑/工业材质的真实色彩关系。真人写实风格，电影画质，影视级真实材质，8K超精细，光影真实自然，物理准确的光照和阴影，材质纹理清晰可触。
```

## A.2 七层递进模板（强制遵循，每层不得跳过；第八层拼接 A.1）

### 第一层 · 世界观定位（30-50 字）

必须包含：超写实 ＋ 时代/风格 ＋ 场景类型 ＋ 题材属性 ＋ 美术风格。

- 古装示例：超写实中国古代仙山山门牌坊，仙侠修真题材，东方奇幻风格，影视概念设计
- 现代示例：超写实现代都市高层写字楼办公区，职场商战题材，冷峻写实风格，影视美术设计
- 科幻示例：超写实2087年赛博朋克城市天台，科幻末世题材，新黑色电影风格，工业概念设计

### 第二层 · 地理位置（20-30 字）

必须包含：具体地形/地段 ＋ 空间关系 ＋ 环境特征/风险。

- 古装示例：位于万丈悬崖峭壁边缘，下方深渊云海翻涌，地势险峻
- 现代示例：位于市中心金融区38层落地窗前，俯瞰立交桥车流与霓虹楼群
- 科幻示例：位于巨型企业塔楼顶层平台，下方是层叠飞行器航道与酸雨笼罩的下城区

### 第三层 · 主体建筑/场景实体细节（100-150 字，必含 6 个子项）

1. **整体形制**：建筑结构 / 空间布局 / 体量关系
2. **顶部系统**：屋顶 / 天花 / 顶棚结构 ＋ 材质 ＋ 装饰
3. **材质老化**：主体材质 ＋ 颜色 ＋ 年代痕迹 ＋ 表面细节
4. **装饰细节**：匾额 / 招牌 / 标识 / 涂鸦 / LOGO ＋ 文字 ＋ 字体 ＋ 边框
5. **营造规范/工艺标准**：
   - 古建筑：引用《营造法式》《工程做法则例》等
   - 现代建筑：引用具体建筑流派（包豪斯 / 解构主义 / 新中式 / MUJI 性冷淡风）
   - 工业/科幻：引用工艺规范（CNC 加工痕迹 / 3D 打印层纹 / 纳米涂层 / 金属冲压）
6. **基础节点**：柱础 / 地基 / 地面材质 ＋ 拼接方式 ＋ 雕刻或工业纹理

### 第四层 · 延伸空间与周边设施（80-100 字，必含 4 个子项）

1. **延伸结构**：通道 / 走廊 / 楼梯 / 管线 / 线缆 ＋ 材质 ＋ 数量
2. **中途细节**：转折处 / 平台 / 摆设 / 植物 / 设备
3. **围护与悬挂物**：栏杆 / 帘幕 / 旗帜 / 招牌 / 广告牌 / 全息投影 ＋ 状态 ＋ 文字纹样
4. **照明设施**：灯具类型（油灯 / 烛台 / 钨丝灯 / 霓虹灯 / LED 灯带 / 全息光柱）＋ 位置 ＋ 光效

### 第五层 · 自然与远景层次（60-80 字，必含 3 个子项）

1. **近景元素**：地面 / 缝隙 / 角落的植物 / 积水 / 落叶 / 垃圾 / 碎屑 ＋ 状态
2. **中景地貌或建筑群**：山石 / 建筑天际线 / 工业管道 ＋ 纹理 ＋ 侵蚀或老化状态
3. **远景大气**：云海 / 远山 / 城市天际线 / 大气层 ＋ 层次 ＋ 色彩分区 ＋ 体积感

### 第六层 · 光影与色彩系统（60-80 字，必含 4 个子项）

1. **主光源**：方向 ＋ 色温 ＋ 强度（自然光 / 灯光 / 霓虹 / 月光 / 篝火 / 激光）
2. **光线效果**：丁达尔效应 / 体积光 / 镜面反射 / 雨幕折射 / 烟雾透射
3. **天空或顶光渐变**：从上至下的色彩过渡
4. **色调关系**：冷暖对比 ＋ 明确主色调（暖金调 / 冷灰调 / 青绿调 / 金蓝调 / 品红青蓝赛博调 / 橙青末世调）

### 第七层 · 技术规格与风格参考（50-70 字）

必须包含：渲染引擎 ＋ 光照系统 ＋ 材质技术 ＋ 镜头类型 ＋ 参考作品。

- 古装参考：《长安十二时辰》《妖猫传》《卧虎藏龙》
- 现代参考：《狂飙》《白夜追凶》《繁花》《华尔街之狼》
- 科幻参考：《银翼杀手2049》《沙丘》《赛博朋克边缘行者》《爱死机》
- 民国参考：《罗曼蒂克消亡史》《风声》《邪不压正》
- 末世参考：《最后生还者》《辐射》《疯狂麦克斯》

### 第八层 · 全局尾缀

强制添加 A.1 原文。

## A.3 材质「可触摸」标准（适配万能题材；道具卡同样适用）

- **木材**：树种（楠木 / 橡木 / 松木 / 胡桃木 / 柚木）＋ 颜色 ＋ 漆面状态 ＋ 纹理走向 ＋ 年代痕迹
- **石材**：岩性（花岗岩 / 大理石 / 水磨石 / 混凝土）＋ 颜色 ＋ 表面处理 ＋ 磨损 ＋ 缝隙状态
- **金属**：材质（青铜 / 铸铁 / 不锈钢 / 钛合金 / 做旧黄铜 / 拉丝铝）＋ 氧化/抛光程度 ＋ 使用痕迹
- **玻璃**：类型（平板 / 钢化 / 夹胶 / 有机玻璃 / 全息屏）＋ 透明度 ＋ 反光 ＋ 划痕/裂纹
- **织物**：材质（丝绸 / 棉麻 / 锦缎 / 牛仔 / 皮革 / 凯夫拉 / 记忆纤维）＋ 颜色 ＋ 破损 ＋ 动态
- **塑料/复合材料**：注塑光泽 / ABS 磨砂 / 碳纤维编织纹 / 老化发黄 / 喷漆磕碰
- **电子/科技元件**：电路板蚀刻 / 散热鳍片 / LED 指示灯 / 数据线缠绕 / 全息流光
- **陶瓷/琉璃**：釉面光泽 ＋ 颜色层次 ＋ 冰裂纹 ＋ 污渍磕碰

## A.4 色彩管理规则

**通用禁止**：

- 与世界观主色调严重冲突的跳色
- 不符合时代/题材的违和配色

**题材分色调**：

- **古装/仙侠**：暖金调 / 青绿调 / 金蓝调 / 水墨灰调；修仙发光仅用低饱和幽蓝 / 淡金 / 暖白
- **现代都市**：冷灰调 / 暖橘调 / 黑白灰高级灰
- **民国**：旧照泛黄 / 茶褐 / 墨绿 / 复古胭脂红
- **科幻赛博**：品红 ＋ 青蓝 ＋ 局部酸黄霓虹（必须服从统一画面节奏，不允许全屏荧光）
- **末世废土**：橙青对比 / 沙黄 / 锈红
- **校园/治愈**：低饱和粉绿 / 米白 / 浅蓝

