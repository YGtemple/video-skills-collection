# 交付前自检清单（QA Checklist）

**自检不过，不交付。** 分四部分：规格核验（ffprobe）、能量指标（metrics.py）、人工目检、跨平台播放。
可直接复制命令执行。

---

## 1. 规格核验（ffprobe）

把 `$F` 换成成片文件名：

```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,r_frame_rate,nb_frames,codec_name,pix_fmt,profile \
  -of default=noprint_wrappers=1 "$F"
ffprobe -v error -select_streams a:0 \
  -show_entries stream=codec_name,sample_rate,channels,channel_layout \
  -show_entries format=duration -of default=noprint_wrappers=1 "$F"
```

必须满足（当前片单）：

| 项 | 要求 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 30fps（`r_frame_rate=30/1`） |
| 帧数 | 900 |
| 视频编码 | h264 / profile High |
| 像素格式 | yuv420p |
| 音频编码 | aac |
| 采样率 / 声道 | 48000Hz / 2（stereo） |
| 时长 | **精确 30.000000s** |

### faststart（网页 / 手机边下边播）

- 编码时已带 `-movflags +faststart`（moov atom 前置）。
- 快速核对：`ffmpeg -v trace -i "$F" 2>&1 | grep -m1 "type:'mdat'"`，mdat 之前应已出现 moov；
  或直接在网络差的手机浏览器里打开，能立刻起播即正常。

## 2. 能量指标（metrics.py）

```bash
python3 metrics.py
```

| 指标 | 含义 | 阈值（朋克片单） |
|---|---|---|
| 平均帧差 | 相邻帧平均像素变化，衡量"整片是否在动" | **≥ 6** |
| 连续静止帧占比 | 属于"连续 ≥3 帧（0.1s）几乎无变化"的帧比例 | **≤ 10%** |
| 黑 + 红面积 | 近黑与朱红像素的平均占比，衡量对比 / 情绪浓度 | **≥ 12%** |

本片实测：平均帧差 7.92、静止帧 5.78%、黑+红 27.75%，三项 PASS。

判读静止帧时注意区分：
- **意外静止**（缺运动、滤镜 seed 没换）→ 要修；
- **表达性静止**（失败弹窗定格、结尾黑场）→ 刻意保留。

### 换风格时必须重定义阈值

- "黑+红面积"是**朋克片单专属**：暗底风格（赛博）天然大面积黑、水彩几乎没有纯黑与朱红，
  原阈值会失真甚至永远 FAIL。
- 换风格时按新风格的关键色 / 期望对比重写这条指标，并相应调整帧差 / 静止帧目标。

## 3. 人工目检（抽关键帧）

从成片抽若干时间点，拼成联系表一次扫完：

```bash
for t in 1.1 3.6 5.9 7.1 9.6 12.9 15.3 16.7 18.6 20.4 22.6 23.7 25.6 28.0 29.4; do
  ffmpeg -v error -ss $t -i "$F" -frames:v 1 qc/q_$t.png
done
```

逐项核对：

- [ ] 所有文字 / 印章 / 大标题**完整不被切**，在安全区内（警惕双重 translate 推出画面，见 P3）；
- [ ] 仪表数字 **37 / 64 / 88 / 99 / 100%** 正确，99% 在发抖、100% 有通过印章；
- [ ] 图标造型正确、目标物与干扰物区分得清；
- [ ] 定格 / 静音、闪白、推镜、集中线等五件套在对应时刻出现；
- [ ] 开场黑场只在最前极短时间，不遮正片（见 P6）；
- [ ] 结尾署名正常（本片为 "由 Doubao 在30秒内用纯代码制作完成"）。

## 4. 跨平台播放确认

要能在 Windows、macOS、iPhone、安卓、抖音、微信直接播放，关键就三点（已在编码里保证）：

1. **H.264 + yuv420p**：兼容性最广的视频组合（避免 High 10-bit / 异形像素格式）；
2. **AAC 音频**：全平台硬解支持；
3. **+faststart**：网页 / 手机可边下边播。

有条件时在至少一台手机 + 一个社交平台（抖音 / 微信）各播一遍，确认有声、不卡、比例正确、起播快。

---

## 5. 交付前 30 秒总检查

1. 输入 / 规格：ffprobe 九项全对、时长精确；
2. 指标：三项（或新风格对应指标，见 [restyling-guide](restyling-guide.md) 风格库）全 PASS；
3. 画面：联系表目检无文字出界、数字正确、署名在；
4. 声音：峰值 −1dBFS 不破音，重击清晰，无意外静音；
5. 旁白（若有）：人声清晰居中、配乐 ducking 不盖人声、无句顶破 30s，旁白版/无旁白版齐全；
6. 播放：手机 + 社交平台各验一遍。

全部打勾，再交付。

> 合规：本流程不启动任何 VPN / 代理软件，不依赖 GitHub 推送；归档与交付均为本地操作。
