# 通用 Prompt · 《AI 大战验证码》30 秒代码动画

> 用法：把下面整段（从「任务」开始）复制给任何能写代码、能跑命令的 AI 编程助手，例如 Claude Code、Codex、Cursor 的 Agent 模式。
>
> 运行环境要装好：Node.js 18+、Google Chrome（或 Chromium）、Python 3（带 numpy、scipy）、ffmpeg。
>
> 不需要任何图像、视频或音乐生成模型。

---

## 任务

只用 HTML + SVG + JavaScript 画一支 30 秒的横屏动画短片《AI 大战验证码》。用无头浏览器逐帧截图，用代码合成声音，最后用 ffmpeg 合成 MP4。

**故事：** 一个鼠标光标（AI）想通过「我不是机器人」验证。它先是点得太快被识破，于是学着装成人类，一路过关，最后露出真面目。

**笑点：**
- 越是机器，越要证明自己是人；
- 结尾把「我不是机器人」里的「不」划掉。

## 一、硬规格

- 画面：1920×1080 横屏，30fps，**正好 30 秒 = 900 帧**，文件命名 `frame_0000.png` … `frame_0899.png`。
- 成片：H.264（High profile）/ yuv420p / AAC 48kHz 立体声 / `-movflags +faststart`。要能在 Windows、macOS、iPhone、安卓、抖音、微信里正常播放。
- 画面**只能**用 HTML + SVG + JS 绘制。不要用 Canvas 录屏，不要用图片素材，不要用任何生成模型。
- 声音**只能**用代码合成（Python numpy 或 WebAudio），不要真实采样，不要有版权的音乐。
- 不放人物形象，主角是**鼠标光标**。

## 二、必须遵守的技术做法（决定成败）

1. **只用一个纯函数 `render(t)` 画画面**：输入秒数 t，画出那一刻的整帧。同一个 t 必须永远画出同一帧。
   - render 里禁止出现 `Math.random`、`Date`、CSS animation 或 transition、`requestAnimationFrame`。
   - 随机效果用确定性哈希，例如 `h(n) = frac(sin(n*127.1+311.7)*43758.5453)`。
   - 所有 SVG 元素在加载时建好一次，`render(t)` 只改属性、只切换显示和隐藏。
2. **只有一张时间表**：所有事件的秒数写在一个 `timeline.js` 的常量表 `T` 里，画面和音效都从这里取时间，不在别处写死秒数。
   - 页面上暴露 `window.SFX_CUES`（音效列表），渲染脚本把它导出成 JSON，交给合成音效的 Python 脚本。
3. **逐帧渲染**：用 Playwright（或 Puppeteer）打开本地 `index.html`，视口 1920×1080。对每一帧执行 `render(i/30)`，然后截图。
   - 开 4 个页面并行渲染；
   - 字体全部加载完之后才开始截第一张（`document.fonts` 每个都要是 `loaded`）。
4. **字体只用本地开源字体文件**，用 `@font-face` 声明，放在 `fonts/` 目录：
   - 中文粗海报体：ZCOOL QingKe HuangYou；
   - 中文毛笔体：ZhiMangXing；
   - 英文马克笔：Permanent Marker；
   - 英文窄粗海报：Anton。

   都可以从 github.com/google/fonts 下载。字体族名不要叫 `serif` 这类 CSS 通用关键字，否则会失效。
5. **图层顺序就是创建顺序**，先建的在下面。压暗层要在结尾字下面，闪白、黑场、纸纹放最上面。
6. **定格**：把时间钳住（`tt = 定格中 ? 定格起点 : t`），线条抖动也要用 `tt`，否则定格时画面还在动。
7. **声画同步**：每个音效的时间都引用 `T.xxx`。
   - 呼啸、上升音这类「在命中那一刻到顶」的声音，要让它的**结束点**对准命中时刻。
   - 音频长度必须正好 30.000 秒。
8. **合成命令参考**：
   ```
   ffmpeg -framerate 30 -i frames/frame_%04d.png -i sfx.wav -c:v libx264 -preset slow -crf 19 \
     -maxrate 16M -bufsize 32M -profile:v high -pix_fmt yuv420p -r 30 -c:a aac -b:a 192k -ar 48000 \
     -t 30 -movflags +faststart out.mp4
   ```

## 三、视觉风格：90 年代朋克地下杂志拼贴

- **配色：** 只用三色加少量点缀。
  - 暖米黄纸 `#efe2c2`（深一档 `#e4d2a8`）
  - 近黑墨 `#1b1410`
  - 朱红 `#d7261e`
  - 米白 `#f5ebd2`
  - 点缀橙 `#f2781f`
- **质感：**
  - 线条：粗黑描边，手绘不规则线条；
  - 线条沸腾：给元素组挂 `feTurbulence + feDisplacementMap` 滤镜，每 3 帧换一次 seed；
  - 纸：粗糙纸纹叠在最上层，每 3 帧移位一次；
  - 拼贴：撕纸黑边、胶带、网点、斜线排线、硬投影（同形状的黑块偏移 14–20px）；
  - 漫画元素：爆炸框、集中线、速度线。
- **大字：** 150–300px，描边宽度约为字号的 1/14，用 `paint-order: stroke`，背后可以衬爆炸框或底框。
- **要避免：** 赛博朋克、霓虹、3D、光滑渐变、AI 光效、现代企业 UI、照片。
- **能量要炸（片头级）。每个重点冲击在同一帧叠 5 件事：**
  1. 主体 0.08–0.12 秒到位：弹入用过冲缓动 backOut；盖章从 2.2 倍砸到 1 倍；
  2. 震屏：幅度 6–44px，按 `exp(-9t)` 衰减；
  3. 闪白 0.07–0.1 秒，或镜头从 1.12–1.18 倍推回 1 倍；
  4. 爆炸框、集中线、速度线，任选；
  5. 重击音效。

  事件之间不能有死帧：每 0.5 秒至少有一个可见变化，定格只用在「验证失败」那一处。
- **自检目标：** 用逐帧差分量一下成片。
  - 平均帧差（缩到 160×90 后逐像素差的均值）≥ 6；
  - 连续 0.1 秒以上完全静止的帧 ≤ 10%；
  - 黑色加红色的面积 ≥ 12%。

## 四、主角与舞台

- **主角 · 鼠标光标：**
  - 外形：黑色箭头，米白描边，红色硬投影；
  - 要演：从天上掉下来，落地时挤压回弹，发抖，分身，绕圈，探头。
- **舞台 · 手绘的「人机验证」界面：**
  - 左侧黑卡写题目「请选出所有 ××」，下方是红色「验证」按钮；
  - 右侧是图片网格，依次为九宫格 → 4×4 → 6×6 → 16×16；

## 六、声音

**音效：** 全部用 numpy 合成，每个可见冲击对应一个音效，gain 0.6–1.0，同一瞬间最多叠 3 个。需要的音色：
- 呼啸、甩入、鞭声：带通噪声，中心频率上扫；
- 啵、点击、滴答；
- 闷响：低频正弦下滑；
- 重击、重砸：低频下潜 + 噪声爆裂 + 尾音；
- 爆开、盖章（闷击 + 纸面拍打）、啪；
- 咚（木块）、弹簧声、咔嚓；
- 数字故障声、电流嗡声（60Hz 谐波 + 噼啪）；
- 叮（钟声泛音）、错误蜂鸣（低沉双音方波）；
- 撕纸、镲片、连续打字声；
- 上升音：噪声加正弦一起上扫。

0 秒起铺一条极低的房间底噪。混音加软限幅，峰值 −1 dBFS，时长正好 30 秒。

**配乐（二选一）：**
- **A 版，只有音效：** 最干净，适合当片头钩子。
- **B 版，加代码合成配乐：** 120BPM，正好对上 0.5 秒网格。用锯齿波做失真和弦，加鼓组，按段落切换风格：

  | 段落 | 风格 |
  |---|---|
  | 开场 | 大和弦 + 半速 |
  | 九宫格 | 车库朋克 |
  | 「杆子算吗」 | 只剩闷音和踩镲，制造紧张 |
  | 4×4 | 车库朋克 |
  | 分身、满屏 | 双倍速 |
  | 验证失败 | **真静音**，从满音量掉到完全无声 |
  | 「装成人类」 | 慵懒爵士（Cmaj7–Am7），做反差笑点 |
  | 钻层 | 双倍速 |
  | 99% | 上升音悬停 |
  | 验证通过 + 跳切 | 双倍速 |
  | 结尾 | 静音一拍后，E 和弦长鸣 |

## 七、交付前自检（必须做完再交）

1. **规格：** 用 ffprobe 确认 1920×1080、30fps、900 帧、h264、yuv420p、aac、时长 30.000 秒。
2. **抽帧检查：** 从成片抽这些时间点的帧：1.1、3.6、5.9、7.1、9.6、12.9、15.3、16.7、18.6、20.4、22.6、23.7、25.6、28.0、29.4 秒。逐张看：
   - 文字有没有被切出画面；
   - 有没有被别的层盖住；
   - 中文有没有变成系统兜底字体（缺字）；
   - SVG 有没有黑块或滤镜裁切；
   - 数字（37/64/88/99/100%）对不对；
   - 署名是否完整。
3. **声画同步：** 在 1.0、7.0、15.0、23.5、27.6 秒附近检查音频起音，前后误差不超过 1 帧。
4. **冲击力：** 平均帧差、死帧占比、黑红面积达到第三节的目标。
5. **重做：** 发现问题就改 HTML / SVG / JS，重新渲染，直到全部通过。

最终交付 `AI大战验证码-1920x1080-30fps.mp4`；做了 B 版就另外交一个 `-配乐版` 文件。
