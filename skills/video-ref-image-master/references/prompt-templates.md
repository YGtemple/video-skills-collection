# 提示词模板库

按场景分类的参考图视频提示词模板，使用时替换方括号内容。

## 角色+场景双参考（最常用）

```
[年龄段+性别+体型]，[发型颜色长度样式]，[脸型+面部特征+表情]，
穿着[服装款式颜色细节]，[配饰/标志性特征]，
位于[具体场景空间]，[主要物体布局]，
[光线方向强度色温]，[整体色调氛围]，
[具体动作/表情变化]，[镜头运动方式]，
[美术风格]，[画质描述]
```

## 纯角色参考（角色特写/动作）

```
[年龄段+性别]，[发型]，[面部特征]，穿着[服装]，
[背景环境简述]，[光线]，
[动作描述]，[镜头角度]，
[风格]，电影级光影，高细节
```

## 纯场景参考（空镜/环境展示）

```
[空间类型]，[主要物体和布局]，[时间/天气]，
[光线方向和色温]，[整体色调]，[氛围描述]，
[镜头运动：缓慢推镜/横移/固定]，
[风格]，电影级质感
```

## 多人场景

```
[人物A描述]和[人物B描述]，
位于[场景]，[两人相对位置和互动]，
[光线]，[色调]，
[动作/对话状态]，[镜头]，
[风格]
```

## 常见风格关键词

- 国漫青春半写实：`国漫青春半写实风格，暖色调怀旧，电影级光影`
- 日系动画：`日系动画风格，清新明亮，赛璐璐上色`
- 写实电影：`写实电影风格，胶片质感，浅景深`
- 赛博朋克：`赛博朋克风格，霓虹灯光，高对比冷色调`
- 古风：`中国古风风格，水墨晕染，暖黄灯光`

## 镜头运动关键词

- 缓慢推镜：`slow push-in` / `缓慢向前推镜`
- 横移：`slow pan left/right` / `缓慢横移`
- 固定：`static shot` / `固定镜头`
- 环绕：`slow orbit` / `缓慢环绕`
- 跟拍：`tracking shot` / `跟随拍摄`
- 仰拍/俯拍：`low angle` / `high angle`
