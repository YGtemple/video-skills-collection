图生视频时，让生成结果严格遵循参考图的每一个细节。

## 核心原则

参考图不是"灵感"，是"约束"。生成视频前必须先把参考图拆解为可被视频模型理解的精确描述，再写入提示词。

## 工作流程

### Step 1: 参考图分类与优先级

先判断用户给的图属于哪类，按优先级处理：

| 类型 | 优先级 | 作用 | 示例 |
|------|--------|------|------|
| 角色设定图 | P0 | 锁定人物外貌、服装、发型 | 人物立绘、角色三视图 |
| 场景图 | P0 | 锁定环境、建筑、氛围 | 教室、街道、室内场景 |
| 道具/关键物品 | P1 | 锁定特定物品外观 | 草稿纸、手机、武器 |
| 分镜/构图参考 | P1 | 锁定镜头角度、构图 | 参考剧照、分镜稿 |
| 风格参考 | P2 | 锁定美术风格 | 画风参考、色调参考 |

多图同时存在时，**角色图和场景图必须同时写入提示词**，不能只写一个。

⛔ **本步暂停确认**：把参考图分类 / 优先级清单（哪张是 P0 主参考、哪张辅助）给用户确认后，再进入深度拆解。

### Step 2: 参考图深度拆解（必做）

对每张参考图，按以下维度逐项拆解，写入提示词：

**角色图拆解清单：**
- 性别、年龄段、体型
- 发型（颜色、长度、样式）
- 面部特征（脸型、眼睛、表情）
- 服装（款式、颜色、细节、污渍/破损）
- 配饰（眼镜、首饰、背包等）
- 肤色、标志性特征（伤疤、痣等）

**场景图拆解清单：**
- 空间类型（室内/室外、具体场所）
- 主要物体和布局
- 光线（方向、强度、色温——暖光/冷光/逆光）
- 色调（整体偏暖/偏冷/高饱和/低饱和）
- 氛围（空旷/拥挤、明亮/昏暗、整洁/凌乱）
- 时间感（白天/黄昏/夜晚）

**关键规则：拆解出的每个细节都必须在提示词中出现，不能"心里知道但不写"。视频模型不会自动继承图片信息，必须用文字明确描述。**

### Step 3: 提示词结构化编写

按固定结构组织提示词，确保参考图细节不丢失：

```
[主体描述] + [服装细节] + [场景环境] + [光影色调] + [动作/镜头] + [风格约束]
```

**示例（角色+场景双参考）：**
```
一个15岁左右的初中男生，黑色短发略凌乱，脸型偏瘦，眼神淡漠，
穿着蓝白相间的校服，袖口和肩部有明显污渍，
坐在空旷教室的最后一排靠窗位置，课桌上堆满草稿纸，
夕阳从左侧窗户斜射进来，金色光束中有浮尘，整体暖色调怀旧氛围，
少年低头伏案演算数学题，笔尖在纸上移动，
国漫青春半写实风格，电影级光影
```

**禁止写法（会导致参考图丢失）：**
- ❌ "参考图片生成视频"（模型不知道参考什么）
- ❌ "一个男生在教室里"（细节全丢）
- ❌ 只写角色不写场景，或只写场景不写角色

### Step 4: 多图参考的组合策略

当用户同时提供角色图和场景图时：

1. **角色图** → 提取人物全部细节，写入提示词前半段
2. **场景图** → 提取环境全部细节，写入提示词中段
3. **道具图** → 提取物品细节，在动作描述中明确出现
4. 如果有多张角色图（不同角度），综合描述，标注"多角度一致"

### Step 5: 跨镜一致性保障

多片段/多分镜生成时：

1. **第一个片段**：完整写入角色+场景全部细节
2. **后续片段**：重复角色核心特征（发型+服装+脸型），场景可简化但必须出现
3. 每个片段的提示词中，角色描述**不能省略**，即使上一片段已经写过
4. 服装变化必须在提示词中明确说明，否则模型会自动保持

## 常见问题与修复

| 问题 | 原因 | 修复方法 |
|------|------|----------|
| 角色变脸/换发型 | 提示词中角色细节不足 | 补充发型、脸型、年龄等具体描述 |
| 服装颜色/款式变化 | 服装描述太笼统 | 写明颜色、款式、材质、细节 |
| 场景漂移/环境变了 | 场景描述缺失或太简单 | 补充空间类型、物体布局、光线方向 |
| 色调不一致 | 未指定光影和色调 | 明确写"暖色调"/"冷色调"/"夕阳逆光"等 |
| 人物比例失真 | 未指定年龄/体型 | 写明"初中生""成年人""瘦高"等 |
| 关键道具消失 | 道具未写入提示词 | 在动作描述中明确道具出现 |

## 与视频生成工具的配合

⛔ **交视频前暂停确认**：把完整视频提示词（含 @ 引用的用户参考图与全部拆解细节）先展示给用户，用户确认后才调用视频模型逐批生成；AI 不在此步代出任何参考图 / 定稿图。

- 使用 `image_to_video` 时，参考图通过 `image_reference_url_list` 传入，同时提示词中必须包含图的文字描述
- 参考图数量建议 1-3 张：1张角色+1张场景为最佳组合
- 角色一致性要求高时，优先使用角色图作为主参考图，场景图作为辅助
- 生成后如发现细节丢失，**不要只说"重新生成"**，要在提示词中补充丢失的具体细节后再生成

## 三维控制参数指针

> 三大控制维度（风格化 / 怪异度 / 多样性，对应 MJ `--stylize` / `--weird` / `--chaos`+`--seed`）的取值档位**以资产模板与 `script-asset-master` 为准**；本技能的目标是**锁定参考图与角色一致性优先**——发现漂移时**不要靠提高 chaos/多样性/怪异度去"碰运气"**，而应补全角色细节描述、固定 seed 并回落多样性。

## 边界

本技能专注于技术层面的参考图遵循度优化，通过精准提示词和结构化分析提升一致性。不涉及、不尝试绕过任何内容安全或平台使用限制。
