## 一、技术规格

| 项 | 规格 |
|---|---|
| 成片时长 | 5–6 分钟 |
| 视频单元 | 11–12 个，每个 **30 秒（必须满 30 秒）** |
| 每段分镜 | 约 **12 个** |
| 视频模型 | **Seedance 2.5** |
| 资产图模型 | **Seedream 5.0**（出图≠出片） |
| 画幅 / 分辨率 | 16:9，1280×720，30fps |
| 编码 | H.264 + AAC |
| 影像风格 | 贾樟柯式纪实：低饱和、褪色发灰、16mm 胶片颗粒、纯自然光、粗粝真实、真实东亚面孔与年代装束 |
| 默认声音 | 无 BGM、无外挂字幕/台词条/标题/花字/水印 |

## 二、分镜片段模板：镜头语言 / 情绪总述

每个 30 秒片段开头先写一段总述，**情绪层次不少于 4 层**，覆盖：
1. **调度**：人物站位、谁进画谁出画、群体位置；
2. **运镜**：景别、角度（俯/仰/平）、镜头运动（推/拉/摇/移/跟）；
3. **光影**：具体时间、光位、色温、光质、阴影；
4. **叙事意图 + 人物内心**：这一段推进什么、人物当下的心理与情绪。

> 场景开场不直接给特写：先用环境空镜建立，再以高空俯拍 → 贴近侧面 → 缓慢上摇 → 透过前景定格主体的方式入场；多用创造性转场。

## 三、台词模板：台词前标情绪

每句台词前用（）写明人物当下情绪与内心活动：

```text
（暴怒，指着对方）把人放开！
（扑通跪下、撕心裂肺地喊）求求你们，放过孩子！
（含泪却用尽全力喊）金珠玛米——！
```

## 四、视频提示词必写要素

1. **具体时间**：清晨 / 上午 / 正午 / 黄昏 / 夜；
2. **光照**：太阳方位与高度、色温、光质（硬/软）、阴影方向；
3. 声明「**不照抄参考图中的太阳位置**」；
4. **禁用首帧 / 关键帧**：只传角色/场景/道具资产图作外观参考，动作与硬切由脚本驱动；段间不喂上一段末帧；
5. **人物完整**：该段要出现的所有人物与场景元素必须完整出现，不遗漏、不让角色无故消失；
6. **渲染**：开启光线追踪与全局环境光照 GI，真实间接光、软阴影、环境遮蔽；玻璃/积水/金属反射折射准确；
7. **空气感**：极细微尘埃与薄雾，光线穿过形成体积光/光束与轮廓光；近实远虚、拉开前后纵深。

## 五、台词与声音风格

- 台词**全部大声、有爆发力**：怒斥、呐喊、号令、控诉、欢呼、孩子哭喊；
- 随片由视频模型**同期一次生成**，不单独生成音频、不后期合成；
- 语速自然、流畅、利落，接近日常说话，不拖音、不做过长停顿（平静克制 ≠ 语速慢）；
- 仅剧情必需处个别低声（如弥留、自语、结尾稚嫩轻呼）。
