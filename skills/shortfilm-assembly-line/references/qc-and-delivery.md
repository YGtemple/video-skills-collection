# 自检、配乐、目录与交付

## 目录
- 一、自检与重生成清单
- 二、（可选）原创配乐与混音
- 三、目录结构约定
- 四、交付规范

## 一、自检与重生成清单（每段必做）

**1. 时长**：ffprobe 核验 ≈ 30.0 秒，不足即重生成。

**2. 抽帧**：每段 12 帧 + 每秒 1 帧共 30 帧密检。

**3. 逐项目视**：
- 开场是否**首帧即冲突**（有无空镜/空账房拖沓）；
- 敌我装束是否可辨、有无帽徽/钢盔错位串色；
- 有无烧入字幕 / 乱码文字 / 现代物件；
- 人物是否完整、有无无故消失；
- 有无肢体穿模、黑场、白雾/粉尘遮屏；
- 空间方位、攻防因果是否连贯；
- 台词是否大声清晰、同期生成。

**4. 音频**：True Peak 无削波；记录 Integrated LUFS。

**5. 处置**：不合格**自行多次重生成**，无需询问；自检帧放独立「自检帧」文件夹；**弃用版本全部保留不删**。

> 实战参考：金珠玛米重制版重生成 8 段/10 次（烧字幕 6、武器钢盔穿帮 2、契约汉字 1、白雾遮屏 1、开场偏慢 1）；解放东北生成 17 版/弃用 5 版（U10 历经 5 版）。

## 二、（可选）原创配乐与混音

仅当用户明确要求配乐时执行；无声版始终保留。

- 用文生音频工具分段生成**无字吟唱 / 纯器乐**（单条 ≤120 秒），避免版权；
- 含吟唱片段可用语音转写链路核查「transcript empty」，确认无歌词、无人声；
- 情绪线索按剧情分段（悲怆 / 清冷 / 进军 / 战争 / 温暖 / 紧张 / 终曲）；
- 混音做 **ducking**：配乐给台词与战争音效让位，台词与配乐 RMS 差值约 12–23 dB；
- 目标响度参考：Integrated 约 **-15.5 ~ -18 LUFS**、**True Peak ≤ -1 dBTP**，无削波；
- cue 边界 2–3 秒淡入淡出，保留必要留白；无声版与配乐版分别成片、互不覆盖。

## 三、目录结构约定

```text
<留底盘>:\短剧项目\<片名>\
   剧本\        （梗概/角色/世界观/分场/剧本）
   资产图\      （角色/场景/道具 + 对比图 + 方位图）
   视频单元\
   自检帧\      （独立文件夹）
   成片\
   提示词\
   考据\
```

- 成片、资产、中间产物**一律保留不删**，被新版本取代也留档；
- 产物默认不放系统盘，按用户指定盘/目录留底。

## 四、交付规范

- 成片上传**在线直链**，经 `present_files` 上屏（内嵌播放器直接预览）；本地 mp4 仅留底；
- 交付前用 `verifier-hub` / `artifact-preview` 校验：
  - 双副本哈希一致；
  - 成片独立抽帧复核（各段中点 + 开场逐秒 + 关键道具/红旗特写）；
  - 在线直链实测返回 **206 video/mp4**、可正常播放；
  - blackdetect 无黑场。
- 每部交付清单：成片直链 ＋ 剧本五件套（梗概/角色/世界观/分场/剧本）＋ 资产清单 ＋ 分镜提示词 ＋ 自检记录；
- 多部并行时**完成一部交付一部**，最后汇总。
