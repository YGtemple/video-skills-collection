## 一、军装 / 帽徽按年代（不得张冠李戴）

| 时间 / 题材 | 帽徽 · 胸章 | 标志性装束 |
|---|---|---|
| 辽沈 / 淮海 / 平津（1948.11–1949.1） | **无统一红五星帽徽、无胸章**（全军统一帽徽 1948 年 12 月之后才逐步推行） | 东野**狗皮帽**为图腾；华野/中野多戴棉帽 |
| 进军新疆 / 西藏（1949 年底—1951） | 建国后戴**红五星帽徽 +「中国人民解放军」胸章**（50 式前后） | 土黄/草绿棉军装、绑腿 |
| 凉山民主改革（1956） | 50 式 / 55 式换装期，按具体年份 | 1955 授衔后为 55 式 |
| 云南（1950–1958） | 早期 50 式、后期 55 式，按年份 | 民族工作队与解放军并存 |

**旗帜与字样处理**
- 为避免「八一」等字生成乱码：建制部队**不做持旗 / 帽徽特写**；
- 群众迎接场景使用**只含五角星图形、无文字**的红旗。

## 二、敌我各方装束（配合并排对比图，每战必传）

- **解放军 / 工作队**：土黄/草绿/灰布棉军装、棉帽或狗皮帽、绑腿、棉手闷子、三八式步枪、干粮袋；
- **国民党军**：美式钢盔 / 大檐帽、卡其装、军靴；
- **还乡团**：黑棉袄；
- **中央胡子 / 乌斯满匪**：光板皮袄、匪刀、骑匪；
- **藏军（金珠玛米）**：黑/暗红/深褐藏袍袒臂束腰、黑绒盘帽或英式遮阳盔、带叉架叉子枪、长藏刀、嘎乌护身符。
  - 关键：**藏军本无统一军装**，勿用「英式卡其」与我军撞色；战场主体为黑袍藏兵。

**教训固化**：「敌方群像参考图」会把**钢盔等特征外溢到我方**——对比图与提示词需显式隔离，分别描述各方，避免特征串色。

## 三、战场空间与方位图

固定一张地理方位图，明确上下前后：
- 固定**进攻方向与机位朝向**（例：我军自东/画面右下向西/左上打、敌据左上高地、我在右下低处）；
- **江河走向**、起渡/抢滩方向、爆破组抵近路线一次锁定；
- 攻坚：正面牵制 + 爆破组沿沟右下→左上抵近。

**完整攻防因果链**：
侦察发现火力点 → 火力压制 → 起渡 / 跃进 → 爆破 / 突破 → 白刃 → 敌溃逃 → 追歼。

**拍摄手法**
- 肉搏用**中景短切**、爆炸以**烟尘遮挡**，规避肢体穿模；
- 光线连续（清晨冷调 → 上午 → 正午 → 午后，色温逐段标注）；
- 史实核对（例：**昌都县城本身未发生战斗**，拍外围山地碉堡攻坚）。

## 四、文字道具规则

- 卖身契 / 地契 / 账本 / 票据 / 路牌须符合年代与民族文字（如藏文契约：藏纸做旧、朱红指印/私章）；
- 通过**手部遮挡、焦外、快速硬切**规避乱码；
- **严禁**：现代简体汉字、拉丁字母、乱码方块、现代物件（塑料、拉链、现代标牌、钢盔错位等）入画。
