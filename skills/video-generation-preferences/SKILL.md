# 用户视频生成硬约束

## 🏷️ 技能分类标识

> **归属类别**：【通用跨类型】（用户硬约束/规范底座层，不决定画风，**所有视频任务生成前必读**，真人与漫剧任务一律适用）
>
> - **🎬 典型任务场景**：任何文生视频/图生视频/AI 视频/短剧/动态漫/广告/口播生成任务开始前——作为全局规范底座被读取，校准字幕/BGM/提示词展示/@参考图/路径等硬约束。
> - **🚫 不适用场景**：本技能不下发剧本、分镜、资产提示词或执行生成；具体创作路由交给 `video-master-suite` 总控分派到各子技能。
> - **🔗 上下游 / 推荐搭配**：**本技能**是所有视频任务的规范底座 → 约束下游〔`video-master-suite` 及其路由到的全部生成子技能〕。
> - **🧭 与相邻技能的边界**：本技能只承载"用户固定制作规范"，不做任务路由、不产内容；路由由 `video-master-suite` 负责。
> - **📦 标准三件套产出职责**：本技能是**三件套的规范底座**（约束①②③及最终成片的无字幕/无BGM/无TTS/@引用规范），不单独产①②③。
> - **⚠️ 本用户固定规范**：成片无字幕、无 BGM、禁用 TTS（台词由视频模型直接生成）；生成前先展示完整提示词；人物图必须 @ 引用、强制图片参考不纯文字生成人物。


**每次生成视频前，必须读取并遵守本技能中的全部规则。**

## ⛔ 阶段门控与全资产用户自制（最高交互范式）

> 标准范式全文：`/home/user/Doubao/chats/38436370915409154/_工作规范/阶段门控总则（标准范式）.md`。本底座的规则与该范式叠加生效。

1. **禁止自动端到端跑完整制作**；每个阶段结束 **⛔ 暂停 → 给选项（亮点 / 利弊 / 推荐）→ 等用户明确确认**才进入下一阶段。
2. 门控节奏：故事发散（AI 给 3–5 差异化方向）→ 人物 / 资产方案选择（用户确认）→ **全部资产由用户本人生成并回传、逐项确认** → 才进入视频生成 → 后期逐项确认。
3. **所有进入成片的美术资产（角色 / 场景 / 道具 / 关键画面 / 分镜参考图）由用户本人生成**；AI 只给两套提示词（通用 + MJ）、三维参数、资产清单 / 顺序、制作建议，**不调用文生图替用户产出定稿资产**；确需示意图须先征得用户明确同意。
4. 钩子必须是**看得见的具体画面**、关联核心矛盾，不靠旁白 / 台词 / 字幕 / 标题；剧情按**因果链 A→B→C** 推进。
5. 视频生成（T2V / I2V）仍由 AI 在资产确认后、展示完整提示词并经确认执行。

## 1. 无字幕

- 视频画面中**不得出现任何字幕、文字叠加、caption、lower-third、花字、贴纸文字、标题文字或画面内文字**。
- 即使用户 brief 中提到"字幕""台词显示""旁白文字"，也默认不生成画面字幕。
- 口播/旁白台词只作为声音轨（audio voiceover）存在，**不得映射为画面文字**。
- 若用户本轮明确要求加字幕，才允许加；否则一律不加。

## 2. 无 BGM

- 视频**不得包含任何 BGM 背景音乐、配乐、鼓点、节奏音效或环境音乐**。
- 仅保留自然环境声和必要的人物同期声。
- 即使用户 brief 中提到"动感音乐""节奏鼓点""背景音乐""BGM"，也默认不加，除非用户本轮**明确口头要求加音乐**。
- 分镜表中声音字段默认写"无 BGM，仅环境声 + 同期声"。

## 3. 生成前必须展示完整提示词

- 每次调用视频生成工具前，**必须向用户展示完整、详细的视频提示词**（用代码块逐字展示，保留换行和符号）。
- 同时展示：模型、时长、比例、参考素材列表、是否无字幕无 BGM。
- 等待用户明确确认后，才能调用视频工具。
- 不得跳过确认直接生成。

## 4. 人物图片必须 @引用

- 用户提供的人物图片，**必须在提示词中以 `@image1`、`@image2` 等方式明确标注引用**。
- **强制使用图片参考，不得纯文字凭空生成人物。**
- 每个需要出镜的人物镜头都要复述核心外观锚点（脸型、发型、服装主色、年龄感等），防止人物漂移。

## 5. 禁用 TTS 与一切语音合成

- **禁用 TTS 及一切语音合成**：角色对话、内心独白、画外音、旁白等所有台词，必须由视频生成模型在生成视频时直接产出语音，**不得**事后用 TTS/语音合成工具补配音。
- 提示词中按 `角色A说："台词内容"` 写出完整台词。
- 生成的视频没有语音时，**只改提示词重生成**，不用 TTS 补救。

## 6. 素材与产物路径

- 剪映项目文件默认保存到用户 D 盘 `剪映素材` 文件夹。
- 所有视频/音频素材也放在该目录下。
- 所有最终产物文件保存到 `D:\豆包产物` 目录，不要存 C 盘。

## 调用前自检清单

每次调用视频生成工具前，逐项打勾：

- [ ] 提示词中明确写了"无字幕、无文字叠加"或等效约束
- [ ] 提示词中明确写了"无 BGM、无背景音乐"或等效约束
- [ ] 已向用户展示完整提示词并获得确认
- [ ] 人物图片已在提示词中 @imageN 引用
- [ ] 时长、比例已确认
- [ ] 素材路径符合 D 盘规范

任一项不满足，不得调用视频生成工具。
