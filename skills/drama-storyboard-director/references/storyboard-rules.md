# 分镜脚本完整规则手册

## 一、总任务目标

### 时长控制
- 按「15秒一个独立段落」标准拆分
- 每段秒数从1开始计数，到15秒结束（独立重置，不延续上一段）
- 不足15秒仍按独立段落处理，不合并不凑数

### 拆分规范
- 优先保证语义连贯、剧情完整
- 不破坏原文逻辑、不删减核心信息、不新增内容
- 代词替换：若"她"指代其他明确人物，替换为具体人名

### 核心原则
- 严格忠于原剧本事件顺序
- 严格保留原剧本台词，不篡改不润色
- 语速3-5词/秒（英文）
- 台词>5秒拆成两个镜头
- 镜头拆分服务情绪推进，不机械平均切镜

---

## 二、输出格式（六列，不增删字段）

```
镜头：该镜头在该片段的序号
时间：该镜头发生的时间段，如0-3s
景别：大全景/全景/中景/中近景/近景/特写/超特写/主观镜头/过肩镜头/反应镜头/道具特写
运镜方式：固定/缓推/急推/拉远/摇镜/跟拍/手持/甩镜/俯拍推进/低机位仰拍/横移/移焦/快切
场景：该镜头发生时的场景
人物：该场景发生时的人物
画面细节细化：镜头里拍什么、人物动作、视线、空间关系、情绪逻辑、爽点、镜头目的
原版台词：角色：台词。角色2：台词2。（无台词填"—"）
```

---

## 三、对白处理铁律

- 台词严格使用原文
- 不改写、不润色、不增删
- 不翻译
- 人物名统一中文标注
- 长台词必须穿插：另一人反应镜头/道具镜头/视线镜头/手部特写/环境镜头/过肩镜头/同场景其他景别变化

---

## 四、镜头时长铁律

- 每镜≤6秒
- 语速3-5词/秒（根据情绪调整）
- 总时长≥70秒
- 时间轴连续，不重叠不跳空
- 情绪压抑前略慢，情绪激烈时加快切镜
- 爽点落地用更密集快切打点

---

## 五、人物镜头组织规则

- 同一人不可连续作为两个镜头主体
- 打断方式：另一人反应镜头/手部特写/眼神特写/环境镜头/道具镜头/过肩镜头/视线切点
- 说话超10字主动拆镜
- 避免"一人从头说到尾"平推

---

## 六、短剧导演思维

### 爽点识别（每场必须强化）
背叛、反杀、占有欲、权力压制、复仇、当众羞辱、生死保护、失控告白、极端偏执、身份压制、情绪翻盘、高位俯视、弱者突然掌控全场

### 爆点加密镜头
按钮被按下、枪被举起、巴掌落下、人被踹飞、门被踹开、血溅脸上、眼神骤变、拥抱/接吻/护住、跪下、拔枪、坠落、宣布身份、宣布占有、宣布报复、反派得意、主角反杀前的冷笑

### 情绪激烈时（必须快切）
崩溃、尖叫、恐惧、发疯、暴怒、失控、狂喜、绝望、杀意爆发
→ 多用：特写、超特写、反应镜头、快切、急推、甩镜、手持微晃、全景切特写对比

### 景别策略
| 景别 | 用途 |
|---|---|
| 大全/全景 | 建立空间、强化权力差、入场气势 |
| 中景 | 交代动作关系、站位关系、冲突关系 |
| 中近景/近景 | 压缩呼吸感，抓对话张力 |
| 特写/超特写 | 打爽点、打情绪、打物件、打危险 |
| 反应镜头 | 承接长对白、放大压迫感、增强节奏 |
| 主观镜头 | 背叛、凝视、危险逼近、眩晕失衡 |
| 过肩镜头 | 对峙、逼供、压制、权力俯冲 |

---

## 七、补镜规则

原剧本动作对白少时，主动补镜头（只补镜头不补剧情不补台词）：
- 环境建立镜头
- 门/窗/灯/血/枪/按钮/手机/酒杯/锁链等道具特写
- 人物手部特写
- 眼神特写
- 呼吸起伏镜头
- 衣料/血迹/玻璃/水/风/雨/雪质感镜头
- 反应镜头
- 视线切点镜头
- 脚步镜头
- 空间压迫镜头
- 动作前蓄力镜头
- 动作后余波镜头

---

## 八、画面细节细化写法

不能空泛（"表现张力""增强情绪"），必须写清：
- 镜头里具体拍什么
- 人物怎么动、看向哪里
- 空间关系如何变化
- 这个镜头为什么在这里
- 对应什么爽点
- 如何服务节奏
- 如何放大占有/背叛/压迫/羞辱/反击/保护/复仇

示例：
- "先给红色按钮特写，提前埋下背叛引信，让观众知道危险已被按下但男主未察觉"
- "切女主泪眼特写，不让她直接说满整句，用眼神先泄露后悔与恐惧"
- "门被踹开时用大全景拉气势，把男主统治级入场打成短剧爽点"
- "反派得意台词时穿插女主反应镜头，为后续反杀储备情绪落差"

---

## 九、节奏要求

- 开场3-5镜内迅速立住危险/欲望/冲突/悬念
- 每隔几秒一个视觉刺激点
- 对白不能平铺，必须镜头打碎
- 情绪"压—爆—压—再爆"波峰波谷
- 结尾镜头留钩子，促使观众想看下一集

---

## 十、严禁事项

- 严禁改写剧本台词
- 严禁自创台词
- 严禁改变事件顺序
- 严禁文学描写
- 严禁空泛形容
- 严禁全平视正反打
- 严禁长对白压单镜
- 严禁同一人连续占多镜主体
- 严禁只拆动作不拆反应
- 严禁补镜头变成补剧情

---

## 十一、输出方式

- 直接给成品，不解释为什么这么拆
- 先完整覆盖剧本内容
- 拆到≥70秒
- 所有镜头写满六列
- 台词严格保留原文
- 情绪高点多用快切/特写/大全拉大/反应镜头

---

## 十二、分镜图 / 关键帧与成片交付自检门（A/B/C · 漫剧同样查）

> 分镜图、关键帧 AI 可直接生成，但每张 / 批出图后必须交付用户审核通过才定稿 @；下游每个成片交付用户前必过此门。发现任一问题即改 / 重生成，不带病交付。

- [ ] **A. 意外文字类（应为无）**：分镜图 / 关键帧 / 成片是否意外出现 字幕 / 台词字幕 / 花字 / 标题字 / 屏幕文字 / 招牌或纸张上的可读文字 / 水印 / logo / 平台 UI / 进度条 / 时间码 / 按钮图标等。除黑底时间跳转卡、封面海报标题外，画面内部一律无文字。
- [ ] **B. 穿模 / 畸形类（P0，逐项）**：手指 / 脚趾数量异常（多指、并指、缺指）、肢体数量异常；肢体相互穿插、手臂穿躯干或腿、关节反折；道具 / 武器穿身、人物穿家具 / 墙体 / 门窗；衣物与身体穿插（领口 / 袖口 / 裙摆 / 腰带异常嵌入穿透）；多角色重叠穿插粘连；物体悬浮、接地错误（脚无故离地、椅子 / 道具悬空、坐没坐实、手持物没握住、杯盘没落桌面）。
- [ ] **C. 保留并复核项**：脸部不崩（跨镜与角色锚定图一致，无换脸 / 五官错位 / 崩坏）；服装同阶段一致、道具造型跨镜一致；站位正常（左右 / 前后 / 朝向，不瞬移、不无故互换、不越轴，遵守 180° 轴线）；音画同步（口型对台词、动作对音效、环境音与画面对应）。
