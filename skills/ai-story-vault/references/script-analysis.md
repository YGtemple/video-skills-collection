## 一、最高原则

### 禁止的分析方式
- ❌ "因为感人所以火了" → 太泛，等于没说
- ❌ "用了第一人称所以火了" → 所有片子都用第一人称
- ❌ "亲情题材现在火" → 这是现象，不是原因

### 正确的分析方式
- ✅ "这条比同创作者其他作品数据高3倍，核心差异是XX设计"
- ✅ "观众在评论区都在说XX，说明真正戳中的是这个点"
- ✅ "它火在'遗忘vs记得'的错位，比普通父女情多了X层情绪"

### 核心问题
> 不是"这个视频讲了什么"，而是**"为什么是这条，在这个时间，火了"**？

## 二、解析前必做：数据验证搜索

> 拿到一个视频开始拆解前，**必须先搜索数据**，不能凭感觉分析。

### 必搜清单

```
搜索1：[作品名] + 抖音/点赞/播放/数据
搜索2：[创作者名] + 全部作品 + 数据对比
搜索3：[作品名] + 评论区 + 高赞/分析
搜索4：[同题材] + 其他爆款 + 对比
```

### 必须拿到的数据

| 数据项 | 用途 |
|--------|------|
| 点赞量 | 判断爆款等级 |
| 播放量 | 判断传播广度 |
| 转发量 | 判断传播动力（转发高=社交货币） |
| 评论量+高赞评论 | 找真实共鸣点 |
| 涨粉数 | 判断对账号的拉新效果 |
| 创作者同期其他作品数据 | 做横向对比 |

## 三、七层拆解法

> 从外到内，逐层深入，直到挖到"为什么火"的底层原因。

### 第一层：一句话故事

**问题**：用一句话讲清"谁，在什么处境下，因为什么，发生了什么，最终怎么样了"？

**输出格式**：
> [人物]，在[处境]，想要[目标]，被[阻碍]阻挡，最终[结果/变化]。

**检验标准**：这句话能不能一句话卖出去？朋友听到会不会想看？

---

### 第二层：结构定位（四段式）

**问题**：按时间轴，标注每个节拍的内容和功能。

| 节拍 | 时间占比 | 内容 | 功能 |
|------|----------|------|------|
| 钩子 | 0-10% | | 抓注意力 |
| 铺垫 | 10-40% | | 建立关系 |
| 冲突 | 40-70% | | 积累情绪 |
| 反转 | 70-90% | | 情绪爆发 |
| 金句 | 90-100% | | 升华转发 |

**分析要点**：
- 钩子是什么？为什么前3秒能留住人？
- 铺垫用了几个场景？会不会太多？
- 冲突从哪里开始？情绪怎么积累的？
- 反转在哪？反转前有没有伏笔？
- 金句是什么？为什么这句适合转发？

---

### 第三层：情绪曲线标注

**问题**：观众的情绪是怎么一步步被带起来的？

**逐段标注表**：

| 时间段 | 内容 | 情绪 | 强度(1-10) | 触发点 |
|--------|------|------|-----------|--------|
| | | | | |

**分析要点**：
- 情绪最高点在哪？占总时长的百分之几？
- 情绪是一直上升还是有起伏？
- 有没有"假高点"（小高潮）？
- 结尾情绪是释放了还是留有余韵？
- 情绪最高点和反转点是不是对齐的？

---

### 第四层：核心反差（最重要）

**问题**：这条片最核心的"反差"是什么？

> 反差 = 爆款的发动机。没有反差，就没有情绪。

**常见反差类型对照**：

| 反差类型 | 公式 | 示例 |
|----------|------|------|
| 遗忘vs记得 | 他忘了一切，但记得爱你 | 阿尔茨海默症 |
| 贫穷vs给予 | 他自己都没有，却给了你全部 | 卖瓜供学 |
| 过去vs现在 | 以前他什么都行，现在不行了 | 父亲变老 |
| 严厉vs温柔 | 表面很凶，背地里很爱 | 中国式父爱 |
| 天真vs沉重 | 孩子的天真，戳破大人的伪装 | 童言无忌 |
| 沉默vs表达 | 从来不说，但什么都做了 | 沉默的爱 |

**分析要点**：
- 这条片的核心反差是什么？
- 这个反差和同类片子比，新在哪里？
- 反差是不是贯穿全片？还是只在结尾才出现？
- 反差有没有伏笔？还是突然反转？

---

### 第五层：物件与细节载体

**问题**：用什么具体东西承载情感？

> 最有力的情感，从来不是说出来的，是通过一个具体物件"演"出来的。

**分析要点**：
1. **核心物件**：全片围绕什么物件？
2. **出现次数**：这个物件出现了几次？每次意义有什么变化？
3. **前后对比**：物件的过去vs现在有什么变化？
4. **细节精度**：有没有一个具体的小细节，让你瞬间破防？
5. **普适性**：这个物件观众自己生活中有没有类似的？

---

### 第六层：时机分析（为什么现在火）

**问题**：为什么是这个题材，在这个时间点爆？

> 同一个题材，去年拍可能不爆，今年拍就爆了——时机很重要。

**分析维度**：
1. **节点因素**：是不是赶上了父亲节/母亲节/春节？
2. **社会情绪**：当下社会有什么集体情绪？这个片子戳中了什么？
3. **赛道空白**：这个题材之前没人做？还是做得不够好？
4. **技术红利**：是不是赶上了平台的AI创作扶持计划？
5. **传播节点**：有没有官媒转发/大V推荐/上热搜？

---

### 第七层：可复用公式提炼

**问题**：把这条片的成功拆解成可以复用的创作公式。

**输出格式**：
> [题材] + [核心反差] + [物件载体] + [叙事视角] + [金句类型] = 爆款

**示例**：
> 父亲变老 + 遗忘/记得反差 + 一碗面 + 女儿第一人称 + 哲理金句 = 爆款

## 四、对比分析方法

> 单看一条片看不出规律，必须横向对比。

### 对比维度

1. **和同创作者其他作品比**：这条为什么比别的数据高？
2. **和同赛道其他爆款比**：它有什么是别人没有的？
3. **和去年同题材比**：今年的新变量是什么？
4. **和失败案例比**：它做对了什么，那个失败的没做？
