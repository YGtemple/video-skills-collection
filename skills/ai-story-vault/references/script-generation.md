# 原创剧本创作指南

> 基于爆款规律，从零创作一条故事类AI短片脚本。
> 适用于30秒-3分钟短片，主打亲情/催泪/治愈赛道。

## 一、创作流程总览

```
选题材 → 找反差 → 选物件 → 搭结构 → 写分镜 → 自检 → 优化
```

**总原则**：先想清楚"为什么观众要哭"，再想"怎么拍"。

---

## 二、第一步：选题材和核心卖点

### 高爆款率题材清单（按优先级排序）

1. **父女/父子情** — 最大赛道，受众最广
2. **隔代亲（爷爷奶奶/外公外婆）** — 情绪浓度最高
3. **打拐/寻亲** — 官媒加持，传播广
4. **父母变老** — 节点性爆发强
5. **童年怀旧** — 治愈向，转发高
6. **姐妹/兄弟情** — 次热门
7. **师生情** — 教师节节点
8. **历史人物** — 文化向，质量高

### 核心卖点检验

选题材后，用一句话检验：
> "如果我刷到这个视频标题，会不会停下来看？"

**好的卖点特征：**
- 有反差/悬念（"我爸一直活在过去"）
- 有情绪预期（"看完不哭算我输"）
- 有普适性（所有人都能联想到自己）
- 具体不空泛（不说"父爱伟大"，说"他连毕业典礼都忘了，但还记得煮面"）

## 三、第二步：设计核心反差

> 反差是爆款的发动机。没有反差，就没有情绪。

### 十大经典反差公式

| 反差类型 | 公式 | 示例 |
|----------|------|------|
| **遗忘vs记得** | 他忘了一切，但记得爱你 | 阿尔茨海默症 |
| **贫穷vs给予** | 他自己都没有，却给了你全部 | 卖瓜供学 |
| **过去vs现在** | 以前他什么都行，现在他什么都不行 | 父亲变老 |
| **严厉vs温柔** | 他对你很凶，但背地里很爱你 | 中国式父爱 |
| **沉默vs表达** | 他从来不说，但什么都做了 | 沉默的父亲 |
| **天真vs沉重** | 孩子的天真，戳破了大人的伪装 | 孩子问的问题 |
| **等待vs归来** | 他等了一辈子，你却一年回一次 | 留守老人 |
| **失去vs永恒** | 他走了，但爱还在 | 纪念短片 |
| **误解vs真相** | 你以为他不爱你，其实他用你不懂的方式爱你 | 代际冲突 |
| **微小vs伟大** | 最伟大的爱，藏在最微小的细节里 | 细节催泪 |

### 反差设计检查
- [ ] 我的故事核心反差是什么？
- [ ] 这个反差够不够强？（一句话能不能说清楚）
- [ ] 这个反差有没有普适性？（别人看了能不能联想到自己）

## 四、第三步：选择物件载体

> 用一个具体物件承载所有情感，比直接说"我爱你"有力十倍。

### 选物件的原则

1. **日常**：观众生活中常见的东西
2. **有变化**：这个物件可以有"过去vs现在"的对比
3. **有记忆**：物件能勾起观众自己的回忆
4. **可视觉化**：拍出来好看，有画面感

### 题材-物件对照表

| 题材 | 推荐物件 | 情感内涵 |
|------|----------|----------|
| 父亲 | 工具箱/自行车/修车摊/旧手表 | 他的技能=他的爱 |
| 母亲 | 针线盒/围裙/菜篮子/毛衣 | 一针一线都是牵挂 |
| 奶奶 | 油条/菜篮子/蒲扇/老花镜 | 永远让你多吃点 |
| 爷爷 | 怀表/烟斗/旧照片/摇椅 | 时间与等待 |
| 童年 | 海盗船/纸飞机/弹珠/连环画 | 天真的愿望 |
| 打拐 | 旧相机/寻人启事/毛绒玩具 | 记忆与寻找 |
| 怀旧 | 纸手机/收音机/黑白电视 | 回不去的时光 |
| 夫妻 | 旧照片/结婚证/搪瓷杯 | 一辈子的陪伴 |

### 物件使用三步法

1. **埋**：前半段自然出现，不强调
2. **变**：中间发生变化（旧了/坏了/丢了）
3. **收**：结尾揭示它背后的故事，情感总爆发

## 五、第四步：搭建四段式结构

### 90秒短片结构模板

```
【0-5s】钩子：反常画面/悬念句
【5-30s】铺垫：2-3个日常场景，建立关系
【30-60s】冲突：矛盾显现，情绪开始积累
【60-80s】反转：真相揭示，情绪顶点
【80-90s】金句：升华主题，促发转发
```

### 结构填充步骤

#### 1. 写钩子（5秒）
- 用最反常的那句话开场
- 不要铺垫背景，直接抛问题
- 示例："我爸，好像一直活在过去。"

#### 2. 写铺垫（25秒）
- 选2-3个最有代表性的日常场景
- 每个场景一个小细节
- 不要太多，点到为止
- 目的：让观众快速代入"我爸也是这样"

#### 3. 写冲突（30秒）
- 核心矛盾开始显现
- 情绪从温暖转向心酸
- 观众开始心疼
- 目的：积累情绪，让观众开始难过

#### 4. 写反转（20秒）
- 前面铺垫的细节全部回收
- 真相揭示，情绪总爆发
- 这是全片的泪点
- 目的：让观众哭出来

#### 5. 写金句（10秒）
- 一句总结性的话
- 适合截图转发
- 留余韵，不要说太满
- 目的：让观众转发给某某人

## 六、第五步：写分镜脚本

### 分镜脚本格式

| 镜号 | 时长 | 画面 | 台词/旁白 | 情绪 | 备注 |
|------|------|------|-----------|------|------|
| 1 | 3s | 特写：一双布满老茧的手笨拙地拿手机 | （无台词，只有按错声） | 困惑 | 暖黄灯光 |
| 2 | 5s | 中景：父亲放下手机，叹气 | 父亲："这玩意儿……又坏了？" | 心酸 | 山东话 |
| ... | ... | ... | ... | ... | ... |

### 写分镜的要点

1. **能不用台词就不用**：用画面/动作表达
2. **每个镜头都有目的**：不能推进情绪的镜头删掉
3. **节奏要快**：90秒的片子，15-25个镜头比较合适
4. **有视觉记忆点**：至少2-3个让观众记住的画面

## 七、第六步：爆款自检

### 十维自检清单

写完脚本后，逐项检查：

| 维度 | 自检问题 | 合格标准 |
|------|----------|----------|
| **钩子** | 前5秒能不能抓住人？ | 看完想继续看 |
| **代入** | 观众能不能联想到自己？ | "我家也这样" |
| **反差** | 核心反差够不够强？ | 一句话能说清 |
| **物件** | 有没有具体物件承载情感？ | 不只是说"爱你" |
| **情绪** | 情绪有没有起伏？ | 不是一条直线 |
| **泪点** | 哪个瞬间会让人哭？ | 至少1个明确泪点 |
| **金句** | 结尾有没有可转发的金句？ | 适合截图 |
| **节奏** | 有没有废话？ | 每句每帧都有用 |
| **普适** | 所有人都能看懂吗？ | 不需要解释背景 |
| **传播** | 看完想转发给谁？ | 有明确转发对象 |

### 不合格的常见问题

1. **太像作文**：通篇抒情，没有具体故事
2. **太满**：什么都想说，反而什么都没说透
3. **太平**：没有情绪起伏，从头到尾一个调
4. **太假**：为了煽情而煽情，没有真实细节
5. **太长**：铺垫太长，重点太晚出现
