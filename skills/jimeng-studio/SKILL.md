## ⛔ 阶段门控总则（选项驱动 · 用户确认 · 全资产用户自制）

> 本技能（Studio＝**前期创作**：剧本→资产→分镜→提示词）**默认不再端到端一次性跑完全流程**。标准范式全文见 `/home/user/Doubao/chats/38436370915409154/_工作规范/阶段门控总则（标准范式）.md`；以下为本技能落地要点，**优先级高于下文任何「自动连续 / 直接进入 / 顺序推进」表述**。

**最高原则（不可违反）**：
1. **禁止一次跑完整制作**：不得用户只给一句话想法就自动把剧本→资产→分镜→单镜提示词→视频全做完。
2. **每个阶段结束必须：⛔ 暂停 → 给选项（每个附一句话亮点 + 利弊 + ⭐推荐项）→ 等用户明确回复**，未确认绝不往下做。用户每一步可：**回复编号选定 / 混搭多个 / 回复「再发散」换一批 / 直接写修改意见**。
3. **【美术资产全部由用户本人产出 · 强约束】**：角色、场景、道具、关键画面 / 分镜参考图等**所有进入成片的图像资产**，一律由用户拿 AI 给的提示词**自行生成、挑选并回传**；**本 Studio 不得调用任何图像生成（文生图 / T2I）工具替用户产出定稿资产、不替用户拍板**。AI 仍负责产出资产提示词与单镜视频提示词；**视频生成（T2V / I2V）由下游 jimeng-director 在全部资产回传确认后执行**。
4. **任何阶段都不自动出定稿资产图**；确需示意图 / 参考图辅助沟通时，**先说明用途并征得用户明确同意**，且示意图不得直接当定稿资产进入成片。

**门控点统一输出格式**：每个暂停点必须写清四件事——①给几个选项、②各选项利弊、③⭐推荐项及理由、④需要用户回复什么（编号 / 确认 / 修改意见），格式照范式 §1。

**本技能（Studio 前期）门控节奏：**

| 门 | 阶段 | 给用户的选项 / 动作 | 通过条件 |
|---|---|---|---|
| 第1门 | **故事发散（⛔ 写剧本之前）** | AI 先给 **3–5 个彼此差异化**方向（题材 / 核心设定 / 主角原型 / 主要矛盾 / **开头钩子画面**各不相同），填《故事发散选项表》 | 用户选定 / 混搭 / 再发散并**确认故事**后才写剧本、才定稿①立项大纲 |
| 第2门 | **资产方案选择（只定方案不出图）** | 给角色数量与人设、场景配置、道具清单、关键画面 / 分镜方向等**方案选项**，填《资产自制确认表》A 节 | 用户选 / 改并**确认资产方案** |
| 第3门 | **全部资产用户自制（关键，逐类逐门）** | AI 只产出**两套提示词（通用模型版 + MJ 版）+ 三维参数 + 资产清单与制作顺序 + 制作建议**；**用户逐个生成回传、逐项确认**后才 @ 引用（详见下文「资产阶段职责边界」） | 角色→场景→道具→关键画面**全部回传并逐项确认**前不得进分镜定稿 / 视频 |
| 第4门 | **分镜文字方案确认** | 分镜大纲 / 逐镜表给**文字选项**（景别 / 节奏 / 运镜档位）供确认迭代；**分镜图 / 关键帧由用户自制、AI 只给提示词** | 用户确认分镜文字方案 |
| 第5门 | **单镜提示词分批交付** | 按选定风格引擎**逐批**给单镜视频提示词（每组先展示完整 prompt），确认后进下一批 | 用户逐批确认 |

> 全部角色 / 场景 / 道具 / 关键画面**回传确认完毕之前，不得把项目交给 jimeng-director 进视频生成**。

**钩子与因果（两条硬性创作要求，真人 / 漫剧通用）**：
- **①钩子结合画面（看得见，不靠「说」）**：开头钩子必须是**看得见的具体画面 / 动作 / 场景**，靠第一帧 / 前几秒视觉冲击或视觉悬念抓人，**不靠旁白 / 台词 / 字幕 / 标题去说**，且直接关联核心矛盾、不用与正片无关的唬头；故事发散与立项时「开头钩子」栏一律填**具体钩子画面**（谁在干什么 / 出现什么异常画面），不填抽象概念。
- **②因果关系（A→B→C，消灭流水账）**：剧情按**因果链**推进（A 导致 B、B 导致 C），不是「然后…然后…」罗列；钩子抛出的异常 / 悬念须有成因（可后置揭示），人物每个行动有动机有后果；**伏笔是因、回收是果**，反转意料之外情理之中；自检时对每个场景追问「它因什么发生、又导致了什么」，删除与主线无因果的段落。

**三件套分批产出（不要一股脑全给）**：①立项大纲在「故事确认」后才定稿；②通用资产提示词、③MJ 提示词**按用户生成进度分批**给（角色确认给角色的、场景确认给场景的、道具 / 关键画面同理），不提前一次性全给。模板：`故事发散选项表.md`、`资产自制确认表.md`（项目目录 `/home/user/Doubao/chats/38436370915409154/`）。

**与既有规范叠加（不冲突、不删除）**：保留 🏷️ 真人 / 漫剧分支、📋 脚本自检六要点、📦 三件套、🎛️ 资产三维、⚠️ 无字幕 / 无 BGM / 禁 TTS / 生成前展示完整提示词 / 人物资产图强制 @ 与图片参考。本总则仅改变两点：①阶段推进由「自动连续往下跑」改为「逐门暂停、给选项、等确认」；②资产产出由「AI 可代生成资产图」改为「**全部定稿资产用户自制，AI 只给提示词 / 参数 / 清单 / 建议，不代生成**」；其余能力零删除，**视频生成仍由 AI（下游 Director）执行**。

## 五阶段全流程管线（逐门等确认，⛔ 见上方《阶段门控总则》）

根据用户输入判断起始阶段（这只是决定从哪一步切入，**不代表切入后自动连续跑完**）：用户给题材→先从「故事发散」第1门开始；用户给已有剧本→从阶段二资产方案开始；用户给剧本+要求出提示词→经资产方案 / 资产自制门后再进分镜与单镜提示词。

〔第2门〕资产方案选择   →  角色/场景/道具/关键画面 方案选项（只定方案不出图）

阶段二  资产标准化设定  →  角色/环境/道具资产卡（②通用+③MJ 提示词，按用户进度分批给）

阶段五  单镜提示词输出  →  按选定风格引擎逐批输出即梦/Seedance 可直接粘贴的 Prompt，逐批等确认

**分步执行协议（⛔ 逐门暂停）**：严禁一次性输出全部内容，也**严禁把「用户给剧本」当成自动连续跑完阶段二→三→四→五的许可**。每完成一个阶段必须：⛔ 暂停 → 给选项（亮点+利弊+⭐推荐）→ 等用户明确回复后再进入下一阶段。故事方向未经用户确认不得写剧本；故事 / 立项大纲未经确认不定资产方案；**全部资产未经用户回传并逐项确认，不得 @ 引用、不得进入分镜定稿与单镜提示词**。

## 本用户既定制作规范（强制，全阶段生效）

1. **生成前先展示完整提示词**：每次出图/出视频前，必须先把完整、详细的提示词展示给用户，确认后再调用生成。
2. **人物图强制 @ 引用**：用户提供的人物图片必须在提示词中以 **@ 引用**；**强制图片参考，禁止纯文字凭空生成人物**；一人一角色、用户图片不重复分配，多余角色才用纯文字描述。
3. **成片无字幕、无 BGM**：画面不写任何屏幕文字/字幕，不要求背景音乐（仅保留环境声/动效）。
4. **禁用 TTS 及一切语音合成**：台词/旁白直接写进提示词、由视频生成模型直接出声；出错就改提示词重生成，不用 TTS 补救。
5. **复刻/仿照他人视频**：必须启动 **script-asset-master**，场景/角色/道具等全部美术资产重新制作，**不得搬运原片素材**；要求高还原——场景、剧情顺序、台词、人物站位与机位**逐镜对齐，不得自由改编**。

## ★ 三大控制维度标注（②资产卡 / ③生图Prompt · 每个资产必标，缺一不可）

> 依据《通用模型资产提示词模板》《MJ提示词模板》的「★ 三大控制维度」权威小节。阶段二角色/场景/道具资产卡、阶段三角色锚定生图 Prompt（③MJ 英文 Prompt）**每一个资产旁，除正文外都必须列出以下三个维度的取值与理由，不能只给提示词正文**。

| ① 风格化 | `--stylize`/`--s` 0–1000（默认100） | 写实↔风格化档位/风格强度滑块（低/中/高，默认低=写实） | 低=听话贴参考、写实稳定；高=更艺术化 | 过高偏离参考、削弱写实与一致 |

### 基础视听与物理法则
- **物理真实**：遵循牛顿力学、地球重力、流体动力学。人体骨骼、布料材质、光线折射写实，符合生理常态。水下场景额外遵循浮力、水流阻力、光线衰减。

- **画幅帧率**：横屏16:9/21:9，24fps/30fps cinematic；竖屏9:16，30fps/60fps。

- [ ] **人物侧写**：基于故事情境分析人物而非贴标签；写清性格特点与面临的问题；用神态/动作/习惯等细节立人。
- [ ] **场景与转场**：设计专门转场避免硬切；区分/交代背景让观众看懂时空；用光影/道具/状态变化处理同场景不同时间的流逝。
- [ ] **叙事结构（多线 + 因果）**：含主线 + 亲情线 + 社会关系线且各线有交汇、相互推动、不平行堆砌；**剧情按因果链 A→B→C 推进、不是「然后…然后…」流水账**；每场景追问「因什么发生、导致什么」，删除与主线无因果的段落；人物行动有动机有后果，伏笔是因、回收是果，反转意料之外情理之中；钩子抛出的异常 / 悬念须有成因（可后置揭示）。
- [ ] **开头钩子与互动（画面化）**：钩子必须是**看得见的具体画面 / 动作 / 场景**，靠第一帧 / 前几秒视觉冲击或视觉悬念抓人，**不靠旁白 / 台词 / 字幕 / 标题去说**，且直接关联核心矛盾、不用与正片无关的唬头；开头用热点 / 焦点 / 强冲突抓人；全片设置讨论点（留争议、留悬念、留共鸣）引发留言。
- [ ] **观众视角自检**：切换为普通观众重看一遍，回答"哪里可优化？整体是否吸引我继续看？"。

### 分镜/提示词阶段自检（横屏引擎）
- [ ] 角色资产是否在全镜保持一致（服装/面部/装备）？
- [ ] 每镜是否标注景别/视点/运镜/速度？
- [ ] 运镜速度是否匹配情绪档位？
- [ ] 即梦Prompt是否可直接粘贴（无表格、无多余解释）？
- [ ] 画面描述是否包含主体+动作+环境+光影+镜头+情绪？
- [ ] 音效与转场是否每镜都有？
- [ ] 时间码是否连续无重叠无缺口？

### 分镜/提示词阶段自检（竖屏引擎）
- [ ] 单镜是否仅一个核心动作+一次情绪变化？
- [ ] 单镜台词是否≤5-7词？长台词是否拆分？
- [ ] 主角镜头是否标注参考图（首帧锁五官）？
- [ ] 每镜是否标注人物站位/前后层次/朝向？
- [ ] 重要道具是否处于中心安全区？
- [ ] 画面内容是否前置4K/8K/60fps/cinematic lighting/9:16/焦段？
- [ ] 每镜是否带强制去字幕指令和负向提示？
- [ ] 是否每5-6镜分组并给出场景空间坐标？
- [ ] 伤害/死亡画面是否已通过合规替换？
