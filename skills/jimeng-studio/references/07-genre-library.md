# 短剧题材库

## 使用说明

本文件为阶段一剧本创作提供题材灵感与各题材的冲突/反转/爽点模式。用户给题材后，先在本库中查找匹配题材，套用其核心模式，再结合用户具体要求创作。

---

## 一、都市逆袭类

### 核心模式
- **主角设定**：被轻视的底层角色（赘婿/保安/外卖员/实习生/穷小子），实际隐藏身份（首富继承人/退役战神/神医/黑客之王）
- **核心冲突**：被羞辱/被欺负/被背叛，隐忍不发
- **反转**：身份暴露，所有轻视者震惊
- **爽点**：打脸势利眼、碾压反派、美女/权贵倒贴
- **悬念**：更大的敌人出现/身份背后还有秘密

### 经典冲突场景
- 同学聚会被嘲笑穷→买单时亮出黑卡
- 被丈母娘/岳父嫌弃→豪车车队来接
- 被上司欺压→一个电话让公司被收购
- 救了被欺负的美女→美女是集团总裁

### 反转类型
- 身份反转（最常用）：废物=大佬
- 能力反转：被欺负的人有超能力/绝世武功
- 关系反转：欺负他的人其实靠他活着

## 二、古风/古装类

### 核心模式
- **主角设定**：重生/穿越/废柴皇子/庶女/被休弃的王妃
- **核心冲突**：前世被害/被欺，今生复仇；或宫廷权谋斗争
- **反转**：前世仇人其实有隐情/盟友是叛徒/主角身份更高贵
- **爽点**：手撕白莲花、虐渣、权谋碾压、皇帝/王爷独宠
- **悬念**：前世真相/更大的阴谋/身世之谜

### 子类型
- **重生复仇**：带着前世记忆回来，步步为营
- **穿越逆袭**：现代知识在古代降维打击
- **宫廷权谋**：皇子争位/后宫争宠
- **仙侠修真**：废柴修仙，打脸天才

### 经典场景
- 被赐死/被休→重生回到关键节点
- 庶女被嫡姐欺负→设计让嫡姐身败名裂
- 废柴皇子被轻视→暗中布局夺取皇位

---

## 三、悬疑/惊悚类

### 核心模式
- **主角设定**：警察/侦探/普通人卷入事件/有特殊能力（通灵/预知）
- **核心冲突**：连环案件/密室杀人/超自然现象，线索层层递进
- **反转**：最信任的人是凶手/死者是假死/主角自己是凶手/一切是幻觉
- **爽点**：真相大白、智斗凶手、反转震撼
- **悬念**：案件背后有更大阴谋/凶手还在/新的案件出现

### 子类型
- **本格推理**：密室/不可能犯罪，逻辑至上
- **社会派**：案件背后反映社会问题
- **超自然悬疑**：鬼/灵异/预知，但最终可能有科学解释
- **犯罪心理**：连环杀手/心理博弈

### 经典反转
- 叙述性诡计：观众一直被骗（主角身份/时间线/视角）
- 全员恶人：没有无辜者
- 闭环：结局回到开头，无限循环

## 四、科幻/末世类

### 核心模式
- **主角设定**：末世幸存者/科学家/军人/有特殊体质/AI觉醒
- **核心冲突**：生存危机/怪物威胁/人类内斗/科技失控
- **反转**：灾难是人为的/主角是实验品/AI其实在保护人类/同伴是卧底
- **爽点**：绝境反击、科技碾压、拯救众人、揭开真相
- **悬念**：末世真相/新的威胁/主角的命运

### 子类型
- **丧尸/感染**：病毒爆发，求生+人性考验
- **废土/末世**：文明毁灭后，资源争夺
- **赛博朋克**：高科技低生活，义体/AI/大公司
- **太空/星际**：飞船/外星/空间站危机
- **时间旅行**：穿越时间改变命运
- **末世水世界**：海平面上升/深海文明/水下都市（本Skill竖屏引擎主打）

### 末世水世界特色元素
- 场景：铁城贫民窟、下水道、沉船墓场、上古遗迹、方舟舱体、轨道站
- 角色：半人半海洋生物（半鲨/半水母/人鱼/海龟人）、深渊生物、机械改造人
- 道具：引擎核心、心鳞、护符、旧照片、机械巡逻兵、平板
- 光线：生物电光、霓虹灯管、金色净化光、暗紫深渊光
- 色调：海洋蓝（守护）、引擎金（希望）、深渊紫（腐化）、警报红（冲突）

## 五、甜宠/爱情类

### 核心模式
- **主角设定**：普通女孩+霸道总裁/冷面王爷/顶流明星/天才医生
- **核心冲突**：身份差距/误会/第三者/家族反对
- **反转**：男主其实早就暗恋/女主身份不简单/男二是反派
- **爽点**：霸总护妻、当众撒糖、虐渣男渣女、双向奔赴
- **悬念**：感情新危机/隐藏情敌/身世秘密

### 子类型
- **先婚后爱**：契约婚姻/闪婚，日久生情
- **破镜重圆**：前任重逢，解开误会
- **暗恋成真**：一方默默守护，最终双向奔赴
- **穿越恋爱**：古今穿越的爱情
- **职场恋爱**：上司下属/同事恋情

### 经典场景
- 被欺负时男主霸气护妻
- 误会解开后的深情告白
- 情敌面前宣示主权

---

## 六、复仇/打脸类

### 核心模式
- **主角设定**：被背叛/被陷害/被夺走一切的人
- **核心冲突**：隐忍布局，一步步复仇
- **反转**：仇人其实被利用/主角复仇对象错了/复仇中发现更大阴谋
- **爽点**：以牙还牙、让仇人身败名裂、夺回属于自己的一切
- **悬念**：复仇后的空虚/新的敌人/复仇代价

### 经典路径
1. 被害/被背叛（开场冲击）
2. 绝境/假死/隐姓埋名
3. 积累力量/找到盟友
4. 一步步反击，小爽点不断
5. 最终对决，大反转+大爽点
6. 悬念：复仇之后呢？

---

## 七、职场/商战类

### 核心模式
- **主角设定**：职场新人/被排挤的老员工/创业者/卧底
- **核心冲突**：职场斗争/商业竞争/公司内斗/行业黑幕
- **反转**：方案被偷是局/对手是自己人/公司老板在考验主角
- **爽点**：方案碾压、升职加薪、揭穿阴谋、创业成功
- **悬念**：更大的商业危机/行业格局变化

---

## 八、玄幻/异能类

### 核心模式
- **主角设定**：废柴/平凡人，意外获得异能/系统/传承
- **核心冲突**：修炼升级/异能世界的规则/黑暗势力
- **反转**：系统是陷阱/传承来自仇人/主角身世惊天
- **爽点**：升级打脸、异能碾压、收服神兽/美女
- **悬念**：异能世界真相/最终BOSS/主角极限

### 子类型
- **系统流**：获得系统，做任务升级
- **赘婿修仙**：都市背景+修仙能力
- **超能力**：现代都市异能者
- **修真界**：传统修仙升级

## 题材选择决策树

```
用户给题材
  │
  ├─ 有明确题材关键词 → 匹配对应子类型，套用核心模式
  │
  ├─ 只有一句话创意 → 提取核心冲突，选择最匹配的大类
  │
  └─ 完全开放/无题材 → 推荐高传播度题材：
       1. 都市逆袭（受众最广，爽点直接）
       2. 重生复仇（情绪最强，节奏最快）
       3. 甜宠霸总（女性受众大，完播率高）
       4. 悬疑反转（话题性强，追更欲强）
       5. 末世科幻（视觉冲击强，AI生成效果好）
```
