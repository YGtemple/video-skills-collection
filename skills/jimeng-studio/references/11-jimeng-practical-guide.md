# 即梦AI实操全指南

## 一、即梦AI视频生成模式概览

即梦（Jimeng）支持两种核心生成模式，本Skill产出的提示词分别适配：

| 模式 | 输入 | 适用场景 | 本Skill对应 |
|---|---|---|---|
| 文生视频 (Text-to-Video) | 纯文字Prompt | 大场面、环境空镜、无主角镜头 | 横屏引擎空镜 / 竖屏引擎大场面 |
| 图生视频 (Image-to-Video) | 首帧参考图 + Prompt | 主角镜头、需要保持角色一致性的镜头 | 所有主角镜头（必填参考图） |

**核心原则**：主角镜头一律用图生视频，以阶段三产出的锚定图作为首帧；环境空镜/大场面可用文生视频。

## 二、图生视频操作流程

### 2.1 准备锚定图
1. 使用阶段三产出的英文生图Prompt，在即梦「图片生成」中生成角色锚定图
2. 每个角色至少准备：正面标准像 + 3/4侧面像
3. 有形态变化的角色（如半鲨战斗形态/离水虚弱形态），每种形态各1张
4. 锚定图要求：角色占画面主体、面部清晰、服装完整可见、背景简洁
5. 命名规则：`角色名_形态.png`（如 `Adam_半鲨.png`、`Adam_虚弱.png`）

### 2.2 图生视频参数设置
在即梦「视频生成」中选择「图生视频」模式：

| 参数 | 推荐设置 | 说明 |
|---|---|---|
| 首帧图 | 上传对应角色锚定图 | 必须与本镜角色匹配 |
| 提示词 | 粘贴本镜即梦Prompt（中文或英文） | 即梦对中文理解较好，推荐中文 |
| 视频时长 | 5秒（默认）/ 10秒 | 单镜建议5秒，长镜头拆多镜拼接 |
| 画幅比例 | 横屏16:9 / 竖屏9:16 | 与风格引擎一致 |
| 创意强度 | 0.6-0.75 | 太低画面不动，太高角色漂移 |
| 首尾帧 | 关闭（除非需要精确结束帧） | 短剧单镜一般不需要 |

### 2.3 图生视频Prompt优化技巧
- **首帧已有角色形象**，Prompt中不需要重复描述面部/服装细节，聚焦动作和环境
- 但必须保留**情绪/表情描述**（如"震惊的表情""愤怒的眼神"），因为首帧是常态表情
- 动作描述要**具体且单一**（一个核心动作），避免"他走过去然后拿起东西然后说话"
- 环境描述要**精确到光源和色调**，即梦对光影描述响应良好
- 末尾固定追加画质标签：`8K, cinematic, sharp focus, high detail`

## 三、文生视频操作流程

### 3.1 适用场景
- 大场面（城市全景、舰队压境、能量爆发）
- 环境空镜（场景建立、氛围镜头）
- 没有主角的道具特写（但重要道具建议用图生视频保持一致）
- 抽象/特效镜头（能量波、光柱冲天、环境变化）

### 3.2 参数设置
| 参数 | 推荐设置 | 说明 |
|---|---|---|
| 提示词 | 粘贴本镜即梦Prompt | 文生视频需要更完整的画面描述 |
| 视频时长 | 5秒 / 10秒 | 大场面建议10秒 |
| 画幅比例 | 16:9 / 9:16 | 与风格一致 |
| 创意强度 | 0.7-0.85 | 文生视频可以更高，发挥创意 |

### 3.3 文生视频Prompt优化技巧
- 文生视频没有首帧约束，**必须完整描述主体+动作+环境+光影+镜头**
- 开头先给**整体画面定性**（如"深海沉船墓场全景，暗蓝色调"），再细化
- 大场面用**拉镜/俯瞰/广角**，避免复杂的人物动作
- 特效镜头描述**能量颜色、形态、运动方向**（如"金色能量波从中心向外扩散，照亮周围海水"）

## 四、多镜拼接流程

90秒短剧由15-25个镜头组成，每个镜头单独生成后需要拼接：

### 4.1 生成顺序建议
1. 先生成**主角特写/关键镜头**（图生视频，最容易出问题，优先调试）
2. 再生成**对话/中景镜头**
3. 最后生成**空镜/大场面/转场镜头**（文生视频）
4. 每个镜头生成2-3个版本，选最佳

### 4.2 拼接工具
- 推荐使用剪映/CapCut（免费，AI字幕、音效库丰富）
- 或Premiere Pro（专业调色、音频混合）
- 即梦自身也有简单的拼接功能

### 4.3 拼接要点
- 按分镜时间码顺序排列
- 硬切为主，节奏快；情感镜头可用0.2-0.3秒叠化
- 转场处注意**动作匹配**（前镜结束动作与后镜开始动作衔接）
- 音效在拼接时添加，确保声画同步
- 台词配音在拼接后添加，对齐口型

## 五、常见问题与解决方案

### 5.1 角色面部漂移
- **原因**：图生视频创意强度太高，或锚定图质量差
- **解决**：降低创意强度到0.5-0.6；重新生成更高质量的锚定图；Prompt中强调"保持面部特征不变"；使用同一seed生成多角度锚定图

### 5.2 动作糊帧/不自然
- **原因**：单镜动作太多太复杂，或时长太长
- **解决**：严格执行一镜一动作；长镜头拆为2-3个短镜拼接；降低动作速度描述；创意强度调到0.6左右

### 5.3 画面出现文字/字幕
- **原因**：Prompt中提到了文字相关内容，或模型自动生成
- **解决**：竖屏引擎每镜强制指令"画面全程无任何字幕、文字、水印"；负面提示词添加`text, watermark, subtitles, caption`；横屏引擎负面词同样添加

### 5.4 光线/色调不一致
- **原因**：不同镜头的Prompt中光线描述不统一
- **解决**：回到资产卡，每个场景的光线设定是固定的，所有同场景镜头使用相同的光线关键词；在Prompt开头统一光线描述

### 5.5 水下场景大范围死黑
- **原因**：Prompt中描述太暗，或模型对水下低照度处理不佳
- **解决**：严格执行"禁止大范围死黑"规则；Prompt中添加"暗部保留冷蓝色轮廓光""生物微光照明""水中悬浮颗粒反射光线"；增加环境光描述

### 5.6 手部/手指畸形
- **原因**：AI视频模型对手部生成不稳定
- **解决**：减少手部特写镜头；必须有手部动作时，Prompt中精确描述手部姿态（如"右手紧握短刃刀柄，手指关节发白"）；负面提示词添加`extra fingers, missing fingers, fused fingers, mutated hands`；手部动作尽量简单（握拳/伸手/触碰，避免复杂手势）

### 5.7 生成速度慢/排队
- **解决**：非高峰时段生成（凌晨/上午）；优先生成关键镜头；批量提交后等待；使用即梦Pro会员加速

## 六、批量生成管理表

建议在生成过程中维护一个管理表（可用飞书表格/Excel）：

| 镜号 | 时长 | 模式 | 锚定图 | Prompt版本 | 生成状态 | 最佳版本 | 备注 |
|---|---|---|---|---|---|---|---|
| 01 | 5s | 图生视频 | Adam_半鲨.png | v1 | 已完成 | #2 | 面部稳定 |
| 02 | 5s | 图生视频 | Ronald_深渊.png | v1 | 生成中 | - | 触须需调整 |
| 03 | 10s | 文生视频 | 无 | v2 | 待生成 | - | 大场面 |

这样可以追踪每个镜头的生成进度，避免遗漏或重复。

## 七、即梦Prompt中英文选择建议

- **即梦对中文Prompt理解更好**，推荐默认使用中文
- 英文Prompt在某些场景（特别是科幻/特效/电影感关键词）效果更稳定
- **建议**：主体动作和环境用中文描述，电影感/画质标签用英文追加（如`cinematic, 8K, ARRI 65, film grain`）
- 图生视频模式下，中文Prompt更精准控制动作；文生视频模式下，中英文混合效果最佳
