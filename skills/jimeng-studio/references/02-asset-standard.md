# 资产标准化设定规范

## 一、为什么需要资产标准化

AI视频生成中，角色/场景/道具在不同镜头间保持一致是最大难题。资产标准化设定在分镜前完成，为后续所有镜头提供"视觉锚点"，确保：
- 角色面部、服装、装备在全剧不漂移
- 场景空间关系、光线色调统一
- 关键道具外观、质感、发光特征一致

## 二、角色资产卡 (Character Asset)

每个主要角色必须填写以下字段：

### 基础信息
- **角色名**：
- **年龄/性别**：
- **身份**：职业/社会角色/隐藏身份

### 外观特征
- **面部**：脸型、五官特征（眼型/鼻型/唇形）、肤色、面部标记（疤痕/痣/纹身）、当前状态（伤痕/汗水/泥泞/妆容）
- **发型**：长度、颜色、样式、当前状态（凌乱/湿透/束起）
- **体型**：身高/体型关键词（健壮/瘦削/高挑/娇小）

### 服装与装备
- **上身**：款式、颜色、材质、细节（纽扣/拉链/徽章/磨损）
- **下身**：款式、颜色、材质、细节
- **鞋/靴**：款式、颜色、磨损状态
- **外层/配件**：外套/背心/披风/围巾/手套/腰带/包
- **标志性配件**：眼镜/手表/项链/耳环/头盔/护目镜（必须精确描述，这是角色辨识度核心）

### 武器/随身物
- **名称/型号**：
- **外观**：颜色、材质、尺寸、磨损/装饰
- **携带方式**：腰间/背上/手中/口袋

### 异化/特殊特征（竖屏Seedance引擎必填）
- 非人类特征的精确描述：鳞片位置与颜色、触须数量与尖端特征、鱼尾细节、义眼颜色与光效、皮肤透明度、体内能量导管等
- 不同形态的差异描述（如"半鲨形态"vs"离水虚弱形态"）

### 表情基线
- 常态表情关键词（冷峻/疲惫/温柔/嚣张）
- 情绪爆发时的面部特征（瞳孔变化/青筋/泪痕/咬牙）

## 三、环境与场景资产卡 (Environment Asset)

每个核心场景必须填写：

### 场景标识
- **场景名**：
- **类型**：室内/室外/水下/太空/虚拟空间
- **地点感**：城市/乡村/飞船/废墟/宫殿/贫民窟

### 空间特征
- **建筑/空间结构**：层高、开间、柱子/墙壁位置、门窗、楼梯
- **破坏/使用痕迹**：弹孔/裂缝/锈迹/水渍/杂物堆积/涂鸦
- **地面**：材质（水泥/木地板/金属格栅/沙土/水面）、状态（积水/碎片/血迹/脚印）

### 光线设计
- **主光源**：来源（窗户/顶灯/霓虹/火把/屏幕/生物光）、方向、强度
- **辅助光**：补光来源、颜色
- **色调**：主色调+情绪色（冷蓝压抑/暖黄温馨/暗红紧张/惨白诡异/金紫神圣）
- **特殊光效**：丁达尔效应/光束/霓虹反射/水面波光/闪烁/明暗对比

### 空气感
- 悬浮颗粒（灰尘/灰烬/水珠/气泡/雪）
- 雾/烟/蒸汽浓度
- 水下场景：水流方向、可见度、浮游生物

### 声音环境
- 环境音（雨声/风声/机器嗡鸣/水流/人群嘈杂）
- 远处噪音（炮声/警笛/音乐/喊叫）
- 寂静程度

## 四、核心道具资产卡 (Prop Asset)

每个对剧情有关键作用的道具必须填写：

### 基础信息
- **道具名**：
- **类型**：武器/电子设备/信物/文件/容器/能量装置

### 外观与质感
- **材质**：金属/塑料/玻璃/木质/石材/生物组织/能量体
- **颜色**：主色+细节色
- **尺寸/形状**：相对人体的大小、形状描述
- **磨损/使用痕迹**：划痕/凹陷/锈迹/贴纸/标签

### 特殊视觉特征
- **发光**：颜色、强度、发光部位、闪烁/常亮/脉动
- **动态效果**：屏幕显示内容/机械运动/能量流动/烟雾/液体
- **在场景中的存在感**：是否显眼/是否被刻意隐藏/是否在中心安全区

### 与角色的关系
- 持有者/使用者
- 使用方式（手持/佩戴/放置/激活）
- 情感价值（信物/武器/证据/诅咒）

## 六、资产一致性检查清单

- [ ] 每个角色的服装描述是否精确到颜色/材质/细节？
- [ ] 标志性配件是否每个角色都有且描述唯一？
- [ ] 场景光线是否有明确来源和色调？
- [ ] 关键道具是否有特殊视觉特征（发光/动态）？
- [ ] 竖屏引擎角色是否填写了异化特征？
- [ ] 资产描述是否足够具体，AI可以直接生成？
- [ ] 是否有角色/场景/道具在剧本中出现但未建资产卡？
