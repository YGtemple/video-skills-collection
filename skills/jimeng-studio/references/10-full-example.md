# 完整全流程示例

## 示例题材：末世水世界·深渊之子（竖屏Seedance引擎）

用户输入："写一个90秒末世水世界短剧，主角是半鲨人Adam，在沉船墓场发现父亲留下的引擎核心，却被深渊王Ronald伏击"

---

## 阶段一：90秒剧本创作

```
【剧名】《深渊之子》
【题材】末世水世界×赛博朋克
【时长】90秒（第1集）
【人物设定】
- Adam｜半鲨人战士｜外表冷峻内心柔软，离水虚弱｜寻找父亲下落，守护引擎核心
- Ronald｜深渊王/Adam生父｜威严残暴，半人半深渊异化｜夺取引擎核心，掌控深渊
- Evan｜百年海龟人｜苍老智慧，温和沉稳｜Adam的导师，守护上古秘密

【第一幕：开场强冲击】（0-12秒）
镜头01（0-5秒）：
【画面】大特写，Adam竖瞳骤然收缩，鳞片在暗紫光中逆光竖起。水下，他被一股巨力掀飞，撞在锈蚀的沉船舱壁上，金属凹陷。嘴角溢出金色光尘。
【台词】Adam："不可能……这力量……"
【音效】金属撞击闷响、水流爆裂、低频心跳声
【转场】硬切

镜头02（5-12秒）：
【画面】中景，Adam背靠舱壁滑落，单膝跪地。面前的黑暗中，无数触须缓缓摆动，眼窝黑红光晕亮起——Ronald的巨大剪影从深渊中浮现。
【台词】Ronald："孩子，你不该来这里。"
【音效】触须划水低沉声、深渊嗡鸣、Adam急促喘息
【转场】硬切

【第二幕：核心冲突推进】（12-55秒）
镜头03（12-20秒）：
【画面】近景，Adam猛地抬头，竖瞳锁定Ronald。双手撑地站起，鳞片从脖颈蔓延到脸颊，尖牙微露。身后，沉船墓场的巨轮残骸在暗蓝海水中静默。
【台词】Adam："你是谁？为什么知道我父亲？"
【音效】鳞片竖起的细碎声、水流、远处金属呻吟
【转场】硬切

镜头04（20-30秒）：
【画面】对峙型手持跟拍，Ronald的触须缓缓缠绕上一根锈蚀铁柱，黑红能量沿触须流动。他侧影在暗紫光中半明半暗，金属义眼般的黑红眼窝脉动。
【台词】Ronald："我？我是给你生命的人……也是夺走他的人。"
【音效】能量低频嗡鸣、触须收紧的金属吱嘎声
【转场】甩镜切换

镜头05（30-42秒）：
【画面】情感揭示型慢推，Adam瞳孔骤缩，身体微微后退。脑海闪回——旧照片中，一个男人抱着婴儿，背景是方舟舱体。照片在水中飘动，被一只苍老的手接住（Evan的手）。
【台词】Adam："你……你是他？不可能！Evan说他已经……"
【音效】心跳声放大、水流声、遥远的记忆回声
【转场】匹配剪辑（照片→现实）

镜头06（42-55秒）：
【画面】深海追逐型高速跟拍，Ronald触须猛地激射而出！Adam侧身闪避，触须击穿他身后的舱壁，铁锈爆裂。Adam反手拔出腰间的短刃，刀刃泛着蓝白生物电光，冲向Ronald。
【台词】Ronald："死了？不，他只是变成了我的一部分。"
【音效】触须破空、金属爆裂、刀刃嗡鸣、高速水流
【转场】硬切

【第三幕：反转爆发】（55-75秒）
镜头07（55-65秒）：
【画面】大特写，Adam的短刃刺中Ronald肩膀——却像刺中岩石，刃身崩裂出火星！Ronald冷笑，触须缠绕Adam的手腕，将他举起。Adam挣扎，鳞片全部竖起，竖瞳布满血丝。
【台词】Ronald："你以为一把破刀能杀我？天真。"
【音效】刀刃崩裂、触须收紧、Adam闷哼、能量嗡鸣
【转场】硬切

镜头08（65-75秒）：
【画面】反转瞬间——Adam被举在空中，左手突然按向胸口。他的胸膛裂开一道金光，一枚引擎核心从体内浮出！金色净化光瞬间爆发，Ronald的触须被金光灼烧，碳化剥落！Ronald震惊后退，黑红眼窝骤缩。
【台词】Adam："杀不了你？但他留给我的东西……可以净化你。"
【音效】金色能量爆发、触须碳化嘶嘶声、Ronald低吼、神圣低频共鸣
【转场】硬切

【第四幕：结尾强悬念】（75-90秒）
镜头09（75-85秒）：
【画面】大场面史诗型拉镜，金色净化光从沉船墓场冲天而起，穿透深海，照亮了上方的铁城轮廓。Adam悬浮在金光中心，引擎核心在胸前脉动。Ronald在远处阴影中，触须颤抖，眼窝黑红闪烁。
【台词】Ronald："引擎核心……竟然在你体内？你果然是他的儿子……"
【音效】金色能量轰鸣、深海共振、远处铁城警报声
【转场】慢推

镜头10（85-90秒）：
【画面】极端特写，Adam的竖瞳中倒映着金色光芒。突然，他的瞳孔猛缩——光芒深处，一个全息影像浮现：Vivian（母亲）的温柔面容，嘴唇微动。
【台词】Vivian（全息）："Adam，不要相信……任何人……"
【音效】全息电流声、Vivian温柔但遥远的声音、心跳骤停
【转场】黑屏卡点

【结尾悬念钩子】母亲的全息影像为何出现在引擎核心中？"不要相信任何人"——她指的是谁？Evan？Ronald？还是Adam自己？
```

## 阶段二：资产标准化设定 + 分镜大纲（节选）

```
【第一阶段：全剧资产标准化设定】

1. 角色资产 (Character Asset)
【Adam（半鲨）】
身份/外观：男性半鲨人战士，25岁，面部轮廓硬朗。脖颈至脸颊有银蓝色鲨鱼鳞片，竖瞳（银灰色虹膜，黑色竖瞳），尖牙。此时嘴角有金色光尘残留，表情震惊而愤怒。
服装/装备：身穿深灰战术潜水服（带防腐蚀涂层，肩部有磨损），腰间挂载短刃（蓝白生物电光刀刃），手腕有旧式护腕。
武器：短刃（蓝白生物电光刀刃，黑色防滑握柄，刃身有深海符文）。
异化特征：银蓝色鳞片（脖颈/脸颊/手背），竖瞳，尖牙，离水时鳞片暗淡、脸色苍白。
表情基线：冷峻戒备，愤怒时鳞片竖起、竖瞳收缩。

【Ronald（深渊王/生父）】
身份/外观：男性半人半深渊生物，年龄不明（看似50岁）。身形巨大（约2.5米），上半身人形，下半身化为无数深紫色触须。眼窝无眼球，取而代之的是黑红色光晕脉动。皮肤呈深灰紫色，有深渊符文般的纹路。
服装/装备：无服装，上半身有深渊甲壳（深紫色，金属质感，肩部有尖刺）。
异化特征：深紫色触须（约8-12条，尖端有黑红发光点），黑红眼窝，深渊符文皮肤，半人半深渊形态。
表情基线：威严冷漠，愤怒时眼窝黑红爆亮、触须尖端发光。

【Evan（百年海龟）】
身份/外观：男性海龟人，年龄极老（数百岁），面容苍老但眼神温和智慧。龟甲覆盖背部和肩部（深褐色，有金色符文），手指有蹼，皮肤呈深绿色。
服装/装备：身穿破旧的深褐色长袍（海底织物，有盐渍磨损），手持一根古木权杖（顶端有发光水晶）。
异化特征：龟甲（背部/肩部，金色符文），蹼指，深绿皮肤，苍老面容。

2. 环境与场景资产 (Environment Asset)
【沉船墓场】
空间特征：深海海底，无数锈蚀巨轮残骸交错堆叠，形成迷宫般的空间。舱壁布满铁锈和珊瑚，管道暴露，玻璃破碎。地面是细沙和金属碎片。
光线设计：极低照度，主光源为生物电光（蓝白色，来自浮游生物和Adam的刀刃）和Ronald的黑红深渊光。远处有微弱的海面透入光（深蓝色）。丁达尔效应明显。
空气感（水下）：悬浮颗粒（铁锈粉尘/浮游生物/气泡），水流缓慢，可见度低（约5-10米）。
声音环境：水流声、金属呻吟（沉船受压）、远处深海生物叫声、低频共振。

3. 核心道具资产 (Prop Asset)
【引擎核心】
外观与质感：球形，直径约15cm，外层是金色金属机械结构（有旋转环和精密齿轮），内部是流动的金色能量体（液态光）。
特殊视觉特征：金色净化光，脉动发光（与心跳同步），激活时光芒爆发向外扩散净化波。温度极高（周围水产生气泡）。
与角色的关系：Adam体内（胸膛中），父亲留下的遗物，Ronald渴望夺取。

【第二阶段：剧本拆解与分镜大纲】
本幕时长共90秒，情绪曲线：震惊恐惧→对峙困惑→闪回痛苦→战斗爆发→反转震撼→悬念惊悚。

镜头01（5秒 | 0-5s）：大特写/主观，Adam竖瞳收缩被撞飞，视觉基调：冲击+恐惧
镜头02（7秒 | 5-12s）：中景/低角度，Ronald巨影浮现，视觉基调：压迫+神秘
...（后续镜头省略，完整大纲按03-shot-breakdown.md格式）
```

## 全流程关键提示

1. **阶段间必须等待用户确认**，不要一次性输出全部
2. **风格引擎在阶段五前确认**，横屏和竖屏输出格式不同
3. **竖屏引擎每5-6镜分组输出**，每组后询问是否继续
4. **合规替换在阶段五画面描述中执行**，台词一字不改
5. **参考图命名规则**：`角色名_形态.png`，主角镜头必填
6. **资产卡是全剧视觉一致性的基石**，阶段二必须做扎实
