# 高级编剧技巧库

## 一、90秒节奏公式

### 1.1 注意力曲线
短视频用户的注意力在第1秒决定是否划走，第15秒决定是否继续看，第60秒决定是否点赞/追更。90秒剧本必须在这三个节点设置强刺激：

| 时间节点 | 用户心理 | 剧本必须做的事 |
|---|---|---|
| 0-3秒 | "这是什么？要不要划走？" | 强视觉冲击+悬念提问，禁止铺垫 |
| 12-15秒 | "有点意思，继续看" | 第一个小反转/小爽点，确认价值 |
| 30-35秒 | "接下来呢？" | 冲突升级，抛出更大的问题 |
| 50-55秒 | "快到结尾了吧" | 情绪推到临界点，伏笔开始回收 |
| 65-80秒 | "哇！" | 大反转+大爽点，情绪最高点 |
| 85-90秒 | "然后呢？下一集！" | 强悬念钩子，制造追更欲望 |

### 1.2 三秒钩子公式
开场3秒必须命中以下至少一种：
- **视觉冲击**：爆炸/血迹/坠落/特写异常物/极端表情
- **信息冲击**：一句颠覆认知的台词（"你已经死了"/"孩子不是你的"）
- **情境冲击**：极端处境（被枪指头/悬崖边/葬礼上醒来）
- **反差冲击**：身份与行为的巨大反差（乞丐坐进豪车/总裁在扫厕所）

**禁止**：缓慢的环境镜头、人物出场介绍、日常寒暄、"从前有一个……"式开场。

### 1.3 节奏密度公式
90秒短剧的理想镜头数：15-25镜。
- 平均每镜3.6-6秒
- 开场和高潮段落镜头更短（2-3秒/镜），制造快节奏
- 情感揭示段落镜头更长（5-8秒/镜），给情绪留空间
- 禁止连续3镜以上同景别同运镜，必须有变化

## 二、反转设计高级技巧

### 2.1 反转的三层结构
一个好的反转不是"突然发生"，而是有三层铺垫：

1. **表层误导**（第10-30秒）：让观众相信A是真相
   - 例：观众相信Ronald是杀父仇人
2. **中层伏笔**（第30-55秒）：不经意间埋下B的线索
   - 例：Ronald说"我是给你生命的人"（双关，观众以为是比喻）
   - 例：Evan听到Ronald名字时表情微妙（不解释）
3. **深层揭示**（第65-80秒）：B真相爆发，所有伏笔回收
   - 例：Ronald是Adam的生父，"杀父"是假的，父亲还活着

**关键**：伏笔必须在反转前出现，但不能让观众猜到。技巧是让伏笔看起来是别的意思（双关/误导/无关细节）。

### 2.2 五种经典反转类型

| 反转类型 | 机制 | 经典案例 |
|---|---|---|
| 身份反转 | 最弱者=最强者/敌人=亲人 | 乞丐是首富、仇人是生父 |
| 关系反转 | 盟友是叛徒/对手是保护者 | 最好的朋友是幕后黑手 |
| 真相反转 | 观众相信的A其实是B | 死亡是假死、受害者是加害者 |
| 能力反转 | 废柴觉醒/强者隐藏实力 | 被欺负的人一拳打飞反派 |
| 时间反转 | 现在是过去/因果倒置 | 结局才发现开头是结局 |

### 2.3 反转后的爽点释放
反转本身不是终点，反转后的**爽点释放**才是观众记忆点：
- **打脸式**：反转后主角碾压之前欺负他的人
- **揭穿式**：反转后当众揭露反派的真面目
- **逆袭式**：反转后主角从被动转为主动，掌控全局
- **守护式**：反转后主角保护了之前保护他的人

爽点必须**动作+台词+神态三位一体**，且在反转后5秒内出现，不要让情绪冷却。

## 三、台词写作技巧

### 3.1 台词的三个功能
每一句台词必须至少实现一个功能，否则就是废话：
1. **推进冲突**：制造/升级/解决矛盾
2. **塑造人物**：展现性格/身份/动机
3. **埋设伏笔**：为反转/悬念做铺垫

**检查方法**：删掉这句台词，剧情是否受影响？如果不受影响，这句就是废话，必须删或改。

### 3.2 强台词公式
- **反差式**：身份与台词的反差（乞丐说"这个城市是我的"）
- **双关式**：一句话有两层意思，反转后回收（"我是给你生命的人"）
- **悬念式**：话说一半，留下疑问（"你以为你父亲是怎么死的？"）
- **打脸式**：用对方的话反击对方（"你刚才说我不配？现在谁不配？"）
- **卡点式**：最后一句台词卡在情绪最高点，然后切黑/转场

### 3.3 台词节奏
- 短句为主，每句不超过15字（短视频配音节奏）
- 关键台词（反转/爽点/悬念）独立成句，前后留白
- 对话要有"攻防感"：你一句我一句，像打乒乓球，不要一个人长篇大论
- 长台词拆分为"台词+反应镜头+台词"，用对方的反应打断

### 3.4 禁用语
- 禁止解释性台词（"也就是说……""换句话说……"）
- 禁止总结性台词（"所以这一切都是因为……"）
- 禁止自我介绍式台词（"我叫XXX，是XXX"——用行动展示身份）
- 禁止重复信息（观众已经知道的事，角色不要再复述）

## 四、人物塑造高级技巧

### 4.1 人物反差公式
扁平人物=只有一面。立体人物=至少两层反差：
- **外表vs内心**：外表冷酷内心柔软 / 外表懦弱内心腹黑
- **身份vs行为**：高高在上的人做卑微的事 / 底层的人做伟大的事
- **常态vs爆发**：平时温和的人爆发时极恐怖 / 平时暴躁的人关键时刻极冷静

**关键**：反差必须在剧本中通过具体场景展示，不能只靠设定描述。

### 4.2 人物动机链
每个角色的行为必须有清晰的动机链：
- **表层动机**：本集想要什么（找引擎核心/报仇/救人）
- **深层动机**：为什么想要（父亲的遗愿/被背叛的恨/守护亲人）
- **隐藏动机**：观众后期才发现的真实目的（Ronald"报仇"其实是保护儿子）

动机链越完整，人物越可信，反转越有冲击力。

### 4.3 人物关系张力
人物之间的关系必须有"未解决的张力"：
- 秘密：一方知道另一方不知道的事
- 误解：一方误解了另一方的行为
- 利用：一方在利用另一方
- 背叛：一方已经/即将背叛另一方
- 身份差：地位/身份的巨大差距

**禁止**：人物关系平淡友好、没有任何矛盾。即使是盟友，也要有秘密或误解。

## 五、场景与氛围技巧

### 5.1 场景即情绪
每个场景的选择必须服务于情绪：
- **封闭空间**（电梯/房间/船舱）= 压迫、窒息、秘密
- **开阔空间**（荒野/海面/广场）= 自由、孤独、宏大
- **高处**（楼顶/悬崖/飞船）= 危险、抉择、命运
- **低处**（地下室/下水道/海底）= 压抑、黑暗、隐藏
- **过渡空间**（走廊/楼梯/道路）= 变化、转折、不确定

### 5.2 氛围三要素
每个场景的氛围由三个要素构成，必须在剧本中写清：
1. **光线**：来源+颜色+强度（冷蓝月光/暖黄台灯/暗红警报）
2. **声音**：环境音+远处噪音+寂静（雨声/机器嗡鸣/完全安静）
3. **细节**：3-5个具体物件/痕迹（散落的文件/墙上的弹孔/桌上的冷咖啡）

**禁止**：只写地点名（"在房间里"），不写氛围细节。

### 5.3 场景转换技巧
- **硬切**：默认，节奏快，适合动作/冲突场景
- **匹配剪辑**：前后镜有视觉相似元素（形状/颜色/动作），高级转场
- **声音先导**：下一镜的声音先出现，画面后切，制造悬念
- **道具衔接**：用同一个道具连接两个场景（照片从一只手传到另一只手）
- **光线变化**：从暗到亮/从冷到暖，暗示情绪/场景变化

## 六、悬念钩子设计

### 6.1 五种结尾钩子
| 钩子类型 | 机制 | 示例台词/画面 |
|---|---|---|
| 神秘人登场 | 新角色出现，身份不明 | 门被推开，黑影："你终于来了" |
| 真相一角 | 关键证据出现，但不解释 | 发现照片，照片背面写着一个名字 |
| 新危机 | 刚解决一个问题，更大的出现 | 反转后，窗外舰队压境 |
| 惊天台词 | 最后一句话颠覆认知 | "爸，你怎么会在这里？" |
| 身份揭示 | 某个角色的真实身份露出 | 摘下面具，是已经"死"的人 |

### 6.2 钩子的节奏
- 钩子必须在最后5秒出现
- 钩子出现后立即切黑/结束，不要解释
- 钩子的台词/画面必须有冲击力，能让观众立刻想看下一集
- 最好的钩子是"回答了一个问题，但抛出了更大的问题"

### 6.3 全剧悬念链（多集规划）
虽然本Skill只写第1集，但第1集的悬念必须为后续集数埋下线索：
- 第1集结尾抛出的悬念，应该在第2-3集部分解答，同时抛出新悬念
- 核心悬念（主角身世/末日真相）贯穿全季，最后才解答
- 每集结尾一个小钩子，每3-5集一个大反转

## 七、AI短剧适配特殊技巧

### 7.1 场景数量控制
- 90秒短剧场景数控制在2-4个，避免频繁切换
- 场景太多会导致AI生成不一致，且观众来不及理解空间关系
- 如果剧情需要多场景，用"同一场景不同区域"替代（如沉船的不同舱室）

### 7.2 人物同框控制
- 单镜同框人物不超过3人（AI生成4人以上容易出错）
- 群戏用"正反打"替代（A说话时拍A，B说话时拍B）
- 大场面人群用背影/剪影/模糊处理，不拍清晰面部

### 7.3 动作复杂度控制
- 单镜一个核心动作，禁止多动作堆叠
- 复杂动作（打斗/追逐）拆为多个短镜，靠剪辑制造快节奏
- 避免需要精确肢体接触的动作（拥抱/握手/打斗接触），AI容易穿模
- 用"动作前+动作后"的剪辑替代"动作中"（如：举拳→对方倒地，不拍出拳过程）

### 7.4 文字/屏幕内容规避
- 避免需要精确显示文字的场景（手机屏幕/文件内容/电脑屏幕）
- 必须显示时，用角色的反应（震惊/愤怒/悲伤）替代文字内容
- 或用模糊/反光/过曝处理屏幕，不显示具体文字

### 7.5 服装/造型一致性
- 全剧角色服装不变（除非剧情需要换装，且换装要有明确镜头）
- 标志性配件（眼镜/项链/头盔）每镜都要出现，是AI识别角色的关键
- 角色发型/妆容全剧一致，避免"换脸"感
