# 完整镜头语言库

## 一、景别体系 (Shot Size)

| 景别 | 英文 | 画面范围 | 叙事功能 | 情绪效果 |
|---|---|---|---|---|
| 大远景 | Extreme Long Shot (ELS) | 人物极小，环境为主 | 建立空间、展示规模、交代环境 | 孤独、渺小、宏大、压迫 |
| 远景 | Long Shot (LS) | 人物全身+较多环境 | 人物与环境关系、展示动作全貌 | 距离感、客观、观察 |
| 全景 | Full Shot (FS) | 人物全身，环境较少 | 全身动作、肢体语言、走位 | 完整、动作感、舞台感 |
| 中景 | Medium Shot (MS) | 膝盖/腰部以上 | 对话、常规叙事、上半身动作 | 自然、亲近、日常 |
| 中近景 | Medium Close-Up (MCU) | 胸部以上 | 表情为主、关键对话、情绪互动 | 关注、投入、亲密 |
| 近景 | Close-Up (CU) | 肩部以上/面部 | 情绪细节、关键反应、内心戏 | 紧张、强烈、代入 |
| 特写 | Big Close-Up (BCU) | 面部/手部/道具局部 | 情绪极点、关键道具、细节揭示 | 冲击、聚焦、窒息 |
| 大特写 | Extreme Close-Up (ECU) | 眼睛/嘴唇/物品细节 | 悬念点、反转瞬间、极致情绪 | 震撼、悬疑、心理压迫 |

## 二、视点体系 (Camera Angle/Viewpoint)

| 视点 | 英文 | 描述 | 效果 |
|---|---|---|---|
| 平视 | Eye Level | 镜头与角色眼睛同高 | 自然、平等、客观 |
| 仰拍 | Low Angle | 镜头从下往上拍 | 高大、权威、压迫、英雄感 |
| 俯拍 | High Angle | 镜头从上往下拍 | 渺小、脆弱、无助、被监视 |
| 鸟瞰/上帝视角 | Bird's Eye / Top Down | 垂直向下 | 全局、命运感、规模、抽离 |
| 第一人称POV | Point of View | 角色视角，观众=角色 | 极强代入、沉浸、体验 |
| 过肩 | Over-the-Shoulder (OTS) | 从一人肩后拍另一人 | 对话关系、空间感、对峙 |
| 主观镜头 | Subjective | 带角色情绪的镜头处理（不一定是POV） | 情绪外化、心理感受 |
| 荷兰角/倾斜 | Dutch Angle | 镜头倾斜 | 不安、疯狂、失衡、诡异 |

## 三、运镜体系 (Camera Movement)

### 基础运镜
| 运镜 | 英文 | 描述 | 效果 |
|---|---|---|---|
| 固定 | Static/locked-off | 镜头不动 | 稳定、客观、凝视、压迫 |
| 推 | Push In / Dolly In | 镜头向主体靠近 | 聚焦、强调、进入内心、紧张上升 |
| 拉 | Pull Out / Dolly Out | 镜头远离主体 | 揭示、抽离、孤独、结束感 |
| 摇 | Pan | 镜头水平转动 | 跟随、展示空间、扫视 |
| 俯仰摇 | Tilt | 镜头垂直转动 | 展示高度、从上到下/从下到上揭示 |
| 移 | Truck / Tracking | 镜头水平移动（非转动） | 跟随、平行展示、空间流动 |
| 跟 | Follow | 镜头跟随主体移动 | 沉浸、陪伴、追逐感 |
| 环绕 | Orbit / Arc | 镜头围绕主体做圆周运动 | 展示全貌、戏剧性、英雄感、时间凝固 |
| 升降 | Crane / Jib / Boom | 镜头垂直升降 | 揭示规模、从局部到全局、神圣感 |
| 手持 | Handheld | 手持拍摄，带自然晃动 | 真实、紧张、混乱、纪录片感、临场 |
| 斯坦尼康 | Steadicam | 稳定器跟拍，平滑流动 | 沉浸、流畅、梦幻、跟随 |
| 甩镜 | Whip Pan | 快速摇镜，产生运动模糊 | 转场、节奏加速、冲击、注意力转移 |
| 变焦 | Zoom | 镜头焦距变化（机位不动） | 突兀、强调、复古、惊悚（希区柯克变焦） |

### 组合运镜
- **推+环绕**：情绪爆发时的戏剧性强调
- **手持+跟拍**：追逐/逃亡的临场混乱感
- **慢推+特写**：情绪渐进到极点
- **拉+升降**：从人物到全局的史诗揭示
- **甩镜+硬切**：快节奏转场，动作片常用

## 四、运镜速度档位（横屏引擎）

| 档位 | 倍速 | 适用情绪 | 运镜方式 | 典型场景 |
|---|---|---|---|---|
| 慢速铺垫 | 0.2-0.4x | 压抑、低落、温情、对峙、神秘 | 固定微移、慢推、慢环绕、慢摇 | 反派登场、悲伤回忆、温情时刻、悬念铺垫 |
| 标准叙事 | 0.4-0.5x | 日常、对话、试探、普通叙事 | 平行跟拍、C形侧移、中速推/拉 | 日常行走、对话场景、暧昧试探、信息交代 |
| 高潮冲击 | 0.6-0.85x | 愤怒、爆发、打斗、挣扎、奋起 | Z字快跟拍、平行快跟拍、甩镜、手持快摇 | 打斗爆发、情绪爆发、追逐、反击、挣扎奋起 |

**速度与情绪匹配原则**：
- 情绪上升→速度加快
- 情绪爆发→最快速度+手持晃动+甩镜
- 情绪回落/沉淀→减速甚至固定
- 反套路：极度悲伤/恐惧时用极慢固定镜头（静比动更有力量）

## 五、构图体系 (Composition)

| 构图法 | 描述 | 效果 |
|---|---|---|
| 三分法 | 主体放在三分线交点 | 平衡、自然、美观 |
| 居中构图 | 主体在画面正中 | 正式、权威、对称、压迫 |
| 对称构图 | 画面左右对称 | 稳定、仪式感、完美、诡异 |
| 框架构图 | 用门窗/物体框住主体 | 聚焦、窥视感、层次、深度 |
| 引导线构图 | 用线条引导视线到主体 | 聚焦、纵深、流动感 |
| 前景遮挡 | 画面前景有物体遮挡 | 层次、窥视、临场、空间深度 |
| 负空间 | 主体周围大量留白 | 孤独、渺小、思考、呼吸感 |
| 头顶空间 | 人物头顶留白多少 | 多=自由/呼吸，少=压迫/窒息 |
| 视线空间 | 人物视线方向留白 | 自然、期待、方向感；反用=压迫 |
| 倾斜构图 | 画面倾斜（荷兰角） | 不安、失衡、疯狂、危险 |
| 垂直/水平强调 | 强调垂直线或水平线 | 垂直=崇高/力量，水平=平静/延伸 |

## 六、光线体系 (Lighting)

### 光源类型
| 光源 | 描述 | 效果 |
|---|---|---|
| 自然光 | 太阳光/天光/月光 | 真实、时间感、户外 |
| 人工光 | 灯光/霓虹/屏幕/火把 | 戏剧、色彩、室内/夜景 |
| 生物光 | 发光生物/能量/特效光 | 科幻、奇幻、神秘、超自然 |
| 混合光 | 多种光源组合 | 丰富层次、真实感、复杂情绪 |

### 光线方向
| 方向 | 描述 | 效果 |
|---|---|---|
| 正面光 | 从正面打亮主体 | 平坦、清晰、少阴影（纪录片/新闻） |
| 侧光 | 从侧面打光 | 立体感、质感、戏剧性（明暗对比） |
| 45度侧光（伦勃朗光） | 前侧45度 | 经典人像、立体、有质感 |
| 逆光 | 从背后打光 | 轮廓光、剪影、神圣、神秘、分离主体 |
| 顶光 | 从上方打光 | 压迫、恐怖、审讯感、眼窝阴影 |
| 底光 | 从下方打光 | 恐怖、诡异、非人、篝火/屏幕光 |
| 柔光 | 散射光，阴影柔和 | 温柔、唯美、梦幻、女性/儿童 |
| 硬光 | 直射光，阴影锐利 | 硬朗、力量、冲突、男性/战斗 |

### 特殊光效
- **丁达尔效应(Tyndall)**：光束穿过灰尘/雾气/水汽，可见光路——神圣、神秘、电影感
- **霓虹反射**：彩色霓虹在湿润表面/皮肤/水面反射——赛博朋克、都市夜景、迷幻
- **光斑(Bokeh)**：背景虚化成彩色光斑——唯美、梦幻、聚焦主体
- **闪烁/频闪**：光源不稳定闪烁——紧张、故障、危险、夜店
- **明暗对比(Chiaroscuro)**：强烈明暗对比——戏剧、冲突、善恶、黑色电影

## 七、色调体系 (Color Grading)

| 色调 | 色彩倾向 | 情绪/题材 |
|---|---|---|
| 冷蓝 | 蓝/青/灰 | 冷静、科技、压抑、悲伤、末世、水下 |
| 暖黄 | 黄/橙/金 | 温暖、希望、怀旧、家庭、夕阳、救赎 |
| 暗红 | 红/深红/棕 | 危险、激情、暴力、欲望、警报、地狱 |
| 暗紫 | 紫/品红/深蓝紫 | 神秘、腐化、污染、超自然、深渊、迷幻 |
| 青橙 | 橙+青对比 | 好莱坞标准、动作片、商业、对比强烈 |
| 黑白/低饱和 | 去色/灰度 | 严肃、历史、回忆、艺术、死亡、绝望 |
| 高饱和 | 鲜艳浓烈 | 梦幻、童话、迷幻、漫画、超现实 |
| 金色 | 金/琥珀 | 神圣、希望、财富、温暖、救赎、胜利 |
| 绿色 | 绿/墨绿 | 自然、病态、恐怖、毒、军事、监视 |

### 色彩情绪对应（末世水世界题材）
- 蓝色 = 冷静守护
- 金色 = 希望救赎
- 紫色 = 腐化污染
- 红色 = 冲突压迫

## 八、竖屏(9:16)构图特殊要点

- **纵深优先**：竖屏横向空间窄，靠前后层次（前景/中景/背景）营造空间感
- **中心安全区**：重要道具/面部/关键动作放在画面中心，避免被UI遮挡
- **人物站位标注**：每镜标注各人物前后层次与朝向
- **避免横向大场面**：横移/全景在竖屏效果差，改用纵深移动/仰拍/俯拍
- **头顶空间控制**：竖屏人物头顶留白不宜过多，否则主体过小
- **上下信息分层**：可利用竖屏上下区域分别展示不同信息（如上：反应，下：动作）
