# 通用竖屏短剧分镜引擎

## 一、定位与适用

本文件是竖屏(9:16)短剧分镜的**通用引擎**，适用于除末世水世界以外的所有竖屏短剧题材（都市逆袭、古风重生、甜宠霸总、悬疑推理、复仇打脸等）。

末世水世界×赛博朋克题材请使用专用引擎：[08-style-seedance-waterworld.md](08-style-seedance-waterworld.md)。

## 二、竖屏通用核心规则

### 2.1 画幅与参数
- **画幅**：9:16 竖屏
- **分辨率**：4K / 8K
- **帧率**：30fps / 60fps（动作类60fps，情感类30fps）
- **质感**：真人实拍质感，非卡通/非动画
- **每镜画面内容前置**：`4K resolution, 60fps, cinematic lighting, 9:16 aspect ratio, [焦段], [光线环境]。`

### 2.2 单镜限制（与Seedance引擎一致）
- **单镜一个核心动作**：一个动作 + 一次情绪变化
- **单镜台词≤5-7词**：长台词拆分多镜
- **主角镜头用图生视频**：必填首帧参考图锁五官
- **每镜标注人物站位**：前景/中景/背景 + 朝向
- **重要道具在中心安全区**

### 2.3 分段输出
- 每5-6镜为一组
- 每组开头给出【场景与人物】空间坐标
- 每组输出后询问是否继续

### 2.4 强制去字幕
每镜必带：`强制指令：画面全程无任何字幕、文字、水印、标语、标题、配乐。`

## 三、竖屏构图规范

### 3.1 纵深三层构图
竖屏横向空间窄，必须靠前后层次营造空间感：
- **前景**：遮挡物/人物肩部/道具（增加临场感和层次）
- **中景**：主要人物/动作（画面核心）
- **背景**：环境/其他人物/光源（交代空间和氛围）

每镜必须标注各人物处于哪一层，朝向哪个方向。

### 3.2 中心安全区
竖屏视频在各平台播放时，上下会被UI元素（标题/点赞/评论栏）遮挡。重要内容必须放在**中心安全区**：
- 垂直方向：画面中间60%区域（避免顶部20%和底部20%）
- 水平方向：画面中间80%区域
- 人物面部、关键道具、核心动作必须在安全区内

### 3.3 焦段选择（竖屏适配）
| 焦段 | 适用 | 竖屏效果 |
|---|---|---|
| 24mm wide angle | 大场面、环境展示 | 竖屏中展示空间高度，适合仰拍/俯拍 |
| 35mm lens | 中景、叙事 | 标准竖屏叙事，人物+环境平衡 |
| 50mm lens | 对话、自然人像 | 竖屏人像标准，面部不变形 |
| 85mm close-up | 近景、表情 | 竖屏特写首选，压缩空间，聚焦面部 |
| 135mm telephoto | 极端特写、远距离 | 竖屏中压缩纵深，适合眼神/道具特写 |
| 100mm macro | 道具/细节微距 | 竖屏中展示细节，适合信物/手部/道具特写 |

**竖屏偏好**：85mm和100mm使用频率最高（特写/近景在竖屏中冲击力最强），24mm用于大场面仰拍。

## 四、通用运镜分型（四型）

所有竖屏题材共用这四型运镜，根据场景情绪选择：

### 型一：快节奏动作型
- **运镜**：手持跟拍带晃动、甩镜切换、快速推拉
- **光影**：高对比度、硬光、闪烁光
- **适用**：打斗、追逐、逃亡、冲突爆发、反击
- **速度**：0.6-0.85x
- **焦段**：35mm/50mm 为主，配合甩镜

### 型二：对峙对话型
- **运镜**：固定微移、慢推、过肩正反打、手持轻晃
- **光影**：侧光、明暗对比、逆光剪影
- **适用**：对话、对峙、谈判、威胁、试探
- **速度**：0.3-0.5x
- **焦段**：50mm/85mm（正反打）

### 型三：情感揭示型
- **运镜**：慢推、极端特写、环绕、慢动作
- **光影**：单光源、柔光、暗部大但保留主体光
- **适用**：告白、诀别、回忆、真相揭示、情绪爆发
- **速度**：0.2-0.35x
- **焦段**：85mm/100mm/135mm（特写为主）

### 型四：大场面揭示型
- **运镜**：拉镜揭示、俯瞰、仰拍、升降
- **光影**：环境光、大光源、光束
- **适用**：场景建立、规模展示、人群/建筑、能量爆发
- **速度**：0.2-0.4x
- **焦段**：24mm wide angle

## 五、各题材竖屏适配指南

### 5.1 都市逆袭类
- **场景库**：豪华酒店/办公室、贫民窟/出租屋、同学聚会厅、街头、车库
- **光线**：暖金奢华光（富人区）、冷白荧光（贫民区）、霓虹夜景（街头）
- **色调**：金色=财富权力、冷灰=底层压抑、红色=冲突打脸
- **标志性道具**：黑卡/豪车钥匙/名表/合同/手机
- **爽点镜头**：85mm特写反派震惊表情 → 甩镜 → 24mm仰拍主角霸气身姿
- **反转镜头**：100mm macro特写道具（黑卡/印章）→ 慢推 → 85mm众人反应

### 5.2 古风/古装类
- **场景库**：金銮殿/宫殿、后花园/庭院、牢房/冷宫、街市、战场
- **光线**：烛光/灯笼暖光、月光冷光、殿内阴影、自然光
- **色调**：朱红=权力宫廷、青灰=压抑冷寂、金色=皇家神圣、素白=悲伤
- **标志性道具**：玉佩/圣旨/毒酒/刀剑/发簪/信件
- **爽点镜头**：85mm特写白莲花惊恐脸 → 甩镜 → 50mm主角冷笑转身
- **情感镜头**：100mm macro特写颤抖的手/流泪的眼 → 慢推 → 柔光

### 5.3 甜宠/爱情类
- **场景库**：咖啡馆/办公室/家/街头/医院/学校
- **光线**：暖黄柔光、逆光剪影、窗光、路灯
- **色调**：暖橙=温馨、粉色=暧昧、冷蓝=误会/悲伤、金色=告白
- **标志性道具**：咖啡杯/雨伞/手机/戒指/外套/情书
- **甜宠镜头**：85mm特写两人对视 → 慢推 → 100mm macro特写触碰的手
- **误会镜头**：50mm中景两人距离拉开 → 冷光 → 85mm一方受伤表情

### 5.4 悬疑/惊悚类
- **场景库**：密室/走廊/地下室/废弃建筑/警局/雨夜街道
- **光线**：闪烁荧光、手电筒光、阴影、低照度、红光警报
- **色调**：冷青=悬疑、暗红=危险、深灰=压抑、惨白=恐怖
- **标志性道具**：照片/钥匙/手机/刀具/血迹(合规替换)/录音笔
- **悬念镜头**：100mm macro特写关键道具 → 慢推 → 85mm角色震惊表情
- **惊悚镜头**：手持晃动POV → 甩镜 → 固定特写（突然出现的人影）

### 5.5 复仇/打脸类
- **场景库**：公司/法庭/宴会/家/街头/医院
- **光线**：硬光对比、聚光、逆光、冷光
- **色调**：冷蓝=隐忍、金色=反击、红色=冲突、深灰=绝望
- **标志性道具**：证据文件/录音/合同/支票/手铐
- **复仇镜头**：85mm特写反派得意 → 甩镜 → 50mm主角出示证据 → 85mm反派崩溃
- **隐忍镜头**：85mm特写攥紧的拳头/隐忍的表情 → 冷光 → 慢推


## 七、负向提示词（通用）

**基础负向（每镜必带）**：
`模糊、变形、多余肢体、五官漂移、卡通化、低清晰度、噪点、字幕、水印、配乐`

**按场景追加**：
- 人物特写：`面部不对称、五官错位、多余手指`
- 动作场景：`过度运动模糊、物理穿模、姿态不自然`
- 古风场景：`现代物品、塑料质感、拉链、运动鞋`
- 都市场景：`古代服饰、繁体字招牌、过时物品`
- 情感场景：`表情僵硬、眼神空洞、笑容不自然`
- 大场面：`人物重复、建筑扭曲、透视错误`

## 八、竖屏引擎检查清单（通用）

- [ ] 单镜是否仅一个核心动作+一次情绪变化？
- [ ] 单镜台词是否≤5-7词？长台词是否拆分？
- [ ] 主角镜头是否标注参考图？
- [ ] 每镜是否标注人物站位/前后层次/朝向？
- [ ] 重要道具/面部是否在中心安全区？
- [ ] 画面内容是否前置4K/60fps/cinematic lighting/9:16/焦段？
- [ ] 画面内容是否描述动线/纵深/质感/表情/光影，且未描述服装？
- [ ] 每镜是否带强制去字幕指令？
- [ ] 每镜是否带负向提示（按场景追加）？
- [ ] 是否每5-6镜分组并给出场景空间坐标？
- [ ] 运镜是否属于四型之一且匹配场景情绪？
- [ ] 焦段是否适配竖屏构图（85mm/100mm特写优先）？
- [ ] 色调是否匹配题材情绪？
- [ ] 伤害/暴力画面是否通过合规替换（见09-compliance-safety.md）？
