# 分镜大纲拆解规范

## 一、分镜拆解原则

将剧本逐句转化为镜头，每个镜头是一个独立的视觉叙事单元。拆解时遵循：
- **一个镜头一个核心动作**：避免多动作堆叠导致AI生成糊帧
- **一个镜头一次情绪变化**：情绪转折处切镜
- **长台词拆多镜**：单镜台词控制在合理长度，用反应镜头/动作镜头穿插
- **时间码连续**：各镜时长加总等于总时长，无重叠无缺口

## 二、分镜大纲字段规范

每镜必须标注以下字段：

### 基础标识
- **镜头编号**：01, 02, 03...（全剧连续编号）
- **时长**：X秒（精确到秒，短剧通常2-6秒/镜）
- **时间码**：XX-XXs（如"10-14s"）

### 视觉设计
- **景别**：大远景/远景/全景/中景/中近景/近景/特写/大特写
- **视点**：第三人称客观/第一人称POV/过肩/主观/上帝视角
- **运镜**：固定/推/拉/摇/移/跟/环绕/升降/手持晃动（详见06-camera-language.md）
- **运镜速度**：横屏引擎用0.2-0.85x档位；竖屏引擎用运镜四型

### 内容
- **核心动作**：一句话概括本镜主体动作（谁+做什么+情绪）
- **视觉基调**：本镜的情绪/氛围关键词（紧张/诡异/温情/震撼/压抑）

### 竖屏Seedance引擎额外字段
- **人物站位**：各人物在空间中的相对位置、前后层次、朝向
- **单镜限制确认**：是否仅一个核心动作+一次情绪变化
- **台词长度确认**：是否≤5-7词，长台词是否已拆分

## 三、景别选择指南

| 景别 | 功能 | 适用场景 |
|---|---|---|
| 大远景 | 建立空间、展示规模 | 场景开场、大场面、环境交代 |
| 远景 | 人物与环境关系 | 行走、追逐、场景内移动 |
| 全景 | 全身动作、肢体语言 | 打斗、舞蹈、全身反应 |
| 中景 | 上半身动作+表情 | 对话、常规叙事、互动 |
| 中近景 | 胸部以上，表情为主 | 情绪对话、关键反应 |
| 近景 | 肩部以上，面部细节 | 情绪爆发、关键台词 |
| 特写 | 面部/手部/道具局部 | 情绪极点、关键道具、细节揭示 |
| 大特写 | 眼睛/嘴唇/物品细节 | 悬念点、反转瞬间、极致情绪 |

## 四、视点选择指南

- **第三人称客观**：默认叙事，观众旁观
- **第一人称POV**：代入感极强，用于主角视角的关键体验（恐惧/发现/奔跑）
- **过肩镜头(OTS)**：对话场景，建立人物空间关系
- **主观镜头**：角色看到的画面（不一定是POV，可带角色情绪的镜头处理）
- **上帝视角/俯瞰**：展示全局、命运感、规模感

## 五、情绪曲线标注

每幕/每组镜头需标注情绪曲线：
- 起点情绪 → 终点情绪
- 如："极度生理恐慌 → 诡异的心理震撼"
- 如："隐忍压抑 → 愤怒爆发 → 反转震惊"

情绪曲线指导运镜速度和景别变化：
- 情绪上升→景别渐进（中→近→特写）、运镜加速
- 情绪爆发→大特写+快切/手持晃动
- 情绪回落→景别拉开、运镜减速/固定

## 六、分镜大纲输出模板

### 横屏电影质感引擎

```
【第X幕：幕名】（XX-XX秒，共X秒）
情绪曲线：XXX → XXX

镜头XX（时长: X秒 | XX-XXs）：
景别与视点：XXX / XXX
运镜：XXX（速度: X倍速）
核心动作：XXX
视觉基调：XXX

镜头XX（时长: X秒 | XX-XXs）：
...
```

### 竖屏Seedance 2.0引擎

```
【第X组（镜号 X-X）：组名】
【场景与人物】
场景：XXX（位置与前后纵深，注明水下/日常/战斗）
人物：XXX（站位与层次：前景/中景/背景，朝向）
道具：XXX（中心安全区确认）

镜头XX（X秒 | XX-XXs）：
景别：XXX
运镜与光影：XXX（运镜四型之一 + 手法 + 光影）
核心动作：XXX（一个动作+一次情绪变化）
人物站位：XXX
台词：角色名："XXX"（≤5-7词）
视觉基调：XXX

镜头XX（X秒 | XX-XXs）：
...
```

## 七、分镜拆解检查清单

- [ ] 所有镜时长加总是否等于总时长？
- [ ] 时间码是否连续无重叠无缺口？
- [ ] 每镜是否仅一个核心动作？
- [ ] 情绪转折点是否有切镜？
- [ ] 景别是否有变化节奏（避免连续同景别）？
- [ ] 是否有POV/特写等变化视点增强代入感？
- [ ] 竖屏引擎：单镜台词是否≤5-7词？
- [ ] 竖屏引擎：每镜是否标注人物站位？
- [ ] 重要道具是否在关键镜头中出现？
- [ ] 转场方式是否标注（硬切/淡入淡出/匹配剪辑）？
