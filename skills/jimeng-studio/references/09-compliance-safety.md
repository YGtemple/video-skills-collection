# 过审安全与合规替换词库

## 一、核心原则

- **画面描述合规，台词绝对保真**：仅修改画面描述中的暴力/血腥/敏感元素，原剧本台词一字不改
- **伤害有表现但不直观**：让观众感知到伤害，但不展示血腥细节
- **死亡有暗示但不特写**：用动作/状态/道具暗示死亡，不展示尸体/断肢
- **用电影语言规避**：烟雾、快速摇镜、强光过曝、剪影、物理遮挡、反应镜头替代直接展示

## 二、绝对禁止画面

以下内容**不得出现在画面描述中**：
- 血腥特写（伤口细节、血液喷溅、内脏暴露）
- 喷溅血液（大面积血迹、血雾喷向镜头）
- 断肢/截肢（肢体分离、残肢特写）
- 尸体（死亡状态的人体特写、尸体堆）
- 利器刺穿身体（刀/剑/子弹穿入身体的直接画面）
- 暴力慢放（殴打/伤害动作的慢动作特写）
- 自残/自杀的直接画面
- 儿童受害的任何直接画面
- 性暴力/性侵犯的任何画面

## 三、合规替换词库

### 3.1 血液/出血类

| ❌ 禁止描述 | ✅ 合规替换 | 说明 |
|---|---|---|
| 吐血 | 嘴角溢出金色光尘 / 嘴角溢出液体 | 用"液体"替代"血"，科幻题材用"金色光尘" |
| 喷血 | 血雾散入海水 / 红色光尘扩散 | 水下场景用"散入海水"，弱化喷溅感 |
| 金血喷溅 | 金色光尘 | 完全去除"血"和"喷溅" |
| 血流如注 | 衣衫浸染深色 / 身体微光闪烁 | 用衣物颜色变化暗示 |
| 血迹 | 深色痕迹 / 锈迹般的印记 | 模糊化处理 |
| 血腥味 | 金属味 / 咸腥味 | 用嗅觉替代视觉 |

### 3.2 死亡/尸体类

| ❌ 禁止描述 | ✅ 合规替换 | 说明 |
|---|---|---|
| 死亡 | 失去气息 / 生命体征消失 / 闭上眼睛 | 用状态描述替代"死亡" |
| 尸体 | 瘫倒的身影 / 静止不动的人 / 垂首的身影 | 不强调"尸体"属性 |
| 尸体堆 | 散落的战甲 / 倒伏的身影群 | 用物品/姿态暗示 |
| 杀死 | 击败 / 击倒 / 让其失去战斗能力 | 用战斗结果替代"杀" |
| 被杀死 | 倒下 / 被击溃 / 光芒熄灭 | 用状态变化暗示 |
| 斩首 | 被震飞 / 鳞甲碎裂跪地 / 身形消散 | 完全替换为非致命表现 |

### 3.3 肢体/伤害类

| ❌ 禁止描述 | ✅ 合规替换 | 说明 |
|---|---|---|
| 断肢 | 手臂无力垂下 / 肢体失去知觉 / 护甲碎裂 | 用功能丧失替代肢体分离 |
| 骨裂 | 蜷缩 / 单膝跪地 / 身体剧烈颤抖 | 用痛苦姿态替代 |
| 内脏 | （完全删除，不做任何描述） | 绝对禁止 |
| 刺穿身体 | 被击退撞壁 / 护甲出现裂痕 / 身体僵住 | 用冲击效果替代刺穿 |
| 子弹击中 | 身体一震 / 护甲溅出火星 / 踉跄后退 | 用反应替代击中画面 |
| 刀砍中 | 鳞甲裂出火星 / 被震退 / 衣物裂开 | 用表面效果替代深入伤害 |
| 烧伤 | 皮肤微光闪烁 / 鳞甲变色 / 烟雾升腾 | 用特效替代烧伤细节 |

### 3.4 暴力动作类

| ❌ 禁止描述 | ✅ 合规替换 | 说明 |
|---|---|---|
| 暴力慢放殴打 | 快速摇镜 / 强光过曝 / 剪影对抗 | 用电影语言遮挡 |
| 拳拳到肉 | 能量碰撞 / 冲击波扩散 / 护甲震动 | 用特效替代肉体打击 |
| 掐脖子 | 单手按住肩膀 / 能量压制 / 衣领被揪住 | 替换为非致命压制 |
| 撞墙（暴力） | 被冲击波推至墙边 / 踉跄后退靠壁 | 弱化暴力感 |
| 摔打 | 被能量震飞 / 身形失衡 / 护甲刮擦地面 | 用能量/物理效果替代 |

## 四、安全表现法（伤害/死亡/怪物消散）

### 4.1 伤害安全表现
用以下方式表现角色受伤，既传达痛感又过审：
1. **鳞甲裂出火星**：科幻/异化角色受击时，护甲/鳞片裂开迸出火星/光尘
2. **被击退撞壁**：角色被冲击力推飞，撞在墙壁/物体上（不展示撞击细节）
3. **嘴角溢出液体**：角色受伤后嘴角有液体溢出（不说是血，用"液体"/"光尘"）
4. **面色发白喘息**：角色脸色变得苍白，急促喘息，表现虚弱
5. **伤口瞬间愈合**：科幻/异能角色受伤后伤口快速愈合（展示愈合而非伤口）
6. **护甲/衣物裂痕**：伤害体现在外层护甲/衣物的裂痕，不展示肉体
7. **能量紊乱**：角色身体周围能量/光效不稳定闪烁，表现受创

### 4.2 致命/死亡安全表现
用以下方式暗示角色死亡/失去战斗力：
1. **闭眼垂头**：角色闭上眼睛，头垂下（经典死亡暗示）
2. **倚墙滑坐**：角色沿墙壁缓缓滑下，坐倒在地（失去力量）
3. **护符滚落**：角色的护符/信物从手中滑落，滚到地上（生命消逝的象征）
4. **光芒熄灭**：角色身体/眼睛/装备的光芒逐渐熄灭（科幻/异化角色）
5. **身形消散**：角色身体化为光点/烟雾/碎片消散（非人类角色）
6. **单膝跪地+垂首**：角色单膝跪地，头垂下，不再动弹

### 4.3 怪物/敌人消散安全表现
反派/怪物被击败时的安全表现：
1. **寄生藤碳化剥落**：怪物身上的寄生/腐化组织碳化后剥落
2. **化为黑灰**：怪物身体崩解为黑色灰烬，随风/水流飘散
3. **崩解为石**：怪物身体石化后碎裂崩解
4. **收作黑烟**：怪物化为一团黑烟，被吸收/消散
5. **能量过载爆裂**：怪物身体能量过载，爆裂为光点（无血腥）
6. **鳞片/外壳碎裂后消散**：怪物外壳碎裂，内部化为光尘消散

## 五、电影语言规避技巧

当画面必须涉及暴力/伤害时，用以下镜头语言规避直接展示：

| 技巧 | 描述 | 效果 |
|---|---|---|
| 烟雾遮挡 | 战斗/伤害发生在烟雾/蒸汽/水花中 | 隐藏细节，只感知动作 |
| 快速摇镜 | 伤害瞬间用快速摇镜/甩镜带过 | 观众看不清细节但感知冲击 |
| 强光过曝 | 伤害瞬间画面被强光/爆炸光覆盖 | 完全遮挡，只留光影 |
| 剪影处理 | 人物/动作以剪影形式呈现 | 无细节，只有轮廓 |
| 物理遮挡 | 用前景物体/其他角色/柱子遮挡关键画面 | 部分遮挡，留想象空间 |
| 反应镜头 | 伤害发生时切到旁观者/受害者的反应表情 | 不展示伤害本身，展示情绪 |
| 声音先导 | 伤害声音先出现，画面后切或切到反应 | 用声音暗示，画面规避 |
| 水下模糊 | 水下场景利用水流/气泡/低可见度模糊 | 天然遮挡，深海氛围 |

## 六、合规检查流程

每镜画面描述完成后，按以下流程检查：

1. **扫描敏感词**：画面描述中是否出现"血/死/尸/断/刺穿/内脏/骨裂/喷溅"等词？
2. **判断是否可替换**：如果出现，是否有合规替换词？→ 替换
3. **判断是否需规避**：如果无法用替换词解决（如直接暴力动作），是否用电影语言规避？→ 调整镜头
4. **确认台词未改**：合规修改仅针对画面描述，台词是否一字未改？→ 确认
5. **最终确认**：修改后的画面是否仍能传达原剧情的情绪和冲突？→ 确认

## 七、常见错误与纠正

| 错误 | 纠正 |
|---|---|
| 把台词中的"血"也改了 | 台词绝对不改，只改画面描述 |
| 替换后画面失去冲击力 | 用反应镜头/音效/光影补充情绪 |
| 用了"血雾"但画面还是喷血 | "血雾散入海水"是弱化版，不能配喷溅动作 |
| 死亡场景用了"尸体"二字 | 改为"瘫倒的身影"/"静止的人" |
| 战斗场景慢放殴打动作 | 改为快速摇镜/剪影/能量碰撞 |
