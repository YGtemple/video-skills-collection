# AI短剧漫剧提示词库

这是一套"影视语言翻译器"：把"很伤心、很紧张、电影感"这类模糊感觉，翻译成模型能执行的运镜、光线、表情、动作、声音指令。核心方法是把影视创作拆成 61 个"语言库"、约 4000 条词条，像点菜一样组合。素材来自千秋|AI造梦等高赞教程，适配固定工具链：**豆包/DeepSeek 写词 · Seedream 5.0 Pro 生图 · Seedance 2.5 生视频**。

先读本文件建立全局观；接到具体环节时，**只读命中的那一本分册**，不要一次加载全部。

## 两条铁律（任何时候都不能破）

1. **资产先行**：先固定人物三视图/角色板、场景俯视图+九宫格、道具图，再用它们生视频。脸、服装、场景没锁死，多镜头必换脸、必崩。
2. **用参考图绑定，不用嘴描述**：生视频用 Seedance 2.5 的全能参考/多图参考，把人物图、场景图、站位图一起喂进去，并在提示词里 **@对应图片**；首次命名后，下文只用名字，不重复 @。

## 九步全流程（横屏 16:9）

1. **剧本/大纲**：豆包/DeepSeek 写大纲、分集、人物小传、对白 → 读 `01`
2. **资产先行**：Seedream 5.0 Pro 出人物三视图、场景俯视图+九宫格、道具图 → 读 `03`（人物）、`05`（场景）
3. **分镜脚本**：拆成"每镜≤5秒"分镜表（镜号/时间码/景别/角色/动作/情绪/场景/生图提示词/图生视频提示词/台词音效）→ 读 `02`
4. **Seedream 生图**：按分镜出每镜首帧，横屏 16:9，每个美术资产**至少出 4 个候选**挑最稳
5. **Seedance 生视频**：多图参考绑定人物+场景+站位，逐秒时间轴，单段 5–15 秒、关键镜头最长 30 秒 → 运镜动作词读 `07/08/09`
6. **段间衔接**：用 1 秒技术全景站位图、动作接点搭桥，保持运动方向/画面位置/视线连续，在转身开门拔刀等动作瞬间切镜 → 读 `02/06`
7. **声音**：台词由 Seedance 2.5 直接生成（标准普通话、中文口型同步，不用 TTS）；BGM 由助手在剪辑阶段统一选曲加 → 读 `10`
8. **剪映后期**：调色、去重帧、统一 BGM/音效；导出 H.264 Baseline + AAC + faststart（保证 Windows 直接可播）
9. **封面/海报**：片名与文案直接写进 Seedream 生图提示词，模型一步渲染，**禁止本地 PIL/PS 叠字**；统一 16:9、≥4 候选 → 读 `12`

## 61 个语言库怎么查

不确定该用哪个"语言库"时，先读 `00-总览与工具链地图.md` 第四节"61 个语言库用途速查"，一句话定位到库，再按表中标注的分册去取具体词条。组合顺序参考：**先定情绪 → 选镜头 → 配光线色彩 → 加声音表演 → 最后查反提示词**。

## 固定工具链与参数（用户既定偏好，默认遵守）

- **生图**：Seedream 5.0 Pro 最高质量，不降级；横屏 16:9；每个美术资产≥4 候选；锁角色/场景时上传参考图，提示词最前加"以参考人物为准"，参考度量约 68。
- **生视频**：Seedance 2.5 最高质量，不降级；横屏 16:9；关键镜头最长 30 秒。
- **省积分分级用模**：用 Seedance 2.0/2.0-fast 打草稿、定机位、跑分镜节奏，2.5 只留给关键镜头、情绪特写、打戏高潮和最终交付。
- **台词**：标准普通话、中文口型同步，由视频模型直接生成，不用 TTS、不用日语。
- **字幕**：视频一律不做字幕、不加水印，提示词写明"不要字幕"，字幕用户后期自己加。
- **封面**：片名/文案写进生图提示词由模型一步渲染，不本地叠字。
- **BGM**：由助手选曲、剪辑阶段统一加，生成阶段只留对白与环境音。
- **导出**：H.264 Baseline + AAC + faststart。

## 提示词输出规范（每次生视频前必须执行）

1. 生成前**完整展示**该镜的详细提示词，用户提供的人物图/场景图必须在提示词中以 **@图片** 引用；**强制使用图片参考，禁止纯文字凭空生成**。
2. 默认直接用已审核通过的资产 + 提示词生视频，**不产出关键帧/逐镜定帧/首尾帧**（除非用户明确要求）。
3. 分镜提示词无需逐条找用户确认，可直接生视频，用户只审核视频成品、通过后再做下一条。
4. 图生视频提示词三段式：全局设定层（风格/光影/材质/角色锚定）→ 人物层（@人设图、外形、性格、情绪、潜台词）→ 分镜层（逐秒时间码+镜头+动作+台词+音效）。
5. 总公式：风格 + 角色（@图） + 场景（@图） + 分镜头（时间+镜号+画面+动作+音效+台词）。

## 避坑清单

- 不要跳过资产先行直接生视频；不要一句话往一张参考图塞太多信息（人脸要放大占比）。
- 不要只说"电影感/氛围感/高级感"空词，要翻译成可执行的运镜、光线、情绪词。
- 不要用 2.5 跑全部草稿；不要每段各加各的 BGM；不要在视频里加字幕。
- 不要本地叠字做封面；不要竖屏成片；台词不要走 TTS；导出不要忘 faststart。
- 每条提示词末尾按分册 `11` 加反提示词（无畸形手、无面部崩坏、无多手指、无衣物穿透、无背景闪烁、口型同步）。

## 使用方式

- 把分册里的"系统提示词"整段粘贴进豆包/DeepSeek 对话框，末尾补用户的创意种子即可；豆包与 DeepSeek/GPT 同为大模型对话接口，用法一致。
- 分册内容较大（多本 6 万–17 万字），需要具体提示词时用关键词在对应分册里检索（如"三视图""希区柯克变焦""法相元神""逐秒时间轴"），不要整本通读。
