# Seedance 逐镜头提示词渲染器

## 渲染目标

把内部动作设计渲染为“全局风格锁定 + 各 Clip（空间站位 + 镜头一至镜头 N + 结尾状态 + 集中约束）”的正文。默认适配 Seedance 2.x；用户指定其他模型时保持相同正文结构，只调整模型明确限制。

## 全局风格锁定

全局风格锁定只输出一次，必须放在全部 Clip 提示词之前。它负责锁定整支视频的底层生成质感，不负责画幅、人物表演尺度、镜头节奏或剧情执行。任何 Clip 内不得重复全局风格锁定词。

普通风格锁定必须由用户指定风格、视觉资产库风格和剧本题材共同推导，不得机械套用固定词。用户只给出一个风格词时，不得照抄原词，必须先内部解析，再输出可执行的六槽位锁定词。用户指定风格与资产库风格不一致时，提醒用户并询问沿用哪一方，不自动覆盖。

内部解析维度：

- 风格类别：真人 / 2D / 3D / 混合媒介。
- 媒介来源：电影摄影 / 游戏过场 / 插画 / 动画 / 漫画 / 实时渲染 / 实验影像。
- 渲染方式：实拍 / UE5 / PBR / 手绘 / 平涂 / 赛璐璐 / 水墨 / 低多边形。
- 角色质感：真人演员 / 数字人 / 动捕角色 / 卡通角色 / 漫画人物 / 剪纸或黏土角色。
- 运动质感：真实摄影运动 / 动捕驱动 / 手K动画 / 有限动画 / 逐帧动画 / 电影级运动模糊。
- 材质语言：真实皮肤 / PBR材质 / 厚涂笔触 / 纸张纹理 / 漫画网点 / 胶片颗粒。
- 光影色彩：冷暖对比 / 高饱和 / 低饱和 / 暗调 / 柔光 / 高反差 / 平面色块。

输出格式：

```text
风格锁定：{媒介来源}，{渲染方式}，{角色质感}，{运动质感}，{材质语言}，{光影色彩}。
```

锁定词中的专业锚点通常保留 3—8 个。用户未要求强风格时，不使用导演名、胶片品牌、强类型风格词；强风格词只在用户明确指定或剧本风格高度匹配时使用。

## 特殊风格化

特殊风格化只在有明确触发依据时启用，用于回忆、梦境、监控、手机直播、新闻画面、游戏 UI、古籍插画、精神幻觉等局部段落，不得覆盖全片普通风格锁定。

无触发依据时必须显式输出：

```text
特殊风格化：不启用。全片保持普通风格锁定，不额外叠加梦境、回忆、监控、漫画化、游戏 UI 等局部风格。
```

启用时输出：

```text
特殊风格化：启用。
特殊风格提示词：……
启用段落：Clip 02 镜头四至镜头六（回忆段）。
```

启用时必须写明启用段落范围；被标记的 Clip 镜头内可以叠加特殊风格词，其余 Clip 不受影响。

## Clip 标题

把时长、画幅和视觉媒介放在代码块外的 Clip 标题中：

```markdown
### Clip 01｜15秒｜16:9｜真人写实武侠
```

代码块正文必须从“空间站位：”开始，不再用一整段自然语言开场，也不重复全局风格锁定词。

## 固定正文格式

```text
空间站位：@角色A 位于画面左侧，面对画面右侧的 @角色B；@角色B 位于画面右侧，面对 @角色A；说明姿势、表情、距离、场景轴线和关键道具位置。

镜头一（0-1.2秒）：光圈 f/2.8（浅景深，背景明显虚化），焦段 80mm（近景），中近景（medium close-up）或机位/运镜说明，动作发起、接触和结果。
镜头二（1.2-2.4秒）：光圈 f/2.8（浅景深，背景明显虚化），焦段 100mm（近景），机位/视角/运镜说明，承接上一动作的局部变化。
镜头三（2.4-3.6秒）：光圈 f/4（中等景深，背景轻微虚化），焦段 25mm（全景），低角度（low angle）广角或移动镜头，表现双方完整身体位移和局势变化。
……

结尾状态：人物位置、朝向、姿势、武器归属和环境结果。
约束：集中列出当前片段最容易失败的连续性问题；声音要求。
```

使用中文数字编号与括号时间戳：`镜头一（0-1.2秒）：`、`镜头二（1.2-2.4秒）：`。不要输出“Shot 1”或把时间范围放到摄影描述末尾，除非用户明确要求其他格式。

## 每个镜头的必要成分

每一行镜头至少包含：

1. 标题中的起止时间 `（起始-结束秒）`。
2. `光圈 f/x（景深描述）`。
3. `焦段 xxmm（景别）`。
4. 景别、角度、视角、固定/手持或运镜方式中的至少两项；专业视听术语按「视听术语双语对照」写作 中文（English）。
5. 可见动作；对峙镜头写完整台词原句（标注情绪与语速）或微动作。
6. 接触、受力、位移或对下一镜头有用的结果；对峙镜头写视线变化、失态或关系改变。

第一个镜头从 0 秒开始；后一镜头的起点必须等于前一镜头的终点；最后一个镜头必须结束在 Clip 总时长。不得重叠、留空或累计超过总时长。需要小数时最多保留一位，统一使用半角连字符 `-`。

推荐写法：

```text
镜头三（2.4-3.8秒）：光圈 f/4（中等景深，背景轻微虚化），焦段 25mm（全景），低角度（low angle）荷兰角（Dutch angle）手持（handheld）后拉（pull out），承接梅紫右手锁住丹眉颈侧的动作；梅紫后搓步试图把丹眉带倒，丹眉立刻前搓步贴近，使两人距离没有被拉开，丹眉身体被迫前倾但仍未失去平衡。
```

不要只写摄影参数或只写“二人继续打斗”。镜头行内不写全片级风格与材质词，光线只写本镜头的剧情光源落点或变化。

## 动作单元与镜头数

允许多个镜头覆盖同一个连续动作单元，但必须让每个镜头提供不同的观看信息：

- 全景交代双方动作和空间结果。
- 中近景看清抓腕、锁颈或武器接触。
- 脚部特写表现搓步、滑停和重心。
- 主观镜头表现攻击逼近或受压。
- 反应近景强调决定性受力。

切换角度不代表动作重新开始。使用“顺势、同时、承接、动作未停”保持连续。

镜头数量遵循 `SKILL.md` 的「动作容量」并按模式核对：动作模式每个完整 15 秒 Clip 不得少于 10 个镜头，对峙模式不得少于 5 个；一镜到底或用户明确指定更少镜头时除外。渲染时实际统计“镜头一、镜头二……”条目数并与当前模式核对。

增加镜头时使用不同观看重点覆盖同一条动作因果链，例如建立空间、攻击发起、格挡接触、手部或武器细节、脚步、主观视角、受力反应、局势变化和收势。镜头数服务动作与节奏，不复制动作，也不把十个镜头误写成十个互不相关的招式。对峙模式按 dialogue-scene-mode.md 的配额增加镜头，不为凑数切分台词或重复反应。

## 一镜到底的例外格式

用户明确要求一镜到底时，不得伪装成多个剪辑镜头。使用：

```text
空间站位：……

镜头一（0-15秒）：光圈 f/4（中等景深，背景轻微虚化），焦段 35mm（全景），连续长镜头（long take），说明起始机位与唯一摄影运动；动作阶段一……；动作阶段二……；动作阶段三……；摄影机全程不切镜。

结尾状态：……
约束：……
```

不要在一镜到底模式中输出镜头二、镜头三。

## 光圈与焦段

统一格式：

- 写 `f/2.8`，不要写 `f2.8`。
- 写 `80mm`，不要只写 `焦段80`。
- 光圈值后必须紧跟中文景深描述，写作 `光圈 f/2.8（浅景深，背景明显虚化）`。
- 焦段值后必须紧跟中文景别描述，写作 `焦段 85mm（近景）`。
- 参数括号内的景深、景别注释保持纯中文、不附英文，避免逐镜头膨胀；双语规则只作用于摄影描述正文（见「视听术语双语对照」）。

光圈与景深描述对照：

- f/1.2—f/2：极浅景深，背景强烈虚化。
- f/2.2—f/2.8：浅景深，背景明显虚化。
- f/4—f/5.6：中等景深，背景轻微虚化。
- f/8—f/11：深景深，前后景基本清晰。
- f/16 及以上：全景深，远近皆清晰。

焦段与景别描述对照：

- 24mm 及以下：大全景。
- 25—35mm：全景。
- 36—55mm：中景。
- 56—79mm：中近景。
- 80—120mm：近景。
- 121—200mm：特写。
- 200mm 以上：大特写。

根据镜头功能选择参数：

- 24—35mm、f/4 左右：全身动作、空间位移、低角度和多人关系。
- 35—50mm、f/2.8—f/4：中景攻防。
- 80—100mm、f/2—f/2.8：表情、抓腕、锁颈和打击近景。
- 135—200mm、f/2.8—f/4：脚、手、武器接触等强压缩细节；狭小空间慎用。

用户明确提供参数时优先保留，但景深与景别注释仍按实际使用的参数填写；明显无法完成镜头目的时调整为最接近的可执行参数，并在生成前提醒中说明。

## 视听术语双语对照

镜头行内的专业视听语言（景别、运镜、角度、视角等）使用「中文（English）」格式：同一术语在同一 Clip 内首次出现时附英文，之后只写中文。光圈、焦段参数括号内的注释不附英文。台词、动作描述和普通动词不附英文。

常用对照表：

| 中文 | English |
|---|---|
| 大全景 | extreme long shot |
| 全景 | full shot |
| 中远景 | medium long shot |
| 中景 | medium shot |
| 中近景 | medium close-up |
| 近景 | close-up |
| 特写 | close-up detail |
| 推进 | push in |
| 后拉 | pull out |
| 横摇 | pan |
| 上摇 / 下摇 | tilt up / tilt down |
| 横移 / 侧移 | truck |
| 跟拍 / 跟随 | tracking shot |
| 环绕 | orbit |
| 升降 | crane |
| 甩镜 | whip pan |
| 手持 | handheld |
| 固定拍摄 / 固定机位 | static shot |
| 低角度 | low angle |
| 高角度 | high angle |
| 俯拍 | overhead shot |
| 荷兰角 | Dutch angle |
| 第一视角 / 主观镜头 | POV |
| 过肩 | over-the-shoulder |
| 升格 | slow motion |
| 深焦 | deep focus |
| 长镜头 / 一镜到底 | long take |

未列入表中的术语按同样规则处理：确有通用英文译法时附英文，生造或模型侧无共识译法的词不强行翻译。

## 第一视角与主体

正确：

```text
梅紫第一视角拍摄丹眉：画面看见丹眉挣扎。
丹眉第一视角拍摄梅紫：画面看见梅紫膝盖逼近。
```

错误：

```text
丹眉第一视角拍摄丹眉。
```

只有存在镜子、反射或显示屏时，第一视角才可以看见视角拥有者本人。

## 空间站位

空间站位必须说明：

- 主要角色在画面左侧、右侧、前景、后景或高低位置。
- 双方相互面向的方向。
- 初始距离和姿势。
- 动作轴及关键场景结构。
- 关键武器由谁持有、哪只手持有。
- 对峙场景补充空间权力：谁站着、谁坐着、谁正对门、谁背对门。

资产首次出现时使用短锚点，后续镜头只写资产名或角色名。

同框超过四人时，空间站位用分组写法：

```text
左侧由外到内：@阿豹（站）、@凤姐、@肥佬；右侧：@矮仔（扶椅背）、@七叔、@老鬼。
```

不逐人单句展开位置；首次出现的资产短锚点不受此限。

如果用户没有提供可见资产特征，直接使用裸 `@资产名`，不要添加“沿用既有资产”这种无信息括号。

## 结尾状态与约束

结尾状态只记录下一段或成片真正需要的事实，不重复最后一个镜头全文。剧本要求的黑屏、渐隐在此写明，格式「画面随××渐黑」。

约束集中写一次，最多五至八项，例如人物数量、持握手、轴线、武器归属、场景破坏、穿模和动作瞬移。其中至少三项必须引用本 Clip 的具体事实（人名、持物、座位、血迹、已熄灯笼），不允许整段由“人物穿模、动作瞬移、无音乐无字幕”等通用项组成。声音要求固定占最后一项：

```text
约束：保持两名角色、右手持刀和画面左右关系稳定，避免武器换手、人物穿模、动作瞬移和第一视角身份错误；保留脚步、喘息、衣料与打击声，无音乐，无字幕。
```

## 字数与去重

- 15 秒逐镜头正文目标为 1000—2000 个汉字；超过 14 个镜头时允许接近 2400 字。
- 对峙模式 15 秒正文目标为 700—2400 个汉字：台词完整原句计入字数，镜头数少时下限放宽，台词密集时允许接近上限。
- 30 秒逐镜头正文目标为 1400—2600 个汉字。
- 每个镜头都写光圈和焦段属于必要格式重复；全局风格锁定词只允许出现在锁定块，Clip 内重复视为去重遗漏。
- 不要重复同一整段机位声明、资产外貌、风格展开描述或否定约束。
- 删除无意义的开头和结尾引号。

超长时保留顺序：全局风格锁定 > 空间站位 > 动作连续性 > 接触与受力 > 台词原句 > 镜头功能 > 参数 > 结尾状态 > 必要约束 > 装饰性光影。

## 输出前检查

- 全局风格锁定是否只输出一次且位于全部 Clip 之前；用户给的风格词是否已解析为六槽位锁定词。
- 特殊风格化是否显式输出启用或不启用；启用时是否写明启用段落范围。
- 任何 Clip 内是否无全局风格锁定词重复。
- 正文是否从“空间站位：”开始。
- 是否使用“镜头一（起始-结束秒）：”格式。
- 时间轴是否从 0 秒开始、首尾连续且准确结束在 Clip 总时长。
- 镜头条目数是否与当前模式下限核对通过（动作 ≥10，对峙 ≥5）。
- 每个镜头是否同时具有参数、摄影和动作结果。
- 第一视角拥有者是否正确。
- 机位是否保持在动作轴同一侧；若越轴，是否有中性镜头或连续运动建立新关系。
- 相邻镜头是否无因重复同一个动作；对峙镜头是否无因重复台词或反应。
- 手腕、锁颈手、武器持握手和人物左右是否连续；对峙中座位、视线与持物是否连续。
- f 值和 mm 单位是否规范；光圈后是否有景深描述，焦段后是否有景别描述。
- 镜头行内专业视听术语是否按「中文（English）」处理，且同一术语在同一 Clip 内只标注一次英文。
- 是否存在多余引号、未完成句或截断镜头。
