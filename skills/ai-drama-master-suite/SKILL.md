## ⛔ 阶段门控总则（选项驱动 · 用户确认 · 资产 AI 生成必审 + 视频成片必看）

**0. 最高原则（不可违反）**
1. **禁止一次性自动跑完整制作**：用户只给一句话想法后，不得自动把剧本→资产→分镜→视频→后期全部做完。
2. **每个阶段结束必须走三步**：**⛔ 暂停 → 给选项（每个附一句话亮点 + 利弊 + ⭐推荐项）→ 等用户明确同意**，之后才进入下一阶段；用户未确认绝不往下做。
3. 用户在每个门控点都可：**回复编号选定 / 混搭多个选项 / 回复「再发散」换一批 / 直接写修改意见**。
4. **【美术资产 AI 可直接生成，但出图必审、通过才定稿 @】**：角色、场景、道具、关键画面 / 分镜参考图等进入成片的图像资产，**AI 可以直接调用文生图（T2I）生成**；但每一张 / 每一批生成完，必须立即把「成图 + 该图所用通用模型提示词 + 三维参数」给用户审核（**如你点名 MJ，再附 MJ 版英文提示词**）——用户可 ✅ 直接通过 / 提修改意见 / 要求重生成——**通过后才定稿**，才在分镜与视频提示词中以 `@` 引用、强制图片参考；未通过则按意见改提示词 / 重生成、再审，通过才定稿。「用户自制」保留为可选路径：用户想自己出图时，AI 默认给通用模型版提示词 + 三维 + 清单顺序 + 建议（你点名 MJ 时再补 MJ 版），用户回传后同样走审核确认。
   - AI **仍负责视频生成（T2V / I2V）**：**每次生成视频，先在对话中完整展示该视频的详细提示词，展示提示词的同时直接调用生成（不停下等待确认、不设确认环节）**；成片生成后，把「成片（内嵌预览播放器）+ 该视频完整脚本/分镜 + 完整视频提示词（@已审核资产）」一起给用户看，用户认可才生成下一个。
5. **任何资产出图都必须交付用户审核、不自作定稿**：AI 可直接出资产图，但出图后立即交付审核、不攒批、不擅自定稿；示意图 / 参考图若要直接当作定稿资产进入成片，同样必须经用户审核通过。

**3. 故事发散操作法（放在模块1最前）**
- 用户只有一个想法 / 题材 / 一句话故事时，**先不写大纲、不定资产**，一次产出 3–5 个差异化方向填入《故事发散选项表》（项目目录 `/home/user/Doubao/chats/38436370915409154/故事发散选项表.md`）：编号 / 方向 / 题材 / 核心设定 / 主角原型 / 主要矛盾 / 开头钩子 / 一句话亮点 / 利 / 弊 / 推荐。
- 各方向必须在题材、核心设定、主角原型、主要矛盾、开头钩子上明显不同；给完即 ⛔ 暂停等确认。
- **用户确认故事之后**，才产出 / 定稿①立项大纲。

**3+. 钩子画面化与因果链 · 两条硬性创作要求**
- **① 钩子结合画面（看得见，不靠「说」）**：开头钩子必须是**看得见的具体画面 / 动作 / 场景**，靠第一帧 / 前几秒的视觉冲击或视觉悬念抓人；**不能靠旁白、台词、字幕、标题去「说」钩子**；钩子画面必须直接关联核心矛盾 / 悬念，不用与正片无关的唬头。故事发散与立项时「开头钩子」栏一律填**具体钩子画面**，不填抽象概念。
- **② 因果关系（A→B→C，消灭流水账）**：剧情按因果链推进，不是「然后…然后…」的事件罗列；钩子抛出的异常 / 悬念必须有成因（可后置揭示）；人物每个行动都要有动机、有后果；伏笔是「因」、回收是「果」，反转意料之外情理之中；自检时对每个场景追问「**它因什么发生、又导致了什么**」，删除与主线无因果关系的段落。

### 模块1：剧本创作
**输入**：想法/题材/一句话故事
**输出**：完整剧本（时长由故事需要决定，90秒到10分钟均可，不强行锁死）
**⛔ 门控前置**：用户只有想法时，**先做故事发散——一次给 3–5 个彼此差异化方向**（题材/核心设定/主角原型/主要矛盾/开头钩子各不相同，钩子栏填看得见的具体画面）填入《故事发散选项表》，给完即 ⛔ 暂停等确认；**故事确认后才写大纲、才进人物/资产方案**。详见上方「⛔ 阶段门控总则」。
**核心能力**：
- **时长灵活**：根据故事信息量自然决定时长，参考模板有"90秒四幕"和"5分钟五阶段"，但只是参考不是硬约束
- **爆款公式库（默认套用）**：09结构公式 + 10情绪设计，写都市奇幻/爱情/灵异/超能力类剧本时默认使用；**现实亲情/家庭伦理/社会痛点题材（默认赛道）默认套 34 号公式**（3秒钩子+5秒留人+双故事双转折+刀+故意片面引评论）
- **默认赛道：亲情**——故事发散时 3–5 个方向里至少 2 个是亲情/家庭伦理题材
- 五大赛道：都市日常/都市玄幻脑洞/古风仙侠/悬疑科幻末日/开放赛道
- 九大结构原型：单空间高压对峙、倒计时规则收缩、交易代价升级、身份关系错位揭底、错误解法反噬、仪式中断夺权、系统失控推演、多维视角塌缩、绝对规则置换
- 三大叙事重心：角色向/创意向/强剧情向
- 高级编剧技巧：三秒钩子、反转三层结构、台词功能检查、人物反差公式、翻转簇节奏、信息差收网、翻盘台词句法、签名道具

**详细规范**：见 [references/01-script-creation.md](references/01-script-creation.md)，奇幻灵异爆款结构见 [references/09-hkkk-formula.md](references/09-hkkk-formula.md)，**现实亲情爆款打法见 [references/34-viral-family-drama-formula.md](references/34-viral-family-drama-formula.md)**，情绪扎心见 [references/10-emotion-design.md](references/10-emotion-design.md)；把大纲写成完整剧本的双写作模式（M1影视/M2小说化）与节奏档位四档见 [35号](references/35-script-drafting-modes.md)，整剧/单集/单场会诊见 [36号](references/36-script-doctor.md)，逐句台词精修见 [37号](references/37-dialogue-expert.md)

### 模块2：分镜设计
**输入**：剧本/小说片段
**输出**：标准化分镜脚本（中文画面规格书格式 或 分镜组格式）
**核心能力**：
- **分镜全流程操作法（26号，主线）**：剧本→切场景→《场景卡》（目标/冲突/**价值转折**）→**戏剧节拍 Beat 拆解**→空间调度→Coverage 覆盖机位→镜头排序时长换算→衔接自检；含真人写实戏完整走查
- **高频场景镜头配方库（27号，照着套）**：双人对话/行走对话/多人饭局/争吵/重逢/离别/进门/单人独白/打电话/对峙/职场/亲情饭桌/时间蒙太奇/悬疑 14 套成套镜头
- **镜头连贯与剪辑思维（28号）**：30°规则、动作接动作、视线匹配、屏幕方向、主镜头/反应/插入/切出、场景进出、声音桥
- **为 AI 生成而设计镜头（29号，落地校验）**：AI 单镜能力边界、高失败镜头黑名单+替代、复杂镜头拆分四法、真人写实可信度清单、表演三要素（凝视对象+情感节拍+身体微约束）、虚词动作化、去 AI 味技巧
- **动作戏正面设计（30号）**：打斗/追逐/枪战的因果语法（局势距离→发起→防守命中→受力位移→恢复）、**"动作单元≠剪辑镜头"**（多镜覆盖同一动作不重演）、容量配额、徒手/兵器/枪战/一对多/Boss、摄影三策略与连续性校验
- **对峙深化＋全局风格锁定＋长场景＋时间戳渲染（31号，输出协议层）**：对峙张力链（施压→承受→泄露反制→新平衡）与微动作、**全局风格六槽锁定（全片一次）**、特殊风格化不污染全局、资产短锚点卡、长场景在动作结果处拆分与跨 clip 连续、**逐镜头闭环时间戳（光圈景深/焦段景别/术语双语/结尾约束）**、Pre-flight
- 专业电影级镜头语言约束（02号，红线）：光源动机铁律、纵深主层机制、五层色彩思维、物理可行性铁律、情绪-镜头匹配与反规则、人物出现节制、重技法频率上限
- 通用分镜组格式（V2.0 PLUS，22号输出层）：分镜组5–30秒灵活（不锁死），@人物@标注，XMB运镜规范，长台词拆分
- **组末技术全景锚点（33号，第4层连续性）**：同场景跨组、多人连续走位/动作交接时，非末组可在组尾追加1秒无对白技术全景（模式A，正片预扣1秒），或在正片完成后另生成5秒技术补段（模式B，正片不裁切）；截末帧作下一组锚点帧，与24底图（静态房间）/25俯视图（调度规划）/04末帧链（组内镜间）互补
- 双输出格式：中文【标签】块画面规格书（给人看）+ 结构化分镜组（给AI用）

**详细规范**：**操作主线 [26号](references/26-storyboard-workflow-beats.md)**，场景配方 [27号](references/27-scene-coverage-recipes.md)，连贯 [28号](references/28-continuity-editing-rules.md)，AI 适配 [29号](references/29-ai-shot-design.md)，**动作戏 [30号](references/30-action-scene-shot-design.md)，对峙/风格锁/长场景/时间戳渲染 [31号](references/31-standoff-style-lock-continuity.md)**；红线见 [02号](references/02-storyboard-design.md)，容器格式套 [22号](references/22-15s-storyboard-group-template.md)；动作分题材打法（自由格斗/武侠兵器/超能力/战场群战）见 [38号](references/38-action-choreography-subgenres.md)，文字场记表与跨组首镜对账见 [39号](references/39-field-continuity-notes.md)

### 模块3：提示词生成
**输入**：分镜脚本 + 用户提供的人物参考图
**输出**：可直接粘贴的AI视频生成提示词（含人物@艾特+图片参考）
**核心能力**：
- MiniMax H3 15秒三流程：文戏模式（关系变化/对白/微表情）、武戏模式（高密度打斗/连续攻防）、九宫格模式（先生成3×3关键画面再生成视频提示词）
- 即梦/Seedance三引擎：横屏电影质感（阿莱65）、竖屏Seedance末世水世界、通用竖屏
- **Seedance 2.5 最高优先级**：生成的提示词以Seedance 2.5为默认目标引擎，提示词一经用户确认即原文透传，不改写不润色
- **强制图片参考+@艾特**：用户提供的人物图片必须在提示词中用`@图片N`格式艾特，每次生成必须带参考图，不用纯文字
- **人物图片不重复**：用户给的人物图一人一角色，多余角色纯文字描述
- 图片内联引用：`主体名称（@图片N）`格式
- 全正向描述结构：只陈述"生成什么"
- **★ 资产提示词必标三大控制维度**：②每个资产旁必须列出 风格化(`--stylize`/写实↔风格化档)、怪异度(`--weird`/创意奇特档)、多样性(`--chaos`+`--seed`/种子差异度) 三项取值或档位＋理由；③仅在你点名 MJ 产出时同样必标。本套件默认真人写实=低/低/低并固定 seed，切漫剧分支时风格化可中~高、其余仍低；高 weird/chaos 牺牲一致性、定稿回落。详见「📦 标准交付」。
- **跨组技术全景块（33号）**：模式A在非末组 video_prompt 末尾追加1秒无对白技术全景块；模式B在正片完成后另写5秒技术补段提示词。技术素材只复现整空间与全员末态（位置/朝向/姿势/服装/道具/门窗/光源），无对白、无字幕、无BGM；下一组 prompt 开头按31号“承接上一段，”起句，并挂载技术全景锚点帧作参考图

**详细规范**：见 [references/03-prompt-generation.md](references/03-prompt-generation.md)，纯净正文写法（只留模型可执行内容、删管理话术、素材先定义再@）与超长去重拆组见 [41号](references/41-seedance-prompt-adapter.md)

### 模块4：视频生成执行
**输入**：提示词列表 + 角色锚定图（用户提供的人物图片）
**输出**：批量生成的视频片段（内嵌预览播放器+公共链接，视频自带角色对话语音）
**核心能力**：
- **Seedance 2.5 最高优先级默认引擎**：固定model_version=seedance_2.5，提示词原文透传不改写；**每次生成先完整展示详细提示词、展示提示词的同时直接生成（不停下等待确认）**（提示词必须在生成时完整展示，不省略、不事后补），时长5-30秒整数，比例仅支持16:9/4:3/1:1/3:4/9:16/21:9
- **生成后成片+完整脚本/提示词必看**：每个视频生成后，必须把「成片（内嵌预览播放器）+ 该视频完整脚本/分镜 + 完整视频提示词（@已审核资产，含模型/时长/比例/参考素材/人物@艾特）」一起给用户看；**用户认可才生成下一个**，逐个生成、逐个审核，禁止未经认可连续批量自动出全部片段；不合适按意见改/重生成再审
- **强制图生视频**：每次生成必须带参考图，用户提供的人物必须@艾特，不使用纯文字生成
- **人物图片不重复**：用户给的人物图一人一角色，多余角色纯文字描述
- **台词写入提示词**：有台词的镜头，必须在提示词中明确写出角色台词（如"角色A说：'你来了'"），让AI视频模型直接生成带语音的视频，不使用TTS单独合成
- 生成任务卡：每镜建立任务卡（Prompt/参考图/模式/优先级/依赖）
- 批次策略：按场景分组，同场景同批生成，单批≤6镜
- 优先级调度：P0反转/高潮/悬念镜优先
- 连续镜首帧处理：前一镜末帧作为后一镜首帧参考
- **跨组挂组末锚点帧（33号）**：跨组续接时参考图顺序＝机位底图/场景主图（第1位）→技术全景锚点帧（第2位、不作为角色@）→各角色锚定图（逐角色@）；模式A尾段错误但正片正常时，转模式B生成5秒技术补段；锚点帧不合格不得下传
- 重试与版本管理：每镜2-3版本，最多重试3次，3次后导演决策
- **全局铁律：每生成完一个视频，必须以内嵌预览播放器形式把「成片 + 该视频完整脚本/分镜 + 完整视频提示词（@已审核资产）」一起交付（用户可直接在聊天中预览播放），⛔ 用户认可这个成片后才生成下一个（不未经认可连续批量自动出全部片段），同时附公共访问链接。

**详细规范**：见 [references/04-video-production.md](references/04-video-production.md)

### 模块5：质量审核 + 一致性管理
**输入**：已生成的视频片段
**输出**：审核报告 + 一致性检查报告 + 修复方案
**核心能力**：
- 七维逐镜审核：画面质量/角色一致性/动作自然度/场景还原度/镜头语言/合规安全/时长节奏
- AI问题诊断库：面部崩坏/肢体扭曲/场景跑偏/光影异常/动作卡顿等20+常见问题
- 分级修复策略：轻度（后期修复）/中度（调Prompt重生成）/重度（重新设计镜头）
- 四维跨镜一致性追踪：角色一致性/场景连续性/光影衔接/道具追踪
- **跨组锚点一致性核对（33号）**：核对下一组开场人物站位/朝向/服装/道具/场景状态与上一组技术全景锚点帧一致；偏差属P0（越轴/换脸/服装跳变/道具消失）即回模块4重生成对应组、不带错锚进入下一组
- 剪辑掩盖技巧：插入过渡镜/快切蒙太奇/音效桥接/调色统一
- **群演与小道具资产层（40号）**：群演人数密度分级/前中远景排布/不挡脸不围观不同脸；小道具朝向与单实例锁（手机正反面、桌上与手里不同时各一个）；与15号（主角/主场景/关键叙事道具锁定）互补——主角主场景资产仍以 script-asset-master（铁律33 P0）＋15号为准，40号只补群演道具层

### 模块6：硬拼接交付（不做剪辑）
**输入**：审核通过、用户已确认的镜头（视频自带角色对话语音）
**输出**：按分镜顺序无损硬拼接成的一条粗成片（原样、未做任何处理），供用户导入自己的剪辑软件；全片无字幕
**核心能力（只硬拼接，不做后期）**：
- 后期剪辑、节奏重编、调速、调色、片头片尾，以及配乐BGM的添加，一律用户自理，技能不主动做（**用户后期自己配乐 / 声音设计的判断标准见 [32号](references/32-sound-design-reference.md)**）
- 零改动硬拼接：一刀不裁、不重编码、不重采样，不加转场/字幕/配乐BGM/特效；台词与真实环境音原样保留，镜头边界处环境音自然衔接、不突变不重叠（声音口径详见铁律26；采用33号模式A时，各组末尾1秒锚点尾在拼接前预设剔除，不计入“正片一刀不裁”范围；无法精确流拷贝切尾时转模式B，5秒技术补段不进filelist）
- 先统一规格再流拷贝：ffprobe 核对分辨率/帧率/编码/像素格式/音频采样率/声道一致后，用 concat demuxer ＋ `-c copy` 流拷贝（零重编码）；成片以 H.264(yuv420p)+AAC、faststart 的 MP4 封装；仅源编码/像素格式不兼容（HEVC、非 yuv420p）才视觉无损高码率转码（CRF≈16–18，不缩放/不降帧）；分辨率帧率不一致回源头重新导出，禁止硬拼、禁止靠转码对齐
- 音画同步红线：严禁嘴型与声音错位；拼后逐边界核对同步、总时长＝各段时长之和、无丢帧/重复帧，不合格重拼
- 不压缩画质：保持原始分辨率/帧率/码率，默认流拷贝零损失；上传选原画质，通道必压缩则另附原始文件并说明
- 文件按内容命名（4–20 字、见名知意、带镜头/段落编号，禁空泛名），口径见铁律25与06/07号

**详细规范**：见 [references/06-post-production.md](references/06-post-production.md)

**核心能力**：

## 全局铁律（所有模块必须遵守）

### 铁律0：Seedance 2.5 为最高优先级视频生成引擎
**所有视频生成默认使用 Seedance 2.5 引擎，优先级高于即梦/MiniMax等其他引擎。** 具体规则：
- 调用视频生成工具时，`model_version` 固定为 `seedance_2.5`，不得因画质判断/速度/成本/时长或其他偏好切换到其他模型
- 用户确认的最终视频提示词**逐字原文透传**，不得改写、润色、精简、翻译、纠错、重排，不得增加前缀/后缀/负面提示词/风格词/质量词
- 每次生成视频必须先完整展示提示词、展示提示词的同时直接生成（不停下等待确认）；模型/原始prompt/时长/比例/参考素材等完整信息随提示词展示、成片后一并给出，⛔ 用户认可这个成片后才生成下一个（不未经认可连续批量自动出全部片段）
- 时长支持5-30秒整数；比例仅支持16:9/4:3/1:1/3:4/9:16/21:9，不支持的比例必须让用户重新选择，不得擅自替换
- 若用户明确指定使用其他引擎（如即梦），按用户指定执行，但Seedance 2.5仍为默认推荐

### 铁律1：视频交付与逐镜审核流程（内嵌预览＋完整提示词＋用户认可才下一个）
**每生成完一个视频，必须以内嵌预览播放器形式展示在聊天对话中**（用户可直接点击播放，类似视频消息卡片），不是只给文件链接或本地路径。

**完整流程（合并原铁律5/8/29）**：
1. **先完整展示提示词，展示同时直接出片**：每个视频生成时先在对话中完整展示提示词（代码块），包含画面描述/人物@艾特/台词/运镜/光影/时长/比例；同时直接调用生成（不停下等待确认）；提示词完整透明，不省略、不事后补。
2. **强制图片参考＋@艾特**：每次生成必须用图生视频模式，不允许纯文字生成；提示词中出现用户提供的人物时，必须用`@图片N`格式艾特对应参考图，紧跟角色名后。
3. **成片必看**：成片后把「成片（内嵌预览）＋该视频完整脚本/分镜＋完整视频提示词（@已审核资产）」一起给用户看。
4. **逐镜自检**：成片生成后立即自检——①意外字幕/屏幕文字/水印/UI（应为无）；②穿模/畸形（手指肢体数量异常、肢体穿插、道具穿身、人穿家具墙体、衣物穿身、多角色粘连、悬浮接地错误）；③脸不崩、服装同阶段一致、站位正常不越轴、音画同步。问题即改提示词/重生成，不带病交付。
5. **用户认可才下一个**：用户认可这个成片后才生成下一个，逐个生成逐个审核，禁止未经认可连续批量自动出全部片段；不合适则按意见改提示词/重生成。
6. **模块间同样确认**：剧本→分镜→提示词→视频→后期，每完成一个模块先自检展示，用户说"可以"再进下一模块。

- 内嵌预览是首选交付形式，公共访问链接作为补充同时提供
- 不允许只说"已生成"而不给预览，不允许只给本地文件路径

### 铁律2：不含任何去水印内容
**全技能不包含、不推荐、不指导任何去水印操作。** 涉及水印时，建议用户使用平台官方无水印导出，或在生成时选择无水印版本。不提供去除他人水印的方法或工具。

### 铁律3：合规安全
- 所有涉及伤害/死亡/暴力的画面描述必须经过合规替换，仅改画面描述不改台词
- 不出现血腥特写、喷溅血液、断肢、尸体、利器刺穿身体、暴力慢放
- 即使Prompt已合规，AI生成仍可能"脑补"违规内容，必须逐镜人工审核
- 发现违规内容立即标记并重生成

### 铁律4：物理可行性优先
**优先级铁律：物理可行性 > 叙事情绪 > 多样性指标。** 所有景别/焦段/机位/运镜必须先匹配场景物理空间，再谈情绪与多样性。室内小空间禁止大远景/鸟瞰/升降，特殊封闭场景禁止横移/拉镜/环绕。

### 铁律5：模块间用户确认后推进
- 全流程按模块1→2→3→4→5→6→7顺序推进，不跳步；每完成一个模块先自检展示，用户说"可以"再进下一模块。**完整视频生成流程见铁律1。**

### 铁律6：不编造，不猜测
- 缺少关键信息时（主角是谁/对白语言/特定结局），补问一个简短问题
- 其他细节自行做合理决定，不把用户拦在连续的选择题前
- 所有数字、时长、规格必须有依据，不编造

### 铁律7：有台词必须在提示词中写清楚，不使用TTS语音合成
**角色对话、内心独白、画外音、旁白等所有台词，必须直接写进视频生成提示词中**，让AI视频模型直接生成带语音的视频。不使用TTS（文本转语音）单独合成语音，不在后期单独做语音合成。
- 提示词中写台词的格式：`角色A说："台词内容"`、`角色A内心独白："..."`、`画外音："..."`
- 台词必须完整写入提示词，不能省略、不能只写"角色A说话"
- 生成的视频应自带角色语音，后期只需调整音量和混音，不需要额外合成语音
- 如果生成的视频没有语音或语音不清，检查提示词中台词是否写清楚，调整后重新生成，而不是用TTS补救

### 铁律8：强制图片参考＋@艾特人物
- 每次生成必须用图生视频模式（带参考图），不允许纯文字生成；提示词中人物必须用`@图片N`格式艾特对应参考图。**完整流程见铁律1。**

### 铁律9：用户提供的人物图片一人一角色，不得重复使用
**用户提供的每个人物图片只对应剧中一个角色，不得复用同一张图片扮演多个角色。**
- 用户提供N张人物图片，就锁定N个角色的形象，每张图只对应一个角色
- 如果剧中角色数量超过用户提供的图片数量，多余的角色**只用纯文字描述外貌**（如"中年男性，短发，戴眼镜，穿灰色西装"），不使用任何参考图
- 禁止用同一张参考图扮演两个不同角色（会导致"一人分饰两角"或角色重复）
- 禁止把用户提供的角色图片用于描述其他角色
- 角色与参考图的对应关系在全剧中保持一致，不中途更换

### 铁律10：不用终端，全流程在对话界面完成
- 所有创作、生成、预览、交付均通过对话内工具调用和 present_files 完成，不需要用户进行任何命令行/终端操作
- 视频生成后通过 present_files 以内嵌预览播放器形式交付，用户直接在对话中点击播放
- 文件产出通过对话内交付，不要求用户手动下载、转换或运行脚本
- 不向用户展示终端命令、不要求用户执行任何本地操作

### 铁律11：每3-5秒一个信息点，节奏紧凑不空镜
- 每3-5秒必须出现一个新信息点（镜头变化/对话推进/物品特写/动作转折），杜绝空镜拖时间；单镜头超5秒中间必须穿插对话/物品/反应镜头。**详细节奏曲线与六拍节拍表见43号，P0节奏原则见铁律41。**

### 铁律12：选题优先社会问题、矛盾冲突、情感痛点
- 题材选择优先：**社会问题、现实矛盾、情感痛点、人性挣扎**——容易引发共鸣和传播的方向
- 不写悬浮空想、脱离现实的剧情
- 核心戏剧张力来自**反差+矛盾**：人物身份反差、立场矛盾、表里不一、阶层冲突
- 题材举例（感人故事/社会残酷现实/乱梗/笑点泪点并存）仅为参考，**不设限**，各种情感方向均可，灵活选择最有张力的

### 铁律13：横屏拍摄，全片无字幕
- 默认横屏16:9画幅
- **全片不加字幕**，台词通过视频自带语音传达
- 不靠字幕解释剧情，靠画面+对话+动作让观众看懂

### 铁律14：人物通过剧情行动立住，不靠旁白解释
- 在3分钟/5分钟的时长内，**必须通过人物的行动、选择、冲突反应来展现性格和背景**
- 禁止用旁白/独白/人设卡直接介绍"他是谁、他什么性格"
- 人物特征要在剧情推进中自然流露：他怎么对人、怎么做选择、愤怒时什么反应、隐忍时什么表现
- 每个角色的性格必须在出场后通过至少一个具体行动立住，不能只靠设定描述

### 铁律15：每幕自检必须包含角色贴合度和脸崩检查
- 每完成一幕/一个镜头，自检内容必须覆盖：
  - **角色是否合适**：这个角色放在这个情境里合不合理？人物行为是否符合已建立的性格？
  - **脸崩检查**：生成的视频中人物面部是否一致、有无变形/崩坏/穿帮
  - **提示词→镜头→场景→分镜→脚本→视频**逐环检查
- 自检结果必须展示给用户，用户确认后才继续
- 发现角色不合适或脸崩，必须修改后重新生成，不带病推进

### 铁律16：站位必须写进提示词，生成前后双轮详细检查
**人物站位是本剧最高优先级视觉一致性项，出错率极高，必须在提示词里写死，生成前后各做一轮详细检查。**

**A. 提示词中必须写清楚站位（生成前）**
- 每个有两人及以上同框的镜头，提示词里**必须明确写出每个人物的站位/位置/朝向**，不能只写"两人对话"就完事。
- 站位描述必须包含三要素：
  1. **左右位置**：谁在画面左侧、谁在画面右侧、谁居中
  2. **前后远近**：谁站前景、谁站后景、谁靠近镜头
  3. **朝向关系**：两人面对面？并排朝同一方向？一人背对镜头？一人侧身？
- 站位描述示例：`李明（@图片1）站在画面左侧，面向右；王芳（@图片2）站在画面右侧，面向左，两人面对面相距一步`
- 单人镜头也要写：`李明（@图片1）坐在画面中央偏左，面朝镜头方向`
- 同一场景连续多镜，**左右站位必须保持一致**（不能上一镜A在左B在右，下一镜突然互换），除非剧情设计了换位动作。
- 生成前检查：逐镜扫一遍提示词，凡≥2人同框的镜头，站位三要素是否都写全了？缺了就补，不能直接生成。

**B. 生成后逐帧详细检查（生成后）**
每镜视频生成完，必须逐帧（至少抽3-5个关键帧）检查以下项目，一项不过就重生成：
- **站位是否正确**：左右位置对不对？前后远近对不对？朝向对不对？有没有人莫名其妙换位、穿到别人位置上？
- **脸崩检查**：面部是否对称自然？五官是否变形？眼睛/嘴巴有没有崩坏？脸型是否和参考图一致？
- **肢体异常**：手指数对不对？四肢有没有扭曲/多出来/穿模？
- **人数对不对**：镜头里应该出现几个人？有没有多出来的人、少了人、或者背景里冒出陌生人？
- **服装一致性**：衣服颜色/款式/配饰是否和设定一致？有没有换装、变色？
- **场景道具**：关键道具在不在？背景场景是否跑偏？
- **光影方向**：光源方向是否统一？有没有阴阳脸、光影跳变？
- **动作自然度**：动作是否流畅？有没有卡顿、抽搐、物理不合理的姿势？

**C. 检查结果展示**
- 每镜生成后，把检查结果列成清单展示给用户（✅通过 / ❌有问题+问题描述）
- 任何一项❌，必须调整提示词后重生成，不带病进入下一镜
- 站位错误和脸崩属于**P0级问题**，必须重生成，不能用后期剪辑掩盖

### 铁律17：以画面和人物表演为主，旁白为辅（Show, Don't Tell —— 尽可能）
**要表达的东西，优先用画面、对话、内心独白、物品特写、镜头语言来"演出来"；旁白/字幕可以用，但只作为补充手段，不能成为主要表达方式。**

**优先用画面表现的内容（尽量"演出来"）：**
- **人物性格/身份/背景** → 优先用动作、选择、穿着、环境、待人接物来展现
- **时间流逝** → 优先用日历翻页、窗外天色变化、道具变化（杯子空了、烟变长了）来表现
- **情绪变化** → 优先用表情、肢体动作、物品（攥紧的拳头、颤抖的手、撕碎的照片）来表现
- **关键信息/设定** → 优先用人物对话、发现道具、看到文件、手机屏幕特写来传递
- **转折/反转** → 优先用镜头切到关键物品、人物反应镜头、环境变化来让观众自己发现
- **关系变化** → 优先用距离远近、站位变化、眼神交流、肢体接触来展现

**四种优先表达手段：**
1. **对话**：人物之间的自然对话，把信息藏在台词里
2. **内心独白**：人物内心OS（视频自带语音），配合画面动作
3. **物品镜头**：给关键道具特写（手机屏幕、信件、照片、账单、药瓶），让物品替人物说话
4. **反应镜头**：一个人物做了什么，切到另一个人物的面部反应，情绪就出来了

**旁白/字幕可以用，但要克制：**
- ✅ **可以用旁白的场景**：开场引入氛围、结尾点题升华、时空跳跃过渡、人物内心独白补充
- ✅ **旁白应该是点睛之笔，不是叙事主力**——观众主要靠看画面和听对话就能看懂故事，旁白只是锦上添花
- ✅ **单段旁白不宜过长**，尽量一两句话带过，不要大段念背景介绍
- ❌ **禁止用旁白代替叙事**：不能让旁白把剧情全讲完，画面只是配图
- ❌ **禁止用旁白介绍人物背景**（"他是一个公司老板，十年前……"这种大段人物小传）
- ❌ **禁止用字幕卡打出大段说明文字**
- ❌ **禁止一个人站着不动，靠嘴把所有信息念完**

**判断标准**：闭上眼睛只听声音，能不能跟上故事？如果离开旁白就完全看不懂，说明旁白太重了，必须改成画面表达。如果旁白只是偶尔点一句、氛围衬一下，那是合适的。

**检查方法**：写完剧本/分镜后逐段看——这段主要靠什么传达？如果是画面+对话为主，旁白只是点缀，OK；如果主要靠旁白念，必须改成画面表达。

### 铁律18：开局钩子必须强烈，但必须扎根剧本，禁止标题党假钩子
**用户刷到视频的前3秒决定了划走还是停留，开局钩子必须强到让人手指停住；但钩子必须是整个故事的浓缩种子，不能是和正片无关的噱头。**

**A. 钩子要多强？**
- **前3秒必须出冲击点**：一个反常画面、一句炸台词、一个高反差冲突、一个悬念问题——不能是慢悠悠的日常铺垫
- **钩子必须制造"为什么？"**：让观众心里冒出一个问号，不看下去就难受
- **钩子要具体、有画面感**：不是"一个感人的故事开始了"，而是具体的画面/动作/台词
- **情绪要直接打到脸上**：悲伤就直接是哭，愤怒就直接是摔东西，悬念就直接是反常，不要温吞

**B. 钩子不能瞎弄（这是关键）**
- ❌ **禁止和正片无关的假钩子**：开头放一个和故事没关系的爆点画面，正片却是另一个内容——这是标题党，观众会骂"被骗了"
- ❌ **禁止为了强而强行夸张**：开头车祸/哭喊/吵架，结果正片是平淡日常——情绪接不住
- ❌ **禁止用别人的画面/素材当钩子**：钩子必须是本剧中真实存在的镜头
- ✅ **钩子是整个故事的"种子"**：开头那个画面/那句话，必须能在后文找到答案和呼应
- ✅ **钩子是核心矛盾的浓缩**：开头展示的冲突，就是全片要解决的问题
- ✅ **钩子可以提前剧透最炸的那个瞬间**：把全片最冲击的画面放到开头，然后倒叙回去讲为什么会这样——这是合法且有效的钩子

**C. 好钩子的四种类型（选一种，不要堆砌）**
1. **反常画面钩**：一个不符合常理的画面（老人在雨中跪着、葬礼上有人在笑、手机收到自己发的短信）
2. **炸台词钩**：一开口就是冲突/悬念（"妈，我今天把你老伴的退休金捐了"、"爸，这婚我不结了"）
3. **高反差钩**：身份/处境的强烈反差（穿西装的人在捡垃圾、乞丐拿出黑卡、婚礼现场新郎消失）
4. **悬念问题钩**：一个观众必须知道答案的问题（她为什么十年不回家？这个孩子是谁的？）

**D. 钩子与正片的衔接**
- 钩子之后30秒内必须进入正题，不能一直卖关子
- 钩子留下的"为什么"，必须在全片中后段给答案
- 结尾最好回扣开头钩子，形成闭环（观众看完回头想开头，恍然大悟）

**检查方法**：
- 把开头3秒单独拎出来，问自己：陌生人刷到这3秒，会不会停下来？如果不会，重写
- 再问：这个钩子和正片内容是什么关系？如果答案是"没啥关系"或"正片接不住"，重写
- 钩子必须能在后面剧情中找到呼应或答案

### 铁律19：封面必须电影海报级设计，画面氛围+片名式大字
**封面是观众在信息流里看到的第一印象。最高标准是像电影海报——不是截图加字，而是专门设计的画面，用氛围感和片名式大字吸引点击。**

**参考标杆风格（用户指定）：**
- 画面是电影海报质感，不是随便截一帧
- 大字标题像电影片名（"望山跑死马""栖野""平安馒头""爱你老妈""女孩"），简洁有力，不啰嗦
- 标题竖排或横排放在画面一侧，粗体大字，不挡主体
- 人物在场景中（全身/中景），和环境氛围融合，不是大脸怼镜头
- 氛围感强：雨夜暖灯、老巷炊烟、黄昏远山——用光影色调讲故事
- 暖黄+暗蓝的电影色调，统一有质感

**A. 封面画面要求**
- **专门设计的画面，不是截图**：封面要有电影海报级构图、光影、氛围
- **人物在环境中**：中景/全景，人物和场景融为一体，用环境衬托情绪
- **氛围感>表情夸张**：靠光影、色调、场景传达情绪，不是非要崩溃大哭的大脸
- **情绪要和内容匹配**：感人故事用温暖/烟火气画面，悬疑用冷调/反常画面
- **封面画面必须来自正片或与正片同场景同人物**：不能用无关素材

**B. 封面文字要求**
- **标题=片名**：用一个词或短句作为标题，像电影名，不要写说明文
  - ✅ "望山跑死马""栖野""平安馒头""一碗面的温度"
  - ❌ "她为什么十年不回家""结果出来全家崩了"（这种太像标题党）
- **大字样式**：粗体，白色为主（暗背景上），可加黑色描边保证清晰；竖排在画面左侧或右侧
- **小字副标题（可选）**：紧贴大字下方，小字，黄色或白色，补充情绪点
- **文字不挡人物面部和主体**
- **标题要短**：4-8字最佳，最多不超过10字

**C. 封面规格**
- 抖音/快手竖屏：9:16（1080×1920）
- 标题文字不要太靠边缘，留出平台UI遮挡的安全区

**D. 封面和内容的一致性**
- 封面氛围和片名气质，正片必须接住
- 封面人物必须是本片真实角色
- 不靠标题党骗人点进来

**检查方法**：
- 把封面放到信息流里，像不像一张电影海报？如果像截图加字，重做
- 标题像不像电影名？如果像公众号标题，重做
- 氛围感够不够？能不能一眼感受到情绪？

### 铁律20：成片只做硬拼接，不主动剪辑；全片绝对零字幕（P0红线）
**这是两条红线，违反任何一条都算交付不合格。**

**A. 剪辑规则：默认只硬切硬拼接，不主动剪辑**
- 所有镜头生成完后，**默认只把镜头按顺序硬拼接起来就是成片**——不裁剪、不调速、不混剪、不蒙太奇、不加片头片尾卡、不做节奏再编排
- **除非用户明确说"帮我剪一下/精剪/调速/加片头/做混剪"，否则不要进入模块6后期剪辑流程**
- 硬拼接 = 镜头A结束的瞬间直接接镜头B开始的瞬间，一刀不剪，一帧不裁
- 不要主动做：入点出点修剪、动作连贯性剪辑、节奏重排、快慢速、倒放、抽帧、插过渡镜
- 不要主动加：剧名片头、结尾悬念卡、黑场字卡、转场（哪怕是硬切之外的任何处理）
- 用户要求剪辑时，才进入模块6；且模块6里也仅允许硬切/硬拼接，不允许任何转场特效

**B. 字幕规则：全片绝对零字幕（最高红线，反复强调）**
- **成片里任何位置都不能出现字幕**：台词字幕、旁白字幕、解释性字幕卡、开头剧名卡、结尾黑场字卡、集数标题、时间地点字幕——一律禁止
- **✅ 唯一例外：时空跳转过渡卡**——当剧情需要在"现在/回忆/多年后"之间跳转时，可以用**纯黑底+居中白色时间文字**的方式做过渡，例如：
  - 黑屏白字"二十年前"
  - 黑屏白字"三天后"
  - 黑屏白字"1998年 冬"
  - 这种字卡用于让观众知道时空切换，不是用来念台词/解释剧情的
  - 形式要求：必须是纯黑背景+居中白字，单屏停留1-2秒即切走；不要加花哨字体/描边/动效；一部片子里不要用太多，只在真正需要时空跳转时用
- **❌ 仍然禁止的字幕**：人物说的每句话打在屏幕上、旁白念的内容打在屏幕上、剧情解释性文字、开头剧名大字、结尾"未完待续"之类
- 视频生成提示词里也**不要写任何"屏幕上出现XX字""画面下方显示字幕"之类的指令**（时空跳转黑卡除外，且要明确写"纯黑背景居中白色文字显示'二十年前'"），避免AI自己乱生成字幕
- 不靠字幕解释剧情，台词靠视频自带语音传达，人物关系靠画面和对话让观众看懂
- 自检时必须逐帧确认：画面里有没有任何台词字幕条/对白字幕/水印字？有就重生成；黑底时间卡属于允许项，不算违规
- **封面标题文字是唯一另一例外**（封面是海报不是视频，封面按铁律19设计）；视频画面内部（除黑底时间跳转卡外）严禁出现任何文字

**C. 双红线自检（每镜必查）**
- [ ] 提示词里有没有写"屏幕显示文字""字幕""标题字"？（时空跳转黑卡除外）有就删
- [ ] 生成的视频画面里有没有任何台词字幕条/对白字幕/水印字？有就重生成
- [ ] 交付时是否只是硬拼接，没有自作主张做剪辑/调速/加片头？
- [ ] 有没有主动做了用户没要求的后期处理？有就撤掉

### 铁律21：每交付一个用户满意的产物后，主动提醒沉淀经验
**技能是越用越好用的。每次做出一个用户点头说"可以/满意/不错"的产物后，必须主动问一句要不要把这次的经验固化进技能里。**

**什么时候触发**：
- 用户对某段剧本、某个分镜、某条提示词、某镜视频、某个封面说"可以""行""满意""不错""就这样"
- 用户明确表扬某个做法/风格/效果（"这个感觉对了""就按这个来"）
- 某一轮反复修改后最终定稿的产物——这轮里踩过的坑、找到的对的方向，最值得沉淀

**怎么提醒**（简短一句话，不啰嗦）：
> "这版感觉对了。要不要把这次的[具体做法/风格/坑]沉淀进技能里？下次遇到类似场景直接套用。"

**沉淀什么**（挑有复用价值的，不是什么都存）：
- ✅ 新的视觉风格/色调/镜头语言配方（这次用了什么词效果特别好）
- ✅ 新的避坑经验（这次踩了什么坑、怎么修的）
- ✅ 新的场景符号/道具/情绪套路
- ✅ 用户明确表扬过的句式、结构、节奏
- ✅ 反复修改后才找对的方向（弯路最值钱）
- ❌ 一次性的、跟特定剧情绑定的具体台词/情节（不通用）

**沉淀到哪里**：
- 通用方法论 → 新建或追加到 references/ 下对应编号文件（按技能开头的扩展规范走：新文件编号续排，在SKILL.md索引里加一行）
- 铁律级规则 → 加到本文件"全局铁律"里（编号续排）
- 不要往SKILL.md里堆具体内容，SKILL.md只放规则和索引

**用户说"要沉淀"后**：
1. 先口头总结这次值得存的是哪几条
2. 跟用户确认存哪条、怎么表述
3. 写入对应references文件或SKILL.md
4. 问用户要不要同步推GitHub

**用户说"不用"**：跳过，不追问。

### 铁律22：用户没要求时，默认做横屏16:9视频
**除非用户明确说要竖屏/9:16/抖音竖版，否则所有视频默认横屏16:9。**
- 用户没提画幅 = 默认横屏16:9，不要自作主张出竖屏
- 只有用户明确说"做竖屏""9:16""抖音竖版""手机全屏"时，才用竖屏比例
- 封面图例外：封面按目标平台规格出（抖音封面仍为9:16），但视频本身默认横屏
- 生成视频前如果不确定画幅，默认按横屏16:9走，并在提示词确认信息里标注"默认横屏16:9（用户未指定）"
- 不要因为"抖音是竖屏平台"就默认做竖屏视频——用户明确要的是横屏感人短剧

### 铁律23：开头钩子要非常强，全片持续爆点刺激，必须跌宕起伏
**这是一条P0级节奏铁律。观众的手指随时会划走，必须从第1秒起就抓住他，并且全程反复刺激，不能有任何一段让他觉得"无聊了可以划走"。**

**A. 开头钩子——必须非常强烈，不是一般强**
- **前3秒必须出王炸**：反常画面/炸台词/高反差/悬念问题，直接打到脸上，不要任何铺垫、不要慢热、不要"先交代一下背景"
- **钩子强度自检**：把开头3秒单独拎出来，想象自己在抖音上躺着刷——陌生人刷到这3秒，手指会不会停下来？如果不会，重写，不要侥幸
- 钩子必须和正片核心矛盾绑定（见铁律18），不能是标题党假钩
- 开头不要用：慢镜头空镜、日出日落、城市全景、人物慢慢走路、旁白慢悠悠念背景——这些都是划走重灾区

**B. 全片持续爆点——每几秒必须刺激一次，不能平**
- **每3-5秒必须出现一个新信息点或情绪刺激**：对话推进、动作转折、物品特写、反转预兆、人物反应、环境变化——让观众的脑子一直有新东西接
- **不能有连续两段以上情绪平铺**：刚温和一段，必须立刻接一个冲突/意外/炸点/反转预兆，把情绪再提起来
- **跌宕起伏=情绪曲线必须上下波动**：不能从头到尾一个调调（一直惨、一直暖、一直平）。要有蓄力→爆发→回落→再蓄力→更大爆发的节奏
- **每30秒左右必须有一个小高潮或小反转**：让观众觉得"哎？怎么回事""哦原来是这样""我去"
- **严禁中段塌陷**：开头钩子很强，但演到中间就开始流水账、日常对话、没有冲突——这是最常见的死法。中段必须持续扔信息、扔冲突、扔情绪点
- **结尾必须留余味或回扣钩子**：不能平淡收尾

**C. 自检方法（写剧本/分镜时必过）**
- [ ] 把开头3秒单独拎出来：陌生人会不会停下来？不会就重写
- [ ] 逐段数：每3-5秒有没有新信息点？连续两段以上没刺激就是问题
- [ ] 情绪曲线画出来：是不是平的？必须有高有低
- [ ] 每30秒有没有一个小高潮/小反转？
- [ ] 中段（故事讲了一半时）有没有冲突或意外？还是变成流水账了？
- [ ] 结尾有没有回扣开头钩子或留余味？

**D. 不合格就重写，不带病推进**
- 开头不够炸 → 重写开头
- 中段太平 → 加冲突/加反转/加快节奏
- 情绪一条线没有起伏 → 重新排情绪节奏
- 不要用"后面会好的"骗自己，开头留不住人，后面再好也没人看

### 铁律24：脸不崩 ＋ 服装同阶段锁死（该锁锁死，该换才换）
- **面部（P0）**：每镜生成后抽帧/逐帧核对面部，跨镜与角色锚定参考图保持一致，无变形、崩坏、换脸、五官错位；脸崩一律重生成（详见铁律15/16、05号）。
- **服装（同阶段锁死）**：同一角色在同一剧情阶段/同一套服装设定内，服装款式、颜色、配饰必须一致（如八路军/解放军长征到达村落后，军装不得出现明显款式或颜色跳变）。
- **换装例外**：仅当剧情明确设计换装才允许变化——换季、入伍/改编、受伤换装、身份转变、长大成人、时间跨度等，且必须有镜头或情节交代；无交代的服装跳变判不一致、重生成。
- **落地卡点**：15号资产表为每个角色记录"服装锁定 ＋ 换装节点（适用剧情区间）"；模块4每镜自检、模块5跨镜检查、模块6硬拼接前后都必须核"面部 ＋ 服装"，任一不通过不交付、不拼入成片。

### 铁律25：硬拼接与交付不压缩画质；H.264+AAC 兼容封装，流拷贝优先
**画质铁律（P0）：不压缩画质、不降分辨率、不降帧率。** 单镜视频与最终硬拼接成片，一律保持原始分辨率、帧率、码率、编码，不压缩、不降清。

**交付编码（为兼容性，不为压画质）**：最终成片统一以 **H.264（yuv420p）＋ AAC、faststart（moov 前置）的 MP4** 封装交付，确保 Windows 双击、聊天预览、剪映 / Pr / DaVinci 正常播放。按以下优先级处理：
1. **源片段已是 H.264+AAC（Seedance 通常直接输出此格式）→ 优先流拷贝（`-c copy`）拼接 / 封装，零重编码、零画质损失**；封装时可加 `-movflags +faststart`（只重排容器、不动码流）。
2. **仅当源编码 / 像素格式不兼容**（如 HEVC / H.265、非 yuv420p）**才转码为 H.264+AAC**，且转码必须**视觉无损、高码率**（低 CRF≈16–18 或沿用源码率），**不缩放、不降帧率、不降噪、不调色、不丢帧**，仅做 `format=yuv420p` 与编码 / 封装兼容。
3. 分辨率 / 帧率不一致属规格问题，**回模块4源头重新生成 / 导出对齐，不靠对成片缩放、转帧率来"对齐"**。

**二者关系（不矛盾）**：兼容性靠封装 / 必要时的高画质转码，画质零损失靠流拷贝优先。上传 / 导出必须选"原画质 / 不压缩"，禁止交付通道默认二次压缩；若某通道必然二次压缩，须同时提供原始文件并向用户说明。
- 操作细节见06号（含 ffmpeg 命令），交付规格见07号。

### 铁律26：保留真实环境音，只禁止人为配乐 BGM
- **保留**：画面里真实存在的环境音/环境声（Ambient）——脚步声、下雨、风声、水流、虫鸣鸟鸣、火焰噼啪、衣物摩擦、门轴、马蹄、集市/人群嘈杂、远处犬吠等；可在视频提示词中写明（如"环境音：雨声、脚踩泥泞声、风声"），由视频模型直接生成。
- **禁止**：人为配乐/旋律性背景音乐（BGM）——歌曲、情绪配乐、钢琴/弦乐 score、铺垫背景音乐一律不生成、不添加、不混入，以免干扰用户后期剪辑。
- 硬拼接时原样保留视频自带的台词与环境音、不添加 BGM，并注意镜头边界处环境音自然衔接、不突变不重叠。
- 22 号标签 `（no srt，no music）` 中，no music 仅指无配乐/无 BGM，不限制真实环境音。

### 铁律27：站位不越轴不乱跳
- 人物站位不得无理由乱跳/瞬移/左右互换/朝向突变/穿模重叠；同场景连续多镜遵守180°轴线，仅当剧情明确演出换位动作才允许改变位置。**站位三要素写法与双轮检查见铁律16，场景空间锚定见15号，多段锁场景用24号机位底图。**

### 铁律28：美术资产 AI 可直接生成，但出图必审、通过才定稿 @
- 角色 / 场景 / 道具 / 分镜·关键画面参考图，AI 可直接调用文生图生成；每一张 / 批生成后立即把「成图 + 所用提示词 + 三维」交付用户审核；用户通过才定稿、才在分镜 / 视频提示词中 `@` 引用、强制图片参考；未通过按意见改提示词重生成再审。
- 「用户自制」为可选路径：用户自己出图时 AI 默认给通用模型版提示词 + 三维 + 清单顺序 + 建议（你点名 MJ 时再补 MJ 版），回传后同样审核确认。
- 本条替代第二、三轮「全资产用户自制 / AI 不代出定稿图」口径；其余资产三维、@ 强制图片参考等规范不变。

### 铁律29：成片逐镜自检（字幕/穿模/脸崩/音画）

### 铁律30：不出关键帧
- **不主动为每个镜头生成或输出「关键帧（Key Frame）/ 定帧图 / 首帧图 / 尾帧图」等额外静态帧；不设「先出关键帧、再图生视频」环节。**
- 直接用**已审核的美术资产**（角色 / 场景 / 道具 / 机位底图）＋ 视频提示词生成视频。
- **边界（保留项）**：分镜参考图、平面俯视图 / 调度图、资产图、机位底图属于前期规划与资产，**照常保留**；被禁止的是**逐镜头额外新做的「定帧 / 关键帧成品」**。若视频模型必须挂参考图，**复用已审核资产图或机位底图，不专门新出关键帧**；连续镜之间复用前一镜已生成视频的末帧做链式衔接，同样不算新做关键帧成品。
- **标准化链式锚定尾帧法（33号）**：除最后一组外，可使用模式A在组尾追加1秒“技术全景”，或使用模式B在正片完成后另生成5秒技术补段；技术素材镜头稳定，完整展示当前场景空间与所有已出场人物的位置/朝向/姿势/表情/服装/道具，以及关键家具/物品/门窗/光源与场景状态，截取最后一帧作为下一组图片参考。模式A尾段拼接前剔除；模式B补段不进filelist。详见 [references/33-tech-panorama-anchor.md](references/33-tech-panorama-anchor.md)。本做法即上文“复用前一镜已生成视频末帧做链式衔接”的标准化版本，仍不算新做关键帧成品。
- 仅当用户明确点名要某张帧时才按需产出，否则不主动给。

### 铁律31：段间必做衔接（⛔ 模块2/模块4 必读，不得跳过）
> **⛔ P0 必读声明**：进入模块2（分镜设计）和模块4（视频生成）之前，必须完整读通本铁律 + 以下四份关联文件，不得凭印象执行：

> - `references/33-tech-panorama-anchor.md`（组末1秒技术全景链式锚定尾帧法——同空间连续时间跨组续接的标准做法）
> - `references/02-storyboard-design.md §5.4`（分镜阶段如何标注衔接点）
> - `references/04-video-production.md §六+`（衔接片段生成顺序：上段→衔接片段→下段）
> - `references/22-15s-storyboard-group-template.md` 末尾「衔接（至下一组）」字段写法
> 不读就分镜/生成，必然出现"凭空切到新场景人物直接说话""上段终点接不住下段起点""脸/服装/站位跨组漂移"。

- **分镜阶段在每两个相邻分镜组（默认 30 秒段）之间标注「衔接点」**；**凡存在场景转换、动作 / 动线跳跃、朝向或光影不连续、强冲突 / 反转后需要情绪缓冲的，必须先单独生成一个「衔接片段」再进入下一段**。
- 两段本就同机位连续、硬切自然的，**标注「硬切连贯」即可，不强行加片，避免冗余**。
- **衔接类型按前后关系选择**：①动作延续（脚步 / 过门 / 手部承接）②跨场转场（出门—路上—到达、环境空镜）③情绪 / 反应缓冲 ④视线方向引导（沿人物视线揭示）⑤关键道具特写 ⑥同场景不同时间（光影变化）。
- **连贯铁律：上段动作 / 动线 / 朝向终点＝衔接起点，衔接终点＝下段起点**；复用已审核资产与机位底图，遵守脸 / 服装 / 站位一致、不越轴、不出关键帧、强制 @ 图片参考。
- **⛔ 每一组（每一幕）开场镜头必须自带「承接入口」**：设计每一组分镜时，**第一个镜头就要回答"观众是怎么从上一幕走到这里的"**——要么靠上一段末尾的衔接片段带进来，要么这一组第一个镜头本身就是承接镜头（人物推门而入 / 从门外走入 / 镜头跟随脚步 / 环境空镜先交代新空间再切入人物）。**禁止"凭空切到新场景、人物直接开始对话"**——观众会出戏。哪怕判定为「硬切连贯」，也要确认这一组的开场镜头在空间/情绪/动向上接得住上一段，而不是硬切硬跳。
- 时长灵活（通常 2–5 秒，长转场可更长）；可纳入相邻 30 秒组，或单独生成、编号 `G03a` / `G03-G04衔接`。
- 无字幕、无 BGM（真实环境音保留）、H.264+AAC、faststart、**不压缩画质**；硬拼接时按序插入两段之间，**不改动原片段**。

**A. 前 3 秒 = 热开场强钩子（禁止慢热）**
- 第 0–3 秒第一帧就必须有动作 / 冲突 / 反常（反常画面 / 炸台词 / 高反差 / 悬念问题 / 全片最炸瞬间前置倒叙五选一），让陌生人躺着刷也停住手指
- **禁止**：慢镜头空镜、日出日落、城市全景、人物慢慢走路、旁白慢悠悠念背景、片头 LOGO / 剧名大字 / 黑场、礼貌寒暄"来了啊吃饭了吗"
- 钩子必须扎根核心矛盾（铁律 18），不能标题党

**B. 第 3–10 秒 = 用画面交代背景（禁止旁白念）**
- 10 秒内必须让观众搞懂三件事：**谁、在哪、出了什么事**
- 靠两句短对话 / 一个关键物（诊断书、药瓶、"拆"字）/ 人物正在做的事带出来
- **禁止**大段旁白"十年前这个家……"、人物站着自我介绍、黑场白字大段背景（时空跳转黑卡除外，见铁律 20）

**C. 第 10 秒后 = 起伏跌宕节奏曲线（禁止平、禁止只升不降、禁止中段塌）**
- 情绪曲线必须按：**矛盾扩散（10–25s）→ 第一次反转/小高潮（25–40s）→ 情绪降落/缓冲（40–55s）→ 矛盾再升级＋第二次反转/刀（55–90s）** 推进；5 分钟长片把六拍重复两轮
- **死法自检**：①一条线平到底（一直哭/一直吵）→ 强制加降落和反转；②只升不降落（观众麻木）→ 每次爆发后必须 3–5 秒沉默/空镜/慢拉缓冲；③中段塌陷（40–60 秒变流水账）→ 必须有一个意外（一句话/一个人/一件事）
- **每 30 秒至少一个小高潮或小反转**；连续两段情绪平铺即重写
- **结尾**：必须回扣开头钩子 / 留白刀 / 金句刀，不能平淡收尾
- 每个节拍用什么镜头（急推/慢拉/手持/固定/焦点转移）查 [42-cinematic-language-toolbox.md](references/42-cinematic-language-toolbox.md)

**D. 详细节拍表、矛盾扩散法、反转伏笔法、下刀方式见 [43-opening-hook-curve.md](references/43-opening-hook-curve.md)**，模块 1 写剧本和模块 2 分镜时必读。

#### 脚本自检质量门 · 六大项（源自《短剧脚本创作自检清单》更新版，剧本产出后、进入资产/分镜/生成前强制逐项勾选）
- [ ] **① 矛盾设计（核心）**：矛盾能让观众代入并做**视觉化**呈现（看得见，非旁白交代）；每个矛盾配具体伏笔（前期埋、后期收）；矛盾 **≥2 个**；矛盾承担「塑造主角 / 推动剧情 / 升华主题」三重作用
- [ ] **② 人物侧写**：基于故事情境分析人物而非贴标签；写清性格特点与面临的问题；用神态、动作、习惯等细节立人
- [ ] **③ 场景与转场**：设计专门转场避免硬切；区分/交代背景让观众看懂时空；掌握同一场景、不同时间的转场（用光影/道具/状态变化体现时间流逝）
- [ ] **④ 叙事结构（多线 + 因果链）**：故事含主线 + 亲情线 + 社会关系线至少三条线，各线有交汇、相互推动而非平行堆砌；**剧情按因果链 A→B→C 推进（A 导致 B、B 导致 C），不是「然后…然后…」的流水账**；对每个场景追问「**它因什么发生、又导致了什么**」，删除与主线无因果关系的段落；人物行动有动机、有后果，**伏笔是因、回收是果**，反转意料之外情理之中；钩子抛出的异常 / 悬念必须有成因（可后置揭示）
- [ ] **⑤ 开头钩子（画面化）与互动**：钩子必须是**看得见的具体画面 / 动作 / 场景**，靠第一帧 / 前几秒视觉冲击或视觉悬念抓人，**不靠旁白 / 台词 / 字幕 / 标题去「说」钩子**，且直接关联核心矛盾 / 悬念、不用与正片无关的唬头；开头用热点 / 焦点 / 强冲突抓住观众；全片设置讨论点（留争议 / 悬念 / 共鸣），引发留言互动
- [ ] **⑥ 观众视角自检**：切换为普通观众（角色扮演）重看一遍；自问「哪里可以优化？整体是否吸引我继续看？」
