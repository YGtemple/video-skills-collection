# 提示词生成实战案例：《斗罗·六子觉醒》

> 本文档聚焦AI短剧视频生成的**提示词编写**，记录从6张角色参考图到56镜视频提示词的完整实战经验。核心是：**提示词要详细、角色必须@艾特参考图、强制图生视频不用纯文字**。

---

## 一、项目背景

| 参数 | 数值 |
|------|------|
| 剧名 | 《斗罗·六子觉醒》 |
| 题材 | 都市玄幻脑洞（穿越斗罗大陆） |
| 集数 | 3集（第一集20镜 + 第二集16镜 + 第三集20镜） |
| 总镜数 | 56镜 |
| 角色数 | 6人（用户提供6张面部照片，一人一角色不重复） |
| 视频引擎 | Seedance 2.5（第一集）→ Seedance 2.0（第二、三集） |
| 生成模式 | **强制图生视频**，每镜带6张角色参考图，提示词中@艾特对应角色 |

## 二、角色参考图与@艾特规范（核心）

### 2.1 角色与参考图对应表

用户上传6张照片，一人一角色，全剧保持一致，不中途更换：

| 序号 | 角色名 | @艾特格式 | 外貌特征（提示词中描述） | 武魂 |
|------|--------|-----------|--------------------------|------|
| 图片1 | 班长 | `班长（@图片1）` | 黑色短发带棕色挑染，穿黑色背心，身材健壮，表情沉稳 | 玄武盾（大地/防御） |
| 图片2 | 老弟 | `老弟（@图片2）` | 戴圆框眼镜，穿浅灰色立领衬衫，文质彬彬，书桌前 | 万象书典（智慧/辅助） |
| 图片3 | 李一康 | `李一康（@图片3）` | 黑色向上短发，浓眉大眼，穿白色T恤，表情严肃刚正 | 八卦乾坤扇（阴阳/控制） |
| 图片4 | 熊七 | `熊七（@图片4）` | 齐刘海黑色短发，穿白色衬衫+黑色运动外套，表情冷淡 | 影刃豹（暗影/敏攻） |
| 图片5 | 王叔 | `王叔（@图片5）` | 反戴浅色棒球帽，穿黑色长袖T恤，表情搞怪幽默 | 百味乾坤锅（生命/食物） |
| 图片6 | 袁泽彪 | `袁泽彪（@图片6）` | 黑色凌乱短发，赤裸上身秀肌肉，身材魁梧，笑容灿烂 | 巨力魔熊（力量/强攻） |

### 2.2 @艾特铁律

1. **每个出现的角色都必须@艾特**：提示词中只要提到某个角色，就必须紧跟`（@图片N）`
2. **@艾特紧跟角色名**：格式为`角色名（@图片N）`，不要分开写
3. **多人同框全部艾特**：一镜中有多个角色，每个都要@艾特对应的参考图
4. **多余角色纯文字描述**：如果剧中有第7个及以上角色（无参考图），只用纯文字描述外貌，不@艾特
5. **一人一角色不重复**：同一张参考图只对应一个角色，禁止用同一张图扮演两个角色

**正确示例**：
```
班长（@图片1）站在最前方，双手凝聚土黄色魂力护盾；
老弟（@图片2）在他身后翻开一本发光的古书；
袁泽彪（@图片6）怒吼着冲向敌人，双拳包裹着黑色魔熊虚影。
```

**错误示例**：
```
班长站在最前方，双手凝聚护盾；老弟在身后翻书；袁泽彪冲向敌人。
（❌ 没有@艾特参考图，会导致角色变脸/形象不一致）
```

## 三、提示词结构模板（核心）

每镜提示词必须包含以下7个部分，按顺序编写：

```
【场景】时间 + 地点 + 环境氛围 + 光影效果
【人物】角色A（@图片N）+ 动作/表情/站位 + 角色B（@图片N）+ 动作/表情/站位
【武魂/特效】武魂召唤形态 + 技能释放效果 + 视觉表现（颜色/形状/动态）
【台词】角色A说："完整台词内容"  角色B说："完整台词内容"
【运镜】景别（特写/近景/中景/全景）+ 运镜方式（固定/推/拉/摇/跟）
【节奏】镜头时长 + 快慢节奏（正常/快节奏/慢节奏）
【风格】电影质感 + 色调倾向 + 整体氛围
```

### 3.1 各部分编写要点

| 部分 | 编写要点 | 示例 |
|------|----------|------|
| **场景** | 写清时间（白天/夜晚/黄昏）、地点（森林/学院/宿舍）、氛围（紧张/温馨/悬疑）、光影（逆光/侧光/烛光） | "黄昏时分，星斗大森林深处，古老巨树遮天蔽日，金色夕阳透过树叶缝隙洒下斑驳光影，空气中弥漫着薄雾" |
| **人物** | 每个角色都要@艾特，写清动作（站/跑/挥拳）、表情（愤怒/惊讶/沉稳）、站位（前景/中景/背景）、服装 | "班长（@图片1）站在队伍最前方，表情沉稳，双手横在胸前做出防御姿态；袁泽彪（@图片6）在他右侧，肌肉紧绷，双拳紧握，眼神凶狠" |
| **武魂/特效** | 具体描述武魂长什么样、什么颜色、怎么动，不要只写"释放技能" | "班长身后浮现出巨大的玄武虚影，土黄色魂力从地面涌出凝聚成一面半透明的岩石护盾，护盾表面有龟甲纹路闪烁" |
| **台词** | 完整写出角色说的话，用双引号括起来，让AI直接生成带语音的视频（不用TTS） | "班长说：'大家小心，这只魂兽的修为不低！' 袁泽彪说：'怕什么，看我一拳打爆它！'" |
| **运镜** | 景别+运镜方式，要匹配场景物理空间（小空间不用大远景） | "中景，镜头缓慢向前推进，聚焦在班长的面部表情和护盾上" |
| **节奏** | 正常速度即可，战斗场景可以写快节奏，情感场景写慢节奏 | "正常节奏，动作连贯自然" |
| **风格** | 电影质感、色调、氛围 | "电影质感，冷色调，玄幻氛围，高对比度，画面细腻" |

## 五、提示词编写技巧与避坑

### 5.1 台词编写技巧

1. **台词必须完整写入提示词**：让AI视频模型直接生成带语音的视频，**不要用TTS单独合成**
2. **台词要符合角色性格**：
   - 班长：沉稳简短，命令式（"大家小心！""顶住！"）
   - 老弟：文绉绉，分析型（"根据我的分析..."）
   - 袁泽彪：热血直接，感叹号多（"太帅了！""吃我一拳！"）
   - 王叔：幽默吐槽（"哎哟喂，这也太吓人了吧"）
3. **每镜台词控制在2-4句**：太多台词AI生成时会语速过快或遗漏
4. **内心独白/画外音也要写**：格式为`角色A（内心独白）："..."`或`画外音："..."`

### 5.2 武魂/特效描述技巧

1. **不要只写"释放技能"**：要具体描述视觉效果
   - ❌ 错误："班长释放武魂技能"
   - ✅ 正确："班长身后浮现巨大的玄武虚影，土黄色魂力从地面涌出凝聚成半透明岩石护盾，护盾表面有龟甲纹路闪烁"
2. **写清颜色**：每个武魂有固定颜色，全剧保持一致
   - 玄武盾：土黄色
   - 万象书典：银白色
   - 八卦乾坤扇：阴阳（黑+白/金）
   - 影刃豹：暗紫色/黑色
   - 百味乾坤锅：热气腾腾（白+橙）
   - 巨力魔熊：黑色+红光
3. **写清动态**：魂力怎么流动、技能怎么释放、有什么粒子效果
4. **战斗场景写清动作连贯性**：出招→击中→反应，三个动作都要描述

### 5.3 多人同框技巧

1. **每个角色都要@艾特**：不要遗漏
2. **写清站位**：谁在前景、谁在中景、谁在背景，避免角色重叠
3. **写清各自的动作和表情**：不要只写"六个人站在一起"
4. **群像镜头用全景**：特写/近景只适合1-2人，多人用中景/全景
5. **角色服装要一致**：全剧同一角色穿同样的衣服（除非剧情中有换装）

### 5.4 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **角色变脸/形象不一致** | 提示词中没有@艾特参考图，或艾特格式错误 | 每个角色都紧跟`（@图片N）`，格式正确，多人同框全部艾特 |
| **生成的视频没有语音** | 提示词中没有写台词，或台词不完整 | 完整写出角色台词，用双引号括起来，格式为`角色A说："..."` |
| **角色说话太快** | 一镜中台词太多，AI为了塞完所有台词加速语速 | 每镜台词控制在2-4句，长台词拆到多个镜头 |
| **武魂特效不明显** | 提示词中只写"释放技能"，没有具体视觉描述 | 详细描述武魂形态、颜色、动态、粒子效果 |
| **多人同框角色重叠/混乱** | 没有写清站位和各自动作 | 写清每个人的位置（前景/中景/背景）和独立动作 |
| **场景跑偏** | 场景描述太简单，AI自由发挥 | 详细描述时间、地点、环境细节、光影、氛围 |
| **动作不连贯** | 战斗场景只写了一个动作 | 写出招→击中→反应的完整动作链 |
| **Seedance 2.5报错** | 引擎不稳定，或提示词过长/复杂 | 简化提示词重试1次，仍失败则切换Seedance 2.0 |

## 六、视频生成执行规范

### 6.1 先展示提示词、展示同时直接生成，成片后交付完整信息

**每次生成先完整展示提示词、展示提示词的同时直接生成（不停下等待确认）。每镜生成完成后，必须向用户一起交付：
1. **成片**（内嵌预览播放器）
2. **完整脚本/分镜**（该镜）
3. **完整提示词**（用代码块展示，包含所有@艾特），连同：模型版本（Seedance 2.5 或 2.0）、时长（5-30秒整数）、比例（16:9/9:16等）、参考图列表（6张角色图）

提示词完整透明、不省略不事后补；**用户认可这个成片后才生成下一镜**，不合适则按意见改/重生成再审。

### 6.2 生成参数

| 参数 | 值 |
|------|-----|
| model_version | seedance_2.5（优先）/ seedance_2.0（备用） |
| 时长 | 第一集30秒/镜，第二、三集15秒/镜 |
| 比例 | 16:9（横屏电影感） |
| 参考图 | 6张角色参考图全部传入 |
| 提示词 | 用户确认后的原文，不改写不润色 |

### 6.3 引擎故障处理流程

1. 第一次报错：重试1次（相同提示词）
2. 第二次报错：简化提示词（去掉一些复杂描述）重试1次
3. 第三次报错：**切换到Seedance 2.0**
4. 切换后：全部后续镜头使用2.0，不再来回切换（避免画质风格不一致）

### 6.4 生成后交付

每镜生成完成后：
1. **以内嵌预览播放器形式交付**（用户可直接在聊天中播放）
2. 同时附公共访问链接，并把该镜完整脚本/分镜 + 完整提示词一起给用户看
3. **逐个生成：先完整展示提示词、展示同时直接出片（不停下等待确认），成片+脚本+提示词一起给用户看，用户认可才生成下一镜；不得未经认可自动连续生成**；用户可随时插话提出修改
4. 发现问题（变脸/动作异常/意外字幕穿模/台词不对）立即重生成，不带病交付

## 七、可复用提示词模板

```

【台词】角色A说："[台词]" 角色B说："[台词]"
```
