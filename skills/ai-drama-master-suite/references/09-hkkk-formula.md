# 爆款公式库：「胡思乱想的空空」方法论

> 来源：抖音可灵AI/即梦双认证优质创作者「胡思乱想的空空」（3.9万粉/242万获赞）4部代表作80帧逐帧拆解。
> 适用：所有都市奇幻/爱情/灵异/超能力类真人短剧创作。写剧本时**默认套用此公式**，除非用户明确要求其他风格。

---

## 一、核心选题公式

### 1.1 一句话选题法

**"高概念奇幻设定 + 极致日常情感"的二元并置**：

| 维度 | 奇幻外壳（超现实） | 情感内核（极日常） |
|---|---|---|
| 示例1 | 男主早已死了，女友抱着他骷髅住进棺材 | 活人的偏执占有欲 |
| 示例2 | 丈夫死后化鬼想劝妻子改嫁 | 相守一生的双向奔赴 |
| 示例3 | 少年集齐所有超能力对抗外星人 | 普通高中生的自卑与幻想 |
| 示例4 | 男友能预知未来，躲着打电话 | 提前告别的深情与遗憾 |

**写剧本第一问**：
1. 这个故事的**情感内核**是什么？（占有/陪伴/自卑/告别/遗憾/嫉妒/思念）
2. 给这个情感套一个什么**超现实规则**能把它推到极端？（鬼/超能力/预言/时间循环/身份互换）

**铁律**：外壳服务内核。奇幻设定不是炫技，是把日常情感推到极端的放大器。

## 二、三幕结构：建立—误导—翻盘

时长不限，但比例约为 **1:1:1**：

```
┌─────────────┬──────────────────┬──────────────┐
│  第一幕 建立  │   第二幕 误导     │  第三幕 翻盘   │
│  0%–33%      │   33%–66%        │  66%–100%     │
│             │                  │              │
│ · 抛出奇幻设定 │ · 按"表面理解"推进 │ · 一句话反转   │
│ · 建立人物关系 │ · 积累情绪/悬念   │ · 全部重写前文 │
│ · 立住视觉基调 │ · 埋伏笔         │ · 情绪峰值收尾 │
└─────────────┴──────────────────┴──────────────┘
```

### 2.1 分层反转（不是一个反转，是2-3层）

**第一层：设定反转（中段，60%-70%处）**
- 用一句话把前文全部重写
- 例："死了就想离开我？""这你也能听懂？""所以我这几年提前录了很多视频"

**第二层：情感反转（后段，80%-90%处）**
- 揭示人物真实关系
- 例：女友不是受害者是加害者；不是单向守护是双向奔赴；不是分手是一辈子告别

**第三层：终极升华（最后5-10秒）**
- 一个画面/一句台词把立意钉死
- 例：白发老人握手机微笑；坟墓即家与尸同棺；"你这样害怕了一辈子"

### 2.2 反转技术要点

1. **靠一句台词翻盘**，不靠画面解释
2. **前文必须有伏笔**——提前埋可双重解释的细节
3. **反转后不解释**——翻盘后立刻进入情绪戏/空镜，让观众自己回味

## 三、视觉DNA

### 3.1 色温编码

| 色温 | 用途 | 场景 |
|---|---|---|
| 暖金黄（2700-3200K） | 甜蜜、回忆、亲密、希望 | 闪回接吻、婚后日常、黄昏校园 |
| 冷青灰（6500K+） | 死亡、孤独、灵异、压抑 | 灵堂、鬼魂段、灾难、太空 |
| 冷暖对撞 | 内心撕裂、阴阳两隔 | 鬼魂白辉光+冷蓝夜、手机冷屏+暖黄室内 |
| 纯黑+硬光 | 情绪暴击 | 银瞳特写、痛哭特写 |

**铁律**：全片一个主色调，关键情绪节点突然切色温——色温切换=情绪切换，不需要台词说明。

### 3.2 布光：全实用光源

所有光必须有出处：
- 台灯/落地灯 = 温馨私密
- 荧光灯管 = 冰冷阴森
- 门缝/窗缝一线光 = 悬念窥视
- 蜡烛 = 邪性执念
- 手机屏幕光 = 隔着屏幕的爱

**签名手法**：
1. 45°侧光打人物，半明半暗
2. 逆光勾金边——甜蜜场景发丝边缘发光
3. 特写保留眼神光——哭戏眼睛里必须有小高光
4. 大面积压暗——惊悚/悲伤段落压暗70%画面，只留脸或道具

### 3.3 镜头语言

**景别分布**（参考值，非死规定）：
- 特写/大特写 ~35%（情绪暴击）
- 近景 ~25%（对话/单人情绪）
- 中景 ~25%（双人互动）
- 全景/大全景 ~15%（场景建立/尺度反差）

**核心手法**：
1. 第一人称POV视角——让观众直接代入"我"
2. 过肩镜头反复用——"跟着主角一起看"
3. 正面怼脸大特写做情绪暴击——停留2-3秒
4. **同机位复用做时间对照**——同场景同角度，不同时间复现，靠状态变化传递时间流逝
5. 空镜/道具特写做转场和暗示
6. 景别极端跳跃——从面部特写直接切到大全景，用尺度反差制造超现实感
7. 几乎无剧烈运镜——固定镜头+缓慢推近，情绪更沉

## 四、人物模板

### 男主
- 黑色短发/碎发，清瘦，单眼皮/内双，五官清秀偏日系
- 服装：温柔系针织衫/毛衣/白衬衫，浅灰/米白/燕麦色
- 气质：内向、敏感、嘴笨、深情，哭起来有破碎感（鼻尖泛红+脸颊挂泪）
- 常常"缺席"——是鬼魂/是回忆/是视频里的人/是死者/是幻想者

### 女主
- 黑/棕中长发，鹅蛋脸/圆脸，卧蚕明显，笑起来温婉
- 服装：米白毛衣/燕麦家居服/奶油睡衣
- 气质：表面柔弱，内核坚韧
- 是全片情绪载体，大量特写对准她的脸

### 跨年龄手法
同一角色跨年龄（少年→成年→老年），靠服装/发型/妆容一笔带过，不做复杂特效。

## 五、台词风格

### 5.1 第一人称低语旁白
- 旁白者是"已经知道结局的人"——死后视角/未来视角/回忆视角
- 语气是低声诉说，不是慷慨激昂
- 句子短，每句不超过15字，像在耳边说话
- 只描述现象和感受，不解释原因（解释留给反转）

### 5.2 对话
- 极短：单句5-10字
- 口语化，不用书面语
- 有黑色幽默
- **重复变奏**：同一句话说两遍，第二遍含义翻转
  - 例："再找一个丈夫"→"再找一个男的"
  - 例："这你也能听懂？"→"你能看到我？"

### 5.3 沉默比话多
- 平均40%帧无台词
- 情绪最浓烈的段落（哭戏/重逢/终极反转）全部静默，靠脸与真实环境音，配乐 BGM 禁止
- 写完台词后，删掉高潮段落50%台词，换成演员的脸和环境音

## 六、道具符号系统

每个剧本选1-2个"签名道具"反复出现，定义一段关系：
- 琥珀色抓夹（定义人生阶段）
- 手机时间码递减（定时遗书的仪式感）
- 联系人备注「笨蛋熊」（一个细节立住情侣关系）
- 中西混搭法器（黑色幽默+民俗恐怖）

---

## 七、时长与节奏（灵活，不锁死）

**时长由故事需要决定，不强行套用90秒或5分钟**：
- 90秒能讲完就做90秒（四幕高密度）
- 3分钟能讲完就做3分钟
- 需要5-10分钟展开就做长片
- **核心约束不是时长，是信息密度**——每3-4秒一个新信息点，杜绝空镜

**节奏参考**：
- 建立-误导-翻盘三幕比例约1:1:1，但可根据故事调整
- 情绪激烈时切镜加快，情绪压抑时镜头可略长但必须有信息流动
- 一个镜头超过5秒，中间必须穿插对话/旁白/物品切换/反应镜头
