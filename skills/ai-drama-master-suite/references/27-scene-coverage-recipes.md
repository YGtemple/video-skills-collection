# 高频真人场景镜头配方库（Coverage Recipes · 照着就能套）

> 定位：26 号管"怎么一步步拆"，本文件管"**常见的戏，直接给成套镜头**"。每个配方＝该场景经过验证的标准镜头序列 + coverage 必备清单 + 节奏 + AI 生成注意点 + 变体。
>
> 用法：先按 26 号 Step 1–3 确认本场的 Beat，再从这里找最接近的配方做"起手骨架"，然后按具体台词和 Beat 增删镜头——**不是生搬，是站在骨架上改**。
>
> 通用前提（所有配方都遵守，下文不重复）：守一条 180°轴线；≥2 人同框写站位三要素；台词每秒 ≤5 字；重台词后给反应；no srt，no music（真实环境音保留）；复杂镜头按 29 号拆分。

## 配方 1：双人坐谈（室内对话，最常用）

**标准镜头序列（约 25–30s，6 镜）：**
1. **中全景·平视·24–35mm·轻推**：定场，两人隔桌 / 沙发的位置关系、环境。
2. **双人镜头 Two-shot·35mm·固定**：同框，先开口的人说话，建立关系。
3. **过肩（过 A 肩拍 B）·50–85mm·固定**：B 回应。
4. **反打过肩（过 B 肩拍 A）·50–85mm·固定**：A 再说，对话推进。
5. **单人特写 / 近景·85mm·固定或微推**：本场最关键的一句、或情绪转折 Beat。
6. **听者反应特写 → 拉回双人 / 留白**·85mm→35mm：反应停顿后收束。

**coverage 必备**：定场 1 + 双人 1 + 正反打各 1 + 关键特写 1 + 反应 1。
**节奏**：中速；正反打可随对话升温逐渐推近 / 加快；转折句后留 1.5–2s 反应。
**AI 注意**：过肩镜头要写清"谁的肩在前景哪一侧"；一次只让一人说完整句，避免两人抢话；若 AI 过肩构图不稳，退化为"单人近景 + 反应特写"交替。
**变体**：地位不对等（一方站一方坐）→ 给站者微仰、坐者微俯，强化权力差。

## 配方 2：站立 / 行走中对话

**标准镜头序列：**
1. **全景 / 中全景·35mm·跟拍（侧向或背向）**：两人边走边谈，交代动线。
2. **侧向中景跟拍·35mm**：A 说（两人保持并排，A 在左 B 在右锁定）。
3. **侧向中景跟拍·35mm**：B 回应（同一机位方向，不越轴）。
4. **正面迎镜中景·50mm·缓退跟拍**：关键一句，让观众正脸读到情绪。
5. **近景·85mm·跟移**：一人的反应 / 停顿（脚步可放慢）。
6. **全景·目送或两人走远**：收尾留白。

**coverage 必备**：走动线的全景 1 + 并排侧跟 2 + 正面关键句 1 + 反应 1。
**节奏**：运动带来天然节奏；关键台词时让脚步放慢或停下（"停步说重话"最有力）。
**AI 注意**：行走是 AI 高失败动作——**镜头跟移幅度要小、速度要慢、背景别太复杂**；一次行走段别超过 8–10s，长了拆成"走一段 → 停下说 → 再走"；人物相对位置（谁左谁右）全程锁死。
**变体**：走廊长谈（纵深透视，用门框 / 柱子做遮挡递退）；上下楼梯（用高低机位差）。

## 配方 3：多人饭局 / 群戏

**标准镜头序列：**
1. **全景·24–35mm·固定或轻摇**：定场，圆桌 / 长桌所有座位、谁在哪（先在俯视图给每人编号定位）。
2. **主发起者中景·50mm**：挑起话题 / 冲突的人说话。
3. **过肩 / 邻座近景**：被针对者或主要回应者。
4. **反应快切组（2–3 个 1–2s 特写）**：周围人交换眼神、低头、夹菜停住——群戏的味道全在反应。
5. **关键对峙双人近景（过桌面）**：矛盾的两人，旁人虚化。
6. **全景收束·一个动作破局**（有人摔筷 / 起身 / 打圆场）。

**coverage 必备**：全桌定场 + 主发言 + 被针对者 + ≥3 个旁人反应 + 破局动作。
**节奏**：前松后紧；反应镜头越到冲突越短越快。
**AI 注意**：**AI 单镜稳定同框人数有限——全景"一桌子人"最容易脸崩 / 多手**。策略：定场全景只给 1 个、接受其略虚；正文**拆成"两两"小景别**（一次只拍 2 人的过肩 / 邻座），靠剪辑拼出群像；别让 AI 在一个镜头里处理 4 人以上交叉对话。
**变体**：家宴（暖调、长座次）；鸿门宴 / 谈判桌（冷调、两端对峙、长桌纵深）。

## 配方 4：争吵冲突戏

**标准镜头序列：**
1. **中景双人·35mm·手持微晃**：争执起句，不稳定画面预埋紧张。
2. **近景·85mm·手持·A 逼问**：A 一句（音量 / 语速上来）。
3. **近景·85mm·手持·B 回击**：B 反打（正反打节奏明显加快，每镜变短）。
4. **插入特写**：攥紧的拳 / 拍桌的手 / 被攥皱的纸 / 发抖的杯子——动作外化。
5. **大特写 / 停顿**：最狠一句后，一方的脸（或一方转身、沉默）——**最高点往往是突然的静**。
6. **拉开 / 一方离场**：冲突中断（摔门 / 夺门而出），留另一方，留白。

**coverage 必备**：起争执的双人 + 加快的正反打 + ≥1 动作插入 + 最高点停顿 + 离场 / 中断。
**节奏**：镜头由长到短、由稳到晃；**在最吵之后给一个突然的安静或停顿，比一直吵更有力**。
**AI 注意**：避免设计"两人同时大喊 + 大幅肢体动作"（AI 必乱）；让争吵以"轮流说短句 + 反应"呈现；拍桌 / 摔东西这种快动作单独给插入镜头、别和对白挤一起；防止动作演变成肢体暴力（合规，见铁律 3）。
**变体**：隐忍型争吵（压低声、越平静越可怕，反用：用固定镜头和长停顿）。

## 配方 5：重逢 / 相认戏

**标准镜头序列：**
1. **全景 / 中景**：一方在人群 / 车站 / 门口中看到对方（先给"看到"的瞬间）。
2. **主观视线 / 焦点**：沿视线找到对方（可轻微虚→实）。
3. **发现特写**：认出的脸，瞳孔 / 呼吸变化（**别急着说话**）。
4. **慢动作 / 停顿双人镜头**：两人靠近、迟疑（脚步、欲言又止）。
5. **相认特写 / 中景**：一句"是你吗 / 我回来了"，或一个拥抱 / 鞠躬 / 握手。
6. **反应 / 环境留白**：周围人流虚化、只剩两人，情绪沉淀。

**coverage 必备**：看见 → 视线 → 认出反应 → 靠近 → 相认动作 / 台词 → 留白。
**节奏**：慢；把"认出"和"开口"之间的迟疑给足（2–3s），这是重逢最戳人的段。
**AI 注意**：慢动作 / 人群中穿行是难点——慢动作幅度小、人群做虚化背景别给清晰路人；拥抱要写清谁面向镜头、手臂位置；**优先用表情和停顿，少依赖台词**。
**变体**：不敢相认（远远看着、转身离开，反向处理更虐）；误会型相认（认错人的落空）。

## 配方 6：离别 / 送行戏

**标准镜头序列：**
1. **全景定场**：车站 / 机场 / 村口 / 门口，交代"要走"的环境。
2. **中景双人**：最后的叮嘱 / 沉默（递东西：行李、袋子、信封——给一个道具）。
3. **近景·叮嘱者**：说最朴素的嘱咐（"到了打电话""好好吃饭"）。
4. **近景·离开者反应**：点头 / 红眼眶 / 不敢看。
5. **中景 / 全景·转身走**：一方走向检票口 / 车 / 路的尽头。
6. **目送特写 → 大远景**：留下的人凝望；走远的人回头一次（或始终没回头），留白。

**coverage 必备**：环境定场 + 叮嘱道具 + 双方近景 + 转身走 + 目送 / 回头。
**节奏**：慢而克制；**最重的情绪放在"走之后"的目送和"回头 / 没回头"上**。
**AI 注意**：人流 / 车辆做虚化；转身和走远用中全景、别让 AI 处理长距离跟拍；递东西的手部动作可单独插入。
**变体**：生离（知是永别，情绪更重、可不给回头）；送别不送（一个人在窗口 / 门后看，对方不知道）。

## 配方 7：进门 / 回家戏

**标准镜头序列：**
1. **外景中景 / 空镜**：楼下、门口、亮着的窗（交代"到家"、定情绪基调）。
2. **手部特写**：掏钥匙 / 敲门 / 推门。
3. **主观 / 过肩进门**：从门口看屋内（光线、陈设、有没有人）。
4. **室内中景**：人物进屋、换鞋、放包 / 行李。
5. **发现 / 相遇**：看到留的灯、饭菜、纸条，或迎上来的人（本场信息点）。
6. **反应特写收束**。

**coverage 必备**：外部基调 + 进门动作 + 主观进屋 + 发现 + 反应。
**节奏**：按"回家"的情绪定——温暖则暖光慢推，冷清 / 异常则静、慢、留出不对劲的悬念。
**AI 注意**：主观进门镜头运动要慢、注意门框过渡；屋内"该有人没人 / 反常细节"是悬疑钩子（见配方 14）。
**变体**：荣归（意气风发）；深夜心虚回家（怕惊动家人）；发现家中异常（恐怖 / 悬疑向）。

## 配方 8：单人情绪 / 独白戏

**标准镜头序列：**
1. **全景 / 中景**：人物独自处在空间里（孤独感、环境即心境）。
2. **中景**：做一个动作（坐下、点烟、对着镜子 / 窗 / 手机）。
3. **近景·侧脸 / 半张脸**：内心独白 OS 第一句（视频模型直接发声）。
4. **插入特写**：独白对应的物件（照片、药瓶、戒指、未发出的消息、窗外）。
5. **特写·正脸 / 镜中脸**：独白最重的一句，眼神有具体凝视对象（**写"看着什么"，不写"很悲伤"**）。
6. **大景别 / 光影留白**：人物在环境中静默收尾。

**coverage 必备**：孤独定场 + 动作 + 侧脸独白 + 物件插入 + 凝视特写 + 留白。
**节奏**：慢；独白句子短、停顿多；**凝视对象（gaze object）+ 身体微约束（攥手、抿唇、下颌绷紧）比形容词有效**（见 29 号表演指导）。
**AI 注意**：单人戏是 AI 最稳、也最容易出质感的戏，可大胆用特写和环境光；避免一个镜头独白超过 8–10s，长了拆"独白 → 物件 → 独白"。
**变体**：对镜独白（分裂感）；对着遗物 / 照片说话（倾诉）；假装坚强（笑着独白却红了眼）。

## 配方 9：打电话 / 发消息戏

**标准镜头序列（打电话）：**
1. **中景**：人物接起 / 拨出电话（看到来电显示可给手机特写）。
2. **近景**：接听第一句。
3. **插入 / 切出**：电话另一端（可选：给对方镜头，或只用声音 + 本方反应）。
4. **反应特写**：听到关键内容后的脸（电话戏的核心是"单方面反应"）。
5. **手部 / 动作插入**：攥手机、靠墙、坐下、脚步停住。
6. **近景收束**：挂断 / "你说话啊" / 忙音，停顿。

**发消息戏**：手机屏幕特写（**注意：屏幕文字属"画面内文字"，与零字幕规则冲突——优先改成"念出消息"或用对方回复的反应表现，避免拍可读屏幕**）；若剧情必须，屏幕文字按"时空 / 信息必要"单独与用户确认。

**coverage 必备**：来电 + 接听 + 关键内容反应 + 动作 + 挂断停顿。
**节奏**：靠"说—听—反应"交替；**听不到对方时，用本方反应让观众脑补对方说了什么**。
**AI 注意**：不建议让 AI 同时演通话双方清晰正脸（容易跳）；一端正脸、一端画外音最稳；手机贴耳的姿势、手部可给插入。
**变体**：未接来电 / 留言（对着忙音说话）；误拨 / 听到不该听的（悬疑）。

## 配方 10：对峙 / 摊牌戏

**标准镜头序列：**
1. **中全景**：两人 / 两方站位（空间距离、谁占上风先在俯视图定）。
2. **中景·A**：摊牌方亮出底牌（证据 / 真相 / 决定）。
3. **近景·B 反应**：被摊牌者的第一反应（**先反应，再辩解**）。
4. **插入特写**：底牌道具（录音、合同、检查报告、照片）。
5. **正反打近景·逐渐收紧**：交锋、攻防（台词短、停顿多）。
6. **一锤定音 + 静场**：最后一句 / 一个动作，长停顿或一方崩溃 / 认输，留白。

**coverage 必备**：对峙站位 + 亮底牌 + 第一反应 + 底牌道具 + 收紧的正反打 + 定音静场。
**节奏**：克制、慢、张力靠停顿而非喊叫；**"亮证据 → 长沉默 → 对方崩"比连环台词更有压迫感**。
**AI 注意**：对峙以静制动，多用固定镜头和近景，少用大幅运镜；证据道具给插入；避免肢体冲撞（合规）。
**变体**：三方对峙（用空间站位和视线切换，仍拆成两两小景别）；笑着摊牌（越平静越狠）。

## 配方 11：职场戏（被裁 / 上下级冲突）

**标准镜头序列：**
1. **办公室全景 / 中景**：工位、加班环境、人物状态（夜里亮着的电脑、收拾纸箱——定场即信息）。
2. **中景·上下级**：谈话起（隔着办公桌 / 会议桌，权力位差）。
3. **过肩 / 近景·上级**：通知 / 施压（微仰上级、微俯员工，或反用）。
4. **近景·员工反应**：听到后的脸（错愕 / 隐忍 / 不甘）。
5. **插入特写**：纸箱里的私人物品、工牌、解除合同、关掉的电脑屏幕。
6. **中景 / 全景收束**：抱纸箱走出办公区 / 玻璃门，背影或回头，留白。

**coverage 必备**：环境定场 + 隔桌谈话 + 双方近景 + 反应 + 物件插入 + 离场。
**节奏**：克制、现实；情绪靠"收拾东西"这类动作和反应承载，少喊口号。
**AI 注意**：办公室格子间背景人群做虚化；电脑屏幕避免可读文字 / UI（零文字规则）；离职收拾的手部 / 纸箱给插入；玻璃门 / 隔断的反光注意别穿帮。
**变体**：反击 / 翻盘（员工亮出自筹码，按"对峙"配方走）；同事围观（群像按配方 3 拆小景别）。

## 配方 12：亲情饭桌戏

**标准镜头序列：**
1. **中全景·暖光**：一桌家常菜、家人落座（烟火气定场，冒热气的菜、碗筷）。
2. **中景·长辈**：夹菜 / 问近况（"多吃点""怎么又瘦了"）。
3. **近景·晚辈**：吃饭 / 敷衍 / 欲言又止。
4. **插入特写**：夹到碗里的菜、添饭、停住的筷子、桌下相握的手。
5. **反应近景**：一句戳心的话 / 一个沉默（催婚、钱、病情、离别——本场价值转折）。
6. **中景 / 暖调留白**：一家人继续吃饭、或一人的凝视，温情收束。

**coverage 必备**：烟火定场 + 夹菜动作 + 双方近景 + ≥2 个饭桌细节插入 + 转折反应。
**节奏**：舒缓、生活化；**情感藏在"夹菜、添饭、嘴硬"的动作里**，不直说"我爱你"。
**AI 注意**：饭桌是 AI 较稳的温情场景；多人仍按配方 3 拆小景别；冒热气、碗筷环境音可写明增强真实感。
**变体**：缺席的碗筷（留给亡者 / 未归的人，催泪）；最后的团圆饭（离别 / 病重底色）。

## 配方 13：时间流逝 / 日常蒙太奇

**标准镜头序列（一组 3–6 个短镜头，每个 1.5–3s）：**
1. **重复动作的不同状态**：同一动作 / 场景在不同时间反复（出门、等门、做饭、看手机）。
2. **季节 / 光影变化空镜**：窗外天色、树叶、积雪、同一面墙的光移动。
3. **道具变化**：日历翻页、钟、花开花落、照片、堆积的物件（**日历 / 屏幕文字属画面文字，优先用无字的光影 / 道具变化表现**）。
4. **人物状态变化**：发型 / 衣着 / 神情随阶段改变（换装需有交代，见铁律 24）。
5. **收束到"现在"**：最后一个镜头落回当前时空，衔接下一场。

**coverage 必备**：重复动作 + 光影 / 季节 + 道具变化 + 人物状态 + 落点。
**节奏**：快剪、靠镜头组接体现时间；可用环境音（脚步、钟、风雨）做声音线索串联。
**AI 注意**：每个镜头单独生成、靠硬切组接蒙太奇（不要让 AI 在一个镜头里演"季节变换"）；各镜头光线 / 时间要明确区分；这是"无台词也成立"的少数段落，但别超过叙事需要。
**变体**：等待蒙太奇（一个人反复等，虐）；奋斗蒙太奇（努力 / 练习的快剪，燃）；衰老 / 成长（同机位、人物变化，对照感强）。

## 配方 14：悬疑 / 信息差戏（希区柯克式）

**核心原理**：**悬念来自"信息差"——让观众知道角色不知道的危险 / 真相（"桌下有炸弹，观众看见了，桌边人还在闲聊"）**，观众替角色着急。区别于"突发惊吓"。

**5-Beat 结构：**
1. **建立日常 / 安全感**：角色在正常场景（同时 / 提前让观众看到隐患：未关的煤气、藏着的人、异常细节）。
2. **给观众"炸弹"**：一个镜头让观众知道威胁所在（角色没发现）。
3. **角色靠近危险而不自知**：日常继续，观众开始紧张（角色的每个平常动作都被观众"另眼相看"）。
4. **时钟 / 临界点逼近**：危险临近（倒计时、声音、影子），角色仍差一点发现。
5. **爆发 / 解除 / 反转**：在最后关头被发现 / 阻止 / 或真相反转（"炸弹"真假、谁是同伙）。

**coverage 必备**：日常定场 + 让观众看到隐患的镜头 + 角色无察觉的动作 + 临界逼近 + 爆发 / 反转。
**节奏**：慢起、持续加压；**用"观众知道、角色不知道"的镜头（隐患特写 + 角色平静的反应并置）制造张力**。
**AI 注意**：隐患靠具体物件 / 细节（门缝、影子、滴答声、亮起的指示灯），少靠血腥；黑暗场景注意别全黑（见 19 号案例经验）；声音（异常响动、突然的静）可写明。
**变体**：罗生门（多视角重述同一事件，每版信息不同）；观众和角色一起被误导（结尾反转）。

## 通用：如何挑选与组合配方

1. **一场戏可能是多个配方的组合**：如"职场被裁后打电话给家人"＝配方 11 的离场 + 配方 9 的电话 + 配方 8 的情绪。
2. **先骨架后血肉**：用配方的镜头序列定 coverage 骨架，再按 26 号 Beat 表把具体台词、反应、道具填进去。
3. **每个配方都要过 29 号的"AI 可生成性"检查**——配方是"理想镜头"，落到 AI 生成时该简化的简化、该拆分的拆分。
4. **不要全片只用一个配方 / 一种景别节奏**：对话戏和动作 / 蒙太奇 / 留白交替，节奏才有呼吸（见铁律 23）。
