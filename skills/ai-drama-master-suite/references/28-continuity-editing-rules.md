# 镜头连贯与剪辑思维（分镜阶段就要想好"怎么接"）

> 定位：02 号管"单个镜头的红线"，26 号管"怎么拆"，27 号管"套什么骨架"，本文件管 **"镜头与镜头之间怎么接才顺、才不露剪辑痕迹"**。这些规则在**分镜阶段就要预埋**——等生成完再发现接不上，只能重生成。
>
> 边界：本套件成片**只硬切、不做转场特效、不主动剪辑**（铁律 20）。本文件讲的不是"后期怎么剪花活"，而是"**如何在分镜设计时就让硬切成立、让空间 / 动作 / 视线连贯**"。180°轴线的完整图解在 02 号 3.5，本文件只引用、不重复。

---

## 一、空间连贯：让观众始终知道"谁在哪、朝哪"

### 1.1 180°轴线（只列要点，图解见 02 号 3.5）

- 对话 / 对峙场景，先在两人（或两组运动方向）之间画一条轴线，**摄影机全程在同一侧**，正反打不越轴。
- 越轴只有三种合法方式：人物走动换位（给完整镜头）、插入中性镜头（正对镜头 / 空镜）、摄影机带观众运动过线。
- 分镜组开头标注轴线与机位所在侧；**每个镜头的朝向要能顺着轴线推出来**（A 始终面向右、B 始终面向左）。

### 1.2 30°规则（避免"假切换"）

**同一场景、同一主体，相邻两个机位如果角度相差不到 30°（或景别几乎一样），切在一起会像"画面跳了一下"（跳切），观众会出戏。**

- 相邻拍同一主体的两个镜头，**机位角度至少相差 30°，或景别明显跳一档**（如中景直接到近景 / 特写）。
- ❌ 错误：机位几乎不动，连续两个"中景说话"硬切——看着像卡顿 / 穿帮。
- ✅ 正确：中景（35mm）→ 过肩近景（85mm，角度和景别都变了）。
- **例外（故意用跳切）**：表现时间压缩、情绪焦躁、人物精神状态不稳时，刻意的同机位跳切是手法——但要明确是"设计"，不是失误。

### 1.3 机位的"接力"要连续

- 同一场戏的镜头，机位移动要有逻辑：从全景到特写是"逐步深入"，不要全景 → 大特写 → 又跳回大全景（除非情绪设计）。
- 一组正反打的机位要"成对"：过 A 肩拍 B 和过 B 肩拍 A，角度 / 焦段 / 肩的位置对称，切在一起才稳。

## 二、动作连贯：在动作中切换最顺

### 2.1 动作接动作（Cut on Action）

**同一个动作，在动作进行中（而不是动作做完后）从一个机位切到另一个机位，观众的注意力被动作带着走，几乎察觉不到剪辑点。**

- 典型：人物起身（中景，开始站起）→（站到一半切）→ 全景已站直；转身、推门、抬手、回头同理。
- **分镜设计时**：把一个完整动作"分给两个镜头"——前一镜演动作的前半、后一镜演后半，并在分镜里标清"动作切点"（如"切在她手碰到门把的瞬间"）。
- 关键：两个镜头里动作的**方向、速度、起始位置必须一致**（前镜右手抬，后镜不能变左手）。

### 2.2 不要在"静止点"硬切（容易跳）

- 两个镜头都是人物"站着不动说话"，硬切最容易暴露（位置 / 姿势稍有差异就跳）。
- 解决：要么让镜头之间有动作 / 反应 / 插入来过渡，要么用明显不同的景别 / 角度（30°规则）。

### 2.3 动作方向一致（屏幕方向）

- 一个人从画面左向右走，下一个镜头（同一段运动）他仍应**朝同一屏幕方向**移动，否则像"走回去了"。
- 追逐 / 赶路尤其重要：追的人和被追的人屏幕方向关系要固定（如被追者一直向右逃、追者一直向右追）。
- 要改变屏幕方向，用一个"转弯 / 正面 / 过轴"的镜头交代。

## 三、视线连贯：让"看"和"被看"对上

### 3.1 视线匹配（Eyeline Match）

**镜头1：人物看向画外；镜头2：他 / 她看到的东西（人 / 物 / 景）。两个镜头里，视线的方向、高度、距离要对得上。**

- 角色抬头看 → 下镜应是高处的东西；低头看 → 下镜是低处 / 手中物；看向画面右侧 → 被看对象在下镜应出现在相应方向。
- **分镜时**：给"看的镜头"标清视线方向和落点高度，给"被看镜头"时让对象位置与之匹配（如 A 视线略偏下，被看的是坐着的 B）。
- 对不上（A 平视看，下镜却是俯视的对象）观众会觉得"没看对地方"，空间感崩。

### 3.2 对话中的视线

- 正反打中，角色视线应落在"画外对方"的位置（过肩镜头里看向对方的脸），而不是看镜头 / 乱飘。
- **让眼睛有具体落点**（看着对方的眼睛 / 桌上的杯子 / 手机），没有落点眼睛就会乱——这也是 29 号"凝视对象"原则。

### 3.3 主观镜头的进出

- 主观（POV）镜头前最好有"角色看向"的镜头做引导，后接"角色反应"做收束（看 → 看到 → 反应），POV 才成立、不突兀。
- POV 全片少用（02 号有上限）。

## 四、素材连贯：主镜头、反应、插入、切出

### 4.1 主镜头（Master / 覆盖镜头）打底

- 一场戏先有一个完整覆盖全场动作的主镜头（通常全景 / 中全景），其他近景 / 特写都"挂"在主镜头的时间线上。
- 作用：任何近景接不上时，都可以回到主镜头重建空间；分镜时先定主镜头，再插入其他角度。

### 4.2 反应镜头（Reaction）——天然的"安全剪辑点"

- 一句台词、一个事件后切听者 / 旁观者反应：**既放大情绪，又给剪辑提供大量安全切点**（反应镜头角度独立，几乎不会接不上）。
- 分镜时主动多备反应镜头（尤其重台词后），这是最划算的 coverage。

### 4.3 插入镜头（Insert）与切出（Cutaway）

- **插入**：道具 / 手部 / 文件 / 细节特写——用来交代信息、强调、或掩盖两个镜头之间的不连贯。
- **切出**：切到场景外 / 环境空镜——用来转场、表现时间、缓冲情绪。
- 分镜时为关键道具和情绪点预留插入 / 切出，后期（用户自剪）才有"缝合"素材。

## 五、场景的进入与退出

- **进入**：一个新场景，通常先用定场镜头（外景 / 全景）让观众知道"在哪、什么时间"，再进中近景。直接跳进两个大脸特写，观众不知道身处何地（对话开场也要中景 / 全景，见 02 号）。
- **退出**：一场戏结束给一个"收束镜头"（人物离场、关门、空镜、定格反应），让场景有"句号"，也为转下一场留缓冲。
- **场景之间**：本套件段间靠硬切或"衔接片段"（铁律 31）——设计衔接时让**上段的终点动作 / 视线 / 情绪**自然引向下段起点（出门 → 路上 → 到达）。

---

## 六、声音连贯（声音是最隐蔽的衔接）

- **环境音连续**：同一场戏各镜头的环境音（雨声、人群、房间底噪）应一致，硬切时环境音不要突变 / 重叠（铁律 26）。
- **声音桥（Sound Bridge）**：让下一场的声音（或本场尾声的声音）提前 / 延续，"先闻其声后见其画"能让硬切更顺——在分镜 / 配音指令里写明，由视频模型直接生成。
- **音画同步**：口型对台词、动作对音效（脚步、关门、放杯子），这是红线（铁律 29/32）。
- 静：刻意的"突然安静"（环境音抽空）是强情绪 / 悬念手法，可在分镜中标注。

> 关于 J-cut / L-cut（声音先于 / 晚于画面进入）：这是相邻镜头的声音叠加，**成片只硬切、不由后期做**；如需要，应在"单个 30 秒生成段内部"由视频模型直接生成（模型可在一段内处理声画的先后），段间仍硬切。

---

## 七、AI 生成模式下，连贯规则怎么落地（重要）

AI 生成和真人拍摄不同，连贯要分两个层面处理：

1. **一个 30 秒生成段内部**：多机位切换、动作接动作、正反打、反应、声音桥——**凡是能在一段内完成的，都写进该段视频 prompt，让模型在同一段里生成这些"镜头切换"**（模型支持一段内 wide → close-up → tracking 的多机位）。这是最连贯的，因为出自同一次生成。
2. **段与段之间**：只靠硬切 / 衔接片段（铁律 31）。为让两段接得上：
   - **链式衔接**：复用前一镜已生成视频的末帧作为下段的参考（不算新做关键帧，见铁律 30），保证动作 / 构图连续。
   - **标准化版本（33 号，见 references/33-tech-panorama-anchor.md）**：当同场景跨段、多人走位、动作交接复杂时，可使用模式A在组尾追加1秒无对白技术全景，拼前剔除；或使用模式B在正片完成后另生成5秒技术补段、不进filelist。取技术素材末帧作下一组锚点，不进正片。
   - 多段同场景：用 24 号机位底图锁同一空间、同一机位。
   - 站位 / 服装 / 光线 / 道具在跨段时对照 15 号资产表保持一致。
3. **把连贯责任前移到分镜**：分镜表上就要标清——动作切点、视线方向与落点、屏幕运动方向、成对正反打、段间衔接点。没标的，生成阶段一定接乱。

## 八、连贯自检（分镜输出前必过，叠加 02 / 26 自检）

- [ ] **轴线**：对话 / 对峙是否全程在轴线一侧？越轴是否用了三种合法方式？
- [ ] **30°规则**：相邻同主体机位角度是否 ≥30°或景别明显跳一档？（故意跳切除外）
- [ ] **动作接动作**：跨镜动作是否标了切点、前后镜方向 / 速度 / 位置一致？
- [ ] **屏幕方向**：人物运动 / 追逐的方向跨镜是否一致？
- [ ] **视线匹配**：每个"看"是否有方向 / 高度 / 落点匹配的"被看"镜头？眼睛是否有具体落点？
- [ ] **主镜头 / 覆盖**：是否有定场主镜头打底？
- [ ] **反应 / 插入 / 切出**：重台词后是否有反应？关键道具是否有插入？转场 / 留白是否有切出？
- [ ] **场景进出**：每场是否有定场进入、收束退出？
- [ ] **声音**：环境音是否连续？音画是否同步？需要声音桥处是否写明？
- [ ] **AI 落地**：能在一个 30 秒段内完成的切换是否都放进了同一段？跨段是否用了末帧链式 / 机位底图 / 资产表锁定（或 33 号技术全景锚点尾，见 references/33-tech-panorama-anchor.md）？
