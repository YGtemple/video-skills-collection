# 动作分题材子库（自由格斗 · 武侠冷兵器 · 超能力 · 战场群战）

> **定位**：本文件是 [30 号动作戏镜头设计](30-action-scene-shot-design.md) 的"按题材细分"补充。
>
> 分工（先看清，不重复）：
> - **30 号管动作因果总纲**：五段语法（局势距离→发起→防守命中→受力位移→恢复）、动作单元≠剪辑镜头、容量与阶段、真人写实五着力点、按形式/按人数分、摄影策略、打击反馈、连续性校验。
> - **本文件只补 30 号没有的四类题材专属打法**——每类的招式因果速查、该题材下摄影机具体怎么动、空间关系怎么交代、Seedance 2.5 真人实拍下的落地要点与常见崩法。
>
> 用本文件前先确认已读 30 号；两文件冲突时，**合规前提（铁律 3：无血腥特写、无刺穿、无暴力慢放）与 30 号总纲优先**。

## 主控语境（吸收时已改写，硬约束）

- 真人写实短剧、横屏 16:9；已剔除源材料里的 2D 动画 / 动态漫 / 竖屏口径。
- **分镜组默认一次 30 秒一组（铁律 36）**。源材料里"4–8 秒单元最多 3 个打击 / 10–15 秒最多 5 个动作"是它自己的保守配置，本文件一律按 30 秒组语境改写为"一组 30 秒内 N 个攻防单元"。
- 视频默认 **Seedance 2.5**；**不出关键帧 / 首尾帧定帧（铁律 30）**——能力首现、内力对撞这类"定场感"镜头也靠连续运动拍，不另画定帧；段间必做衔接（铁律 31）；同场景跨组的整空间状态锚点用 [33 号技术全景截帧](33-tech-panorama-anchor.md)，不在本文件新画任何定帧。
- 动作密度与镜头数对齐 30 号 §三：一组 30 秒真人写实动作段 = 5–8 个攻防单元、10–18 镜。

## 〇、四类共用前提（下文不再重复）

- 动作一律写成可见物理链：**起手 → 接触点 → 受力结果 → 反应 → 段末状态**（与 30 号五段语法同构；本文件只补各题材"接触点长什么样、受力往哪倒"）。
- 不是每次攻击都命中：必须有试探、格挡、闪避、落空、反击、拉开喘息；一组 30 秒全是命中 = 假。
- 镜头震动只给**决定性重击**且轻微短促；慢镜只给该题材"命中 / 落地 / 命中瞬间"一个点，不每击都慢放（铁律 3 禁暴力慢放）。
- 伤害一律用后退、弯腰、捂肋、喘息、失衡、脱手、倒地、被拖离表达；**不写喷溅、刺穿、断肢、血腥特写**。
- 高崩区优先用 [29 号拆分四法](29-ai-shot-design.md) 绕：整段缠斗 / 锁技 / 群战别指望一个镜头演完，拆"起（中景）—关键接触特写—结果"。

## 一、自由格斗与近身搏击（拳脚肘膝 · 摔投 · 擒拿 · 地面控制 · 缴械）

**适用边界**：直摆勾拳、踢击、肘膝、抱摔、过肩摔、绊摔、关节锁、绞技、贴身缠斗、缴械、闪避反打。不适用大规模军阵、纯武侠轻功、纯异能斗法。

**30 秒组容量**：5–8 个攻防单元；贴身缠斗类连续单元不超过 3 个，之后必须给一次拉开、喘息或反打，否则模型必乱。

### 招式因果速查（起手→接触点→受力结果 + 摄影机行为）

| 招式 | 动作因果 | 摄影机行为 |
|---|---|---|
| 直拳 / 摆拳 | 拳自肩侧短促打出，命中对方颧骨/下颌，对方头侧偏、退半步 | 中近景手持，命中瞬间镜头短震一次（仅决定性一击） |
| 低扫 | 前脚假动作后低扫小腿外侧，对方重心塌但未倒 | 低机位跟腿部轨迹，接触点必须清楚 |
| 肘击 | 贴身挤入时肘横切撞下颌/肋，对方肩颈猛缩、弓身 | 近景挤进两人身体间隙，禁止看不清接触点 |
| 膝撞 | 双手短暂控肩颈，膝上顶腹部，对方弯腰吸气 | 侧面中近景，保留双方上半身与膝部 |
| 抱摔 | 压低重心抱腰胯、步进前顶，对方背摔向地面 | 摄影机随身体下坠，落地短震后稳住 |
| 过肩摔 | 借臂过肩线，人翻肩落地 | 侧前方中景，落地后切地面仰拍 |
| 绊摔 | 一手控肩、一脚勾踝，推拉同时发力 | 中景保留脚部与上身，不只拍脸 |
| 关节锁 | 抓腕外旋、另一手压肘，对方身体被迫下沉 | 手腕特写接中景，动作克制不血腥 |
| 绞技 / 地面压制 | 背后锁肩颈；或上位膝压手臂控肩、下位扭身失败 | 肩后近景或俯拍近景，写清谁上位谁下位、四肢位置 |
| 缴械 | 扣住持械腕外拧，武器落地滑向画边 | 手部特写接武器落地，段末写死武器位置 |
| 闪避反打 | 攻击擦脸侧，下潜半步侧击肋部 | 手持快摇随闪避后立刻稳住 |

### 空间关系
- 先定**距离档**：贴身（肘膝/摔投）/ 拳击距离（直摆勾）/ 踢击距离（腿法）。一档距离内拳脚才够得着，不隔空挥。
- 左右侧与摄影机安全侧全程锁死：角色 A 始终画面左、B 始终画面右。
- 地面动作必须写明谁在上方、谁在下方、四肢与躯干朝向，避免"两人倒地后身份互换"。

### 30 秒组节奏骨架
- 一回合攻防：对峙 → 进攻起手 → 防守反应 → 接触点 → 反击 → 拉开喘息。
- 贴身缠斗：抢手 → 控肩颈 → 肘膝短打 → 摔投尝试 → 地面压制或分开。
- 被围（一对多，叠 30 号 §六）：主角后退 → 第一人出手 → 闪避反打 → 第二人补位 → 扫腿/脱身；同框精确交互始终只 1–2 人。
- 失误反转：先手落空 → 被抓腕 → 关节反制 → 重心/武器丢失 → 段末落点。

### AI 落地要点与常见崩法
- 最易崩：肢体穿模、关节反向折断、手脚多指、双方无接触空比划、**切镜后攻防重新演一遍**（守 30 号铁律：切角度动作不重新发生，用"顺势/承接/动作未停"串）。
- 摔投 / 锁技 / 地面缠斗是高崩区——拆成"起（中景）+ 接触（手腕/肩特写）+ 结果（落地/下位弓身）"，别要一个 5 秒镜头演完整过肩摔。
- 缴械后武器位置段末必须写死；下一镜不得桌上、手里同时出现两件同款。
- 伤害不直给：用后退、弯腰、捂肋、喘息、失衡表达。

## 二、武侠冷兵器与轻功（刀剑枪棍 · 暗器 · 身法 · 内力）

**适用边界**：刀/剑/枪/棍/鞭/软兵/匕首/袖里暗器、踏墙、屋顶追逐、兵器格挡、内力对掌。不适用现代地面缠斗、大规模军阵、纯异能轰炸。

**30 秒组容量**：5–8 个兵器攻防单元；拔剑前凝视、兵器试探、内力对掌这类仪式段可降为中速、给克制慢镜，但必须写清慢镜功能。

### 兵器招式因果速查

| 兵器 | 招式路径→接触点→受力结果 | 摄影机行为 |
|---|---|---|
| 剑 | 剑尖点喉前半寸，被对方剑脊横压偏开，剑锋擦冷光 | 长焦中近景，焦点跟剑尖滑到眼神 |
| 刀 | 刀自肩后斜劈落，对方横刀架住，刀背震得对方腕沉 | 低机位拍刀势，交击瞬间短震 |
| 枪 | 枪尖自远景直刺前景，对方侧身避，枪杆擦衣摆 | 长焦压缩空间，保留枪尖直线轨迹 |
| 棍 | 棍尾扫膝侧，对方跃起避，落地脚踩棍身 | 广角中景保留脚步与棍全长 |
| 鞭 / 软兵 | 鞭梢绕过前景柱抽向腕，对方用剑缠鞭身 | 横移跟弧线，禁止软兵形态乱变 |
| 匕首 | 袖中短刃贴身刺出，被扣腕停在衣襟前 | 近景手部到胸前距离必须清楚 |
| 袖 / 衣带 | 长袖卷剑柄短暂牵制，另一手反掌逼退 | 侧拍袖布运动，禁止变成无来源绳索 |
| 暗器 | 指间银针出手，目标偏头，暗器钉入身后木柱 | 出手可升格（慢镜），落点必须入画 |

### 轻功身法
每个腾空都要有**借力点 + 落点**：脚尖点断柱边缘斜跃、衣摆滞后一拍；一脚踏墙横向翻到对手背侧；屋顶掠过落到下一片瓦面、瓦轻震；贴地滑过刀锋下、掌撑地起身。身法残影只用短暂运动模糊表速度，**禁止复制出第二个实体主角**。

### 内力
必须有**来源**（掌心/剑身/脚下/呼吸/衣摆风压）+ **作用对象**（推退人/震开兵/掀尘土/压暗烛火）。特效克制，不要网游大招。例：两人掌心相抵，接触点一圈极淡气流、地面灰尘外推，摄影机从接触点轻后撤，露出两人脚步同滑半寸。

### 空间关系
兵器长度决定挥动空间——窄巷/室内限长枪大刀，让"空间小"成为被压制、换短兵的战术条件（叠 30 号冷兵器条）。屋顶追逐保持屋脊方向与高度连续。

### 30 秒组节奏骨架
- 兵器试探：起手礼 → 试探一击 → 格挡 → 兵器缠住 → 分开对视。
- 屋顶追逐：远景掠脊 → 脚尖落瓦 → 转向避箭 → 近身交击 → 跳落新空间。
- 暗器反转：藏器 → 对方未觉 → 出手 → 闪避或中环境 → 眼神确认。
- 内力对撞：蓄气 → 接触 → 气流扩散 → 双方后滑 → 一方压伤。

### AI 落地要点与常见崩法
- 最易崩：兵器忽大忽小、软硬属性混乱（剑变刀、枪变棍、软鞭变硬棍）；交击没有接触点（刀剑隔空相撞）；无来源漂浮（轻功不给借力点直接飞）；武侠特效做成现代科幻 UI / 网游技能图标 / 文字法阵。
- 长兵器轨迹 AI 最易乱向——单挑长兵 / 长枪阵都用长焦压缩把枪尖"压成一条线"，并在限制里写死枪尖方向。
- 慢镜只给交击 / 暗器落点一个点；衣摆、落叶、尘土是成本最低的东方动作质感，优先于光效。

## 三、超能力 / 异能动作（念力 · 瞬移 · 元素 · 护盾 · 重力 · 空间）

**适用边界**：念力、瞬移、护盾、火/冰/雷元素、重力、空间裂隙、能量束、召唤物、幻觉、能力失控/反制。不适用普通拳脚、纯冷兵器、大规模军阵。

**异能语法（比 30 号玄幻条更细）**：**能力来源 → 视觉形态 → 命中/作用对象 → 物理结果 → 角色反应/代价**。一组 30 秒只突出一种主效果。

### 能力因果速查

| 能力 | 来源→形态→作用对象→结果/代价 | 摄影机与边界 |
|---|---|---|
| 念力牵引 | 抬手，地面碎石先微颤再被拉向掌前悬停 | 只动指定物体，不随机飘无关物 |
| 念力压制 | 对方脚下尘土下陷、肩被无形压力压低半寸 | 写清身体受力，不凭空倒飞 |
| 瞬移 | 原地留短暂残影，下一帧出现在对手右后侧，衣摆方向连续 | 短残影+遮挡切/甩镜，不生成多实体、不改站位逻辑 |
| 护盾 | 掌前半透明弧面，箭撞上偏转落地 | 护盾有边界，不变全屏 UI |
| 火焰 | 火自掌心/地裂出，照亮手背脸侧 | 必须写光源影响，不无来源大火 |
| 冰霜 | 脚下霜纹沿石板蔓延到对方靴边，对方动作变慢 | 不瞬间冰封全场 |
| 雷电 | 指尖蓝白电弧跳到兵器，金属边缘短亮 | 电弧路径清楚，不满屏乱闪 |
| 重力 | 地面碎石下压碎，人膝微弯，镜头轻微下沉 | 写压迫范围与受影响者 |
| 空间裂隙 | 身后空气如玻璃错位、边缘吸尘埃 | 位置固定不乱切场景，不出现代 UI |
| 召唤物 | 光尘聚兽形轮廓，自角色身后半步成形 | 写清大小/位置/与角色关系 |
| 幻觉 | 角色眼神失焦、背景短暂错位再回现实对手逼近 | 必须有现实锚点，不全片变梦 |
| 反制 / 失控 | 护盾被刀锋切缝、能量沿缝熄灭；或掌心光忽明忽暗、碎石乱跳、呼吸失稳 | 写清被什么反制、结果；失控也不让物体无差别爆炸 |

### 摄影机行为
能力首现：先特写来源再拉到作用对象；能力对撞：从接触点特写后撤露出双方站位受力；瞬移/高速：用短残影、遮挡切、甩镜，绝不生成两个实体；大范围能力：先用广角建立影响范围，再切回角色代价/反应。

### 空间关系
能力必须有**作用边界与作用点**——护盾弧面挡到哪、霜纹蔓延到谁靴边、重力压到哪片地面；能力范围、颜色、来源跨镜连续。

### 30 秒组节奏骨架
- 异能首现：微异常 → 来源特写 → 能力成形 → 命中对象 → 对手反应。
- 能力对撞：双方起手 → 能量接触 → 环境受力 → 一方后退 → 段末悬念。
- 瞬移突袭：原地残影 → 对手慢半拍 → 新位置出现 → 近身命中或被反制。
- 能力失控：小范围异常 → 强压 → 环境扩大反应 → 敌我逼近。

### AI 落地要点与常见崩法
- 最易崩：无来源大爆炸、无关物体漫天乱飘、护盾变全屏光板/UI、随机满屏闪电、瞬移复制出好几个主角、**能力替代掉人的表演**。
- 红线：禁止现代科幻 UI、随机符号、文字法阵（除非用户明确要）；特效是动作结果的注解，不是主角——人仍要有眼神、手势、呼吸、体力代价。
- 大范围毁容级特效 AI 必假：把"炸一片"改成"碎石下压/尘土外推/烛火压暗"这种可读的局部物理结果。

## 四、战场群战与军阵（盾墙 · 长枪阵 · 骑兵 · 弓箭 · 攻城 · 撤退 · 指挥视角）

**适用边界**：军阵推进、盾墙、骑兵冲锋、弓箭齐射、长枪阵、伏击、攻城、撤退、指挥视角、烟尘遮挡。不适用两人精细格斗、屋顶轻功、纯异能斗法。

**战场空间语法**：**战场层次 → 主行动线 → 群体压力 → 关键接触点 → 战线结果 → 段末状态**。先分层再谈动作。

### 元素因果速查

| 元素 | 动作→关键接触点→战线结果 | 摄影机行为 |
|---|---|---|
| 盾墙推进 | 前排盾自画面右压入，中景长枪自盾缝探出，主角被迫后退 | 低机位广角，保留盾线方向 |
| 长枪阵 | 枪尖成斜线压向前景，第一支枪擦主角肩侧 | 长焦压缩枪尖密度，枪杆不乱向 |
| 骑兵冲锋 | 马蹄自远景烟尘逼近，前景士兵举盾下蹲 | 地面低角度，冲锋方向写死 |
| 弓箭齐射 | 远景弓手抬弓，箭雨自上斜落，中景盾接住第一波 | 先远景建立，再切盾的接触点 |
| 伏击 | 两侧高处旗影晃，箭自侧后射入队伍 | 镜头跟主角视线转向伏击方向 |
| 攻城 | 云梯靠城，守军推滚木，前景士兵散开 | 广角俯拍建立上下空间 |
| 撤退 | 指挥者后退挥手，前排交替掩护，伤者被拖离中景 | 手持侧跟，撤退方向一致 |
| 冲破阵线 | 主角自盾缝撞开一人，敌阵现短暂缺口 | 中景跟拍，段末写缺口位置 |
| 指挥视角 | 将领立高处，前景旗帜遮半幅，远景战线移动 | 长焦压缩，旗帜做前景锚点 |
| 烟尘遮挡 | 爆炸/马蹄扬尘短暂遮画，尘散后阵型已变 | 遮挡转场必写尘前/尘后两态 |

### 群体调度（前中远景三层）
前景 = 主角 / 关键敌 / 最近兵器接触点；中景 = 3–12 名士兵形成压力、不抢主角脸；远景 = 阵线 / 旗 / 骑兵 / 弓手 / 城 / 烟尘。群演必须有移动方向（自左向右压迫、自深处冲来、向城门撤退）。不需要真大军时用三层纵深造规模，**不写"万人"**。

### 空间关系
每镜写死敌我左右/前后与主行动线；战线方向不得在镜间反复跳变。

### 30 秒组节奏骨架
- 阵线压迫：远景建战线 → 盾墙压入 → 主角后退 → 找缺口 → 反冲。
- 骑兵冲击：烟尘现 → 马蹄近 → 前排举盾 → 接触 → 战线被撕开。
- 城墙攻防：云梯靠墙 → 守军反制 → 攻方坠落躲避 → 主角趁机上墙。
- 伏击突发：安静行军 → 侧后异动 → 第一波箭 → 队伍散开 → 主角判向。

### 声画
只写环境声与同步音效（兵器碰、盾闷响、马蹄、箭破空、远处号角、呼喊），不生成 BGM（铁律 26/32）；关键台词不被战场声盖住。

### AI 落地要点与常见崩法
- 最易崩：群演看镜头/抢主角脸/复制同脸；战线方向镜间乱跳；马、旗、弓、盾、枪数量与方向忽变；大场面没有主行动线、只剩宏观混乱。
- 人群规模是 AI 高危：同框清晰交战人数压到 1–2（主角侧），其余交给前中远景层次与虚化背景；别让一个镜头里 4 个以上清晰正脸混战。
- 伤亡用倒地、丢盾、后撤、被拖离表达，不过血腥。
