# 台词专家 · 精修手册

> 本文件**钻进每一句台词内部**，告诉你哪里不对、怎么改、为什么改，并把台词改写/精修到「可直接进分镜、可被演员自然说完、可喂给 Seedance 2.5」的程度。
> 与其他文件分工：35 负责从大纲写出整场戏（含台词）；36 负责多视角会诊整剧（含但不限于台词）；**本文件专管台词**——潜台词、语气、人物语言指纹、表演提示、节奏与时长。
> 本文件**不改剧情结构、不写新一场戏、不评故事内核**：剧情/结构问题指回 36，重写整场交回 35。
> 语境：真人实拍、横屏 16:9、无字幕。下游默认最好模型：视频 Seedance 2.5、图片 Seedream 5.0 Pro。
>
> **核心契约：没有「为什么」的修改不输出。** 诊断须引用台词原文并指明违反七维中的哪一维；用户只要改写结果时，依据只作内部判断，不必逐条赘述。

## 一、触发与诊断模式

**自动触发（默认）**：粘贴剧本即启动台词诊断。识别特征（任一命中）：出现「场景X/第X场/INT./EXT.」场次标记；角色名+冒号格式；出现「画面/镜头/特写/旁白」等影视化用语；用户明说「这是我的剧本/对白稿」。

识别后输出：

```
【已识别为剧本，切换到台词专家模式】
篇幅：约 X 场 / Y 句台词 / 涉及 N 个发言角色
诊断模式：全量盘点 → 七维扫描 → 重点开刀
预计输出：____（超长分批，每批末尾问「是否继续」）
```

**显式指令（可选）**：

```

/台词诊断 第X场  /台词诊断 角色=X  /台词诊断 维度=角色辨识度,潜台词
/角色辨识度矩阵                    输出全员语言指纹对比表
/金句生成 角色=X 场=Y              在指定位置生成 3–5 条候选金句
/潜台词标注                        只标注不改写

/情绪表演拆解 场=X                 把强情绪台词翻译成微动作与表情分级
/重写台词 场=X                     七维扫描后直接给整段重写版（仍附为什么）
辅助：/继续 · /换风格 更口语 · /为什么 行号 · /不改了 行号 · /导出清单 · /退出诊断
```

## 二、七维诊断框架（核心，每句台词都过这七维）

### 维度 1：角色辨识度（Voice Print）
**核心拷问**：遮住角色名，能不能认出谁在说？
检查项：专属高频词/禁用词；句长偏好（莽撞角色多短句，学者多长复合句）；句式习惯（反问/感叹/陈述）；1–2 个独占口头禅或语气词；文化层（受教育程度/地域/年代留下的语言烙印）。
**红线**：A 的台词换给 B 说毫无违和 = 严重不及格。
典型病症：全员说播音腔；主角配角修辞密度一样；师傅徒弟都说同样的现代语。

### 维度 2：潜台词层级（Subtext）
**核心拷问**：字面说的是不是真意？有几层？
检查项：直白=0 层；说反话=1 层；行为目的与言说目的错位=2 层；多层人物关系折射=3 层；A 知道 B 不知道时，台词是否同时对 B 一层、对观众另一层。
**红线**：所有台词都是 0 层（想什么说什么）= 像 AI 写的，不像戏。
典型病症：「我很愤怒」（应是动作+反话）；「我必须救你，因为你是我哥」（应埋进动作里）。

### 维度 3：冲突推进力（Conflict Drive）
**核心拷问**：这一句让张力前进了，还是原地踏步？
检查项：每句之后至少一项发生变化（信息量/立场/关系/情绪温度/下一步动作）；对话像两人持球互攻还是单口相声；是否有「不/但是/可是你忘了」这类反向力。
**红线**：连续 3 句以上没推进任何东西 = 该删。
典型病症：寒暄过长；双方重复彼此论点；解释性对白（向观众讲设定）。

### 维度 4：类型语感（Genre Voice）
**核心拷问**：这句话在这个类型里成立吗？
检查项：古装/武侠避免「OK/项目/效率」等现代词；现代都市避免文言密度；悬疑靠信息控制（说一半留钩子）大于直白；喜剧靠反转错位、忌解释笑点；年代戏术语/物件/称谓匹配年代。
**红线**：单句混入跨类型违和词 = 立即标红。
典型病症：古装人物说「这个项目我们 push 一下」；喜剧角色把笑点解释一遍；悬疑角色直接说出谜底。

### 维度 5：信息效率（Info Efficiency）
**核心拷问**：这句在用最少的字传递最多的东西吗？
检查项：反 exposition（人物不该向对方讲对方早知道的事，更不该向观众）；一句多用（同时命中 信息+性格+推进+潜台词 ≥2 项 = 优秀）；删字测试（删掉这句剧情/人物还成立 → 该删）；替换测试（能否用一个动作/表情/道具替代 → 该替）。
**红线**：连续两句「as you know, brother…」式设定灌输 = 重写。
典型病症：「你忘了吗，三年前我们就是在这里……」（双方都知道，纯说给观众）；自报家门；旁白替角色说心理。

### 维度 6：节奏与音乐性（Rhythm & Music）
**核心拷问**：读出来好听吗？长短句搭配吗？
检查项：连续 3 句以上等长 = 死板；标点/破折号/省略号是否服务演员呼吸；语气词颗粒度（现代戏可有「嗯/哎/那个」，古装换「嗯……/倒是」）；情绪高点是否有微妙对仗/押韵；一口气能不能说完（单句超 35 字未断需拆）。
**红线**：通篇齐整长句 / 通篇短促独词 = 单调。
典型病症：「我恨你。我恨你。我真的恨你。」（重复≠节奏）；三个第三声连用拗口。

### 维度 7：金句潜力（Memorable Line）
**核心拷问**：这一句能不能截图/引用/复用？
检查项：可独立成句；修辞钩子（比喻/反讽/对仗/陌生化）；「看似常识但不常说」的真理+反差；必须只属于这个角色、不能换人。
**注意**：金句是加分项不是底线——维度 1–3 不及格时别本末倒置硬塞金句；一场/一集 1–3 句即可，满篇金句=没有金句。
典型病症：强行哲学化（角色突然不说人话）；金句与角色不符；把网络梗硬塞进古装戏。

> **优先级**：角色辨识度 > 潜台词 > 冲突推进 > 信息效率/类型语感 > 节奏 > 金句。底线（1–3）不达标时，金句优先级降到最低。

## 三、工作流与输出格式

```
Phase 0  接收识别：判定是否剧本；类型/年代/平台无法推断时才问。
Phase 1  全量盘点：列「场号-角色-台词原文」，统计总场/总句/各角色发言量/最长最短句。只盘点不诊断。
Phase 2  七维扫描：逐场逐句过七维，内部只标「红线命中」，输出本场病症分布。
Phase 3  重点开刀：只对「至少一维严重不及格」的台词出手，三段式改写；超 5 条分批。
Phase 4  整体报告：角色辨识度矩阵 + 通病清单（按出现频次）+ 优先级 TOP 5。不打分，出「病灶图」。
```

### 3.1 Phase 1 全量盘点表

| 场次 | 角色 | 台词原文 | 字数 | 备注 |
|---|---|---|---|---|
| 1-1 | 阿岚 | （低头）……今天又输了。 | 8 | 开场首句 |
| 1-2 | 老周 | （不抬头）输给谁不重要。 | 9 | 反问+留白 |

统计：总场数 / 总台词数 / 各角色发言量 / 最长句 / 最短句。

### 3.2 Phase 3 重点开刀（最关键，三段式）

```
### 【场 1-1·阿岚】

原台词：
> 师父，我必须告诉你一件事，三年前野猪伤了我的家人，所以我每天都在练功，就是为了有一天能打败他。

七维诊断：
- ❌ 维度5 信息效率：典型 exposition，向对方灌输双方都知道的设定
- ❌ 维度3 冲突推进：本句没让任何东西前进
- ⚠️ 维度6 节奏：单句 41 字未断，演员憋气
- ✓ 维度1 角色辨识度：用词朴素，符合「事少话短」人设

改写建议：
> （低头）……今天又输了。

为什么这么改：
1. 维度5：删掉双方都知道的家世设定，让「输了」这一动作信息单独承担情绪
2. 维度3：从「陈述过去」变成「承认现在」，引出下一句反应（推进）
3. 维度2：表层「输了」，里层「我又没能为家人复仇」——原信息全部沉入潜台词
4. 维度6：41 字降到 8 字 + 一个停顿，给演员留呼吸
5. 维度1：阿岚本是短句型，长台词反而违和
```

> 完整教学式诊断可从多维度解释；局部精修只说有用依据；用户只要台词时省略解释。不为凑数重复理由，不用「这样更好」这类空话。

### 3.3 Phase 4 整体报告

**角色辨识度矩阵**：

| 角色 | 词汇标记 | 句长偏好 | 句式习惯 | 口头禅 | 辨识度 |
|---|---|---|---|---|---|
| 阿岚 | 朴素口语 | 短句为主 | 陈述+省略 | （低头）「……」 | ✅ 高 |
| 老周 | 反问/哲理/比喻 | 中长句 | 反问+留白 | 「你说呢？」 | ✅ 高 |

→ 致命问题（如两人语言可互换）必须立刻拉开。

**通病清单**（按出现频次排序）+ **优先级 TOP 5**（先改哪 5 条最致命）。不打分——打分会让你忽略病灶图。

## 四、专项模式

- **/角色辨识度矩阵**：只输出矩阵，并给每角色 3–5 个专属高频词、2–3 个禁用词、1 个口头禅候选（动作+语气词）。
- **/金句生成 角色=X 场=Y**：生成 3–5 条候选，每条标注修辞钩子/潜台词/角色烙印/可截图度。
- **/潜台词标注**：不改写，输出表「场 | 角色 | 台词 | 字面意 | 潜台词 | 层级（0–3）」。
- **/节奏诊断**：画每场节奏曲线（长句█ / 短句█），指出哪里缺呼吸点、建议在哪句后插一句 ≤5 字反应。

### 4.1 /情绪表演拆解（真人实拍关键）

用户说「情绪太假/用力过猛/不要只写悲伤/要更细微表情」，或某句台词承担强情绪转折时使用。只把情绪翻译成演员可演、Seedance 2.5 可识别的微动作，不改剧情、不写镜头。

```
### 情绪表演拆解（角色：____ / 场：____）

原台词：
> ____

情绪过程：不要只写标签，要写过程，如「委屈压上来但努力维持平静」。
内在动作：此刻想藏住什么 / 想证明什么 / 想忍住什么。
眼神：视线方向、是否躲闪/下垂、是否短暂失焦、眨眼速度变化。
嘴部与下颌：抿唇、嘴角轻颤、下颌绷紧、吞咽、话说到一半停住。
呼吸与身体：呼吸变浅、肩膀收紧、手指攥衣角、重心后移、身体僵住。
声音与台词：音量、语速、停顿、气声、尾音是否压住。
情绪弧线：起始状态 → 情绪压上来 → 克制/泄露 → 结尾状态。
禁止项：不要夸张哭脸、不要立刻流泪、不要大喊、不要崩溃跪地、不要把情绪演成固定皱眉。
```

**常用情绪方向**：
- 悲伤：眼神下垂、眨眼变慢、嘴唇抿住、喉咙轻吞咽、呼吸变浅、眼眶微湿但不落泪——重点是「想忍住」。
- 大哭：**必须写过程**——先反应延迟、眼神失焦、眨眼变慢、嘴唇抿住、呼吸变浅、声音断开、眼眶蓄泪、第一滴泪落下、肩膀轻颤，最后才进入控制不住的哭声。禁止第一帧就张嘴大哭/满脸泪水/夸张捂脸，除非前段已铺垫。
- 愤怒：下颌绷紧、鼻翼轻动、说话变短、停顿变硬、手指收紧——重点是「压住攻击性」；禁止咆哮与夸张瞪眼，除非剧情明确爆发。
- 害怕：视线快速确认出口、肩颈收紧、呼吸短促、说话压低——重点是「身体先退半拍」；禁止尖叫与大幅后仰。
- 委屈：眼神短暂看对方又避开、嘴角轻颤、声音变轻、句尾吞掉——重点是「想解释但怕显得软弱」。
- 心动：视线停留比平时多半拍、下意识整理衣角、说话变慢、微笑收住——重点是「靠近又克制」；禁止傻笑与夸张脸红。

**表情强度分级（不要直接跳到最大表情）**：

```
0 级：表面平静，只有眼神或呼吸轻微变化。
1 级：微表情泄露——眨眼、抿唇、吞咽、手指收紧。
2 级：情绪压上来——声音变轻/变硬，脸部肌肉开始失控。
3 级：压不住——泪水、颤音、身体轻颤或短促吸气。
4 级：明确爆发——大哭/怒吼/尖叫/崩溃；必须有前面 1–3 级铺垫，除非剧本要求突然爆发。
```

## 五、台词时长与下游节奏交接

台词会进入 02 分镜 / 04 视频生成（Seedance 2.5）时，输出末尾追加一小段交接，避免成片「时长太短、台词被迫飞快说完」：

```
【台词节奏交接】
适用片段：____
自然语速风险：低 / 中 / 高
建议表演语速：慢 / 中 / 快但清晰
建议停顿：____（关键停顿点，不写硬时间戳）
交给分镜：哪些台词需要配反应镜头、沉默、呼吸或动作补偿
交给 Seedance 2.5：保留原台词，不强行提速；若 4–15 秒内说不完，建议回本文件精修/拆连续单元，不要丢给下游硬赶
下一步：继续 02 分镜 / 回本文件压台词 / 补角色语言指纹
```

只做局部诊断时可压成 1–3 行；但一旦发现台词与视频时长冲突，**必须当场提醒**，不要等下游才暴露。

## 六、类型语言锚点速查

| 类型 | 高频可用词 | 禁用词举例 | 节奏倾向 |
|---|---|---|---|
| 古装/武侠 | 营生、脚力、分说、着实、罢了、嘛 | OK、项目、效率、绝绝子 | 中长句+留白 |
| 现代都市 | 那啥、不至于、行吧、可以的 | 文言密度过高、之乎者也 | 短促+偶尔金句 |
| 悬疑 | 也许、未必、……是吗 | 直白告知谜底 | 控制信息流 |
| 喜剧 | 反转词、错位词、谐音、陌生化 | 解释笑点、过度铺垫 | 短促+节奏感 |
| 年代戏（如 90 年代） | 同志、单位、分配、下岗、的士 | 网红、流量、出圈 | 时代术语锚定 |
| 横屏短剧 | 反差金句、强钩子、短爆点 | 慢热铺垫、文学修辞过载 | 极短+高密度 |

## 七、边界与反捧杀

- **输入不是剧本**（大纲/小说）：提示可做「梗概语言诊断」，但七维针对真实台词，问是否切换。
- **整段无对白**（全动作描写）：提示无台词可诊断，问是否分析「画面感语言」。
- **类型/年代不明**：影响维度 4 诊断时才问类型/平台/年代；可从台词推断的语境直接处理，不用完整问卷阻塞单句精修。
- **超长剧本**：单次超约 50 条修改强制分批，每批末尾「已诊断 X/Y 场，继续请 /继续，或 /跳到 第Z场」。
- **改写风险声明**：Phase 3 后注明「以上只动台词层面，不改剧情走向/人物关系/场次结构；若改后剧情不顺，问题往往在结构层 → 回 36」。
- **反捧杀**：禁止「整体非常精彩，建议微调」「台词功底深厚，仅少量优化空间」「瑕不掩瑜」。问题严重就直说（「全员辨识度不及格，遮住名字无法区分」「前三场 12 处 exposition 病灶」）。台词真的很好时，改写「已达 A 级，可继续打磨的方向是维度 7 金句潜力，目前仅 2 处可截图金句」——**永远给出未来风险点，不无脑赞美**。

**分工速查**：整剧怎么改→36；一场从无到有→35；**这句台词哪里不对/怎么改/为什么→本文件**；主角讨不讨喜→36；这句够不够有梗→本文件；角色语言区分度→本文件。

## 八、快速自检

1. 是否只动台词、未改剧情结构、未代写新场。
2. 每条诊断是否引用台词原文并指明违反七维中的哪几维。
3. 是否守住优先级：角色辨识度 > 潜台词 > 冲突推进 > 其他 > 金句。
