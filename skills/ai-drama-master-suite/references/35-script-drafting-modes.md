# 剧本双写作模式与节奏档位手册（M1 / M2 + 节奏矩阵）

> 本文件是 01-script-creation.md 的下游写作层。01 号管赛道、结构原型、四幕/五阶段、横屏真人短剧总纲与正式分场格式；本文件只管两件事：
> ① 同一份大纲用**哪一种写作模式**落地（M1 标准影视剧本 / M2 小说化叙事剧本，外加一个正交的「分集开关」）；
> ② 这一段戏/这一集该落在**哪一个节奏档位**（电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏但高信息）。
>
> 语境：真人实拍向、横屏 16:9、全片无字幕（沿用 01 号 1.2.4）。下游默认最好模型：**视频 Seedance 2.5、图片 Seedream 5.0 Pro**，不另行询问。
> 与其他文件分工：从 0 到大纲找 01；多视角会诊找 36；台词逐句精修找 37；本文件负责「把大纲写成完整剧本/单集/单场」。

## 一、两个正交维度：写作模式 × 分集开关

最终输出不是三选一，而是两个独立维度相乘：

```
最终剧本 = 写作模式（M1 或 M2，必选其一）  ×  分集开关（是 或 否）

  M1 + 分集=否 → 单部标准影视剧本（单条横屏短片 / 微电影）
  M1 + 分集=是 → 多集标准影视剧本（横屏短剧系列 / 连续剧 / 单元剧集）
  M2 + 分集=否 → 单部小说化叙事剧本（供 Seedance 2.5 分段生成的文学化短片）
  M2 + 分集=是 → 多集小说化叙事剧本（文学性强的系列短片）
```

- **写作模式**决定「单场/单段长什么样」。
- **分集开关**不是第三种模式，而是叠加在 M1/M2 之上的**包装层**（集首钩子、单集三幕、集尾钩子）。不要把「分集」当成一种写作风格。

### 1.1 M1 标准影视剧本

行业通用格式，可直接交真人拍摄团队，也可平滑拆进分镜（02-storyboard-design）。

核心要素：
1. **场景头**：场次 + 日/夜 + 内/外 + 地点；重要节拍在括号标注功能，如 `场景 18  夜.外  阿岚家门口（触发事件）`。
2. **动作行**：第三人称、现在时、只写**镜头能拍到的**，一场不超过 1 页（约 250–300 字中文）。
3. **角色名 + 对白**：角色名单独成行，对白紧跟其下；表演提示用括号、尽量短。
4. **过场提示**：CUT TO / FADE OUT / DISSOLVE TO，偶尔用。

输出格式（严格）：

```
═══════════════════════════════════════════
   《项目名》  第 X 集 「集名（可选）」
═══════════════════════════════════════════

FADE IN:

场景 1  日.外  天台

   阿岚（16）背对镜头远眺，风掀起他风衣下摆。
   远处城市天际线一片赤红。

                    阿岚
              （画外音）
              那年我十六，第一次相信末日是真的。

   教堂钟响三声。阿岚转身，眼神定住。

CUT TO:

场景 2  日.内  卧室
   ……

FADE OUT.
```

严格规则：
- 动作行不写纯心理活动（把「她内心矛盾」改写成「她攥紧又松开的手」）。
- 场景头不出现「突然」「忽然」这类小说化词。
- 对白前可标（CONT'D 续接）/（O.S. 画外音）/（V.O. 旁白）。
- 不写导演意图，只写画面。

M1 的短板：内心活动、环境氛围受限。需要文学性/情绪铺陈时用 M2。

### 1.2 M2 小说化叙事剧本

带感官描写的叙事段落 + 嵌入对白，画面感与情绪并重。最适合喂给 **Seedance 2.5** 分段生成，或做 IP 衍生小说底稿。

核心要素：环境感官（视/听/触/嗅）、可直接写主角内心、连贯动作流、对白嵌入叙述用引号、每段 3–6 句。

输出格式：

```
═══════════════════════════════════════════
   《项目名》  第 X 集 / 完整版
═══════════════════════════════════════════

【场景一  天台】

黄昏最后一道光斜切过废弃工厂的天台。十六岁的阿岚站在
边缘，风衣被风掀起，他没回头，只望着那道赤红的天际线
——像一条没愈合的伤口。

"那年我十六，"他在心里说，"第一次相信末日是真的。"

教堂三声钟响穿过雾霾，落在他指尖。他的手指几不可察地一颤。

【场景二  卧室】
   ……

【完整版结束】
```

严格规则：
- 每段不超过 6 句；对白前后必须留「小动作」或「环境反应」，**禁止对白成串**。
- 心理描写占比 ≤ 30%，其余给画面；多用感官词，少用抽象形容词。
- 一场戏 300–800 字，按节奏档位伸缩。

M2 的短板：团队执行性弱（演员看不到走位/灯光位）；节奏天然偏慢，**不能强压进短视频高密度**。

### 1.3 分集开关（包装层）

| 作品类型 | 分集开关默认 |
|---|---|
| 单部（横屏短片 / 微电影 / 单本） | **否** |
| 连续（横屏短剧系列 / 连续剧 / 单元剧集） | **是** |
| 用户显式覆盖 | 以用户输入为准 |

启用后，单集输出在 M1/M2 主体上叠加：

```
【前情提要】（可选，仅当与前集强关联，一两句服务本集理解）
【集首钩子】（必有，开场即抓住：按所选节奏的前 X 秒法则设计）
   [M1 或 M2 主体，按 建置约25% → 对抗约50% → 解决约20% 分布]
【集尾钩子】（必有：悬念 / 反转 / 情感留白，牵引下一集）
【下集预告】（可选）
```

严格规则：写哪一集必须先定；单集独立完整（新观众进来也能看懂）；集与集人物状态必须连贯（第 3 集受伤，第 4 集开头不能完好如初）；5 集以上先写第 1 集确认风格再批量。

## 二、节奏档位四档（核心吸收）

> 横屏、竖屏、21:9 都只是画幅，不自动等于快或慢。**节奏由发布平台、目标时长、内容类型、完播目标共同决定。**
> 核心原则：**不是所有东西都变快，而是让「慢」有价值。**

每个项目必须先记下节奏档位，并一路传给 36 会诊、02 分镜、04 视频生成。用户未指定时由 AI 自动判定，用户可只改某一段的档位。

| 节奏档位 | 使用时机 | 写作提醒 |
|---|---|---|
| **电影感中速** | 情绪交锋、仪式感、悬疑凝视、单镜调度 | 慢镜头必须承担信息/情绪/关系变化，不许空转 |
| **短视频中高密度** | 默认横屏短剧、平台短片 | 每段要有可见动作、信息增量或反应点 |
| **高密度动作或强钩子** | 前 3 秒/前 15 秒钩子、追逐、爆点、强反转 | 用动作链和短反应推进，不写空泛铺垫 |
| **慢节奏但高信息** | 用户指定，或命中强情绪压迫、重要台词、单镜调度白名单 | 必须写清「慢」的功能，避免下游误判拖沓 |

### 2.1 平台时长层级

| 时长层级 | 节奏要求 | 写作策略 |
|---|---|---|
| 15–30 秒极短 | 0–3 秒直接给钩子，7 秒内给反差，结尾留互动 | 不写完整三幕，只写动作链 + 爆点 |
| 30–90 秒短 | 每 10–15 秒一个新信息/情绪点 | 场景极少，动作与台词都压缩 |
| 90 秒–3 分钟横屏短剧 | 前 5 秒强钩子，每 15–20 秒推进 | 可有小三幕，不允许空转铺垫 |
| 3–10 分钟平台微电影 | 可有电影呼吸，但前 15 秒必须给留人理由 | 慢镜头集中放在情绪峰值前后 |
| 10–30 分钟微电影 | 允许更完整铺陈，但每 30–60 秒要有效推进 | 主题留白保留，重复信息压缩 |

> 注：本主控为横屏 16:9。源材料中「左上角标题字幕留人」属竖屏短视频打法，与 01 号「横屏无字幕」冲突，**一律不采用**——前 3 秒留人只靠画面/动作/对白，不靠字幕卡。

### 2.2 呼吸镜头合法条件

慢镜头、空镜、沉默、长停顿、静止画面，只有满足下列至少一项才保留：

1. **情绪变化**：角色从一种状态进入另一种状态。
2. **悬念加深**：观众产生「为什么会这样」的追问。
3. **人物关系变化**：视线、距离、称呼、肢体反应发生改变。
4. **关键信息释放**：画面里出现必须被看见的道具/环境线索。
5. **视觉记忆点**：可做封面、标题、切片传播的画面。
6. **动作蓄力**：为下一次爆发/反转/决定做准备。

无功能的慢段落默认压缩、合并，或改写成「带信息的动作」。

### 2.3 节奏红线（出现即改）

- 开场 3 秒内只有风景、天气、慢走、背影、环境铺垫，且没有悬念或反差。
- 连续两场重复同一情绪，没有新信息。
- 角色长对白解释设定，却没有动作或关系变化。
- 为了「电影感」写长空镜，观众不知道该看什么。
- 平台微电影结尾有留白，但没有情绪回响、主题回扣或讨论点。

## 三、六种作品节奏参考（已适配横屏真人）

> 下表是「选节奏档位时的参照」，不是硬时间锁。01 号的四幕/五阶段负责结构，本节负责**密度与时间法则**。

### R1 横屏短剧节奏（系列短片，单条约 90 秒–3 分钟）

```
0:00-0:05   开场必有视觉刺激或矛盾爆发，不允许铺垫
0:05-0:30   第一次冲突 / 反转
0:30-1:30   核心矛盾连续推进
1:30-2:30   爽点 / 虐点 / 反杀
2:30-3:00   集尾强钩子（悬念 / 误会 / 反转）
```

写作要点：强人设先行（第 5 秒内立住主角）；每 15–20 秒一个钩子；对白短促、信息密度高；场景切换快；集尾必留钩子。
禁忌：文学化环境描写、慢热开场、配角戏份压过主角、为深刻而深刻。
适配模式：**M1 首选**（M2 会拖慢节奏）；分集=是。

### R2 连续剧节奏（单集 30–50 分钟，主副线交织）

A 线主线 + B 线副线；人物弧光渐进；对白可推敲；高潮戏后接文戏调剂；每集埋 2–3 个未完成线索；集尾钩子多样化（不只悬念）。
禁忌：主角光环过强、单集不收尾、信息密度过高、配角工具人化。
适配模式：M1 首选，文艺年代剧可用 M2；分集=是。

### R3 短视频节奏（单条 15 秒–3 分钟，强留人）

**3-7-30 法则**：0–3 秒强视觉/听觉钩子；3–7 秒抛第一次悬念/矛盾/反差；7–30 秒第一次反转或爆点；之后每 15 秒一个信息点；最后 5 秒留互动钩子。
写作要点：0–3 秒视觉锚点（撞色/冲突姿态/表情特写）；不超过 1–3 个核心信息；踩点剪辑。
禁忌：慢热开场、长对白、一镜到底（除非本身就是创意点）、文学化结尾。
适配模式：**M1 简化版**（场景头精简、对白极短）；M2 不推荐；分集=否。

### R4 单元剧节奏（单集独立故事 + 整体世界观）

每集开端–冲突–高潮–收尾完整；主角性格稳定（靠「招牌」吸观众）；单元任务 + 主角微小成长双线；整体调性统一；3–5 集留一次主线钩子；客串角色必须立得住；故意每隔几集打破程式化防疲劳。
禁忌：把单元剧装上强主线、主角性格剧变、每集套路完全一样。
适配模式：M1/M2 均可；分集默认按多集=是 / 单集=否。

### R5 微电影节奏（5–30 分钟，主题先行）

比例严格：第一幕约 25% + 第二幕约 50% + 第三幕约 25%；主题先行（一句话能说清想说什么）；对白精炼（能用画面不用对白）；视觉象征/重复意象首尾呼应；结尾留白不给标准答案。
平台微电影加速开场：发到短视频平台时，前 15 秒必须给冲突/谜题/反差/强情绪，不要把主题伏笔全压在无信息空镜里。
禁忌：主题不清、用对白说主题、开场过慢、强行 happy ending、视觉无亮点。
适配模式：M2 极佳（文学性恰好需要叙事感），M1 亦可；分集=否。

### R6 长篇电影节奏（45–180 分钟，三幕）

按节拍系统踩点（建置 → 触发事件 → 进入第二幕 → 中点 → 坏蛋逼近 → 一切都失去 → 黑暗时刻 → 进入第三幕 → 终极对决 → 收尾镜头与开场呼应）；主角弧光闭环；副线服务主线；show, don't tell；主题不直接说。
禁忌：节拍混乱、弧光不闭环、副线游离、主题直白、第三幕仓促、反派单薄。
适配模式：M1 院线首选；M2 适合作者电影/Seedance 分段生成；分集=否。

## 四、模式 × 节奏 × 分集 推荐组合矩阵

| | M1 标准影视 | M2 小说化叙事 | 分集开关默认 |
|---|---|---|---|
| R1 横屏短剧 | ✅ 推荐 | ⚠️ 不推荐 | 是 |
| R2 连续剧 | ✅ 推荐 | ✅ 文艺剧适配 | 是 |
| R3 短视频 | ✅ 简化版推荐 | ⚠️ 不推荐 | 否 |
| R4 单元剧 | ✅ 推荐 | ✅ 文学单元推荐 | 是（多集）/ 否（单集） |
| R5 微电影 | ✅ 真人微电影 | ✅✅ 极佳 | 否 |
| R6 长篇电影 | ✅ 院线首选 | ✅ 文艺/Seedance 生成 | 否 |

常见组合参考量级：
- M1+R1（横屏短剧系列）：单集约 800–1500 字，场景密、对白短、人设强。
- M1+R2（连续剧）：单集约 12000–18000 字。
- M2+R5（Seedance 生成微电影）：约 3000–6000 字，文学性强、画面感强、留白结尾。
- M1+R6（长篇电影）：约 30000–40000 字，节拍严谨。

不推荐组合及替代：
- M2+R1 / M2+R3：小说化叙述天然偏慢，会割裂强节奏 → 改用 M1（必要时在动作行加少量画面感词）。
- 分集=是 + R5/R6：单部强加集首/集尾钩子会破坏完整性 → 保持分集=否；确需拆「章节」时，用户显式 `分集=是` 则提示风险后执行。

## 五、写作入口与触发

### 5.1 启动触发（等价识别，忽略大小写与空格）

```
开始写作                                   → 引导式，逐步选模式+节奏+分集
开始写作 模式=标准 节奏=横屏短剧 分集=是    → 直达式
#小说化 #微电影                            → 快捷直达
继续写下一场 / 继续写第 X 集               → 续写
/模式 小说化  ·  /节奏 微电影  ·  /分集 是  → 写作中切换
/重写第X场  ·  /重写第X集  ·  /扩写 第X场
/减字 第X场 [目标字数]  ·  /对白调优 第X场
/节拍检查  ·  批量模式
```

模式等价词：标准/标准影视/行业标准 → M1；小说化/文学化叙事 → M2。
节奏等价词：横屏短剧/短剧、连续剧/网剧、短视频/平台短片、单元剧、微电影/短片、长篇电影/长片。

### 5.2 生成前配置检查（只在缺关键信息时问询）

正式动笔前内部核对，已明确的直接写，不弹确认菜单：

```
即将开始写作，配置如下：
  模式：M1 标准 / M2 小说化
  节奏：R1–R6
  节奏档位：电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏但高信息
  分集开关：是 / 否
  作品类型：单部 / 连续（共 N 集）
  集数：第 X 集 / 第 X-Y 集 / 全部（分集=是 时必填）
  输出规模预估：约 ____ 字 / ____ 场
  前 3 秒任务：____
  呼吸感许可：____
  禁止拖慢点：____
```

连续剧集用户未指定写哪集时，建议先写 1–3 集试稿确认风格再批量。

### 5.3 九步工作流

```
1  项目档案/大纲就位（缺硬需即停并要求补；缺软需提示后用默认继续）
2  校验前置（项目元信息、人物档案≥2、剧情主线/大纲为硬需）
3  解析触发指令 → 定模式 + 节奏 + 分集开关
4  非推荐组合 → 提示「该组合不常见，确认继续？」
5  生成前配置检查（缺集数/核心人物才问）
6  用户确认 / 补全
7  正式输出：严格按模式格式 + 节奏时间法则 + （分集=是 时）集序结构
8  末尾附【创作笔记】与【剧本说明】
9  进入修改循环：用户反馈 → 保留未改部分局部改 → 满意再推进
```

### 5.4 长内容分批协议

总字数预估 ≥ 8000 字主动分批，单次不超过约 8000 字：

| 内容类型 | 分批策略 |
|---|---|
| 单部长片（M1/M2+R6） | 按幕分 4 批：建置 / 对抗前段 / 对抗后段+黑暗时刻 / 第三幕+收尾 |
| 单部中片（M2+R5，3000–6000 字） | 一般不分批，超出按「幕」分 2 批 |
| 单集长内容（M1+R2） | 分 2 批：前半（建置+第二幕前段）/ 后半（第二幕后段+第三幕+集尾） |
| 多集批量（短剧/单元剧） | 每集 1 批；3 集为一个暂停回合 |

分批中途用户提反馈：**先暂停后续批次**，问「先处理这条反馈再继续 / 先把剩余批次出完最后统一改」，由用户选；禁止边输出边说「最后统一处理」。
`批量模式`：批与批之间不再等「继续」，但仍按字数分批；用户随时可「停」中断。

## 六、输出硬规则、创作笔记与剧本说明

### 6.1 输出硬规则

1. 严格按选定模式写，不混格式（别在 M1 动作行里写纯心理，别在 M2 里堆对白成串）。
2. 标准/完整项目按需附【创作笔记】；用户只要正文时省略。
3. 不捏造档案没有的人物/招式/场景；缺失标【待用户确认】。
4. 写出的对白与动作必须符合人物「性格三层」；档案缺该字段时按 6.3 降级处理。
5. 与档案/大纲冲突或指令模糊时，停下追问，不假装理解硬写。
6. 横屏无字幕：分镜提示词不写屏幕文字（时空跳转黑底白字卡除外）。
7. 完整剧本输出后追加简短剧本说明（见 6.3）。

### 6.2 【创作笔记】（每次完整输出末尾）

```
- 取舍：为什么这样写而非那样

```

## 七、边界与切换

- **写作中途改模式/节奏**：先警告「前后格式/节奏割裂风险」，问「是否把已写部分按新模式重写？」，用户确认才继续。例：长篇电影中途想改微电影，已写 5 万字需压到 3–5 千字——提示后由用户选「重写已有部分」或「仅后续按新节奏（可能前后割裂）」。
- **用户改大纲与档案冲突**：列出原大纲 vs 新改，给「仅本次临时用新大纲 / 回 01 更新档案后继续」两选。
- **超规模输出**（如一次写 100 集）：主动保护——先写 1–3 集试稿，确认风格后每次 5–10 集，全部写完再走一次会诊。
- **要求违反人设硬约束**（档案写「沉稳」却要「歇斯底里」）：判断是「阴影层爆发（合理）」还是「档案设定不准（建议回 01 改档案）」，交用户定。
- **档案缺「性格三层」**：明示「OOC 检测退化为轻量版，准确度下降，建议回 01 补全」，用户坚持则带风险继续。
- **场/集层级不匹配**（单部微电影却输入 `/重写第3集`）：提示未启用分集，引导 `/重写第3场` 或 `分集=是`。
- **不捧杀**：创作笔记里不许出现「这版我自己也很满意 / 几乎没得改 / 完美贴合」；必须写出至少 1 个真实弱点。

## 八、快速自检（输出前过一遍）

1. 是否已读 01 的赛道/结构，并明确本文件只管模式与节奏档位。
2. 模式（M1/M2）、节奏（R1–R6）、分集开关是否三者都已定。
3. 是否已记节奏档位，并标注前 3 秒任务、呼吸镜头功能、禁止拖慢点。
4. 是否按 M1/M2 正确格式输出、未混格式。
5. 分集=是 时是否有集首钩子、三幕、集尾钩子，且人物跨集连贯。
6. 慢镜头/空镜/沉默是否都满足 2.2 至少一项功能。
7. 是否横屏无字幕、未用竖屏字幕卡打法。
8. 长内容是否分批，用户反馈时是否暂停后续批次。
9. 是否未捏造档案外人物/场景/招式。
10. 完整输出是否附【创作笔记】+【剧本说明】并指出至少 1 个真实弱点。
