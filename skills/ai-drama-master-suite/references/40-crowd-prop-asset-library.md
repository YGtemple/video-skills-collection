## 一、为什么需要这一层（常见翻车现场）

没有这层时，公共空间戏最容易翻车：

- 街口/商场/餐厅戏，模型把整条街生成得空无一人，像鬼城，生活感全失。
- 想加路人，结果路人齐刷刷看镜头、围一圈盯主角、同一张脸复制五六个、所有人穿同款衣服同方向走。
- 路人偶尔挡住主角的关键表情或关键道具，把反转点遮没了。
- 桌上一个手机、手里又出现一个同款手机、背景桌面上还冒出第三个——道具被模型"复制"。
- 手机/照片/信件这类小道具，模型自动把信息面怼向镜头，露出乱码屏幕或错误 UI。
- 角色拿起桌上手机后，桌上还留着一部手机。

本文件就是把"群演调度"和"小道具防复制"在分镜前提前钉死。

## 二、群众演员（群演/路人）调度建档

### 2.1 什么是群演调度卡

群演**不是人物资产，也不生成进场景图片**。它是一张**文字调度卡**，用来决定：某个公共场景在某个故事时段，画面里该不该有人、大概多少人、分几层景深、怎么走、能不能挡主角。

**核心原则：场景母版永远空场，群演只在视频提示词里动态写。**

### 2.2 什么时候需要群演卡、什么时候禁止额外人物

| 场景类型 | 群演处理 |
|---|---|
| 公共空间：街道、商场、餐厅营业时段、车站、学校走廊、医院大厅、菜市场、演唱会/活动现场 | **需要建群演卡**，把人群密度、层次、移动、遮挡规则写进视频提示词。 |
| 私密空间：卧室、客厅独处、审讯室、密谈包间、车里两人独处 | **默认禁止额外人物**。视频提示词限制里必须写"不允许出现额外人物、路人、群演"，防止模型自己往背景里塞人。 |
| 剧本明确写了第三人/服务员/护士/路人甲 | 按具名配角处理，归 script-asset-master 建档；不按"群演密度"处理。 |

### 2.3 密度等级（人数控制，铁律）

| 密度等级 | 人数 | 适用 | 写法 |
|---|---|---|---|
| 空场 | 0 人 | 剧本要求"空无一人"的公共空间、情绪独处 | 限制里写禁止额外人物 |
| 稀疏 | 1–3 人 | 远处零星经过，几乎不影响主角 | 写"远景零星 1–3 人经过" |
| 日常 | 4–10 人 | 生活感，前景或中景少量路人 | 写清前/中景分布 |
| 繁忙 | 10–30 人 | 前中远景都有行人，方向交错 | 写清各层人数，主角脸和动作仍要清楚 |
| 高峰拥挤 | 30 人以上 | 只用于街口、车站、商场高峰等明确场景 | 远景人头攒动，前景擦肩经过 |

**人数控制红线**：
- 横屏 16:9 真人实拍里，群演是"背景真实感"，不是"主角团"。**主角的脸、关键表情、关键道具必须始终清晰**，群演不得把主角淹没。
- 繁忙/高峰档要写清"主角脸部和动作仍清楚"，否则模型会把人群堆到主角脸上。
- 不要无限制堆人——密度够出生活感即可，人太多反而出戏、出脸崩。

### 2.4 景深层次分布（写进视频提示词的标准结构）

群演必须按**前景 / 中景 / 远景**三层写，不能只写"街上有很多人"：

```text
人群密度：
- 前景：X–Y 名路人，从镜头边缘擦肩经过，轻微虚化；
- 中景：X–Y 名行人，与主角同向/反向/横向移动，保持安全距离；
- 远景：X 人以上，人头攒动/排队/等车/进出店门等背景行为。
```

### 2.5 群演类型与行为

- **年龄身份**：按场景写——白领、学生、老人、游客、店员、快递员、家长带小孩等；符合地点、季节、城市、阶层。
- **服装**：**不要所有人同款衣服、同色、同方向、同动作**。要写"服装、年龄、体态自然分散"。
- **行为**：走路、买东西、看手机、等车、交谈、撑伞、提购物袋——自然多样。

### 2.6 移动与遮挡规则（群演不抢戏）

```text
移动方向：同向 / 反向 / 横穿 / 进店 / 出店 / 排队慢行（按场景选）
速度：慢行 / 正常步速 / 急行 / 停留
遮挡：可短暂擦过身体边缘，不得遮挡主角脸部、关键表情、关键道具、动作标点
与主角关系：无互动 / 擦肩而过 / 被动让路；禁止围观、禁止集体看镜头
```

**群演禁止项（视频提示词硬限制）**：
- 不要空街、不要空商场、不要只有主角孤零零站在公共空间（除非本档就是空场）。
- 不要复制粘贴同脸路人，不要所有路人同服装、同动作、同方向。
- 不要让路人看镜头、围观主角、抢镜。
- 不要挡主角的脸、关键表情、关键动作、关键道具。
- 不要新增与剧情无关的主要角色。

### 2.7 群演的声音层级

群演相关只写**环境声**，不写配乐：

```text
环境声：人群低声嘈杂、脚步声、远处车流/店铺声；强度弱到中，不得盖过主角台词。
```

有台词的段落，环境声必须压在台词之下（音量层级：台词 > 动作音效 ≈ 环境声）。

### 2.8 群演调度卡模板

```markdown
【群演调度卡：CR01_场景名_人群】

绑定场景：SC____（15号场景锚定卡）
适用时段：白天 / 黄昏 / 夜晚 / 高峰 / 深夜
适用分镜组：G__–G__
剧情作用：只做环境真实感 / 制造空间压迫 / 制造遮挡调度（选一项）
密度等级：日常（4–10 人）
景深层次：
  前景：X–Y 人，擦肩经过、轻微虚化
  中景：X–Y 人，同向/反向交错移动
  远景：X 人以上，背景行为
人群类型：白领/学生/老人/游客/店员/……（自然分散，不同脸不同装）
移动与遮挡：[方向/速度；可擦肩、不挡脸、不围观、不看镜头]
环境声：[人群嘈杂/脚步/车流，弱-中，不盖台词]
禁止项：空街 / 同脸复制 / 看镜头围观 / 挡主角脸与道具 / 新增主要角色
```

## 三、小道具与环境道具建档

### 3.1 道具的两类区分

| 类型 | 定义 | 处理 |
|---|---|---|
| **固定陈设道具** | 场景里本来就摆着、不参与剧情动作的：墙上挂钟、柜台收银机、吧台上的酒瓶、货架、不可移动灯具 | 只放进场景母版/空镜参考，**不单独出道具图**，不占用道具卡。 |
| **可移动叙事道具 / 外观修正道具** | 会被拿起、移动、递交、特写，或需要单独补外观细节的：手机、照片、信件、戒指、药瓶、信 | 建道具卡（PR）；是否走"单实例锁"见 3.4。 |

> 关键叙事道具（戒指/手机/信件/情感物）的**跨镜剧情路径**仍由 15号《道具出场规划表》管（谁传给谁、状态怎么变）；本文件只管它的**朝向、单实例防复制、交接字段**。

### 3.2 道具卡模板

```markdown
【道具卡：PR01_道具名】

首次出现：第__场 / 分镜组 G__
持有人：[谁]
叙事作用：线索 / 象征 / 武器 / 证据 / 情感物 / 动作标点
外观设定：
  尺寸 / 材质 / 颜色 / 新旧程度 / 标志性细节
  禁止变化点：[哪些外观跨镜不能变]
使用规则：
  谁可用 / 什么场景出现 / 状态变化（完整→损坏→丢失→被替换）
与分镜交接：
  是否需要特写 / 微距
  是否情绪锚点
  视频朝向锁定（见 3.3）
  易穿帮面 / 禁止展示面（见 3.3）
是否单实例锁：是 / 否（判定见 3.4）
```

### 3.3 小道具朝向规则（防模型乱转道具）

手机、照片、信封、戒指、硬币、钥匙、证件这类有**正反面**的小道具，进视频提示词时必须写清朝向，否则模型会自动把信息面怼向镜头，露出乱码：

1. 写清**哪一面朝镜头、哪一面背向镜头/贴手心/扣桌面/朝角色身体**。
2. 写清**哪些面禁止生成屏幕、文字、图案或错误结构**。
3. 如果镜头**不需要观众看清信息**，优先让**非信息面朝镜头**，避免模型自动把正面怼过来。
4. **手机类必须区分"屏幕正面"和"摄像头背面"**：背面严禁生成 UI、聊天气泡、发光屏幕或文字。

标准写法：

```text
朝向限制：手机背面朝镜头，黑色玻璃背板和斜排双摄清晰可见；屏幕正面朝向角色手心，不可见；禁止把手机背面生成成屏幕、微信界面、发光 UI 或随机文字。
```

若剧情**必须展示手机/纸条内容**，则改成：

```text
屏幕正面朝镜头，只允许显示指定内容；手机背面不可见；禁止随机文字、错误联系人、正反面同时都是屏幕。
```

### 3.4 道具单实例锁（防"桌上一个、手里一个"）

#### 什么时候必须启用

当同一件关键道具**已经出现在场景空镜/机位底图里**（桌上的手机、墙上的钟、柜台收银机），**同时又单独给了它一张道具参考图**，或它会被**拿起/移动/递交/跨段延续**时，必须启用单实例锁。

> 多张参考图不会天然告诉模型"这是同一个物体"。只写"参考手机道具图"，模型可能把场景里的手机和道具图里的手机理解成**两个**。

#### 单实例锁必写四件事

```text
道具单实例锁：
1. 绑定关系：PR01 就是 [场景空镜/首帧/底图] 中 [具体那一个位置] 的那一件道具；
2. 数量限制：本段/全片只允许出现这一件，不允许第二个同款；
3. 道具图用途：@图片N 只参考它的外观/材质/裂纹/颜色/屏幕状态，不是新增道具；
4. 移动规则：角色拿起后，原位置必须为空；放下后，手中必须为空——不能桌上和手里同时各一个，不能复制到背景/沙发/其他桌面。
```

标准句（写进视频提示词）：

```text
道具单实例锁：PR01 碎屏手机就是场景空镜里桌面右下角那一部手机。本段只允许出现这一部手机。道具图只用于修正它的机身颜色、裂纹和背面双摄细节，不新增第二部；如果角色拿起手机，桌面原位置必须变为空。
```

#### 道具首次进入画面

若道具**尚未**在场景/底图里出现，而是剧情中首次拿出来，则道具图是"新增实例"，但仍要写清进入动作、初始位置、数量、段末状态，不得凭空多出一件。

## 四、资产 → 分镜 → 视频提示词的交接字段

### 4.1 @图片N 用途映射（交接必做）

群演不需要 @图片（它是文字调度）；小道具、场景空镜、角色定稿图需要 @图片N 时，每张都必须写清**"只参考什么 / 不参考什么"**，防止模型把不同参考图的职责混淆。

| @图片N | 资产 | 只参考 | 不参考 |
|---|---|---|---|
| @图片1 | 场景空镜/机位底图 | 空间结构、固定家具、门窗、固定光源、透视 | 人物位置、剧情动作、人群状态 |
| @图片2 | 主角定稿图（归 script-asset-master） | 脸型、发型、服装、体态、年龄感 | 该图里的姿态、场景、临时情绪 |
| @图片3 | PR01 道具外观图 | 外观/材质/裂纹/颜色/屏幕状态 | 随机文字、人物手势；若已在场景中，只修正同一件、不新增第二个 |
| @图片N | 群演参考（仅当用户明确给了群演图） | 人群类型、服装时代感 | 具体脸、具体站位 |

### 4.2 单组图片参考预算（铁律）

**主控分镜组默认 30 秒一组（铁律36）。每一组视频提示词实际引用的 @图片N 图片参考总数必须有上限：**

- 单组实际引用的图片参考建议 **≤ 6–9 张**（含角色定稿图、场景空镜/机位底图、道具图等所有图片；群演是文字不占图）。
- 超过时**先筛选、合并、转文字**：
  - 优先保留：当前组的主角定稿图 + 当前场景空镜/机位底图 + 本组关键道具图；
  - 低风险参考（远景道具、非本组角色的服装参考）**改写成文字约束**，或**拆到下一组**再引用。
- 不要把整个项目的资产图一股脑塞进同一组提示词。

### 4.3 交接块模板

```text
【本组资产交接】
- 场景：@图片1 = 场景空镜（只参考空间/家具/固定光源，不参考人物与人群）
- 角色：@图片2 = 主角定稿图（只参考脸/发型/服装/体态）
- 道具：@图片3 = PR01 外观图（只修正场景中那一件，单实例锁，不新增）
- 群演：CR01 = [密度等级 + 前中远景分布 + 不挡脸/不围观/不同脸]（文字调度，不占图）
- 图片预算：本组实际引用 @图片1/@图片2/@图片3 共 3 张，在预算内
- 声音：真实环境声 + 台词 + 同步音效；不生成 BGM（铁律26）
```
