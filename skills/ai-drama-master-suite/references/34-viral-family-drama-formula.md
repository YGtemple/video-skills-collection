# 现实亲情爆款公式：「3秒钩子 + 5秒留人 + 双故事双转折 + 刀 + 引评论」

> 来源：用户实战验证的爆款打法（2026-10 固化）。
> 适用：**现实亲情/家庭伦理/社会痛点类**真人短剧（重男轻女、婆媳、养老、扶弟魔、父母偏心、留守儿童、空巢老人、隔代亲、夫妻冷暖、兄弟姐妹反目等）。
> 与 09 号「空空公式」的区别：09 号是**奇幻外壳+灵异超能力**赛道；本公式是**现实题材+亲情刀+争议引评论**赛道。两者按题材切换，不混用。

---

## 一、开头：3 秒钩子 + 5 秒留人（铁律，不达标不进正片）

### 1.1 前 3 秒 = 钩子画面（不是台词、不是旁白、不是字幕）
- 第一帧/前 3 秒必须是**视觉冲击画面**——观众手指停下来的瞬间：
  - 极端情绪画面：老人在雨里跪/中年人蹲在医院走廊哭/母亲把碗摔在地上/儿子把父亲的东西扔出门
  - 反常动作画面：女儿在年夜饭上掀桌子/父亲偷偷把存折塞给儿子被女儿撞见/老人在垃圾桶里捡别人剩饭
  - 悬念画面：一只手攥着离婚证/一张亲子鉴定报告/医院病危通知书被手捏皱
- **⛔ 禁止**：开头用旁白"我叫XX，今天我要讲一个故事"、用字幕打标题、用人物站着说话——这三种开头 3 秒内必被划走。

### 1.2 前 5 秒 = 留人（让观众觉得"这事跟我有关/我得看完"）
- 3 秒钩子画面之后，**5 秒内必须立刻抛出核心矛盾或身份代入点**：
  - 身份代入：主角是观众自己/父母/兄弟姐妹/身边那种人（"这不是我家吗？"）
  - 矛盾代入：一上来就是冲突顶点（婆媳吵架、父母偏心、孩子被冤枉、老人被弃养）
  - 情绪代入：主角已经在哭/在忍/在爆发，观众瞬间共情
- **自检**：把前 5 秒单独切出来给一个陌生人看，问他"你想不想看后面？"——他说想，才算过。

### 1.3 钩子切割法：矛盾最高点之后先全删（首版只出钩子片段）

**规则**：开头分镜写完后，**找到矛盾最高点（钩子最强悬念点），该时间点之后的内容在首版全删，先只出钩子片段给用户审核；钩子通过后再做后面的正片。**

- **切割点怎么找**：
  - 不是固定 10 秒，是**"观众最想知道接下来会怎样"的那一秒**——通常是矛盾刚抛出来、主角还没反应的那个瞬间
  - 例：领头男孩刚说完"学狗叫，叫就给你糖"——停在这，后面小孩怎么做、糖里是什么，全删
  - 例：母亲刚把存折摔在儿子面前说"这房归你姐"——停在这，后面女儿什么反应，全删
- **典型时长**：8–12 秒（不锁死，矛盾最高点在哪就切哪）
- **为什么先全删**：
  - 钩子片段是引流核心，必须先验证能不能抓人——钩子不行，后面拍再好也没人看
  - 避免一口气做 30 秒结果钩子不对、全部返工
  - 钩子通过后，再做后面 20 秒正片（屈辱/升级/反转/刀），效率最高
- **执行顺序**：
  1. 写完开头 30 秒分镜 → 2. 标出矛盾最高点（如第 10 秒）→ 3. 先只生成 0–10 秒钩子片段视频 → 4. 用户审核钩子 → 5. 通过后再生成 10–30 秒正片段
- **⛔ 禁止**：一口气把 30 秒全做出来再给用户看——钩子没验证就做正片，风险太大。

## 二、中段：双故事 + 双转折（不是单转折，是两层加码）

### 2.1 结构（按比例，不锁死时长）
```
┌──────────────┬──────────────────┬──────────────────┬──────────────┐
│  开头 3+5 秒  │   第一个故事      │   第二个故事      │  结尾刀+引评论 │
│  钩子+留人    │  （表层矛盾）     │  （深层矛盾/真相反转）│  情绪暴击+留钩子 │
│              │  0% – 40%        │  40% – 85%       │ 85% – 100%    │
└──────────────┴──────────────────┴──────────────────┴──────────────┘
```

### 2.2 第一个故事（表层，约 40%）
- 先讲一个观众"一眼就能站队"的故事：谁对谁错一目了然。
- 例：母亲重男轻女，把所有钱给儿子，女儿委屈。观众看完第一反应："这妈太偏心了！"
- 任务：**让观众先站定一个立场**，情绪先起来。

### 2.3 第一次转折（约 40% 处）
- 推翻观众刚刚站定的立场，但**不是洗白**，是加一层复杂度。
- 例：母亲为什么偏心？因为当年女儿病危是儿子捐的骨髓/母亲年轻时被婆婆这样对待过/儿子其实一直在偷偷赡养老人没说。
- 任务：**观众开始犹豫**——"等等，那到底谁对？"

### 2.4 第二个故事（深层，约 45%）
- 把第一次转折揭开的真相往深挖一层，讲背后的无奈、时代的重量、小人物的身不由己。
- 例：母亲不是不爱女儿，是那个年代重男轻女是生存策略；她偷偷给女儿留了一套房，但不敢说。
- 任务：**情绪从愤怒转向心疼/破防**。

### 2.5 第二次转折（约 80% 处）
- 终极刀点——把"心疼"再推一把，让观众彻底破防。
- 例：女儿最后才发现，母亲留的那套房，是她自己住了一辈子的老房子，母亲搬去了养老院。
- 任务：**观众泪崩/意难平**。

## 三、话题：尖锐但不过线（合规边界）

### 3.1 要尖锐（戳痛点，才有讨论度）
- 选题优先选**社会有共鸣、有争议、每个人家里都可能发生**的痛点：
  - 重男轻女 / 扶弟魔 / 嫁妆彩礼
  - 婆媳矛盾 / 丧偶式婚姻 / 夫妻冷暖
  - 养老/啃老/空巢老人/久病床前无孝子
  - 父母偏心 / 兄弟姐妹反目 / 遗产纠纷
  - 留守儿童/隔代亲/亲子隔阂
  - 学历贬值/小镇做题家/普通人的上升困境
- **越尖锐越有评论**——因为每个人都有立场。

### 3.2 别太敏感（合规红线，碰了就封号）
- ✅ 可以拍：家庭内部矛盾、代际观念冲突、普通人的无奈、情感创伤
- ❌ 不能碰：具体民族/宗教歧视、地域黑、政治制度批判、极端血腥暴力、明确的违法美化、未成年人被侵害细节、自杀自残细节
- **判断标准**：话题让观众吵起来（"我妈就这样"/"你这是在洗白"/"我不这么觉得"）就够了；不要让观众举报到平台限流。

## 四、故事必须"刀"（情感暴击，不刀不算完成）

- **刀 = 情感暴击点**：让观众看完心里堵、鼻酸、想哭、想转发给家里人。
- 刀的几种打法：
  1. **反差刀**：前面越暖，后面越刀（父亲表面骂你不争气，背地里偷偷给你塞钱）
  2. **真相刀**：观众以为的坏人其实一直在默默付出（母亲偏心儿子，其实儿子是抱来的/女儿才是亲生的）
  3. **错过刀**：子欲养而亲不待（女儿终于原谅母亲，母亲已经老年痴呆/走了）
  4. **牺牲刀**：小人物用自己的牺牲换孩子的前途（卖血/打三份工/捡废品供孩子读书）
- **自检**：写完问自己"这个故事最让我心里一紧的是哪一秒？"——说不出来，就是不刀，重写。

## 五、故意片面引评论（提高评论率和停留率）

> **核心逻辑**：完全政治正确、面面俱到的故事没人评论。故意留一个"片面的、有争议的、观众想纠正你"的点，他们就会在评论区吵架/炮轰/补充，停留率和评论率就上去了。

### 5.1 怎么"片面"
- 主角的立场**故意带偏见**，不要把话说圆。
- 例：
  - 母亲把房子给儿子，女儿气到断绝关系——别在结尾强行"阖家团圆和解"，就让观众吵"女儿做得对不对？""老人该不该把房子全给儿子？"
  - 儿子啃老，母亲心甘情愿——别评判，把现象摆出来，让观众吵"这妈是不是活该？""儿子是不是白眼狼？"
- **结尾不要给标准答案**——把问题抛给观众。

### 5.2 引评论的具体手法
- 结尾留一句**开放式台词/画面**："你说，她到底做错了吗？"
- 主角的某个决定**故意有争议**：观众看完会分成两派吵起来
- **不要强行升华**——"其实天下父母都是爱孩子的"这种话一出来，评论区就死了
- 可以在视频描述/结尾画面留一个**争议性钩子问题**（但正片不要加字幕，靠台词或画面自然带出）

### 5.3 边界
- 片面 ≠ 价值观扭曲：不能美化违法行为、不能教唆仇恨
- 片面 ≠ 真的偏见：故事里可以有争议，但整体温度要是暖的（让人哭，不是让人恶）
- 目的是让观众**想说话**，不是让观众**想举报**

## 六、亲情赛道优先（默认赛道）

- 用户项目默认优先选**亲情/家庭伦理/社会痛点**题材——受众广、共鸣强、情绪浓、评论多。
- 故事发散时（模块1 第1门），3–5 个方向里至少 **2 个是亲情赛道**。
- 人物小传优先选：母子/母女/父子/父女/夫妻/祖孙/兄弟姐妹，而不是霸道总裁/玄幻修仙。

## 七、自检清单（写完剧本过一遍）

- [ ] 前 3 秒是不是视觉冲击画面？（不是旁白/字幕/站着说话）
- [ ] 前 5 秒是不是立刻抛出矛盾/身份代入点？
- [ ] **【钩子切割】是不是先只做到矛盾最高点（约8-12秒）、之后内容首版全删？是不是先出钩子片段给用户审核、通过后再做正片？**
- [ ] 是不是双故事双转折？（不是单反转，是两层加码）
- [ ] 话题是不是够尖锐？（戳到观众家里的事）
- [ ] 有没有踩合规红线？（民族/宗教/政治/极端暴力/未成年侵害细节）
- [ ] 故事有没有"刀"？（最让人心口一紧的是哪一秒？）
- [ ] 结尾是不是开放式、有争议、观众想吵？（不是强行阖家团圆）
- [ ] 至少留了一个"观众想纠正/想补充/想站队"的片面点？
- [ ] 题材是不是优先亲情赛道？
