# 一致性资产管理规范

## 概述

本文件是AI短剧一致性管理的**生成前规范**——在剧本阶段和分镜阶段就把角色造型、场景空间、光源方向、道具走向全部锁定，从源头杜绝跨镜不一致问题。

**与其他模块的关系**：
- 本文件管**生成前**：角色长什么样、场景长什么样、光从哪来、道具怎么传——全部提前规划
- 05号文件管**生成后**：拍完之后逐镜检查、发现问题、决定修复方案
- 两者形成闭环：15号规划→05号检查→发现问题→回到15号修正规划

**为什么需要这个文件？**

没有一致性资产管理时，最常见的翻车现场：
- 女主在出租屋是长卷发，到了医院突然变成短发（提示词写错，和参考图矛盾）
- 同一场景，上一镜窗户在左边，下一镜窗户跑到右边（空间没锚定）
- 客厅戏，这镜主光从窗户打进来，下镜主光变成顶灯（光源没锁定）
- 关键道具（戒指/手机/信件），上一镜在A手里，下一镜突然在B桌上（道具没追踪）

这些问题的根源都是同一个：**没有在生成前把资产锁定，全靠AI临场发挥**。本文件就是要把这些资产在拍摄前全部钉死。

## 一、角色资产锁定表

### 1.1 什么是角色资产锁定表

每个角色在全剧开始前（剧本阶段或分镜阶段）建立一张资产锁定表，把角色在全剧中的所有造型变化一次性规划清楚。

**核心原则：面部永远跟参考图走，服装发型可以变但必须提前规划。**

| 元素 | 可否变化 | 规则 |
|---|---|---|
| 面部特征（五官/脸型/肤色/年龄感） | ❌ 永远不变 | 任何场景都与参考图一致，绝不改变 |
| 发型（发色/长度/卷直） | ⚠️ 可变化但必须提前规划 | 只有剧情明确设计了"剪发/理发/扎起来/披散"等事件时才变，且必须在本表中记录 |
| 服装 | ✅ 随场景变化 | 每个场景的服装必须在本表中提前规划，不得临时发挥 |
| 妆容 | ⚠️ 随场景微调 | 如素颜/淡妆/浓妆，提前规划 |
| 配饰/异化特征 | ⚠️ 随剧情变化 | 如戴戒指/戴眼镜/异化鳞片，变化必须有剧情依据 |

### 1.4 铁律

1. **面部特征永远与参考图一致**：任何场景，提示词中都必须写"面部特征与参考图一致"，不得改变脸型/五官/肤色/年龄感
2. **服装/发型可以随场景变化，但必须提前规划**：上表中没有的场景，不得临时发明造型
3. **禁止与参考图矛盾的描述**：参考图是长卷发，任何场景都不得写"短发"——除非剧情明确有"剪发"事件，且在表中记录了剪发后的新造型
4. **同一场景所有镜头，造型描述必须完全一致**：不能这镜穿卫衣，下镜突然穿毛衣
5. **纯文字描述的角色（无参考图）也要建资产表**：把外貌特征写死，全剧统一

### 1.5 常见翻车案例

| 翻车场景 | 错误写法 | 正确写法 |
|---------|---------|---------|
| 医院场景 | "短发女生，穿病号服，脸色苍白" | "长卷发扎低马尾（面部与@图片1一致），穿蓝白条纹病号服，脸色苍白" |
| 换装场景 | "她换上了职业装，短发干练" | "长卷发披肩（面部与@图片1一致），换上白衬衫黑西裤，淡妆" |
| 情绪崩溃 | "她披头散发，头发凌乱" | "长卷发披散凌乱（面部与@图片1一致），眼眶泛红，嘴唇颤抖" |

### 1.6 服装锁定与换装节点："该锁时锁死，该换时才换"

1.2 的场景表回答了"每个场景穿什么"，但还缺两层硬约束：
- **服装锁定**：同一剧情阶段、同一套服装设定内，款式 / 颜色 / 配饰**逐镜必须完全一致**——不能这镜土灰军装、下镜突然变蓝军装；
- **换装节点**：只有剧情明确设计的换装才允许变化，每次换装都要登记"适用剧情区间 ＋ 换装原因 ＋ 交代镜头/情节"。

**一句话总原则：该锁时锁死，该换时才换。**

#### 1.6.1 什么算"该锁"，什么算"该换"

| | 判定 | 硬性要求 |
|---|---|---|
| **该锁时锁死** | 处于同一剧情阶段、同一条换装节点区间内 | 款式 / 颜色 / 配饰 / 鞋**逐镜冻结**，与服装锁定卡逐项一致；任一镜跳变即判"服装崩"，需重生成 |
| **该换时才换** | 出现下方登记在案的合法换装情形 | 必须在换装节点表登记，并在镜头中给出交代；**没有交代镜头的换装一律视为穿帮** |

**允许换装的合法情形（必须登记，且必须有镜头 / 情节交代）：**

1. **换季**：季节 / 气温变化——需有天气空镜、添减衣物动作交代；
2. **入伍 / 改编**：参军、部队整编、换发新军装——需有集合点名、领章帽徽特写、换装命令等镜头；
3. **受伤 / 住院**：受伤包扎、术后病号服——需有受伤镜头 ＋ 送入医院 / 换上病号服的交代；
4. **身份转变**：平民↔军人、学生↔职场、卧底伪装、婚丧正装等——需有对应情节（如领证、入职、葬礼入场）；
5. **长大成人 / 时间跨度**：多年后、多年成长——需有时间字幕或明显成长空镜（春→冬、孩童→成年）；
6. **场景正装需求**：婚礼 / 葬礼 / 面试 / 宴会——需有入场或整理着装的镜头。

> **红线**：任何未在"换装节点表"登记、且没有交代镜头 / 情节的服装跳变（款式变了、颜色变了、配饰凭空多出或消失），一律判**服装不一致**，按 5.3 决策表"服装变化"条重生成，不得以"观众看不出来"放过。

#### 1.6.2 服装锁定卡模板

每个造型一套卡。一个角色有几套造型就建几张卡，与 1.2 场景表的每一行造型一一对应。

```

填写要求：
- **适用剧情区间**必须写清起止镜头（或起止剧情阶段），区间内一律套对应那张服装锁定卡；
- **换装原因**必须落在 1.6.1 的合法情形里，不得写"感觉应该换了"；
- **交代镜头 / 情节**必填——没有交代镜头的节点，生成时一旦换服装即视为穿帮。

#### 1.6.5 与决策树、自检门的衔接

- **生成前**：每个造型建一张服装锁定卡，每次换装建一行换装节点（见 6.1 生成前检查）；
- **生成后**：逐镜对照服装锁定卡，发现跳变→查换装节点表→没登记即按 5.3"服装变化"P1 重生成（见 6.2 生成后检查）；
- **面部一致性**不在本节展开，沿用 1.4 铁律1 与 05 号文件的面部审核方法，本节只补服装这一层。

## 二、场景空间锚定卡

### 2.1 什么是场景空间锚定卡

每个场景在分镜前建立一张空间锚定卡，把这个场景的空间布局一次性钉死。同一场景的所有镜头，空间布局必须与锚定卡一致，禁止跨镜家具瞬移、门窗换边。

### 2.2 场景空间锚定卡模板

```
【场景空间锚定卡：场景名】

场景类型：S1/S2/S3/S4/O1/O2/X（见02号文件2.1节）
面积/层高：XX㎡ / XXm
─────────────────────────────────────────────
空间布局（俯视示意图）：
┌─────────────────────────┐
│                         │
│  [窗户]        [门]      │  ← 北墙
│                         │
│  [沙发]                  │
│                         │
│       [茶几]            │
│                         │
│  [电视]        [书架]   │  ← 南墙
│                         │
└─────────────────────────┘

关键家具相对位置：
- 沙发：贴西墙摆放，面朝东
- 茶几：沙发正前方，距沙发0.5米
- 电视：贴东墙挂墙，与沙发正对
- 书架：东南角，高2米
- 窗户：北墙偏西，1.5m×1.2m
- 门：北墙偏东，向内开

门窗位置：
- 窗户：北墙偏西
- 入户门：北墙偏东

可放置机位区域：
- 西墙附近（拍沙发正面）
- 东墙附近（拍电视和客厅全景）
- 门口（拍人物进出）

人物活动动线：
- 入户→换鞋区→沙发
- 沙发→茶几→厨房（东墙北侧）
─────────────────────────────────────────────
```

### 2.3 完整示例

```
【场景空间锚定卡：出租屋客厅】

场景类型：S1（室内封闭小空间）
面积/层高：15㎡ / 2.6m
─────────────────────────────────────────────
空间布局（俯视示意图）：
┌─────────────────────────┐
│ 窗            门         │  ← 北墙（外墙）
│  │                      │
│ 沙发                    │
│  │                      │
│  ──── 茶几 ────         │
│                         │
│ 电视挂墙    小冰箱       │  ← 南墙
└─────────────────────────┘

关键家具相对位置：
- 沙发：贴西墙，面朝东，双人位
- 茶几：沙发正前方1米，木质小方桌
- 电视：东墙挂墙，1.2m高，与沙发正对
- 小冰箱：东南角，门朝北开
- 窗户：北墙偏西，1.5m×1.2m，塑钢窗
- 入户门：北墙偏东，向内（南）开

可放置机位区域：
- 东墙附近（拍沙发+人物正面）
- 西墙附近（拍人物背影+电视）
- 北墙门口（拍人物进门）
- ❌ 禁止：电视墙和沙发之间只有1.5米，无法放机位在中间

人物活动动线：
- 入户门→北墙过道→沙发
- 沙发→茶几（拿东西）→小冰箱（东南角）
- 沙发→窗户（站起来走到窗边）
─────────────────────────────────────────────
```

### 2.4 铁律

1. **同场景所有镜头的空间布局必须与锚定卡一致**：沙发不能从西墙跑到东墙，窗户不能从北边跑到南边
2. **关键家具的相对位置固定**：电视永远和沙发正对，茶几永远在沙发前面
3. **门窗位置固定**：入户门永远在北墙偏东，不会跑到南墙
4. **人物活动动线符合空间逻辑**：从门到沙发必须经过北墙过道，不能穿墙
5. **物理可行性优先**：锚定卡中标注"可放置机位区域"，禁止在物理上放不下机位的地方安排镜头

### 2.5 跨镜一致性检查要点

- 上一镜窗户在左边，下一镜窗户还在左边吗？（不允许跑右边）
- 沙发在画面中出现时，它是贴西墙的沙发吗？（不是凭空出现的另一个沙发）
- 人物从门进来，门在北墙偏东——下一镜人物的位置符合这个入口吗？
- 电视挂在东墙——拍人物正面时，人物背后应该是电视吗？

## 三、场景光源设定卡

### 3.1 什么是场景光源设定卡

每个场景建立一张光源设定卡，把这个场景的主光源、辅光源、环境光全部锁定。同场景相邻镜头光源方向必须一致——允许强度变化，不允许方向跳变。

### 3.2 场景光源设定卡模板

```
【场景光源设定卡：场景名】

主光源：
- 来源：[窗户/顶灯/台灯/路灯/太阳]
- 方向：[从画面左侧/右侧/上方/前方射入]
- 色温：[暖黄3200K/冷白5600K/钠灯橙/月光蓝]
- 强度：[强/中/弱]

辅光源：
- 来源：[墙面反射/台灯/屏幕光/路灯漫反射]
- 方向：[从XX方向补光]
- 色温：[XXX]
- 强度：[弱/中]

环境光：
- 整体亮度：[亮/中/暗]
- 整体色调：[暖/冷/中性]

光源变化规则：
- [角色走到窗边时光变强]
- [夜幕降临整体变暗]
- [打开台灯增加局部暖光]
─────────────────────────────────────────────
```

### 3.3 完整示例

```
【场景光源设定卡：出租屋客厅，夜】

主光源：
- 来源：北墙窗户（窗外是城市夜景，有街灯漫射光）
- 方向：从画面左侧（北墙偏西的窗户）射入
- 色温：冷蓝白色（夜色环境光），约6500K
- 强度：弱（夜晚窗外漫射光，不照亮整个房间）

辅光源：
- 来源：沙发旁的落地台灯（暖黄色）
- 方向：从画面右下方（沙发侧）向上漫射
- 色温：暖黄色，约2700K
- 强度：中（照亮沙发区域和人物面部）

环境光：
- 整体亮度：暗（夜晚室内，只有台灯和窗外微光）
- 整体色调：暗蓝冷调基底+局部暖黄台灯光

光源变化规则：
- 角色坐在沙发上：面部被台灯暖光照亮，背景是冷蓝色夜色
- 角色走到窗边：窗外冷光变强，人物面部变成冷色调
- 角色关掉台灯：只剩窗外冷光，整体变暗偏蓝
- 角色打开顶灯（如有）：整体亮起来，偏暖白
─────────────────────────────────────────────
```

### 3.4 铁律

1. **同场景相邻镜头，光源方向必须一致**：上一镜主光从左边来，下一镜主光不能突然从右边来
2. **允许强度变化，不允许方向跳变**：台灯可以从亮变暗（角色走远了），但不能从左边跑到右边
3. **色温整体统一**：同场景所有镜头的主色温必须一致（都是暖黄，或都是冷蓝），不能这镜暖黄、下镜冷白
4. **光源变化必须有剧情依据**：开灯/关灯/走到窗边/夜幕降临——这些变化必须在镜头中有展示动作，不能凭空变
5. **阴影方向与光源一致**：主光从左边来，人物的影子应该投向右边

### 3.5 跨镜光影检查要点

- 上一镜人物面部左边亮右边暗（主光从左来），下一镜还是吗？
- 同一场景，这镜整体暖黄，下镜突然冷白？
- 阴影方向和主光源方向对得上吗？
- 角色走到窗边，光线应该变强变冷——这个变化在镜头中展示了吗？

4. **道具位置必须合理**：在桌上→在手中，中间必须有"拿起"动作；在口袋→在手中，中间必须有"掏出"动作
5. **与05号追踪表闭环**：本规划表是生成前的计划，05号的追踪表是生成后的实际记录——两者对比，发现偏差就是问题

## 五、重生成决策树

### 5.1 为什么需要统一的重生成决策树

发现问题后，不能每次都凭感觉决定"要不要重生成"。不同类型的问题，严重度不同，修复路径也不同。本决策树把问题分类、分级、给出标准修复路径，避免"小病大治"（小问题反复重生成浪费时间）或"大病小治"（大问题用后期掩盖观众还是看得出来）。

### 5.2 决策流程图（文字版）

```

  │
  ├─ 面部崩坏/换脸 ──────────────────────────┐
  │                                           │
  ├─ 越轴/站位错误 ──────────────────────┐   │
  │                                       │   │
  ├─ 光影跳变/光源方向不一致 ────────┐   │   │
  │                                   │   │   │
  ├─ 道具消失/变形/位置跳变 ────┐   │   │   │
  │                             │   │   │   │
  ├─ 肢体异常（多指/扭曲）─┐   │   │   │   │
  │                         │   │   │   │   │

### 5.3 问题类型与修复路径决策表

| 问题类型 | 严重度 | 修复路径 | 具体操作 |
|---------|--------|---------|---------|
| **面部崩坏**（五官扭曲/融化） | P0 | 先提高参考图权重→仍失败换景别→仍失败用替代方案 | ① Prompt中增加"面部与参考图高度一致"描述，提高参考图权重；② 特写→中景/近景（避开面部大特写）；③ 换角度（正面→3/4侧面）；④ 仍失败→用反应镜/剪影/背影替代 |
| **换脸**（同角色跨镜面部不同） | P0 | 先提高参考图权重→仍失败统一锚定图 | ① 全镜统一使用同一张参考图，每次生成都带图；② 增加面部描述细节（"鹅蛋脸、大眼睛、高鼻梁"）；③ 仍失败→重新设计镜头（减少该角色特写镜头数量） |
| **越轴/站位错误** | P0 | **必须重生成，禁止用剪辑掩盖** | ① 修正Prompt中的站位描述（三要素写全）；② 确认分镜中是否标注了轴线；③ 重新生成。**此项不可后期剪辑掩盖**——观众对左右位置互换非常敏感 |
| **站位穿帮**（人物莫名换位/穿模） | P0 | 必须重生成 | ① 在Prompt中写死站位三要素；② 重新生成。**禁止用剪辑掩盖** |
| **光影跳变**（光源方向跨镜不一致） | P1 | 先后期调色→差异过大重生成 | ① 小差异：后期调色统一色温/亮度；② 方向不同（左光→右光）：必须重生成，修正Prompt中光源描述 |
| **道具消失/变形** | P1 | 增加道具描述重生成→仍失败用替代 | ① Prompt中增加道具位置和状态描述（"桌上有一碗面"）；② 道具放在画面中心安全区；③ 仍失败→用道具特写/遮挡（手拿着道具）替代 |
| **肢体异常**（多指/扭曲/穿模） | P0 | 简化动作重生成→仍失败用遮挡 | ① 避免手部特写，用道具遮挡手部；② 简化复杂动作，拆分镜头；③ 裁切画面去掉异常部位 |
| **场景跑偏**（与Prompt描述不符） | P0 | 增加场景描述重生成 | ① Prompt中增加场景细节（家具/门窗/墙面颜色）；② 使用场景参考图；③ 仍失败→重新设计镜头 |
| **服装变化**（同角色跨镜换装） | P1 | 统一服装描述重生成 | ① 对照角色资产锁定表，统一服装描述；② 重新生成；③ 小偏差后期调色统一 |
| **动作卡顿/不自然** | P2 | 后期加速/剪辑掩盖 | ① 可接受（短剧要求不高）；② 后期加速播放；③ 用反应镜/快切蒙太奇掩盖 |
| **色彩偏差** | P2 | 后期调色统一 | ① 后期LUT统一色调；② 不需要重生成 |
| **文字乱码** | P1 | Prompt加"无文字"+裁切 | ① Prompt中加"无文字无字幕"；② 裁切去掉乱码区域；③ 不需要重生成 |

### 5.4 P0/P1/P2 分级定义

| 级别 | 定义 | 处理方式 | 可否后期掩盖 |
|------|------|---------|-------------|
| **P0 致命** | 观众一眼就能看出来的硬伤，影响叙事理解 | 必须重生成，修正Prompt后重新生成 | ❌ 禁止后期掩盖 |
| **P1 中度** | 仔细看能发现的问题，不影响整体理解 | 调Prompt重生成（1-3次重试），或后期修复 | ⚠️ 小差异可后期，大差异必须重生成 |
| **P2 轻度** | 正常观看速度下注意不到的细节问题 | 后期修复（调色/裁切/音效） | ✅ 可以后期掩盖 |

**P0级问题清单（禁止后期掩盖，必须重生成）：**
- 面部崩坏/换脸
- 越轴/站位错误
- 肢体严重异常（多指/扭曲/穿模）
- 场景完全跑偏
- 合规问题（血腥/暴力/敏感内容）

### 5.5 导演决策流程（重试失败后）

当某个镜头重生成3次仍有P0级问题，进入导演决策流程：
1. **换景别**：特写→中景，中景→全景（避开问题区域）
2. **换角度**：正面→侧面→背影（避开面部/肢体特写）
3. **用替代镜头**：反应镜（拍另一个人的反应）、空镜（环境/道具特写）、剪影/逆光
4. **重新设计镜头**：把这个镜头拆成两个更简单的镜头
5. **最终手段**：如果以上都不行，用剪辑掩盖（快切蒙太奇+音效桥接），但必须在剪辑自检中记录

## 六、一致性自检门

### 6.1 生成前检查（分镜/提示词阶段必过）

- [ ] **角色资产锁定表是否建立？** 每个有参考图的角色都有资产表了吗？
- [ ] **角色资产表是否覆盖了所有场景？** 每个场景的发型/服装/妆容都写清楚了吗？
- [ ] **角色面部特征是否与参考图一致？** 有没有写"短发"但参考图是长卷发的矛盾？
- [ ] **服装锁定卡是否逐造型建立？** 每个造型的款式/颜色/配饰/鞋是否逐项锁死？逐镜核对列是否已备好？
- [ ] **换装节点表是否登记了全部换装？** 每次换装的适用剧情区间(起止镜头)、换装原因、交代镜头/情节是否都填了？
- [ ] **有没有"想换但没登记"的造型？** 1.2 表里的每次造型变化是否都能在换装节点表找到对应行？
- [ ] **场景空间锚定卡是否建立？** 每个场景都有空间布局图了吗？
- [ ] **锚定卡是否标注了门窗位置/家具布局/可放机位区域？**
- [ ] **场景光源设定卡是否建立？** 主光源/辅光源/环境光都写清楚了吗？
- [ ] **光源方向是否统一？** 同场景所有镜头的光源方向是否一致？
- [ ] **道具出场规划表是否建立？** 关键道具的出场路径都规划了吗？
- [ ] **道具持有者变化是否有传递动作？** 有没有凭空转移的？
- [ ] **站位三要素是否写全？** 每个≥2人同框的镜头都写了左右+前后+朝向吗？
- [ ] **180度轴线是否标注？** 对话场景是否标注了摄影机所在侧？
- [ ] **同场景站位是否锁定？** 连续镜头的左右站位一致吗？

### 6.2 生成后检查（视频审核阶段必过）

- [ ] **【A·意外文字类（应为无）】成片是否意外出现：字幕/台词字幕/花字/标题字/屏幕文字/招牌或纸张可读文字/水印/logo/平台UI/进度条/时间码/按钮图标？（仅黑底时间跳转卡、封面海报标题为例外；除此之外画面内部一律无文字，发现即重生成）**
- [ ] **【B·穿模/畸形类（P0）】逐项查：手指/脚趾数量异常（多指/并指/缺指）、肢体/手臂/腿数量异常；肢体穿插/手臂穿躯干或腿/关节反折；道具武器穿身；人物穿家具/墙体/门窗；衣物穿身（领口袖口裙摆腰带嵌入穿透）；多角色重叠穿插粘连；物体悬浮/接地错误（脚离地、道具悬空、坐没坐实、手持物没握住、杯盘没落桌面）？任一即重生成、不带病交付**
- [ ] **跨镜角色一致性？** 同一角色在不同镜头中，面部/发型/服装是否与资产表一致？
- [ ] **面部一致性？** 面部检查方法见 1.4 铁律1 与 05 号文件面部审核（此处不重复方法），只核对结论：同角色跨镜是否仍是同一张脸，有无换脸/崩脸。
- [ ] **服装一致性？** 同一剧情阶段 / 同一造型区间内，款式/颜色/配饰是否与服装锁定卡逐镜一致？任何服装变化是否都能在换装节点表登记、且有交代镜头？没有交代的服装跳变一律判不一致、需重生成。
- [ ] **场景连续性？** 同场景的家具/门窗/空间布局是否与锚定卡一致？
- [ ] **光影衔接？** 相邻镜头的光源方向/色温是否一致？
- [ ] **道具追踪？** 关键道具的位置/状态/持有者是否与规划表连续？
- [ ] **站位一致性？** 同场景连续镜头的人物左右站位是否一致？有没有越轴？
- [ ] **问题分级了吗？** 每个问题是否判断了P0/P1/P2级别？
- [ ] **P0问题是否都重生成了？** 有没有用后期掩盖P0问题？
- [ ] **重生成是否走了决策树？** 修复路径是否按决策表执行？
- [ ] **重试失败的镜头是否进入导演决策？** 有没有换景别/换角度/用替代方案？
- [ ] **【33 号·锚点帧一致】** 跨段人物站位/场景状态若用技术全景锚点帧延续（见 references/33-tech-panorama-anchor.md），须确认锚点帧与本组实际末态一致；锚点错时先选同段稳定帧，失败后转模式B生成5秒技术补段，不带错锚下传。
