# 动作戏镜头设计专项（打斗 · 追逐 · 枪战 · 正面拆解因果）

> 来源：吸收开源 Skill《script-to-shot-engine（剧本到镜头引擎，v2.3.2，作者 Elio Jia）》的动作编排规则，并与本套件体系融合。
>
> 分工（先看清，不重复）：
> - **29 号**管"动作戏的 AI 能力边界 / 高失败黑名单 / 什么时候该绕开"；**27 号**有争吵、追逐的**骨架配方**；**本文件管"动作戏怎么正面设计——怎么排动作因果、怎么用多个镜头覆盖同一个动作"**。
> - 真人写实短剧里，能用反应 / 局部特写暗示的冲突优先用 29 号的"反应表演法"（更稳、更省）；**当剧情确实需要正面呈现打斗 / 追逐 / 枪战时，用本文件**。
>
> 合规前提（铁律 3）：不写血腥特写、喷溅、断肢、武器刺穿身体、暴力慢放；动作以"攻防局势 + 受力反应"呈现，且每个镜头生成后必审。

---

## 一、通用动作语法（每个攻防单元按这五段写）

```text
局势与距离 → 发起动作 → 防守 / 闪避 / 命中 → 受力与位移 → 恢复或新局势
```

- ❌ 避免只写"激战""连续进攻""高速缠斗"；避免罗列一串互不产生结果的招式。
- **动作之间必须有因果**：上一次格挡打开的空当、撞墙造成的失衡、被封住的退路、掉落的武器、被破坏的环境——都要成为下一动作的条件。
- 每个动作都要回答："谁、在什么距离、对谁、做了什么、造成了什么结果、现在局势变成怎样"。

**两条因果链模板：**
- 动作 / 打斗：**攻击 → 格挡 → 命中 → 受力 → 恢复（Attack → Block → Hit → Impact → Recover）**
- 文戏 / 对峙：施压 → 承受 → 泄露 / 反制 → 新平衡（见 31 号）

---

## 二、核心概念：动作单元 ≠ 剪辑镜头（最容易搞错）

- **动作单元**＝一次完整的攻防（一次出拳与格挡、一次夺刀、一次摔投），是"编排容量"。
- **剪辑镜头**＝覆盖这个动作的某一个机位 / 角度，是"覆盖密度"。
- **一个连续动作单元可以、也常常应该用多个镜头覆盖：**

```text
镜头一：看清冲拳与拍挡（中景）；
镜头二：近景表现抓腕；
镜头三：广角表现拉颈、搓步与双方位移；
镜头四：拍脚后跟滑停。
```

> 关键铁律：**这些镜头记录的是同一次连续动作——切了角度，动作不能重新发生**。不能镜头二的抓腕、镜头三的拉颈在每次切镜后又演一遍。用"**顺势 / 同时 / 承接 / 动作未停**"这类词把镜头串起来。

**镜头数 vs 动作单元数：**
- 增加镜头时，优先拆分：动作发起、接触点、脚步、受力、反应——**用不同观看重点覆盖同一条动作因果链**，而不是追加无因果的新招式。
- 判断镜头够不够，看"动作的每个关键阶段（发起 / 接触 / 受力 / 结果）观众有没有看清"，而不是数镜头数量。

## 三、容量与阶段（按单次生成时长配攻防单元）

| 时长 / 类型 | 主要攻防单元 | 镜头数（覆盖密度） |
|---|---|---|
| 15s 真人写实 | 2–3 个，最多 1 次重要环境互动 | ≥10 镜（每镜 1–2s） |
| 30s 真人写实 | 5–8 个 | 10–18 镜 |
| 15s 风格化 / 玄幻 | 3–4 个 | 按动作拆 |
| 对峙（对白驱动） | 不适用攻防，走 31 号 | 5–8 镜（每镜 2–4s） |

- **动作容量按"攻防单元"控制，不按镜头数**——镜头可以多（覆盖细），但攻防单元不能堆（会乱、会假）。
- 如果一段同时包含"三人精确攻防 + 夺武器 + 摔倒 + 复杂环境破坏 + 高速运镜"，**必须删减或拆段**（对接 29 号拆分四法、铁律 31 衔接）。
- 混合场景（先谈后打）可**逐 clip 切换模式**：谈的段落按对峙节奏、打的段落按动作节奏。

## 四、真人写实动作的五个着力点

1. **重心、脚步和落点**：每个发力都有脚步支撑、每个落点都踩实。
2. **有效距离**：拳脚 / 武器要在够得着的距离，不隔空挥舞。
3. **受击后的短暂失衡与恢复**：挨了重击要有反应、有身体的连锁，不能毫无反应。
4. **体力下降与动作幅度变化**：打久了动作变慢、变沉、喘气。
5. **可读的防守动作**：格挡 / 闪避 / 架开要看得清，而不是双方无接触地比划。

- ❌ 避免：无依据腾空、连续空翻、瞬间变向、挨重击毫无反应、**摄影机比人物动得还剧烈**。

## 五、按形式分（只读与本场有关的）

### 徒手
- 先定接触距离：贴身 / 拳击距离 / 踢击距离。
- 用格挡、闪避、架开、抱架、破抱、失衡建立因果。
- **一次清晰重击 ＞ 五次看不清的连拳**；不是每次击中都写成击倒。
- 摔投前先交代抓握、入身或对方重心被破坏。

### 冷兵器
- 跟踪：武器类型、长度、持有者、**持握手（哪只手）**。
- 写明攻击方向：上 / 下 / 左 / 右、直刺 / 横扫；格挡说明接触点或被改变的线路。
- 长兵器需要挥动空间——狭窄场景限制其动作，并让"空间小"成为战术条件。
- 夺武器前先建立压制、卡住、抓腕或杠杆；**武器断裂 / 脱手 / 换手必须成为后续动作的真实变化**。

### 枪战
- 跟踪：掩体、射线方向、弹药 / 换弹状态。
- 每段设一个局部目标：转移掩体、压制出口、救援、突破、撤离。
- 角色暴露后必须移动、还击或退回掩体。
- 近距离枪与徒手转换时，先交代枪口被拨开 / 武器被卡 / 距离被压缩；避免多人在同一射线无差别开火。

### 玄幻 / 法术
- 能力要有可见的：准备 → 释放 → 效果 → 反制 → 代价；一段只突出一种主效果。
- 高速位移后交代落点和朝向；环境破坏要改变后续路线，不是纯装饰。

## 六、按人数分

- **一对一**：用试探、距离变化、假动作、破解、主动权转换；不要让同一人一直进攻、对手只挨打（除非剧情就是展示绝对压制）。
- **一对多（重点）**：
  - **同一时刻最多 1–2 名对手做精确的前景交互**；其余对手负责封路、接近、补位、倒地、扶起同伴或形成武器威胁。
  - 给对手分配不同功能：正面压迫、侧翼切入、低位抓抱、远端封路。
  - 一个敌人倒下后，交代他仍在空间中的位置（不必每段重复所有倒地者）。
  - **主角的移动路线必须解释"为什么没被所有人同时包住"**。
- **多对多**：每个 clip 只跟随一个局部目标或一组核心人物；背景战斗只建立规模、不逐人编排；焦点切换在"自然结果 / 空间转移"后进行。
- **Boss 战**：每个阶段改变"Boss 行为 / 场地规则 / 弱点窗口"中的至少一项；一次 clip 只完成一个阶段目标（观察招式、逼出弱点、避开范围、利用场地、完成反击）。

## 七、摄影策略（一个 clip 先选一种）

| 策略 | 适用 | 输出 |
|---|---|---|
| **逐镜头分镜（默认）** | 常规动作戏 | 用多个不同观看重点覆盖完整动作 |
| **连续跟拍 / 一镜到底** | 用户明确要求 | 正文只输出一个连续镜头（格式见 31 号） |
| **隐藏剪辑** | 有遮挡物规律经过画面 | 遮挡前后人物 / 武器状态保持一致 |

- **摄影机运动必须完成一种功能**：建立距离、揭示侧翼、跟随位移、强调结果。没有功能的绕拍、翻滚、高速推拉一律删。
- 先建立空间站位和**动作轴**（类似对话轴线，沿双方攻防方向），再为每镜选机位；普通切镜保持在动作轴同一侧，越轴需中性镜头或连续运镜（同 02 号轴线逻辑）。

### 镜头参数选择（详细光圈 / 焦段对照见 31 号渲染器）

- 24–35mm：空间、全身动作、低角度冲击、明显位移。
- 35–50mm：中景攻防、自然透视。
- 80–100mm：近景、表情、抓腕、锁颈、局部打击。
- 135–200mm：极窄细节、强压缩、远距离观察；狭小室内先确认拍摄距离。
- f/2–f/2.8：浅景深特写 / 主观反应；f/4–f/5.6：需同时看清双方动作 / 前后层次。

### 第一视角（POV）
- "A 第一视角拍 B"＝机位在 A 的眼睛位置、画面主体是 B；**除镜子 / 反射外，不能"A 第一视角拍 A"**。
- POV 切换前后保持：动作手、攻击方向、人物左右一致；用于"看见攻击逼近 / 受压 / 强调打击结果"，不连续滥用（02 号 POV 上限）。

## 八、打击反馈与连续性校验

**打击反馈（只留与主要动作相关的，别堆满）：**
- 力量方向；身体受力链和脚步变化；武器震动、衣物 / 头发跟随；一个环境次级反应；短暂恢复或新防御姿势。
- **镜头震动只用于决定性重击，且"轻微、短促"**；不要每次命中都加慢动作、粒子、镜头震动。

**连续性校验（跨镜头逐条核）：**
- [ ] 上一镜抓住的手腕，下一镜仍是同一只；右手锁颈，下一镜不能无因变左手。
- [ ] 同一动作换角度时，是否用了"顺势 / 承接 / 同时 / 动作未停"说明仍在继续？
- [ ] 搓步（前 / 后）和人物画面方向是否与空间站位一致？
- [ ] 特写结束后，下一全景里的身体位置是否与特写的动作结果相符？
- [ ] 切镜是否保持在动作轴同一侧？越轴是否有中性镜头 / 连续运镜？
- [ ] 武器持有者、持握手、倒地者位置跨镜头是否连续？

## 九、动作戏自检（输出前必过，叠加 02 / 26 / 29 自检）

- [ ] 每个攻防单元是否按"局势距离→发起→防守命中→受力位移→恢复"五段写、且环环有因果？
- [ ] 是否消除了"激战 / 缠斗"这类无信息词、以及互不产生结果的招式罗列？
- [ ] **动作单元与镜头是否分清**？多镜头覆盖同一动作时，动作有没有重复发生？
- [ ] 攻防单元数量是否在容量内（15s 2–3、30s 5–8）？镜头是否覆盖了每个关键阶段？
- [ ] 真人写实五要点（重心脚步 / 距离 / 受力反应 / 体力 / 可读防守）是否做到？
- [ ] 一对多是否同时只 1–2 人精确交互、其余有明确功能、主角路线合理？
- [ ] 运镜是否都有叙事功能、且不比人物更剧烈？
- [ ] 参数（焦段 / 光圈）是否匹配动作目的？
- [ ] 是否合规（无血腥 / 刺穿 / 暴力慢放）？是否对照 29 号确认 AI 能稳定生成、复杂段已拆？
