# 13. 封面设计规范（电影海报风）

> 本文件基于用户指定的标杆账号封面风格拆解。每次出封面前必须读这个文件。

## 一、标杆风格核心原则

**封面不是截图加字，是一张电影海报。**

观众刷到封面时，应该像在电影院看到海报一样——被画面氛围吸引，被片名勾起好奇，想点进去看。

## 三、设计规则（从上面总结）

### 1. 构图规则

- **人物在画面中下部或中间，占画面1/2到2/3**，上方或一侧留空给标题
- **中景/全景为主**：拍人的全身或大半身，不要大脸特写怼镜头
- **优先背影、侧脸、低头**：人物不需要看镜头，情绪靠场景传
- **人物穿旧衣服、有生活质感**：不要精致妆造，要真实感
- **画面必须有一个"环境主角"**：路、窗、门、面摊、抽屉、路灯、雪——环境本身就在讲故事

### 2. 标题文字规则（主推荐风格：左侧竖排巨大毛笔字）

> **主页封面格子很小，字小了看不清。以下是经过主页实测验证的主推荐版式，每次出封面默认用这个。**

**A. 主推荐版式：左侧竖排巨大白色毛笔书法字**
- **字体必须是毛笔书法体**：要有笔锋、飞白、手写感、粗细变化，像"茶汤""第100条语音""薄银""冰箱""招娣"那种——**不是普通粗黑体、不是综艺体、不是宋体**
- **字号巨大**：标题占画面宽度1/3到1/2，占画面高度2/3以上，在主页小格子里一眼就能看清
- **位置：竖排靠左**，从上到下排列，字顶到画面上方1/6处（不要顶到最上沿），字底到画面中下部
- **颜色：白色**（暗底上），不要加描边、不要加阴影、不要花字
- **片名长度**：2-6字最佳（"茶汤""招娣""薄银""栖野""冰箱""第100条语音"），字越多字号越小，尽量短
- **不挡人物面部和关键道具**：人物放在画面右侧或右下，让开左侧字区

**B. 为什么是这个版式（不要改）**
- 主页封面是小格子，横排大字会挡画面主体
- 顶部小字（像"招娣"那种）在小格子里根本看不清
- 右侧竖排也可以，但左侧是首选（视觉从左往右读）
- 毛笔书法字自带电影感和人文气，比黑体高级

**C. 其他版式（备选，不常用）**
- 横排顶部居中：只适合片名≤3字、且顶部是空场景时
- 横排底部：尽量不用，会被平台UI挡住
- ❌ 不要用：顶部小字+多行说明文字（在小格子里看不清）、花字贴纸、渐变字、描边字

**D. 副标题（可选，尽量不要）**
- 主页小格子里副标题根本看不清，默认不加
- 如果要加，极小字紧贴主标题旁边，补充情绪，可有可无

**E. 抖音封面安全区（P0红线，踩过的坑）**
- **抖音主页实际显示比例 ≠ 9:16整图**：上传9:16图后，抖音只显示中间约3:4的区域，**上下各会被裁掉一截**。如果标题大字顶到画面最上沿和最下沿，在主页小格子里字会被上下裁断
- **标题文字必须放在"中间安全区"内**：
  - 标题顶部距离画面上边缘至少 **15%** 的高度
  - 标题底部距离画面下边缘至少 **20%** 的高度
  - 竖排大字从画面上方1/6处开始，到画面中下部结束，**不要顶到画面最顶和最底**
  - 提示词写法："标题文字位于画面垂直方向中间区域，上下留出充足边距，不顶到画面上下边缘"
- **生成后必须在脑子里模拟一次抖音裁切**：想象上下各裁掉15-20%，剩下中间那块里，字是不是完整？人物脸是不是还在？如果字被切了就重出
- **白框测试**：把生成的图想象成上下各遮掉一条，中间那块才是观众在主页看到的——所有关键信息（标题、人物脸、关键道具）必须在中间那块里

**F. 禁止AI脑补多余招牌文字（P0红线，踩过的坑）**
- AI在生成街景/霓虹/商铺场景时，会**自作主张往招牌、灯箱、墙上加可读的汉字**（比如"牛来城""城影城""来杯好茶""永忱保质明"这种胡编乱造的词）
- 这些字不是我们要的，在封面小格子里显得很乱、像没P干净
- **提示词里必须明确禁止**："背景招牌、灯箱、墙面、路牌上的文字模糊不可辨认，不要出现任何可读汉字，不要出现任何招牌文字"
- 街景类场景写："虚化的霓虹光斑，招牌文字模糊散景，不可辨认"
- 人物脸、道具特写、室内场景一般不会有这问题，但街景/雨夜街道/老巷类必须加这句

### 3. 色调规则

- **电影感冷暖对比**：暗部冷蓝/深蓝，亮部暖黄/橙
- **常见配色方案**：
  - 深夜+路灯黄（雨夜、门口、街道）
  - 黄昏夕阳+远山（归途、离别）
  - 煤油灯+暗褐（怀旧、秘密）
  - 雪+暖黄蒸汽（冬日、食物）
- **整体偏暗但不死黑**：电影感来自光影层次和冷暖对比，**不是把画面压成黑片**。人物面部、关键道具、环境墙面都要清晰可见，暗部要有细节，不能一团死黑
- **曝光适中**：选有明确主光源的时刻（傍晚窗光/下午斜阳/灯泡/路灯），让主光照亮人物和道具；不要纯深夜、不要纯黑环境、不要只靠轮廓光勾边
- **电影感 ≠ 黑**：正确状态是"暗调氛围但每一处都看得清"；错误状态是"人物脸看不清、背景一团黑、道具隐在阴影里"
- **提示词必带**："整体曝光适中，明亮通透不死黑""人物面部清晰可见""画面明亮可见"

### 4. 场景符号库（什么情绪配什么场景）

| 情绪/主题 | 推荐场景元素 |
|---|---|
| 等待/回家 | 雨夜门口、路灯下、村口、车站 |
| 思念/回忆 | 旧抽屉、煤油灯、老照片、旧物、窗、打开的冰箱/柜子里的旧饭盒 |
| 孤独/归途 | 山间土路、远山、一个人走路、黄昏 |
| 温暖/善意 | 面摊、馒头店、热汤、蒸笼冒气 |
| 错过/遗憾 | 背对背、两个人剪影、黄昏湖面 |
| 亲情/母爱 | 母亲站门口、递碗、牵手、老屋 |
| 成长/兄弟 | 一群孩子、旧楼、学校 |
| 年代/委屈/童年 | 斑驳土墙、褪色年画、福字、蹲地择菜/缝衣、搪瓷盆、旧铝饭盒 |

### 5. 禁止事项

- ❌ 大脸特写怼镜头（我们之前做的那版是错的）
- ❌ 标题写成公众号说明文（"她竟然……""结果……"）
- ❌ 大平光、综艺式打光、没有光影层次（但也不要暗到死黑）
- ❌ 人物看镜头摆拍感
- ❌ 花哨字体、花字、贴纸
- ❌ **AI脑补的乱招牌文字**：街景/霓虹/商铺场景里，背景招牌灯箱上出现可读汉字（如"牛来城""城影城"这种胡编词）——提示词必须写"招牌文字模糊不可辨认"
- ❌ **标题顶到画面上下边缘**：抖音主页会裁掉上下15-20%，标题字会被腰斩——必须放在中间安全区

## 四、封面提示词模板

生成封面图时用这个结构：

```
竖屏9:16，电影海报质感，整体曝光适中明亮通透不死黑。[时间/天气]，[场景描述]，[人物在画面右侧/右下，背影或侧脸，中远景，人物面部清晰可见]。[前景必须有一个关键道具特写，占画面下部]。[光源和色调：冷蓝环境+一点暖光]。画面左侧竖排巨大白色毛笔书法字"[片名]"，字体苍劲有力有飞白笔锋，占画面宽度1/3到1/2，标题位于画面垂直方向中间区域（上下留出充足边距，不顶到画面上下边缘），不遮挡人物。整体低饱和度电影色调，空气透视层次（近实远虚、远景带雾），氛围感强，画面明亮可见。背景招牌灯箱上的文字模糊不可辨认，不要出现任何可读汉字。
```

横版16:9提示词把上面改成：
```
横屏16:9，电影海报质感，整体曝光适中明亮通透不死黑。[同场景描述，人物居中偏下，左右环境延展]。[前景关键道具]。画面上方横排巨大白色毛笔书法字"[片名]"（或左侧横排），字体苍劲有力有飞白，不遮挡人物。其余同上。
```

### 已验证成功的封面配方（用户实测满意，直接套用）

> 以下两个配方是用户看过并点头的，**亮度、构图、道具、字的位置都经过主页小格子验证**，写类似题材时直接参考。

**配方A：《冰箱》—— 思念/亲情类（冷蓝环境+暖黄道具光）**
```
竖屏9:16，电影海报质感，整体曝光适中明亮通透不死黑。傍晚老旧厨房，柔和的冷蓝调自然光从旁边窗户透进来，画面右侧一个穿旧棉袄的中年女人侧身站在打开的老式双门冰箱前，低头凝视冰箱内部，侧脸，中景，人物面部清晰可见。前景冰箱内部被里面昏黄的灯泡照亮，架子上摆着几个用保鲜膜包好的旧饭盒、剩菜、贴着泛黄便签的玻璃罐。画面左侧竖排巨大白色毛笔书法字"冰箱"，字体苍劲有力有飞白笔锋，占左半边画面宽度1/3，标题位于画面垂直中间区域上下留出边距，不遮挡女人。整体电影色调，冷蓝环境光+冰箱内暖黄灯光对比，适度低饱和但不灰暗，空气透视层次，胶片质感，思念情绪，画面明亮可见。
```
**可复用公式**：傍晚窗光（冷）+ 打开的家电/抽屉/柜子里那点暖光（道具自己发光）+ 人物侧身低头凝视。适合"旧物里藏着思念"的题材。

**配方B：《招娣》—— 年代/委屈/亲情伤害类（暖黄斜阳+土墙暖色）**
```
竖屏9:16，电影海报质感，整体曝光适中明亮通透不死黑。九十年代北方农村堂屋，下午暖黄斜阳从门口斜射进来，整个堂屋明亮温暖，画面右侧一个扎着麻花辫、穿旧红花布棉袄的十几岁小女孩蹲在地上择菜，侧脸，中景，人物面部清晰可见。前景地上放着一个掉漆的搪瓷盆，盆里是青菜，旁边一个旧铝饭盒。背景是斑驳土墙，墙上贴着褪色的年画和一个红色"福"字。画面左侧竖排巨大白色毛笔书法字"招娣"，字体苍劲有力有飞白笔锋，占左半边画面宽度1/3，标题位于画面垂直中间区域上下留出边距，不遮挡女孩。整体电影色调，暖黄阳光+土墙暖色为主，适度低饱和但不灰暗，空气透视层次，胶片颗粒，生活质感，克制委屈的情绪，画面明亮可见。
```
**可复用公式**：下午斜阳从门口斜射 + 人物蹲/坐小、低头做家事（择菜/缝衣/烧火）+ 前景一个掉漆旧盆/旧饭盒 + 背景斑驳墙+褪色年画/福字。适合年代戏、家庭委屈、童年题材。

**两个配方共同的亮度要点**（之前踩过的坑）：
- ❌ 不要写"深夜、夜晚、纯黑、昏暗房间"——AI会压成死黑
- ✅ 写"傍晚/下午/黄昏"，并且要有明确光源（窗光、斜阳、灯泡）
- ✅ 提示词里必须出现"整体曝光适中""明亮通透不死黑""人物面部清晰可见""画面明亮可见"这几个词
- ✅ 保留冷暖对比，但暖光要够暖够亮，冷光不要压成全黑
- ✅ 街景/霓虹类必须加"招牌文字模糊不可辨认"，否则AI会脑补乱字

### 4.1 多规格封面输出（P0强制：每次必出横屏+竖屏两个版本）

> **每次出封面，必须同时交付一个横屏16:9 + 一个竖屏9:16，两个都要出，不能只出一个。** 用户没说要不要横屏也必须出——这是默认动作。

一张封面设计，派生两种必交规格，**核心构图和氛围保持不变**，仅调整安全区和文字位置：

| 平台 | 比例 | 尺寸 | 调整要点 | 必交？ |
|---|---|---|---|---|
| 抖音/快手（竖版） | 9:16 | 1080×1920 | 竖版主规格。人物在中下部，标题竖排在左/右侧。上下留出平台UI安全区（顶部各留15%空白，底部留20%） | ✅ 必交 |
| B站/视频号/横版（横屏） | 16:9 | 1920×1080 | 横版。从竖版底图向左右扩展场景内容（路向两边延伸、天空加宽），标题改为横排顶部居中或左侧横排。人物在画面中下部 | ✅ 必交 |
| 小红书（3:4） | 3:4 | 1080×1440 | 可选，用户要才出 | 可选 |

**派生方法：**
1. 先生成9:16竖版主封面（信息最全、构图最完整）
2. **必须再生成一张16:9横版**：用image_gen重新生成时，把场景描述改为横版构图（人物居中偏下，左右环境延展），标题改为横排顶部居中或左侧横排毛笔字
3. **不要直接裁剪竖版图当横版用**——裁剪会切掉环境氛围，失去电影感；横版必须重新生成
4. 两个版本必须是同一场景、同一人物、同一色调，只是构图比例不同
5. 3:4小红书版用户要才出，默认不出

### 4.2 封面生成执行步骤

```
第1步：确定封面核心画面
  │  从正片中选一个最有氛围感的场景+人物组合
  │  要求：同场景同人物，能代表全片情绪基调
  │
  ▼
第2步：写两版提示词（竖版+横版）
  │  竖版提示词：按第四节模板，9:16，左侧竖排毛笔大字
  │  横版提示词：16:9，同场景同人物，标题改横排顶部或左侧横排
  │  两版都必带：低饱和度+空气透视+曝光适中不死黑+招牌文字模糊
  │
  ▼
第3步：并行生成两版封面（竖版9:16 + 横版16:9）
  │  两版必须同场景同人物同色调
  │  横版不要从竖版裁剪，必须重新生成
  │
  ▼
第4步：检查电影海报质感（对照第六节自检清单，两版都过）
  │  像不像电影海报？有没有死黑？标题会不会被裁切？有没有乱招牌字？
  │
  ├─ 不合格 → 调整提示词 → 重新生成
  │
  └─ 合格 ↓
第5步：交付封面
  │  ✅ 必交：9:16竖版 + 16:9横版（两个都要）
  │  可选：3:4小红书版（用户要才出）
```

> 📁 **标准项目目录归位（仅本地 Windows 模式）**：封面图本地归位到项目根目录 `D:\豆包产物\短剧项目\<项目名>\06_封面\`（横版/竖版/小红书版按规格命名）；云端 / Linux 环境以实际可写工作目录为准，不强制 D 盘结构。

## 五、高级感视觉关键词（提示词必带）

以下词是"显高级"的关键，**每次生成封面/视频提示词都要带上**：

### 1. 低饱和度（Desaturated / Muted）
- 画面颜色不鲜艳、偏灰、克制
- 去掉数码味/综艺感，显电影感
- **提示词写法**："低饱和度色调""色彩克制""去饱和电影调色""muted colors"
- **不要写**："鲜艳""色彩丰富""高饱和"

### 2. 空气介质透视 / 大气透视（Atmospheric Perspective）
- 前景清晰深暗，中景过渡，远景被雾/水汽笼罩变浅变蓝变模糊
- 让二维画面有三层空间深度，不扁平
- **提示词写法**："空气透视层次""近实远虚""远景带薄雾""前景深远景浅""atmospheric haze"
- **实现方式**：场景里加雾、烟、雨、灰尘、水汽；用逆光/侧逆光让空气可见

### 3. 曝光适中不死黑（Bright but moody）
- 画面要暗调有氛围，但每一处都看得清
- **提示词写法**："整体曝光适中""明亮通透不死黑""人物面部清晰可见""画面明亮可见"
- **不要写**："深夜、纯黑、昏暗、漆黑一片"——AI会压成死黑

### 4. 无乱招牌文字（Street scenes only）
- 街景/霓虹/老巷类必须加
- **提示词写法**："背景招牌文字模糊不可辨认""不要出现任何可读汉字""招牌散景虚化"

### 其他加分词
- **浅景深**（shallow depth of field）：人物清晰，背景虚化
- **电影级光影**（cinematic lighting）
- **胶片质感**（film grain / analog look）

## 六、自检清单

出完封面逐条过：

- [ ] 像不像一张电影海报？（不是截图加字）
- [ ] **标题是不是毛笔书法体？（有笔锋飞白，不是普通粗黑体/综艺体）**
- [ ] **标题是不是左侧竖排巨大字？（占画面1/3到1/2宽度，主页小格子里一眼能看清）**
- [ ] **标题字号够不够大？（缩到手机主页格子大小还能看清吗？看不清就是字太小）**
- [ ] 标题像不像电影名？（2-6字最佳，不是说明文）
- [ ] 人物是中景/全景，在画面右侧？（让开左侧字区，不是大脸特写）
- [ ] **前景有没有关键道具特写？（茶汤碗/冰箱饭盒/搪瓷盆/相框这种，占画面下部）**
- [ ] 色调有没有冷暖对比？暗调电影感？
- [ ] **画面是否过暗？（人物面部、关键道具、环境墙面是否清晰可见？有没有一团死黑？——如果人物脸看不清、背景全黑，必须重出）**
- [ ] **是否低饱和度？（不鲜艳、不数码味）**
- [ ] **是否有空气透视层次？（近实远虚、远景带雾、有空间深度）**
- [ ] 环境场景有没有在讲故事？（路/灯/窗/食物/雨/旧物）
- [ ] 人物有没有生活质感？（不是摆拍）
- [ ] **封面人物是否与正片角色一致？（面部特征、发型、服装是否匹配参考图和正片设定）**
- [ ] **【抖音安全区】想象上下各裁掉15-20%，中间那块里：标题字是否完整不被切？人物脸是否还在？关键道具是否在？如果字被腰斩，重出**
- [ ] **【无乱招牌文字】画面里有没有AI脑补的可读汉字招牌/灯箱/路牌？（如"牛来城""城影城"这种胡编词）——有就重出，提示词加"招牌文字模糊不可辨认"**
- [ ] **【双版本必交】是否同时交付了9:16竖版 + 16:9横版？两个都出了吗？（只出一个不算完成）**
- [ ] 远看标题能不能看清？
