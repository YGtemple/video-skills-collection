# 富士胶片纪实感画风预设（开箱即用 Prompt 配方）

> 定位：[14-cinematic-vocabulary.md](14-cinematic-vocabulary.md) 的"**打包成品**"。14 号是术语字典，本文件是可整段复制的画风预设（preset）。
> 用法：整段贴到 AI 图片/视频 prompt 的**末尾**统一全片调性；或在剪映/调色里照着调。
> 效果：**暖、旧、真、有颗粒**，像真人手持拍下的真实瞬间，而不是数码的光滑塑料感。

---

## 一、七要素配方（可直接复制）

> 富士胶片模拟，暖黄滤镜，真实环境光，轻微手持摇晃，轻微低饱和，胶片颗粒，微暗角

| 要素 | 作用 | 给人的感觉 |
|---|---|---|
| **富士胶片模拟** | 套用富士胶卷色彩科学（如 Classic Chrome / Nostalgic Neg） | 像胶卷拍的，克制、高级 |
| **暖黄滤镜** | 色温偏暖偏黄，如午后阳光/老照片 | 温暖、怀旧、年代感 |
| **真实环境光** | 只用现场自然光/窗光/灯光，不硬补光 | 光影自然、临场、可信 |
| **轻微手持摇晃** | 带一点真人手持的呼吸晃动 | 纪实、像在现场（**必须轻微**，晃狠会晕、显廉价） |
| **轻微低饱和** | 颜色压灰、不鲜艳 | 电影感、克制、有情绪 |
| **胶片颗粒** | 加细密银盐颗粒噪点 | 有材质、复古，盖住 AI 的塑料光滑感 |
| **微暗角** | 四角轻微压暗，视线引向中心 | 有氛围、有层次、老镜头味 |

---

## 二、配合反转：画风"由暗转亮"（关键用法）

当与 [20-oppression-salvation-formula.md](20-oppression-salvation-formula.md) 等强反转结构配合时，让**质感随情绪一起反转**：

| 阶段 | 画风处理 | 情绪 |
|---|---|---|
| **压迫 / 年代 / 困境段** | 保留暖黄 · 颗粒 · 暗角 · 低饱和 | 压抑、真实、陈旧 |
| **反转 / 解放 / 新生段** | 提亮 · 去暗角 · 画面通透 · 色彩回暖 | 希望、新生 |

观众在画面质感转变的瞬间，会更强烈地感受到"天亮了"。

## 三、适用 / 不适用

**适合 ▸**
- 年代怀旧、童年回忆、父辈故事
- 纪实/纪录片、**伪老影像（伪档案 footage）**
- 走心情感、家庭亲情、人间烟火、生活流 vlog、复古 MV
- 广告里的"真实用户感"、品牌情绪片

**不适合 ▸**
- 要干净鲜艳的产品广告（美妆、数码、美食通常要鲜亮清晰）
- 冷感都市、科幻、赛博朋克
- 需要看清细节/文字的画面（颗粒＋暗角会发糊）

---

## 四、剪映 / 调色手动实现

色温往暖（+黄）→ 饱和度略降 → 加胶片颗粒 → 加轻微暗角 → 手持抖动（幅度调到轻微）→ 对比度按胶片曲线微调；反转段把亮度拉高、暗角归零。

---

## 五、使用检查

- [ ] 七要素是否完整（或按题材合理取舍）？
- [ ] 手持晃动是否控制在"轻微"？
- [ ] 有反转时，是否做了"由暗转亮"的画风切换？
- [ ] 是否避开了"不适合"的题材？
