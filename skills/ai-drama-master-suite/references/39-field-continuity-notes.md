# 场记与连续性状态交接手册（真人实拍分镜的"文字场记表"）

> **定位**：本文件把"分镜组与分镜组之间、镜头与镜头之间，下一秒画面必须长成什么样"写成一张**可交接的文字场记表**。它吸收真人实拍场记的连续性状态记录方法——逐镜记下角色位置/朝向/服装/道具/视线/段末可见状态，并在 30 秒组边界做状态交接与自检。
>
> **与已有规范的分工（一句话，不重复它们）**：
>
> | 文件 | 管什么 | 形态 |
> |---|---|---|
> | [24 号机位底图](24-camera-plates-lock.md) | 静态房间/机位/透视/光源方向不变 | 图像锚点 |
> | [25 号俯视图调度图](25-floor-plan-blocking-diagram.md) | 走位"应该怎么走"的前期规划 | 规划图 |
> | [28 号连贯规则](28-continuity-editing-rules.md) | 为什么这么接才顺（轴线/30°/动作接动作/视线匹配的**原则**） | 编辑原则 |
> | [31 号结尾状态](31-standoff-style-lock-continuity.md) | 跨段文本最小连续性的简写 | 一行交接 |
> | [33 号技术全景锚点](33-tech-panorama-anchor.md) | 组末整空间状态的**图像**快照（从已生成视频截帧） | 图像锚点 |
> | **本文件（39）** | **每个镜头/每组结束时"拍得到的可见状态"逐字记录 + 组间文字交接卡 + 边界自检清单** | **文字场记表** |
>
> 一句话：24/33 管视觉锚点（画），39 号管文字场记（写）；28 号讲"为什么"，39 号给"记什么、怎么交、开下一组前怎么对"。33 号那张组末状态快照表，其事实来源就是本文件的文字场记——39 先把状态写成字，33 再把同一组事实变成锚点帧，两者共用一份状态、不互相重写。

## 主控语境（硬约束）

- 真人写实短剧、横屏 16:9；分镜组默认一次 30 秒一组（铁律 36）。
- 视频默认 Seedance 2.5；**不出关键帧/首尾帧定帧（铁律 30）**——本文件**不要求另画首帧图**，只要求把"本段第一帧应该看见什么"写成清晰文字；需要整空间图像锚点时走 33 号从已生成视频截帧，不新做定帧。
- 段间必做衔接（铁律 31）：上一组的场记末端状态，就是下一组提示词的开场事实。
- 工程编号（点位代号、ST/CL/NP 等）只在内部场记表里用，**投喂 Seedance 时必须翻成自然语言画面**，不写编号。

## 一、场记要记哪些"拍得到的状态"（逐镜记录维度）

场记只记**摄影机下一秒能验证的可见事实**，不记心理、不记评价。每个镜头结束、以及每 30 秒组结束时，按下面这张表逐栏填；填不出"具体值"的栏目就是下一组会穿帮的地方。

| 维度 | 要记到的具体值（示例） | 不能只写 |
|---|---|---|
| 角色位置 | 谁在画面左/右、前景/中景、靠哪个环境锚点（靠窗、桌左、门框边） | "在那边" |
| 身体朝向 | 面向画面左/右/镜头/背对；与谁正对 | "面对面" |
| 视线落点 | 眼睛具体看哪（对方眼睛 / 手中杯 / 门口 / 地面） | "看着他" |
| 姿势残留 | 段末停在什么动作上（手抬到嘴前、半转身、椅边前倾、刚摔撑地） | "站着" |
| 服装状态 | 颜色+版型+配饰+破损/褶皱（白衬衫左袖挽起、夹克拉链拉到胸） | "穿衣服" |
| 伤势/妆容 | 右脸擦伤、嘴角干了的血迹、额角汗、刘海粘脸 | "受伤了" |
| 手持道具 | 谁的左手/右手拿着什么；道具朝向（见第三节） | "拿着东西" |
| 道具位置 | 放下的道具落在画面哪、液位/长度/开合状态 | "桌上有杯子" |
| 环境状态 | 门开多少、窗帘位置、灯亮灭、雨/烟/尘、桌椅翻倒 | "在室内" |
| 光线/时间 | 主光从哪侧来、冷暖、时间感（连续/跳秒/跳时） | "有光" |
| 摄影机侧 | 主机位在轴线哪一侧、本镜景别、运镜停在哪 | "拍他" |
| 情绪能量 | 段末情绪余韵一句话 + 能量等级（低/中/高/顶点） | "很激动" |

> 规则：**栏栏写具体值**。"杯里半杯奶茶、吸管推到杯口右侧" ✅；"杯里有奶茶" ❌。AI 视频模型最容易在服装、道具、视线、左右位置上漂移，这几栏必须最具体。

## 二、跨组交接卡（每 30 秒组结束必出，向下一组传递）

每组正片结束、进入下一组之前，把本组末镜状态压成下面这张交接卡。它是下一组提示词"开场事实"的唯一来源，也是下一组首镜对账的依据。

```text
═══════════════════════════════════════
【G0X 组末场记交接卡】（交给 G0(X+1)）
═══════════════════════════════════════
① 末镜机位轴线侧：主角 A 在画面__侧、对手 B 在画面__侧；主机位在轴线__侧
② 末镜景别：远景/全景/中景/近景/特写/大特写
③ 末镜运镜：固定 / 推 / 拉 / 横移(方向) / 升 / 降 / 手持 / 跟 / 快切
④ 末镜视线：[角色] → 画面__侧（或：空镜/门帘静止，无角色视线）
⑤ 角色姿态：[A]=位置+朝向+段末残留动作；[B]=…（多人逐人写）
⑥ 服装状态：[A]=颜色/版型/配饰/破损；[B]=…
⑦ 关键道具状态：[道具]=在谁手/落在何处/朝向/开合/液位；环境元素=雨/烟/光
⑧ 光线与时间：光源方向+色温；时间感=同时刻连续 / 隐含跳秒 / 明确跳时
⑨ 情绪余韵：一句话 + 能量等级(低/中/高/顶点)
⑩ 必延续清单：至少 3 项——下一组不准漂移的事实（如：白衬衫+右手握门把+灯从右窗入+两人隔桌）
⑪ 观看理由接力：本组钩子是否完成 / 留给下一组的悬念或动作牵引
【转场类型】（勾选其一）：
  □ 同时刻同场景延续（①~⑨全延续）
  □ 同场景隐含跳秒（≤1分钟，姿态/情绪可微调，其余延续）
  □ 同场景明确跳时（>1分钟，需过场/字卡，状态可部分重置）
  □ 跨场景硬切（需导演意图+B-roll/音乐桥，首镜不得同景别同方向）
  □ 闪回/梦境/平行剪辑（需调色/滤镜声明，非线性）
═══════════════════════════════════════
```

填写硬约束：
- 11 栏缺一不可；道具/服装栏必须写具体值，禁止"延续上一镜"。
- ⑩ 必延续清单至少 3 项；动作/同场景强连续段额外加"点位、轴线侧、摄影机安全侧"。
- 转场类型必须勾选其一；选了"跳时/跨场/闪回/平行"就要走第六节的"允许重置维度"，不能默默漂。
- 工程点位代号只留在括号备注里，正文同时写成可见画面（"A2=茶几左侧"→"角色站在茶几左侧"）。

## 三、三类最易漂移的专项记录细则

### 3.1 道具状态（AI 重灾区）
- 同一道具跨镜要延续：半杯奶茶下一组还是半杯；燃着的烟几秒后应更短、烟灰更长。
- **小道具朝向锁**（手机/照片/证件/信封）：写清正反面——"手机背面朝镜头、屏幕贴手心不可见"；若剧情要看 UI，写"屏幕朝镜头，只显示指定内容"。禁止手机背面自发亮起屏幕、正反面都是屏。
- **单实例锁**：某道具已在场景/首帧里可见，又另有道具参考图时，记清"这是同一件、全片只此一件；参考图只补外观，不新增第二件"。角色拿起后，原位置必须变空——手里和桌上不得同时各有一件。
- 道具易主/断裂/脱手后，把新归属写进交接卡 ⑦，作为后续动作的真实条件。

### 3.2 服装与外观
- 同组同场不换装：交接卡 ⑥ 记颜色+版型+配饰+破损。换穿、换装、破损累积（撕袖、沾灰）必须有剧情依据，并在转场类型里声明。
- 发型、帽、眼镜、首饰跨组连续；动作戏里的擦伤/汗/凌乱随打斗累积，逐组加重而不是忽有忽无。

### 3.3 视线与屏幕方向
- 交接卡 ④ 记下角色段末"看向画面哪一侧"；下一组首镜必须接住这个方向（他看画面右，下镜被看对象就从右出/反应朝右）。
- 移动/追逐人物的屏幕方向跨组固定（被追者一直向右逃、追者同向右追）；要换向，中间用一个转弯/正面镜头交代。

## 四、开下一组前：首镜对账清单（逐条核，任一不过就修）

生成 G0(X+1) 第一个镜头之前，拿上一组交接卡逐条对：

- [ ] **轴线侧**：本组首镜机位仍在上一组末镜的轴线同侧？（合法越线须有跟随换位/中性镜头/带机过线，见 28 号）
- [ ] **景别**：首镜景别与上一组末镜不同级？（同景别直切=跳切，除非刻意）
- [ ] **运镜衔接**：首镜运镜与上一组末镜属同向/反向/静切动/动切静/同质叠加之一？
- [ ] **视线**：接住了交接卡 ④ 的视线方向？
- [ ] **姿态**：首镜角色姿态延续度 ≥60%，没有凭空跳到另一个姿势？
- [ ] **服装**：与交接卡 ⑥ 一致？换装须有合法情境。
- [ ] **道具**：手持/位置/朝向/液位与交接卡 ⑦ 一致？该空的位置空了？
- [ ] **光线/时间**：光源方向、色温与交接卡 ⑧ 一致？跳时/跨场已声明。
- [ ] **情绪能量**：首镜承接上组余韵，或属于节拍要求的合法转折？
- [ ] **转场**：与交接卡勾选的转场类型实际开镜方式吻合？
- [ ] **无"空话承接"**：没有只写"承接上一段/仍然/继续"却不写第 0 秒可见事实——本组第一帧状态已改写成具体画面？
- [ ] **需图像锚点时**：同场景跨组、多人走位/道具交接复杂的，已按 33 号挂上一组技术全景锚点帧核对"实际走位终点=规划终点"？

任一不过 → 修接缝处镜头并同步更新交接卡，再开下一组。

## 五、段边界自检诊断清单（分镜组出口前过一遍）

每组分镜写完、生成前，把下面当"分镜边界体检表"过：

- [ ] 本组是同场景连续、隐含跳秒、明确跳时、还是跨场景/闪回？转场类型写明了吗？
- [ ] 若**同场景连续**：交接卡 11 栏齐了？首镜对账清单过了？
- [ ] 若**同场景但隐含跳秒**：角色位置、道具、光线没被偷偷重置？
- [ ] 若**明确跳时/跨场**：有没有过场镜头/字卡/音乐桥交代？首镜是不是定场镜头（让观众先知道"在哪、什么时间"），而不是直接两个大脸特写？
- [ ] 若**闪回/梦境**：有没有用调色/滤镜/光影把它和现实区隔？回到现实时有没有现实锚点？
- [ ] 有没有把"承接上一段"这种空话写进提示词，却没写第 0 秒画面事实？
- [ ] 公共空间：人群密度写了吗（前景/中景/远景人数、是否看镜头、是否挡主角脸）？私密空间有没有写"不出现额外人物/路人"？
- [ ] 关键台词有没有被环境声/动作声盖掉？
- [ ] 本组是否最后一组？是则不挂 33 号技术全景锚点；不是则组末要留状态快照供下组。

## 六、合法非延续：哪些维度可以"重置"（不是所有跨组都硬接）

下列情境允许在**已声明转场类型**的前提下，重置部分连续性维度；重置 ≠ 自由漂移，其余栏仍要延续。

| 情境 | 可重置的维度 | 必须配套 |
|---|---|---|
| 明确跳时（"三天后"） | 时间连续性 + 部分状态（服装/道具可换、伤势可变化） | 字卡/过场镜头/时间标识 |
| 跨场景硬切 | 位置/朝向/道具/景别/时间几乎全换 | 导演意图声明 + B-roll 或音乐桥；首镜不得同景别同方向 |
| 闪回 / 梦境 | 几乎全部 | 调色/滤镜/转场效果声明；情绪须服务当前剧情 |
| 平行剪辑 | 轴线/视线/道具相对关系 | 用音乐/主题/节奏统一；两线时间是否同步要写明 |

> 即便在这些情境下，交接卡也照常出——只是把"必延续"改成"明示重置 + 重置理由"。不要因为换了场景就删掉段末状态与下一组开场事实。

## 七、项目级风格交接标记（ST / CL / NP）

当项目已有统一视觉资产时，场记表顶部可带三个项目级标记（内部代号，投喂前必翻成自然语言）：

- **ST（视觉风格锁）**：项目整体画风、人物审美、场景审美、质感颗粒——只锁"风格方向"。
- **CL（色彩/光影设计）**：本场景的光影基调、冷暖、反差。
- **NP（风格防跑偏负面词）**：本项目禁止的画风/脸模/质感（如不要网红塑料脸、不要 2D 扁平感）。

使用规则：
- 本组光影与 CL 冲突时，**以本段真实光源和剧情时段为准**，只保留 ST 的质感、反差、颗粒和 NP 的禁止项。
- 进入 Seedance 提示词时，ST/CL/NP 全部译成自然语言画面，**不写编号**。
- 本文件不重复 [15 号一致性资产] 与 [21 号画风预设] 的建表方法，只规定它们如何在组间被交接。

## 八、AI 漂移高发点 → "限制"栏写法速查

| 漂移点 | 写进提示词的限制句（示例） |
|---|---|
| 服装突变 | 角色服装颜色/版型/配饰与上一镜完全一致，不换装 |
| 道具消失/复制 | 桌上手机只此一部；角色拿起后桌面原位变空，不出现两部 |
| 手机乱亮屏 | 手机背面朝镜头、屏幕贴手心不可见；背面不出现发光 UI/文字 |
| 视线乱飘 | 角色视线落在具体对象上，不看镜头、不左右乱飘 |
| 左右互换 | 角色 A 始终画面左、B 始终画面右；摄影机保持两人正前方这一侧 |
| 公共空间变空 | 按人群密度：前景/中景/远景各有人流，路人不看镜头、不挡主角脸、不同脸复制 |
| 私密空间乱加人 | 不出现额外人物、路人、群演，场景只保留剧本角色 |
| 自动加字/BGM | 无字幕、无水印、无屏幕文字、无背景音乐 |

## 九、填好的样例（一组双人夜戏末态）

```text
【G03 组末场记交接卡】
① 轴线：林晚画面左、母亲画面右；主机位在两人连线南侧
② 景别：近景
③ 运镜：固定
④ 视线：母亲低头扒饭、不看林晚（无对视）
⑤ 姿态：林晚=画面左桌旁、抬头眼眶红、手悬在碗边；母亲=画面右、低头扒饭、侧脸
⑥ 服装：林晚=深色外套、左袖挽起；母亲=灰旧家居衫、袖口起毛
⑦ 道具：桌上三盘菜冒热气、排骨已夹进林晚碗；门在画面左侧半掩；暖黄顶灯
⑧ 光线：暖黄顶灯自上方偏右；同时刻连续
⑨ 情绪：鼻酸克制（能量 6/10，往下沉）
⑩ 必延续：林晚深色外套+抬头红眼 / 母亲灰衫低头侧脸 / 排骨在林晚碗里 / 暖黄顶灯
⑪ 接力：本场情绪已"成全"转正，下一组给林晚临行/离别的行动牵引
转场：☑ 同时刻同场景延续
```

下一组首镜对账：机位仍在南侧、景别从中近起（与近景不同级）、接住母亲低头不看的视线、林晚外套与碗里排骨延续、暖黄光不变——通过，进入生成。
