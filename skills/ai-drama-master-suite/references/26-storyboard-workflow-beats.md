# 分镜全流程工作法：从剧本到镜头的七步拆解（含戏剧节拍 Beat）

> 定位：02 号《分镜设计规范》是"红线手册"——写满了**不能做什么**（光源、物理、站位、频率上限）；本文件是"操作手册"——解决"规则我都看过，可一拿到剧本还是不知道镜头怎么拆、拆出来很平"的问题。**先读本文件走流程，再用 02 号的规则逐条校验**。
>
> 配套：拆出的镜头最终按 [22 号分镜组模板](22-15s-storyboard-group-template.md) 输出；高频场景直接套 [27 号镜头配方](27-scene-coverage-recipes.md)；连贯问题查 [28 号](28-continuity-editing-rules.md)；AI 能不能稳定生成查 [29 号](29-ai-shot-design.md)。

---

## 〇、先纠正一个根本认知

**分镜不是"把一段文字切成几小块"，而是"把文字叙事翻译成镜头叙事"。**

- 文字靠"讲述"，镜头靠"让观众看到 / 听到"。同一个信息，可以用台词说、用动作演、用道具展示、用反应让观众读到——**分镜师的工作是为每一个信息选择"最有效的镜头表达"**。
- 判断一个镜头该不该存在，不看"剧本里有没有这句话"，而看 **"这个镜头要让观众看到什么、知道什么、感到什么"**——答不出来，就是废镜头，删或合并。
- 观众在镜头里**只相信他看到的**：角色说"我没事"但手在抖，观众读到的是"她在逞强"。分镜要主动设计这种"演出来的潜台词"，而不是把台词配个画面。

**三个层级（从大到小，逐层拆解，不要一上来就写镜头）：**

```
故事 Story
 └─ 场景 Scene（同一时间、同一地点的一段完整动作；一场戏必有一次"价值转折"）
     └─ 节拍 Beat（最小的动作 / 反应单位：一次台词交换、一个动作、一个反应、一次发现）
         └─ 镜头 Shot（为呈现某个 Beat 而选择的机位 / 景别 / 运镜）
```

> 新手最大的错误：跳过"场景 → 节拍"，直接把剧本按句子切成镜头。结果是**镜头数量对、但没有戏剧节奏、没有 coverage、该特写的地方在念台词、该反应的地方被跳过**。

## 一、七步工作法总览

```
Step 1  通读全片 → 切分场景（Scene），建《场景清单》
Step 2  给每场戏写《场景卡》：目标 / 冲突 / 价值转折 / 情绪起止 / 关键信息 / 伏笔
Step 3  戏剧节拍拆解（Beat Breakdown）：把一场戏拆成 Beat 表   ← 最核心
Step 4  空间与调度规划：俯视图、站位三要素、轴线、机位底图
Step 5  Coverage 覆盖机位：为每个 Beat 分配镜头，列必备镜头清单
Step 6  镜头排序 + 时长 / 台词字数换算，装进 30 秒分镜组
Step 7  段间衔接标注 + 过 02 号自检门
```

> 门控提醒：全部 Step 走完、分镜组产出后，先完整展示给用户，用户确认才进资产 / 提示词阶段（见 SKILL.md 阶段门控）。

## 二、逐步详解

### Step 1：通读全片，切分场景

先完整读剧本（不要边读边拆），然后按"**时间或地点发生变化即切新场**"的原则切分场景，建《场景清单》：

| 场号 | 地点 | 时间（日/夜、内/外） | 出场人物 | 一句话动作 | 时长预估 |
|---|---|---|---|---|---|
| 1 | 林家餐厅 | 夜·内 | 林晚、周慧兰 | 女儿临行前夜，母亲热菜、两人摊牌 | ~30s |
| 2 | … | | | | |

- 同地点但时间明显跳跃（如同一餐厅，从晚饭到次日清晨）→ 算两场。
- 一场戏的时长按"信息量 + 台词量"预估，不要为凑 30 秒硬拉长。

### Step 2：写《场景卡》（每场一张，30 秒填完）

在拆镜头前，先逼自己回答这场戏"**到底发生了什么改变**"：

```markdown
【场景卡 · 场X】
· 场景目标：这场戏在全片里要完成什么（推进什么剧情 / 揭示什么 / 改变什么关系）
· 人物目标：每个角色"想要什么"（A 想……；B 想……）
· 阻碍 / 冲突：什么挡着（目标对立 = 冲突；两人目标相反才好看）
· 价值转折（关键）：开场价值极性 → 结束价值极性
· 情绪起止：开场情绪(强度1-10) → 结束情绪(强度1-10)，中间峰值在哪
· 关键信息点：观众看完这场必须 get 到的 2-4 条信息
· 伏笔 / 回收：本场埋了什么 / 收了前面的什么
```

**价值转折（Value Turn）——判断一场戏成不成立的核心：**

每场戏都有一个在"正负极之间摆动"的价值（生死、爱恨、希望绝望、信任怀疑、自由压迫、理解隔阂、聚散……）。**开场时的极性 vs 结束时的极性必须发生变化**：

- 隔阂(–) → 理解(+)；希望(+) → 绝望(–)；怀疑(–) → 信任(+)；平静(+) → 危机(–)。
- **如果一场戏从头到尾极性没变（开场和结束是同一个状态），这是"无事件场景"——要么改写让它发生转折，要么删掉。** 这是消灭"流水账"最狠的一刀。
- 转折可以是"明转"（动作 / 台词直接造成）也可以是"暗转"（观众通过反应读到，角色嘴上没承认）。

### Step 3：戏剧节拍拆解（Beat Breakdown）—— 最核心的一步

**Beat（节拍）= 一场戏里最小的"动作 / 反应"单位。** 一个 Beat 通常是：

| Beat 类型 | 说明 | 例子 |
|---|---|---|
| 动作 Beat | 角色做一个动作 | 母亲把菜端上桌、女儿放下行李 |
| 对白 Beat | 一次有效的台词交换（一来一回可算 1-2 个） | "菜热第三遍了" |
| 反应 Beat | 角色听到 / 看到后的沉默反应（**最容易被新手漏掉，也最出戏**） | 夹菜的手停在半空 |
| 发现 Beat | 角色注意到 / 意识到某件事 | 女儿看到母亲白头发 |
| 决定 Beat | 角色做出选择 | "去吧" |

**怎么拆：** 把剧本这场戏按"谁对谁做了什么 / 说了什么 / 有什么反应"逐一切开，每个 Beat 一行，填《Beat 表》：

| Beat# | 谁 | 动作 / 台词（原词） | 潜台词 / 情绪 | 观众任务：要让观众看到·知道·感到什么 |
|---|---|---|---|---|
| B1 | 林晚 | 拖着行李进门，低头换鞋 | 愧疚、不敢看母亲 | **看到**行李（暗示要走）；**感到**气氛压抑 |
| B2 | 周慧兰 | 端菜上桌："回来了？菜热第三遍了。" | 嘴上平淡，实则等了很久 | **知道**母亲等了一晚上；读到"热第三遍"里的牵挂 |
| B3 | 林晚 | "妈，我后天走，公司调我去深圳。" | 硬着头皮摊牌 | **知道**核心事件：女儿要远行 |
| B4 | 周慧兰 | 夹菜的手停在半空，沉默 | 意外、不舍，压住情绪 | **感到**母亲的震动（靠停顿，不靠台词） |
| B5 | 周慧兰 | "……去几年？" | 声音放轻 | 读到母亲的不舍 |
| B6 | 林晚 | "不知道。" | 心虚 | — |
| B7 | 周慧兰 | 把排骨夹进林晚碗里："去吧。在外头，别老吃外卖。" | 用让步和叮嘱表达爱 | **感到**母亲从挽留转为成全（**价值在此转正**） |
| B8 | 林晚 | 抬头，眼眶红了 | 被理解后的崩溃边缘 | 读到女儿的情绪 |
| B9 | 周慧兰 | 低头吃饭，不看她 | 不让女儿看到自己的难过 | **感到**中国式亲情的克制（留白收尾） |

**Beat 拆解的三条铁律：**

1. **"观众任务"栏必填，且要具体到"看到什么"**——这是把文字转成画面的关键。填的是"热第三遍的菜""停在半空的筷子"，不是"母亲很爱女儿"这种抽象结论。
2. **反应 Beat 不能省。** 每一句重台词、每一次信息抛出之后，问"另一个人听到后的反应是什么？"——**情绪往往活在反应的停顿里，而不是台词里。** 新手的分镜全程在"说话"，高手的分镜一半在"反应"。
3. **一个 Beat 只干一件事。** 一个 Beat 里又动作又反转又交代信息，就继续往下拆。Beat 拆得越细，后面分配镜头越从容。

> 悬疑 / 信息差类戏的 Beat 有专门结构（观众知道而角色不知道），见 27 号"对峙 / 悬疑"配方与调研中的希区柯克 5-Beat。

### Step 4：空间与调度规划

Beat 知道"演什么"，这一步定"在哪演、怎么站、机器放哪"：

1. **画平面俯视图（多角色 / 有移动 / 群戏时必做）**：标出家具、门、窗，角色的位置与朝向、动线、摄影机位、180°轴线——方法见 [25 号平面俯视图与调度图](25-floor-plan-blocking-diagram.md)。
2. **写死站位三要素**（每个 ≥2 人同框的镜头）：左右位置 + 前后远近 + 朝向关系——规范见 02 号 3.5。
3. **定轴线**：对话场景画两人连线，摄影机统一在连线一侧，正反打不越轴——规范见 02 号 3.5.2。
4. **多段同场景**：先确立唯一空间，派生机位底图，每段首帧挂对应底图——见 [24 号机位底图锁定法](24-camera-plates-lock.md)。

> 这一步的产出是一张"空间 + 站位 + 机位"的底图，后面所有镜头都在这张图上取，杜绝站位乱跳、越轴、动线穿墙。

### Step 5：Coverage 覆盖机位（为每个 Beat 配镜头）

**Coverage（覆盖）= 为了把一场戏剪出来，需要拍到的全部镜头。** 不要只设计"一条主镜头走到底"，要给剪辑（也给 AI 生成的取舍）留出足够的角度和反应。

**一场标准对话戏的 Coverage 构成（按需取用）：**

| 镜头类型 | 作用 | 是否必备 |
|---|---|---|
| 定场 / 主镜头（全景 / 中全景） | 交代空间、人物位置关系 | 必备 1 个 |
| 双人镜头 Two-shot | 同框建立关系 | 多数对话戏必备 |
| 过肩正反打 OTS（A 过肩拍 B / B 过肩拍 A） | 对话主力，守住轴线 | 对话戏主力 |
| 单人特写 / 近景 | 重台词、情绪锚点 | 关键 Beat 必备 |
| 反应镜头 Reaction | 承接重台词、放大情绪 | **必备，最易漏** |
| 插入镜头 Insert（道具 / 手部 / 细节） | 传递信息、外化情绪、做剪辑点 | 有关键道具时必备 |
| 切出 / 空镜 Cutaway | 转场、留白、时间流逝 | 按需 |

**为 Beat 配镜头的方法：** 拿 Step 3 的 Beat 表，给每个 Beat 标注"用什么镜头呈现"，原则：

- **信息 / 叙事 Beat** → 中景 / 过肩（看得清动作和关系）。
- **情绪 / 反应 Beat** → 近景 / 特写（让观众读脸）；重锤情绪可反用景别（见 02 号景别反规则：崩溃反而拉远）。
- **关键道具 / 信息 Beat** → 插入特写（行李、停住的筷子、那碗排骨）。
- **开场 / 收尾** → 定场全景 / 留白镜头。
- 一场戏先保证"主镜头 + 正反打 + 关键反应 + 关键插入"都覆盖到，再考虑花哨运镜。

> 重要：**不是一个 Beat 必须配一个镜头**——一个长镜头可以覆盖几个 Beat（适合一镜到底的戏）；一个 Beat 也可能需要多个角度（如重台词给说话人特写 + 听者反应两个镜头）。按"剪辑时需不需要"决定。

### Step 6：镜头排序 + 时长 / 字数换算，装进 30 秒组

1. **排序**：按 Beat 的戏剧顺序排列镜头；对话戏一般是"定场 → 双人 / 过肩建立 → 正反打推进 → 反应 / 插入 → 收束"。
2. **分配时长**（所有镜头时长合计＝该组分镜设定时长）：
   - 30 秒组通常 3–6 镜，平均每镜 5–8 秒；快节奏戏每镜 2–4 秒，慢戏 / 留白每镜 6–10 秒。
   - 重台词镜头按台词字数给时间，反应 / 停顿也要给足时间（一个沉默反应通常 1.5–3 秒，别一闪而过）。
3. **台词字数换算**（来自 22 号）：普通语速 **每秒 ≤5 字**，慢语速每秒 ≤3 字；30 秒组对白约 ≤10 句、单句尽量 ≤10 字；一句装不下就拆到前后镜头，**台词原词不改**。
4. **分组**：同场景、同段落尽量整合进一个 30 秒组（对齐 Seedance 单次 30 秒上限）；内容短就在 5–30 秒内灵活缩短。
5. 最终按 [22 号模板](22-15s-storyboard-group-template.md) 的 `OUTPUT_START / FIELD / END` 机器格式输出（场景 / 角色 / 物品三行 @图片 映射 + 镜头序列 + 衔接字段）。

### Step 7：段间衔接标注 + 自检

1. **衔接点**：在每个相邻分镜组之间标注——有场景转换 / 动作跳跃 / 光影不连续 / 强冲突后需缓冲的，设计「衔接片段」（编号 G03a，通常 2–5 秒，满足"本组终点＝衔接起点、衔接终点＝下组起点"）；同机位连续的标「硬切连贯」，不冗余加片——规范见 02 号 5.4 与铁律 31。
2. **过自检门**：先过本文件第四节《分镜工作法自检》，再过 02 号第六节《分镜自检门》（光源 / 物理 / 站位 / 频率等全部硬约束）。
3. 完整展示分镜组给用户，等确认。

## 三、完整走查示例（一场真人写实戏，从剧本到镜头）

**剧本片段（场1·林家餐厅，夜，内）：**

> 林晚拖着行李进门。母亲周慧兰从厨房端出热好的菜。
> 周慧兰："回来了？菜热第三遍了。"
> 林晚（低头）："妈，我后天走，公司调我去深圳。"
> （母亲夹菜的手停在半空。）
> 周慧兰："……去几年？" 林晚："不知道。"
> 周慧兰（把排骨夹进林晚碗里）："去吧。在外头，别老吃外卖。"
> 林晚抬头，眼眶红了。母亲低头吃饭，没看她。

**Step 2 场景卡（摘要）：**
- 人物目标：林晚想让母亲接受自己远行、又怕面对不舍；周慧兰想留、又不愿拖女儿后腿。
- 冲突：女儿的"走" vs 母亲的"不舍"。
- **价值转折：隔阂 / 愧疚(–) → 理解 / 成全(+)（带着不舍）**，转折落在 B7"去吧"。
- 情绪：平静压抑(3) → 摊牌紧张(5) → 停顿(4) → 成全的鼻酸(7) → 克制留白(4)。
- 关键信息：女儿要去深圳、母亲等了一晚上、母亲最终支持。

**Step 3 Beat 表：** 见上文 Step 3 的 B1–B9。

**Step 4 空间（俯视图要点）：** 餐厅，餐桌居中，门在画面一侧、厨房窗口在另一侧；周慧兰在桌右（靠厨房），林晚进门后在桌左；轴线＝两人隔桌连线，摄影机统一在连线南侧 → 林晚面向右、母亲面向左。

**Step 5 + 6：Coverage 与镜头（约 30 秒，一个分镜组）：**

| 镜 | 时长 | 镜头（景别 / 机位 / 焦段 / 运镜） | 呈现 Beat | 画面 / 台词 / 环境音 |
|---|---|---|---|---|
| 1 | 4s | 中全景·平视·24mm·轻推 | B1 | 林晚（@图片1）拖行李进门、低头换鞋；周慧兰（@图片2）在桌旁；环境音：行李箱滚轮、门轴；暖黄顶灯 |
| 2 | 5s | 中景·过林晚肩·35mm·固定 | B2 | 母亲（@图片2）端菜上桌，桌上三盘菜冒着热气："回来了？菜热第三遍了。" |
| 3 | 5s | 近景·平视·50mm·微推 | B3 | 林晚（@图片1）低头："妈，我后天走，公司调我去深圳。" |
| 4 | 3s | 特写·俯拍手部·85mm·固定 | B4 | 母亲夹菜的手停在半空，筷子微颤；沉默；只听厨房冰箱嗡鸣 |
| 5 | 4s | 过肩正反打·85mm·固定 | B5/B6 | 过林晚肩拍母亲："……去几年？" 切过母亲肩拍林晚："不知道。" |
| 6 | 5s | 中近景·平视·50mm·轻推 | B7 | 母亲（@图片2）把排骨夹进林晚碗里："去吧。在外头，别老吃外卖。" |
| 7 | 4s | 特写 / 留白·85mm·固定 | B8/B9 | 林晚（@图片1）抬头眼眶红；切母亲低头吃饭、不看她；停在母亲侧脸上收尾 |

（合计 30s；no srt，no music；真实环境音：碗筷轻碰、咀嚼、冰箱嗡鸣。）

> 对照看这场戏的分镜好在哪：**①有价值转折（隔阂→成全）；②重台词后给了"停在半空的筷子"和"低头不看"两个反应 / 留白；③关键信息靠道具（热三遍的菜、行李、排骨）演出来；④全程守一条轴线、站位不跳。** 这就是"走流程"和"直接切句子"的差距。

## 四、分镜工作法自检（Step 7 必过，再叠加 02 号自检）

- [ ] **场景**：是否按时间 / 地点切分、建了场景清单？
- [ ] **场景卡**：每场是否写清目标 / 冲突 / 关键信息？
- [ ] **价值转折（P0）**：每场戏开场→结束的价值极性是否发生了变化？无转折的"无事件场景"是否已改写或删除？
- [ ] **Beat 表**：是否把每场戏拆成了 Beat，且每个 Beat 都填了具体的"观众任务（看到什么）"？
- [ ] **反应 Beat**：每句重台词 / 每个信息抛出后，是否都有听者反应或停顿？有没有全程只在"说话"？
- [ ] **空间**：是否画了俯视图（该画时）、写死站位三要素、定了轴线、备了机位底图？
- [ ] **Coverage**：主镜头 / 双人 / 正反打 / 关键反应 / 关键插入是否都覆盖到了？
- [ ] **镜头与 Beat**：每个镜头是否都对应明确的 Beat 和"观众任务"，答不出"让观众看到什么"的镜头是否已删？
- [ ] **时长 / 字数**：镜头时长合计＝组时长？台词按每秒 ≤5 字给足时间、反应停顿给足时间？
- [ ] **分组 / 输出**：是否整合进 30 秒组、按 22 号机器格式输出？
- [ ] **衔接**：相邻组之间是否标注衔接点 / 硬切连贯（铁律 31）？
- [ ] **AI 可生成性**：每个镜头是否对照 29 号确认 AI 能稳定生成、复杂镜头已拆分？

## 五、新手分镜最常见的 6 个毛病（对号入座）

1. **跳过 Beat 直接切句子**：镜头数对但没节奏、没 coverage → 回到 Step 3。
2. **全程正反打念台词、没有反应和停顿**：情绪出不来 → 补反应 Beat / 留白镜头。
3. **信息全靠台词说**（"我要走了""我很担心你"），不会用道具和动作演 → 强化"观众任务"里的具体物件。
4. **一场戏没有价值转折**，演完人物关系 / 状态没变 → 删或改。
5. **站位 / 轴线不规划**，拍到哪算哪，成片人物乱跳越轴 → Step 4 必做。
6. **设计了 AI 生成不了的复杂镜头**（长段环绕、多人交叉、复杂调度），成片必崩 → 查 29 号拆分。
