# 16. 项目启动与格式衔接手册（Project Playbook）

> 拿到一个新项目，第一步干什么？剧本怎么转成分镜？分镜怎么转成提示词？这个文件回答这三个问题。
> 写剧本前、启动新项目时、跨模块衔接卡住时，翻这个文件。

---

## 一、项目启动检查清单（拿到新项目第一步）

**开始写剧本之前，先把以下项目确认完。缺什么补什么，不要带着模糊信息往下走。**

### 1.1 人物资产

- [ ] **参考图确认**：用户提供了几张人物参考图？分别对应哪个角色？一人一角色不重复使用
  - 记录：图片1=角色A，图片2=角色B……
  - 没有参考图的角色 → 纯文字描述外貌（年龄/发型/服装/特征）
- [ ] **美术资产出图与审核（对齐铁律28）**：角色/场景/道具/关键画面等美术资产，AI 可直接调用文生图生成，但每张/批出图后必须把「成图+所用提示词+三维」交付用户审核，通过才定稿、才在分镜/提示词里 `@图片N` 强制图片参考；用户想自制则自行出图、回传后同样审核。资产审核进度记入《资产审核确认表》。
- [ ] **角色资产锁定**：每个角色的面部特征、各场景造型（日常装/正式装/情绪崩溃后的状态）是否已规划？
  - 详见角色资产设定文件（15号：角色资产/场景锚定/光源设定/道具规划）
- [ ] **角色数量**：全剧主要角色几人？次要角色几人？是否在AI生成能力范围内？

### 1.2 场景与道具

- [ ] **场景列表**：全剧有几个独立场景？（如：办公室/家/街道/医院）
  - 每个场景的空间锚定卡是否建立？（场景多大？门在哪？窗在哪？光源从哪来？）
  - 每个场景的光源设定卡是否建立？（主光源方向/色温/辅助光/环境光）
  - 详见场景锚定规范（15号文件）
- [ ] **道具列表**：关键道具有哪些？（手机/信件/药瓶/照片/戒指……）
  - 道具出场规划表是否建立？（哪一镜出现、谁拿着、什么状态）
  - 道具是否需要生成参考图？

### 1.3 视听规格

- [ ] **全片色调**：主色调是什么？（暖黄治愈 / 冷蓝悬疑 / 怀旧胶片 / 末世灰绿）
  - 四幕色调变化是否规划？（开场冷→中间中性→反转高对比→结尾冷暗）
- [ ] **时长目标**：规划总时长多少？各幕时长分配？
  - 90秒竖屏：开场15秒+冲突30秒+反转15秒+结尾30秒
  - 3-5分钟横屏：开场40秒+冲突90秒+反转40秒+结尾60秒
- [ ] **画幅比例**：横屏16:9（默认电影感）还是竖屏9:16（抖音爽剧）？
- [ ] **音频模式**：
  - **无配乐 BGM、保留并做足真实环境音**：AI 不添加人为配乐/旋律 score，不做后期混音
  - 真实环境音（脚步/雨/风/水流/虫鸣/火焰/衣物摩擦/门轴/马蹄/人群嘈杂等）在写提示词时写进画面描述，由视频模型生成端直接产出，硬拼接原样保留
  - 用户后期在自己的剪辑软件里可自行决定是否额外加配乐、混音
- [ ] **台词语言**：中文？英文？方言？

### 1.4 合规与风险

- [ ] **合规审查**：是否有伤害/死亡/暴力画面需要合规替换？
  - 血腥特写→合规替换（阴影/反应镜头/声音暗示）
  - 暴力慢放→改为快速硬切+音效
- [ ] **敏感内容排查**：是否涉及政治/宗教/未成年人风险？

## 二、剧本→分镜→提示词 格式衔接指南

**三个模块的产出如何衔接？以下是完整的格式流转链路。**

### 2.1 剧本格式 → 分镜格式

**01号剧本的两种输出：**

| 剧本输出类型 | 格式特征 | 如何转入02号分镜 |
|---|---|---|
| 90秒四幕模板 | 紧凑四幕，每幕有时间锁，台词+动作标注 | 按幕拆镜：每幕拆成2-4个分镜组，每个分镜组5–30秒灵活（不锁死）。把剧本中的"动作描述"转成分镜的"画面内容" |
| 正式剧本格式 | 场景标题+动作行+角色名+台词+括号说明 | 按场景/对白轮次拆镜：每2-4句台词或一个动作变化拆成一个分镜组 |

**衔接关键点：**

| 剧本里写的 | 分镜里对应变成 |
|---|---|
| 场景标题（如"日。客厅"） | 分镜的场景锚定（客厅+光源设定+空间描述） |
| 动作行（如"他猛地站起来"） | 分镜的画面内容+运镜+入点出点 |
| 角色名+台词 | 分镜的台词标注+说话人@参考图编号 |
| 站位描述（如"两人面对面"） | 分镜的**站位锁定**（左右位置+前后远近+朝向） |
| 情绪标注（如"他忍着泪"） | 分镜的景别选择（特写/近景）+光影配合 |

### 2.2 分镜格式 → 提示词格式

**02号分镜的两种输出：**

| 分镜输出类型 | 格式特征 | 如何转入03号提示词 |
|---|---|---|
| 中文画面规格书【标签】块 | 给人看的叙事性描述 | 逐镜翻译：把每个【标签】块的描述转成03号的结构化提示词（场景+人物@艾特+台词+运镜+光影+风格） |
| 结构化分镜组V2.0 PLUS | 给AI用的表格（镜号/时长/景别/运镜/画面/台词） | 直接作为提示词骨架：每一行分镜组→写一条完整提示词，填充03号的提示词模板 |

**衔接关键点：**

| 分镜里写的 | 提示词里对应变成 |
|---|---|
| 景别（特写/近景/中景/全景） | 提示词的景别描述（"特写镜头"/"中景"） |
| 运镜（推/拉/摇/移/固定） | 提示词的运镜指令（参考14号视觉术语表） |
| 站位锁定（A在左B在右面对面） | 提示词的**站位三要素**（左右+前后+朝向） |
| 台词（角色名+台词内容） | 提示词中直接写出`角色（@图片N）说："台词内容"` |
| 光影（暖黄侧光/冷蓝逆光） | 提示词的光源描述+色调 |
| 场景描述 | 提示词的场景环境描述 |
| 时长 | 视频生成的duration参数（5-30秒整数） |

### 2.3 完整格式流转示例

**剧本中的一场戏（01号格式）：**

```
场景：夜。老城区面馆
老张（60岁，面馆老板）正在擦桌子。
门被推开，冷风灌进来。
李远（30岁，落魄男人）站在门口，浑身湿透。
老张："这么晚了，还吃吗？"
李远低着头，走进来，在角落坐下。
李远："一碗面。"
```

**拆解为分镜（02号格式）：**

| 镜号 | 时长 | 景别 | 运镜 | 画面内容 | 台词 | 站位 |
|---|---|---|---|---|---|---|
| S01 | 4秒 | 中景 | 固定 | 老面馆内，老张擦桌子，暖黄灯光，桌上冒着热气 | （无） | 老张在画面左侧，居中偏左，面朝右擦桌子 |
| S02 | 3秒 | 近景 | 固定 | 门被推开，冷风灌入，门口冷蓝色夜光照进来 | （门吱呀声） | 门口居中，门向内开 |
| S03 | 5秒 | 中全景 | 微推 | 李远站在门口，浑身湿透，逆光剪影，老张抬头看他 | 老张："这么晚了，还吃吗？" | 李远在画面右侧门口，老张在画面左侧店内，两人面对面 |
| S04 | 4秒 | 中景 | 固定 | 李远低头走进来，在角落坐下，肩膀垮下来 | 李远："一碗面。" | 李远从右侧走到画面深处角落坐下 |

**对应提示词（03号格式，Seedance 2.5）：**

```
【S01】竖屏9:16，夜晚老城区小面馆内景。暖黄色灯泡吊在天花板上，光线昏黄温暖。老张（@图片1）站在画面左侧，面朝右，正在擦木桌子，桌上有一碗冒着热气的面。背景是斑驳的瓷砖墙和旧木凳。固定镜头，中景，浅景深。4秒。

【S02】竖屏9:16，面馆的木门被猛地推开，冷蓝色夜风和光线从门外灌入，吹得桌上的纸巾微动。固定镜头，近景对准门。门吱呀作响。3秒。

【S03】竖屏9:16，夜晚面馆内。李远（@图片2）站在画面右侧门口位置，浑身湿透，头发滴水，逆着门外冷蓝光形成剪影。老张（@图片1）在画面左侧，停下擦桌子的动作，抬头看向门口。两人面对面相距约三米。老张说："这么晚了，还吃吗？"固定镜头，中全景，缓慢推进。暖黄室内光与冷蓝门外光形成对比。5秒。

【S04】竖屏9:16，面馆内。李远（@图片2）低着头，从画面右侧走到画面深处角落的桌子坐下，肩膀垮下来，双手放在桌上。暖黄灯光照着他湿漉漉的头发。李远说："一碗面。"固定镜头，中景。4秒。
```

### 2.4 常见衔接问题

| 问题 | 原因 | 解决方法 |
|---|---|---|
| 剧本写了大段心理活动，分镜没法拆 | 剧本用了旁白/内心独白解释，没转成画面 | 回头改剧本：把心理活动改成动作/表情/物品特写（Show Don't Tell） |
| 分镜写得太笼统，提示词没法直接用 | 分镜缺景别/运镜/站位 | 补全分镜的镜头语言参数（景别/焦段/机位/运镜/光影） |
| 提示词生成的视频和分镜对不上 | 提示词漏了站位三要素或光影描述 | 回到提示词：逐镜检查站位是否写死、光影是否明确 |
| 同场景连续镜头人物站位跳来跳去 | 分镜没锁定站位，提示词没写左右 | 在分镜阶段就锁定同场景的站位轴线，提示词中逐镜写明 |

## 三、全流程时间估算

**以下为单人AI导演工作的参考时间，实际因项目复杂度浮动。**

### 3.1 各阶段时间参考

| 阶段 | 单位时间 | 说明 |
|---|---|---|
| 剧本创作 | 90秒剧本约30分钟；5分钟剧本约2小时 | 含构思+写作+自检+修改 |
| 分镜设计 | 每镜约5分钟 | 含景别/运镜/光影/站位设计 |
| 提示词生成 | 每镜约3分钟 | 含@艾特+台词+站位+氛围描述 |
| 视频生成 | 每镜生成5-30秒 + 审核2-5分钟 | 批量调度，同场景可并行 |
| 后期合成 | 每10镜约10分钟 | 仅硬拼接+规格校验，不做剪辑/调色/混音 |

### 3.2 不同规模项目总时间参考

| 项目规模 | 镜头数 | 预估总时间 | 说明 |
|---|---|---|---|
| 90秒竖屏爽剧 | 6-10镜 | 约3-4小时 | 剧本30分+分镜1小时+提示词30分+生成1.5小时+后期30分 |
| 3分钟横屏情感剧 | 12-18镜 | 约6-8小时 | 分镜/生成/后期时间线性增长 |
| 5分钟精品短剧 | 20-30镜 | 约10-15小时 | 含多轮审核和重生成，建议分天完成 |
| 系列短剧（3集×56镜） | 约50-60镜/集 | 每集约1-2天 | 同角色同场景可批量生成，效率递增 |

> **注意**：视频生成是最不可控环节——可能需要重试2-3版才能出满意镜头。以上时间已含1-2次重试余量。

## 四、常见项目类型快速配置

**拿到一个新项目，先判断是哪种类型，直接套用默认配置，不用从头想。**

### 4.1 90秒竖屏爽剧（抖音/快手）

| 配置项 | 默认值 |
|---|---|
| 画幅 | 9:16竖屏 |
| 镜头数 | 6-10镜 |
| 单镜时长 | 5-15秒 |
| 节奏 | 快节奏，每镜1-3秒切换频繁 |
| 色调 | 高对比，饱和度略高，爽感直接 |
| 音频 | 无配乐 BGM；真实环境音做足（用户后期可自行加配乐） |
| 开局钩子 | 前3秒炸台词或反常画面 |
| 结构 | 四幕高密度：开场冲击→冲突→反转→悬念 |

### 4.2 3-5分钟横屏情感剧（B站/视频号）

| 配置项 | 默认值 |
|---|---|
| 画幅 | 16:9横屏 |
| 镜头数 | 15-25镜 |
| 单镜时长 | 5-20秒 |
| 节奏 | 中慢节奏，情绪留白多 |
| 色调 | 低饱和，电影感冷暖对比 |
| 音频 | 无配乐 BGM；真实环境音做足（用户后期可自行加配乐） |
| 开局钩子 | 反常画面或悬念问题，不炸但留人 |
| 结构 | 五阶段：定位→世界观→首尾双锁→四幕推进→分段落地 |

### 4.3 5分钟以上横屏电影感短片

| 配置项 | 默认值 |
|---|---|
| 画幅 | 16:9横屏（或21:9电影宽幅） |
| 镜头数 | 20-40镜 |
| 单镜时长 | 10-30秒 |
| 节奏 | 慢节奏，长镜头多，情绪沉淀 |
| 色调 | 胶片质感（用户后期可加LUT，AI不调色） |
| 音频 | 无配乐 BGM；真实环境音做足（用户后期可自行加配乐） |
| 开局钩子 | 氛围开场（环境音+光影），30秒内引入人物 |
| 结构 | 完整三幕+多层反转，伏笔回收 |

### 4.4 配置调整原则

- **节奏不对时**：先调镜头时长，快切=紧张，慢切=抒情（配乐由用户后期决定）
- **情绪不到位时**：先调光影和画面描述，在提示词里把环境音写足，让 AI 生成时就到位（配乐由用户后期决定）
- **长度不够时**：加反应镜头和物品特写，不要注水台词
- **AI感太重时**：降饱和+加颗粒+环境音做足+减少完美构图
