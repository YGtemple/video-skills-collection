# 为 AI 生成而设计镜头（真人写实 · 把电影分镜翻译成 AI 能稳定出片的分镜）

> 定位：02/26/27/28 号默认"镜头是理想的、摄影机无所不能"；本文件负责**落地——同样一个戏剧意图，怎么设计成 AI（Seedance 2.5 等）能一次生成成功、不崩、不假的镜头**。分镜定稿前，每个镜头都要过本文件。
>
> 一句话原则：**AI 不擅长的，不靠"多试几次"硬刚，而靠"换一种镜头设计"绕开。** 分镜阶段多花一分钟拆分，能省下十次重生成。

---

## 一、先建立"AI 单镜头能力边界"意识

AI 生成不是真人摄影机，**单个镜头（一次生成）在以下维度有隐性上限**（随模型升级会改善，但分镜应按"稳定区间"设计，而不是赌极限）：

| 维度 | 稳定区间（建议按此设计） | 高风险区（容易崩 / 假） |
|---|---|---|
| 同框清晰人数 | 1–2 人最稳；小景别偶 3 人 | 一个镜头 4 人以上清晰正脸 / 交叉对话 |
| 运动幅度 | 小幅、缓慢、单一方向的推 / 拉 / 摇 / 移 | 大幅环绕、快速横移、复杂复合运镜 |
| 调度复杂度 | 一次一个主要动作 | 同时多人移动 + 机位运动 + 台词 |
| 交互动作 | 简单接触（递、接、扶、拥抱姿势） | 打斗、争抢、系扣、弹琴、复杂手部操作 |
| 手部 / 手指 | 自然下垂 / 简单手势 | 数手指、特写做精细动作（最易多指 / 畸形） |
| 行走 / 奔跑 | 慢走、短距离、小跟移 | 长跑、追逐、上下台阶 + 长距离跟拍 |
| 儿童 / 动物 | 静态 / 简单动作 | 儿童大段台词、动物复杂动作 |
| 时长 | 单一意图镜头 5–10s 最稳 | 一个镜头塞满多个事件 / 长台词 |
| 背景 | 简洁 / 虚化背景 | 密集可读文字、复杂人群、镜子 / 玻璃反光 |

> 用法：设计每个镜头时对照上表——落在"稳定区间"放心生成；落在"高风险区"，按第三节拆分 / 替换。

## 二、高失败率镜头黑名单 → 替代设计（核心对照表）

| 别这么设计（高失败） | 为什么崩 | 改成这样（同样达成戏剧意图） |
|---|---|---|
| 长段 360°环绕人物 | 轨迹大、背景重建、脸易变 | 小幅轻推 + 切一个侧面近景；或半弧（≤90°）慢移 |
| 一镜多人交叉抢话 | 口型 / 人数 / 声音乱 | 拆成两两正反打，一人一句 |
| 完整打斗 / 肢体冲突 | 肢体穿插、合规风险 | 局部特写（攥拳、拉扯的手）+ 反应 + 声响，**用反应表演法**（见 19 号案例） |
| 长距离跟拍奔跑 | 脚步飘、背景撕裂 | 短距离侧跟 2–3s + 喘气特写 + 空镜（脚步声）组接 |
| 精细手部操作（系领带、弹琴、数钱） | 多指 / 穿模 | 拍肩 / 脸的反应 + 结果镜头，过程用插入带过 |
| 复杂推拉摇移组合 | 指令矛盾、运动失控 | 一个镜头只保留一种运镜 |
| 大远景里一桌子 / 一群人 | 多脸崩、多手 | 定场全景只 1 个（接受略虚），正文拆小景别 |
| 镜子 / 玻璃前表演 | 反射对不上、多出人影 | 侧拍避开镜面，或让反射虚化 |
| 角色快速转身 + 说长台词 | 脸糊、台词切断 | 先转身（动作镜）→ 站稳再开口（对白镜） |
| 黑暗中大幅动作 | 全黑 / 噪点 | 给一个微弱光源动机（窗 / 灯 / 手机光），拍剪影 / 半张脸 |
| 屏幕 / 招牌可读文字 | 乱码文字、违反零字幕 | 改为念出 / 反应，或拍无字的光影与道具 |

## 三、复杂镜头的"拆分四法"

遇到高风险镜头，不要硬生成，按以下方式拆：

1. **按动作拆**：一个连续复杂动作 → 起（动作开始）＋ 承（关键瞬间特写）＋ 合（结果），用动作接动作（28 号）。
   - 例："摔门而去" → 起身（中景）＋ 手抓门把（插入）＋ 门关上、人已在门外（全景）。
2. **按人物拆**：多人戏 → 一次只拍两人的小景别，靠剪辑 / 反应镜头拼出群像（见配方 3）。
3. **按信息拆**：一个镜头又交代背景又反转 → 拆成"信息镜头（道具 / 台词）＋ 反应镜头"，信息抛出后给停顿。
4. **按空间拆**：长调度（穿过多个房间 / 长走廊）→ 每段空间一个镜头，用过门 / 遮挡做衔接（铁律 31）。

> 判断标准：**一个镜头如果需要观众同时注意 3 个以上的变化（多人 + 大运动 + 台词 + 道具），就一定拆。**

## 四、真人写实"可信度清单"（防止"一眼假"）

真人短剧最大的敌人是"假"。分镜时逐项保证：

1. **摄影机要有"存在的位置"**：每个机位都要想"机器放在哪、背后有没有空间"（02 号物理可行性）——房间角落不可能拍出后退拉镜。
2. **运动轨迹要单一、有起停**：运镜写清方向和起止，避免"边环绕边推进边变焦"的矛盾指令。
3. **焦段与景别匹配**：广角不怼脸拍特写（会扭曲）、人物特写用 85mm 左右；一个镜头内不要"变焦段"。
4. **光线有来源且跨镜一致**：光从窗 / 灯来，方向在同场戏固定（02 号光源动机）；冷暖、强弱可随情绪变，方向不能跳。
5. **背景人群 / 环境要"合乎逻辑"**：人群该虚化虚化，别给清晰但脸崩的路人；公共场所的人物密度、道具陈设符合生活。
6. **人物"接地"**：坐有坐相、脚踩地面、手持物握实、杯盘落在桌上（29 号铁律的悬浮 / 接地检查）。
7. **皮肤与质感**：写"写实皮肤纹理、自然光影、摄影机 / 胶片质感"，避免塑料光滑的"美颜假脸"（可叠加 21 号纪实画风）。

## 五、一个 30 秒组的"内部微结构"

一个生成段（默认 30s）内部也应有戏剧结构，不是镜头随便排：

- **起（建置，约前 1/4）**：定场 / 双人镜头，交代空间、人物状态、本场起点情绪。
- **承（推进，中段）**：正反打 / 动作，目标与冲突展开、信息逐步给出。
- **转（重锤，约后 1/3）**：关键台词 / 反转 / 决定 + 反应停顿（本场价值转折落在这里）。
- **合（收束，结尾几秒）**：反应 / 留白 / 引向下一段的动作或视线。

**组内控制：**
- 一个组内机位数量别无限堆（3–6 镜为宜），机位切换太碎模型也会乱。
- **同组时间 / 光线 / 服装 / 站位必须一致**（同一场戏的几分钟内，不能忽明忽暗、人物换装）。
- 把最想让观众记住的镜头放在"转"，并给足反应时间；别让重锤台词被挤在组的最后 1 秒（容易被切断）。

## 六、表演指导：让 AI 把人物"演活"（真人写实关键）

AI 对"开心 / 生气 / 悲伤"这类**情绪形容词不敏感**（调研实测：模型对"欢迎 / 害羞"等虚词反应差）。要把情绪翻译成**"看什么 + 刚发生什么 + 身体哪里绷紧"**：

### 6.1 表演三要素（每个情绪镜头按此写）

1. **凝视对象 Gaze Object**：眼睛看着具体的东西（手中的杯子、对方的眼睛、窗外、照片），**不要写"看着镜头 / 眼神悲伤"**——没有凝视对象，眼睛必乱飘。
2. **情感节拍 Emotional Beat**：人物"刚听到 / 刚意识到什么、正在压住什么"（刚听到坏消息、强忍着泪、欲言又止）。
3. **身体微约束 Micro-constraint**：1–2 个具体的身体细节（下颌绷紧、嘴唇抿住、手指攥紧、喉结动了一下、肩膀微颤），**不要堆一串形容词**。

> 对比：❌"她露出悲伤的表情，眼眶含泪，非常感人" → ✅"她低头看着手里那碗饭（凝视），听到母亲的话后停顿（节拍），嘴唇抿紧、筷子在指间微微发抖（微约束），始终没抬头"。**后者有效得多。**

### 6.2 情绪虚词 → 具体动作 / 表情对照（提示词里直接替换）

| 虚词（别写） | 翻译成具体动作 / 表情 |
|---|---|
| 很开心 / 欢迎 | 嘴角上扬露出牙齿，眼睛弯起，手抬起挥了两下 |
| 很生气 | 眉头压低、抿嘴、呼吸变重、一把把文件拍在桌上 |
| 很害羞 | 视线躲开、低头、手撩了下头发、嘴角忍不住上扬 |
| 很难过 | 眼眶泛红、眨眼变快、喉头滚动、用力抿唇 |
| 很紧张 | 吞咽、手指反复搓、脚尖点地、眼神游移后定住 |
| 很震惊 | 动作停住、瞳孔变化、嘴微张、半天没说话 |
| 很不舍 | 伸手又收回、看了又看、脚步放慢、转身又回头 |

### 6.3 表演指导卡（Express Direction Sheet，重镜头填，六行替代二十个形容词）

```
Beat：（一句话，这个瞬间发生了什么）
凝视对象：（具体名词：看着什么）
情感节拍：（刚……正在……）
身体微约束：（1-2 个：下颌/手/唇/肩/呼吸）
焦段 / 景别：（如 85mm 近景）
主光：（光源来源与方向）
```

## 七、提升"真人感 / 电影感"的 8 个分镜小技巧

1. **轻微手持感**：写"轻微手持、自然呼吸般的微晃"，比死稳的镜头更像真人拍的（激烈戏可加大手持）。
2. **反应先于 / 多于台词**：让人先有表情、再开口；沉默反应往往比台词更真实。
3. **视线先于动作**：人动手之前眼睛先看过去（先看杯子再伸手），符合真实行为逻辑。
4. **加"多余的生活动作"**：说话时撩头发、搓手、挪杯子、靠一下墙——这些"无功能小动作"最能去 AI 味。
5. **用环境音点真实感**：脚步、衣物摩擦、门轴、碗筷、远处车声（铁律 26 写明，由模型生成）。
6. **不完美构图**：人物略偏、被前景物件挡一点、偶尔失焦再拉实，比张张完美居中更像实拍。
7. **给动作"重量和停顿"**：坐下有沉的感觉、放下东西有轻重、转身有惯性——AI 默认动作偏飘，写明节奏。
8. **光线参与情绪**：用窗光、台灯、黄昏光等真实光源塑造，而不是均匀打亮（可叠 21 号富士纪实 / 02 号布光）。

## 八、AI 镜头设计自检（分镜定稿前，每个镜头 / 每组过）

- [ ] **能力边界**：每个镜头是否落在"稳定区间"？高风险镜头是否已拆分 / 替换？
- [ ] **黑名单**：是否对照第二节，消除了环绕 / 多人抢话 / 长跟拍 / 精细手部 / 镜面等高危设计？
- [ ] **单一意图**：一个镜头是否只做一件事、只有一种运镜？需要同时注意 3 个以上变化的是否已拆？
- [ ] **可信度**：机位有落点、运动有起停、焦段匹配、光线有来源且一致、人物接地、皮肤写实？
- [ ] **组内微结构**：30 秒组是否有起承转合、机位 3–6 个、同组时间光线服装站位一致？重锤是否给足反应、没被挤到最后 1 秒？（若用 33 号技术全景尾，重锤须在该 1 秒之前结束，见 references/33-tech-panorama-anchor.md）
- [ ] **表演**：情绪是否写成了"凝视对象 + 情感节拍 + 身体微约束"？虚词是否已替换成具体动作？
- [ ] **真人感**：是否用了手持微晃、生活动作、环境音、不完美构图等去 AI 味技巧？
- [ ] **零文字 / 合规**：画面内无可读文字（例外见铁律 20）、无违规暴力？
