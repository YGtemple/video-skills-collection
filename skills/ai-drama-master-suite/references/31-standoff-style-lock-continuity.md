# 第一部分：对峙（文戏）模式深化

## 1.1 何时启用

动作由**台词、视线、微动作**（掐烟、合扇、按桌、离座）推进，全段无攻防、或攻防只在结尾作为引爆点时启用。

## 1.2 张力因果链（替代打戏的攻防链）

```text
施压（台词或动作发起）→ 承受（听方微反应）→ 泄露 / 反制（视线回避、手部失控、打断、离座）→ 新平衡（座位、视线、持物关系改变）
```

- **每个张力单元必须有人"失态"或关系改变**——不允许"说完换下一个人说"的流水对白。
- 对峙中的"战术限制"通常是：**信息差、把柄、空间权力**（谁站着、谁背对门）。

## 1.3 台词—镜头对齐

- **一句完整台词不跨两个镜头**；长台词（>4 秒）给一个连续镜头，用缓慢推进维持画面活性。
- 镜头动作里写**完整原句**并标注情绪与语速；**方言保留原文**，不改写成书面语。
- 口型时长：中文约 **4–5 字 / 秒**（本套件通用口径每秒 ≤5 字）；时长不足就延长本镜，**不删减台词**。
- 听方反应镜头不重复台词，只写反应本身。

```text
镜头四（5.6-9秒）：光圈 f/2.8（浅景深，背景明显虚化），焦段 85mm（近景），
老大面部近景（close-up）缓慢推进（push in）；老大（慢，一字一句）："完整原句。"
```

## 1.4 镜头节奏与配额（每 15 秒）

| 类型 | 配额上限 |
|---|---|
| 建立空间 | ≤1 |
| 说话人 | ≤3 |
| 听方反应 | ≤2 |
| 微动作特写 | ≤2 |
| 局势变化 | 1 |

- 单镜默认 2–4 秒；凝滞时刻允许 4–6 秒长镜，配缓慢推进或固定凝视。
- 反应镜头不连续超过两个；同一角色的同一反应不重复拍；**不为凑镜头切台词、不重复微动作**。

## 1.5 多人同框与空间权力

- 每个镜头写明焦点人物，用一句交代背景人物（"其余人保持原位静止" / "七叔摇扇未停"）。
- 群体同步反应（全场静下、众人变色）用一个全景 / 双人中景整体呈现，不拆逐人。
- **视线是主要动作资源**：写明谁看谁、谁先移开——视线变化即张力单元的受力结果。
- **空间权力**：谁站着、谁坐着、谁正对门、谁背对门，必须在空间站位写明并保持连续。

## 1.6 微动作反馈（每个微动作要有发起者和可见结果）

- **手部失控**：掐烟、折扇停住、指节泛白、手离开扶手悬空。
- **坐姿变化**：上身前倾、将起未起、慢慢坐回。
- **持物变化**：放下、推开、合拢、不触碰。
- **视线变化**：抬眼、移开、第一次看向某人。
- 一个微动作特写只承载一个微动作及其结果。

> 字幕卡 / 黑屏收尾：剧本未要求时不主动加；需要时写"画面随 ×× 渐黑"（黑屏白字时间卡按铁律 20 处理）。

# 第二部分：全局风格锁定（六槽）

## 2.1 规则

- **全局风格锁定全片只输出一次，放在所有 clip 提示词之前**；它锁定底层"生成质感"，不管画幅、表演尺度、镜头节奏或剧情执行。
- **任何 clip 内不得重复全局风格锁定词**（每 clip 最多用一句短语重申，不复制长段）。
- 锁定词由"**用户指定风格 + 视觉资产库风格 + 剧本题材**"共同推导，**不机械套固定词**；用户只给一个风格词时，先内部解析再输出，不照抄原词。
- 用户风格与资产库风格冲突时，提醒用户沿用哪一方，不自动覆盖。

## 2.2 内部解析维度（7 个视角，推导时参考）

风格类别（真人/2D/3D/混合）· 媒介来源（电影摄影/过场/插画/动画/漫画/实时渲染/实验）· 渲染方式（实拍/UE5/PBR/手绘/平涂/赛璐璐/水墨/低多边形）· 角色质感（真人演员/数字人/动捕/卡通/剪纸黏土）· 运动质感（真实摄影运动/动捕/手 K/有限动画/逐帧/电影级运动模糊）· 材质语言（真实皮肤/PBR/厚涂/纸张/网点/胶片颗粒）· 光影色彩（冷暖/高饱和/低饱和/暗调/柔光/高反差/平面色块）。

## 2.3 输出格式（六槽）

```text
风格锁定：{媒介来源}，{渲染方式}，{角色质感}，{运动质感}，{材质语言}，{光影色彩}。
```

- 锁定词中的专业锚点保留 3–8 个。
- 用户未要求强风格时，**不用导演名、胶片品牌、强类型词**；强风格词只在用户明确指定或高度匹配时用。
- **真人写实默认参考**：电影摄影，实拍，真人演员，真实摄影运动，真实皮肤与胶片颗粒，（按题材填光影，如冷暖对比 / 低饱和暗调）。

## 2.4 特殊风格化（局部，不污染全局锁）

用于回忆、梦境、监控、手机直播、新闻画面、游戏 UI、古籍插画、精神幻觉等**局部段**：
- 无触发依据时显式输出：`特殊风格化：不启用。全片保持普通风格锁定。`
- 启用时输出：`特殊风格化：启用。特殊风格提示词：…… 启用段落：Clip02 镜头四至六（回忆段）。`
- **必须写明启用段落范围**；只在标记镜头内叠加，其余 clip 不受影响。

# 第三部分：美术资产短锚点协议

## 3.1 资产来源优先级

①用户本轮明确给出的名称 / 描述 → ②正式资产库的 `@资产名` 与状态 → ③剧本 / 动作中可见的角色场景道具 → ④保守临时名。**用户已有资产外观优先于系统推断。**

## 3.2 提取规则（每项资产只提取）

引用名 · 类型（角色/场景/武器/道具/群体）· **1–3 个高识别特征** · 本段用途 · 待核对的冲突 / 缺口。忽略资产库里的生成参数、完整外貌、材质堆叠、质量词。

- **短锚点 6–20 字**，保留轮廓、服装主色、标志配件、武器形态、场景固定结构：
  - ✅ `@疲惫男主（深色皱褶西装、松散领带）`、`@走廊管线墙（脏绿墙面、横向裸露管线）`
  - ❌ 把完整文生图描述（年龄 / 脸型 / 颧骨……）塞进来。
- 每个 clip 首次出现写一次短锚点，之后用 `@资产名` / 称谓 / 代词；**多 clip 分别生成时，每个 clip 重写该段实际用到资产的短锚点**。
- 若只有裸 `@资产名`、无任何特征，**不写"外观沿用既有资产"这种无信息括号**，直接用裸名，资产卡标"未提供，请对照现有资产"。

## 3.3 临时资产与群体

- 无正式名时建最少量临时引用（`@主角 / @对手A / @对手群体 / @主场景 / @关键武器`），卡中标"临时锚点，请按现有资产校正"。
- **群体人数不重复累加**：`@对手群体（六人）`与三名具名对手同时出现时，默认具名者包含在六人总数内（不加成九人），用"具名角色 + 其余群体成员"写法，并在提醒中说明该假设。

## 3.4 状态（只有长期可见、影响跨 clip 一致的变化才建状态）

- 算状态：服装破损 / 污损、持续伤势 / 血迹、武器断裂 / 丢失、灯光熄灭、门窗 / 结构破坏。
- 不算状态：短暂表情、转身、出拳、跌倒、一次性光影。
- 不临时伪造 `@资产名_状态`；在动作文字里说明变化即可。

## 3.5 推断外观（不阻塞）

- 纯剧本、无资产外观时，由执行者推断的外观（服装 / 发型 / 体型）在资产卡「请核对」列统一标"**外观为推断**"，**每人 ≤2 个**，不逐项确认、不占固定提醒、不阻塞。
- 用户后续提供真实资产时以真实资产为准重新生成，不做局部修补。

## 3.6 资产对照卡格式

```markdown
| 资产引用 | 文字短锚点 | 本段用途 | 请用户核对 |
|---|---|---|---|
| @主角 | 深色短打、右手单刀 | 完成反击 | 是否与上传角色及持刀手一致 |
```

只列本次生成实际需要的资产，不复制整个资产库。

# 第四部分：长场景拆分与跨 clip 连续

## 4.1 何时拆（连续多 clip 触发）

总时长超单次上限 / 需完整长戏 / 单段承载不下动作因果 / 武器伤势优势目标场景发生重大变化。
**不要机械地每 15s（或 30s）切一刀——先设计完整局势变化，再在"完整动作结果处"拆分。**

## 4.2 拆分位置

- **在这些节点结束 clip**：一次攻防 / 对话产生明确结果；人物到达新空间区域；武器完成夺取 / 丢失 / 断裂 / 更换；一方完成脱困 / 压制 / 反转；门 / 墙 / 烟尘 / 前景遮挡提供自然衔接点。
- **不要在这些状态中间结束**：攻击已发起未命中 / 未避开；抓抱、夺武器、换弹未完成；人物在半空落点不明；法术 / 爆炸已释放结果未现。

## 4.3 最小连续性（只维护对下一段有用的）

人物所在区域与大致面向 · 武器谁持有 / 哪只手 · 持续伤势 / 服装 / 武器变化 · 关键敌人局部状态 · 已发生的场景破坏 · **下段摄影机从哪一侧继续。**
不生成完整坐标、全量状态 JSON、逐帧位置表。

> 本节文本仍只做最小连续性、不写全量状态表；若需把“结尾状态”图像化喂给下一段图生视频，按 references/33-tech-panorama-anchor.md 技术全景锚点帧执行（模式A组尾1秒，或模式B独立5秒技术补段），不要在文本里扩成逐帧位置表。

## 4.4 提示词交接

- 承接信息**不单独成行**，直接写进下段"空间站位"开头，以"**承接上一段，**"起句；上段结尾信息写入"结尾状态"。
- 下段必须从上段结尾状态的事实开始（可改写句式），**不复制上段完整 prompt**。
- **每个 clip 的时间戳独立从 0 秒开始**，覆盖到该 clip 自己的总时长，不用跨 clip 累计时间。
- 全场只输出一次资产对照卡；全局风格每 clip 开头一句短语重申；不足时长的尾段按动作完整性安排镜头，不强行凑数。

# 第五部分：逐镜头闭环时间戳渲染（核心输出格式）

## 5.1 Clip 标题（代码块外）

```markdown
### Clip 01｜15秒｜16:9｜真人写实
```

## 5.2 固定正文（代码块内，从"空间站位："开始）

```text
空间站位：@角色A 位于画面左侧，面对画面右侧的 @角色B；@角色B 位于画面右侧，
面对 @角色A；说明姿势、表情、距离、轴线、关键道具位置；对峙补空间权力。
镜头一（0-1.2秒）：光圈 f/2.8（浅景深，背景明显虚化），焦段 80mm（近景），
中近景（medium close-up），动作发起、接触与结果。
镜头二（1.2-2.4秒）：光圈 f/2.8（浅景深，背景明显虚化），焦段 100mm（近景），
机位 / 运镜说明，承接上一动作的局部变化。
镜头三（2.4-3.6秒）：光圈 f/4（中等景深，背景轻微虚化），焦段 25mm（全景），
低角度（low angle）广角，表现完整身体位移与局势变化。
……
结尾状态：人物位置、朝向、姿势、武器归属、环境结果。（“结尾状态”若需图像锚点，见 references/33-tech-panorama-anchor.md：本组非末组时用模式A组尾1秒并拼前剔除，或用模式B另生成5秒技术补段且不进filelist；截末帧作下组参考。）
约束：集中列最易失败的连续性问题（5–8 项，≥3 项引用本 clip 具体事实）；声音占最后一项。
```

## 5.3 每个镜头行的必要成分

1. 标题起止时间 `（起始-结束秒）`；
2. `光圈 f/x（景深描述，纯中文）`；
3. `焦段 xxmm（景别描述，纯中文）`；
4. 景别 / 角度 / 视角 / 固定手持 / 运镜中**至少两项**，专业术语写"中文（English）"；
5. 可见动作（对峙写完整台词原句 + 情绪语速，或微动作）；
6. 接触 / 受力 / 位移 / 对下镜有用的结果（对峙写视线变化、失态、关系改变）。

**闭环时间戳（P0）：** 第一镜从 0 秒开始；**后镜起点＝前镜终点**；最后一镜结束在 clip 总时长；不重叠、不留空、不超总时长；小数最多一位，半角连字符 `-`。

## 5.4 光圈 → 景深 / 焦段 → 景别对照

| 光圈 | 景深描述 | 焦段 | 景别描述 |
|---|---|---|---|
| f/1.2–f/2 | 极浅景深，背景强烈虚化 | ≤24mm | 大全景 |
| f/2.2–f/2.8 | 浅景深，背景明显虚化 | 25–35mm | 全景 |
| f/4–f/5.6 | 中等景深，背景轻微虚化 | 36–55mm | 中景 |
| f/8–f/11 | 深景深，前后景基本清晰 | 56–79mm | 中近景 |
| f/16+ | 全景深，远近皆清晰 | 80–120mm | 近景 |
| | | 121–200mm | 特写 |
| | | >200mm | 大特写 |

- 写法固定：`f/2.8`（不写 f2.8）、`85mm`（不写"焦段 85"）；**光圈后必跟景深、焦段后必跟景别**；括号注释纯中文、不附英文。
- 用户明确给参数时优先保留（注释仍按实际参数填）；参数与镜头目的冲突时取最接近的可执行参数，并在 Pre-flight 说明。

## 5.5 视听术语双语（中文在前，同 clip 首次出现附英文）

光圈焦段括号注释不附英文；台词、普通动词不附英文。常用对照（节选，全表精神同此）：全景 full shot · 中景 medium shot · 近景 close-up · 特写 close-up detail · 推进 push in · 后拉 pull out · 横摇 pan · 上下摇 tilt · 横移 truck · 跟拍 tracking shot · 环绕 orbit · 甩镜 whip pan · 手持 handheld · 固定 static shot · 低 / 高角度 low/high angle · 荷兰角 Dutch angle · 主观 POV · 过肩 over-the-shoulder · 升格 slow motion · 长镜头 long take。

## 5.6 结尾状态与约束

- 结尾状态只记录下段 / 成片需要的事实，不重复最后一镜全文；黑屏 / 渐隐写这里。
- **约束 5–8 项，≥3 项必须引用本 clip 具体事实**（人名、持物、座位、血迹、已熄光源），不能全是"穿模 / 瞬移 / 无字幕"通用项；**声音固定占最后一项**：

```text
约束：保持两名角色、右手持刀与画面左右关系稳定，避免武器换手、穿模、瞬移、
第一视角身份错误；保留脚步、喘息、衣料与打击声，无音乐，无字幕。
```

## 5.7 一镜到底例外（用户明确要求时）

不得伪装成多镜头：
```text
空间站位：……
镜头一（0-15秒）：光圈 f/4（中等景深，背景轻微虚化），焦段 35mm（全景），
长镜头（long take），说明起始机位与唯一运镜；动作阶段一……；阶段二……；全程不切镜。
结尾状态：…… 约束：……
```
（不输出镜头二、三。）

## 5.8 字数目标（超长时的保留顺序）

- 15s 动作 1000–2000 字（>14 镜可至 2400）；15s 对峙 700–2400；30s 1400–2600。
- 超长保留优先级：**风格锁定 ＞ 空间站位 ＞ 动作连续 ＞ 接触受力 ＞ 台词原句 ＞ 镜头功能 ＞ 参数 ＞ 结尾状态 ＞ 约束 ＞ 装饰光影**。
- 每镜都写光圈焦段属"必要格式重复"，不算冗余；但风格锁定词在 clip 内重复＝去重遗漏。

---

# 第六部分：Pre-flight Notes（生成前提醒）

- **集中放在全部 clip 之后，最多 3 条，诚实、具体**（如"本场含 3 人群戏，已拆成两两小景别，群像靠剪辑拼接""雨夜暗调，已补窗光防全黑""03 镜为长距离跟拍，AI 失败率高，建议拆两段"）。
- 推断外观、群体人数假设等必要说明放这里，但不占用、不稀释真正的风险提示。

# 输出前检查（渲染协议自检）

- [ ] 全局风格锁定是否只输出一次、置于所有 clip 之前、且已把风格词解析为六槽？
- [ ] 特殊风格化是否显式输出启用 / 不启用？启用是否写明段落范围？clip 内有无重复风格词？
- [ ] 正文是否从"空间站位："开始？
- [ ] 是否用"镜头一（起始-结束秒）："格式？时间轴是否从 0 起、首尾连续、准确结束在总时长（后镜起点=前镜终点）？
- [ ] 每镜是否同时具备：时间戳、光圈（景深）、焦段（景别）、≥2 项摄影描述、动作结果？
- [ ] 台词是否完整原句、不跨镜、方言保留、字数 / 时长匹配？
- [ ] 对峙每单元是否有人失态 / 关系改变？微动作是否有发起与结果？
- [ ] 长场景是否在动作结果处拆、交接用"承接上一段"、每 clip 时间戳独立、状态跨段连续？
- [ ] 资产卡是否只列实际用到的、短锚点 6–20 字、推断外观已标注且每人 ≤2？
- [ ] 约束是否 5–8 项、≥3 项引用具体事实、声音占最后？
- [ ] f 值 / mm 单位是否规范、光圈后有景深、焦段后有景别？术语是否按"中文（English）"且每词每 clip 只注一次？
- [ ] Pre-flight 是否 ≤3 条、诚实具体？
