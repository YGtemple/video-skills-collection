## 二、G08 奶奶那场：血腥画面不直接拍，用"反应表演"替代（5版踩坑）

### 剧情原貌
案发夜，母亲被杀，奶奶端着煮好的鸡蛋进屋，发现地上有血、两个孩子不见了。

### 踩了什么坑（5个版本全部失败/不满意）
- **v1**：奶奶正面大脸特写 → 空炕没拍出来，首帧末帧重复
- **v2**：奶奶侧面对门口看空屋子 → 表情变化不够，情绪没出来
- **v3**：奶奶端鸡蛋进屋→看见地上东西→愣住 → **AI不敢直接生成血迹**，且前7秒画面卡住
- **v4**：镜头对准空炕，奶奶只露头顶 → 人物没戏
- **v5（成功，用户认可）**：奶奶端着一碗鸡蛋，**眼睛瞪大愣住，端碗的手在抖，转头朝空屋喊"阿勇？阿宽？"** ——全程没拍血，观众通过奶奶的反应脑补出"地上有血、孩子不见了"

### 可复用经验（血/尸/暴力场景的合规表达法）
1. **AI生成不出血腥画面，反复写"地上有血"只会得到卡死/失效镜头。不要硬刚，换表达**
2. **正确做法=反应表演法**：角色端着日常道具（鸡蛋/碗/盆）进屋→看见地上东西→愣住→手抖→喊人。观众想象力会自动补全惨剧，冲击力反而更强（希区柯克"不直接展示"原则）
3. 反应表演三件套：**表情骤变（瞪大愣住）+ 肢体细节（手抖）+ 声音（喊人名/喊话）**
4. 喊人不要喊全名，喊**小名/昵称**（"阿勇？阿宽？"），更真实更有痛感
5. 这种镜头情绪全靠奶奶的表演，提示词里必须写细：端碗的手在抖、眼睛瞪大、转头环顾、声音发颤

## 三、G11 死亡交代：拍"结果"（坟+遗物+画外音），不拍过程；暗场景防全黑

### 踩了什么坑
- 原G11拍"父亲回乡砸墙"，深夜昏暗场景 → **AI生成全黑，观众什么都看不见**
- 爷爷奶奶去世交代不清：观众不知道两个老人怎么没的

### 修复后的正确拍法
- **画面**：阴天，村外黄土坡上，**两座新坟并排**，左边坟前插着旧木牌、右边是矮石碑，坟头新翻的黄土带湿气；坟边草地靠着一把**旧锄头**（爷爷遗物）和一个**竹篮**（奶奶遗物）
- **画外音**（村民声音）："老李头找孩子的时候摔进了村外深沟，人到那就硬了。他老伴没熬几天，也跟着去了。"
- 观众一眼就懂：两个老人都没了

### 可复用经验
1. **交代人物死亡 = 拍坟 + 遗物 + 画外音一句话**。坟是新坟（新翻黄土带湿气）、遗物放在坟边（锄头/篮子/拐杖）、画外音用旁观者口吻说死因。全程无尸体无血腥，合规且信息完整
2. **暗场景提示词防全黑铁律**：深夜/昏暗场景，AI极易生成死黑。必须在提示词里写**具体可识别的元素**（坟的形状、木牌、石碑、锄头、篮子、荒坡枯树、灰白天色），不能只写"昏暗的屋内"——越具体的实体元素越不会黑
3. **死亡信息的画外音用"村民口吻"**，比旁白更有真实感："老李头……人到了就硬了"——口语化、有地方味
4. 两个老人一起交代时，用"一个先走，另一个也没熬住"句式，观众秒懂前后脚

## 四、G17 台词被切断：关键台词写完整短句 + 时间跳跃用黑场字卡

### 踩了什么坑
- 后爸堵门说"你敢走就别回来"，阿勇只说半句"好不容易攒出……"就**话没说完被切走**，直接跳到12年后
- 观众懵：话没说完，时间怎么跳的？

### 修复后的正确拍法
- 后爸：**"大半夜发什么疯？你敢走就别回来！"**（完整句）
- 阿勇：**"我好不容易攒了三年的钱，我要回家！"**（完整句，补全了断掉的"攒三年钱"信息）
- 阿勇推开后爸跑进夜色 → **画面渐黑 → 纯黑背景居中白色文字"十二年后"** → 切公安局
- 时间跳跃有了明确的视觉过渡

### 可复用经验
1. **AI生成长对话时，台词容易说不完就被切走**。关键台词必须写成**完整短句**（一句不超过15字），宁可少说一句，不能说半句
2. 台词信息密度要够：阿勇那句"攒了三年的钱"同时交代了"钱从哪来+逃了多少年+决心多大"，一句顶三句
3. **时间跳跃过渡=纯黑底+居中白色文字**（如"十二年后"），这是铁律20允许的唯一字幕例外。提示词里必须明确写"**纯黑背景居中白色文字'十二年后'**"，AI才会做对；不写清楚它可能乱加字
4. 黑场字卡停留1-2秒即切走，不用花哨字体

## 五、复刻项目全流程（18号基础上补充，已验证）

1. **解析原片**：飞书妙记转写逐字稿 + PyAV每2秒抽帧（316秒≈158帧）→ 输出分场剧本/角色表/视觉风格/叙事结构
2. **资产大师重做美术**：用户硬约束——复刻必须启动 script-asset-master，场景/角色/道具全部重新制作，**不得沿用或搬运原片素材**
3. **分镜+提示词**：G01-G28，每镜@对应参考图
4. **逐镜生成**：Seedance 2.5图生视频，台词写进提示词由模型直接生成（禁TTS）；**每次生成先完整展示提示词、展示同时直接出片（不停下等待确认），成片后随成片一并交付脚本/提示词给用户审核，认可才生成下一镜**
5. **逐镜检查+用户反馈修复**：只改用户点名的镜头，不整体重来；旧版备份为*_old.mp4
6. **硬拼接**：filelist.txt按G01-G28顺序；替换镜头后重新拼接
7. **封面+标题+文案**：竖版9:16+横版16:9双版本（见下）

### 用户反馈修复的标准动作
- 用户反馈某镜头"是啥玩意/不行" → **先抽帧看实际画面**（不只信生成时的描述），定位具体问题（拍错内容/全黑/台词断了/表情不对）
- 每个问题镜头单独重制，最多重试3-5版，每版换一个明确的改进点（不要一次改所有变量）
- 修完重新拼接、重新交付

## 六、封面/标题/文案（用户已认可，直接套用）

### 标题
**《后院》** ——两个字，电影感，悬念感强（观众会想：后院怎么了？——母亲被埋后院12年）

### 发布文案（短句+悬念+情感，5行）
```
7岁那年，他记住了两张脸。
12年，他每天在脑子里过一遍那天的画面。
母亲被埋在后院，全村人都传她跟人跑了。
他回来了。
```

### 封面
- **画面**：男人背影跪在三座坟前，远山黄昏，冷蓝远山+地平线暖橙余晖，低饱和胶片质感
- **文字**："后院"白色毛笔大字
- **规格**：竖版9:16（抖音/快手）+ 横版16:9（B站/视频号），同场景同人物同色调，两版都出

### 开头引言（黑屏白字，用户要"放视频开头让观众快速了解故事+呼吁"）

> ⚠️ **此为该作者个案，与零字幕红线冲突，默认不效仿。** 开头不放剧情介绍黑卡——仅时空跳转黑卡（如"十二年后"）允许。以下写法仅作历史记录，新项目不要照搬。

写法：黑屏白字，居中，逐段淡入淡出，8-10秒，最后一句是呼吁/致敬：
```
7岁那年，他被人从家里拐走。
走的那天晚上，他亲眼看见母亲被杀害，埋在了自家后院。
……
——谨以此片，献给每一个还在等孩子回家的家。
```

## 七、拼接注意事项（补充18号）

- 用 `-c copy` 硬拼接时，替换镜头后可能出现 **"Non-monotonous DTS"音频时间戳警告**——不影响播放，但如果用户反馈音画不同步，改用libx264重新编码拼接（见18号文件命令）
- 替换镜头流程：新片下载为GXX_new.mp4 → 旧片备份为GXX_old.mp4 → 新片改名为GXX.mp4 → 重跑filelist拼接 → 只交付最新成片
- 每镜时长：8-16秒为主，关键冲突镜可给12秒（保证台词说完+黑场过渡）

## 八、不要做的事（本项目的坑汇总）

- ❌ 不要硬写"地上有血/血迹"——AI不生成，镜头会卡死或失效；用反应表演替代
- ❌ 不要拍深夜昏暗场景却不写具体元素——AI生成全黑，观众看不见
- ❌ 不要让关键台词说半句——AI生成容易切，台词写成完整短句
- ❌ 不要用转场特效——只硬切
- ❌ 不要加字幕、不要配乐 BGM——全片零字幕，真实环境音保留
- ❌ 不要用TTS——台词必须写进提示词由视频模型生成
- ❌ 不要沿用原片素材——复刻必须用资产大师重做全部美术资产
