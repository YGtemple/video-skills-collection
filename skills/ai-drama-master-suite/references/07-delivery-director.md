# 交付与导演决策规范

## 概述

本模块包含两部分：**成片交付规范**（终审清单、多平台规格、公共链接交付）和**导演决策手册**（AI生成遇到瓶颈时的创作替代方案）。

---

## 第一部分：成片交付规范

### 1.1 成片终审清单

> **说明**：本技能交付的是"原样硬拼接粗成片"，不做剪辑/人为配乐 BGM/调色/片头片尾——这些由用户在自己的剪映/Pr/DaVinci 里完成。台词语音与真实环境音（脚步/雨/风/水流/虫鸣等）由视频模型生成端产出，硬拼接原样保留。本清单只检查 AI 负责的部分：素材质量、一致性、合规、音画同步、交付规格。涉及后期加工的项目（配乐 BGM/混音/调色/片头片尾等）见各小节标注，一律用户自理，不在 AI 交付检查范围内。

成片导出后，必须**完整播放至少两遍**，按以下清单逐项检查。第一遍专注画面和节奏，第二遍专注音频。

#### 时长与结构
- [ ] 总时长与剧本规划时长偏差≤10%（时长由故事需要决定，不锁死90秒/5分钟）
- [ ] 四幕时间锁命中（开场/核心冲突/反转/结尾）
- [ ] 开场3秒内有强冲击
- [ ] 反转有前期伏笔，直指核心立意
- [ ] 结尾有强悬念钩子或一击致命的余味
- [ ] 总时长 = 各镜头原始时长之和（硬拼接，未做修剪/调速）

#### 画面质量
- [ ] 全片无明显模糊、噪点、AI拼贴感
- [ ] 无面部崩坏、肢体扭曲、多余手指
- [ ] 无黑帧、跳帧、花屏
- [ ] 无画面裁切（主体不被边缘切掉）
- [ ] 画质在手机全屏播放时清晰可辨

#### 角色与场景一致性
- [ ] 所有角色全镜中面部/服装/发型一致（无换脸）
- [ ] 同场景空间布局、道具位置连续（无跳变）
- [ ] 相邻镜头光影衔接（无硬切式光源突变）
- [ ] 关键道具各镜中位置/状态连续（无瞬移）
- [ ] 无越轴（角色左右位置不无故互换）

#### 节奏与剪辑
- [ ] 镜头顺序与分镜一致，无漏镜/多镜
- [ ] 单镜时长与生成时一致（未做修剪/调速）
- [ ] 全部硬切/硬拼接，无任何转场特效
- [ ] 镜头边界处音画同步，无串音

> **节奏重编/快慢速/蒙太奇**：用户后期在自己剪辑软件里自理，AI 交付的是按分镜顺序原样硬拼的粗成片。

#### 音频质量
- [ ] 台词语音清晰可辨，无杂音/爆音/失真
- [ ] 台词来自视频自带语音（提示词中写入的台词），非后期 TTS 合成
- [ ] 动效音与画面动作大致同步（AI 素材自带的部分；用户后期可自行补音效）
- [ ] 无音频断裂/爆音/异常静音段（故意停顿除外）
- [ ] 整体响度正常，无突然爆音
- [ ] **镜头边界处无"上一镜声音漏到下一镜画面"的串音**（拼接同步检查）

> **人为配乐 BGM/四层混音**：禁止添加，用户后期自理。真实环境音由视频模型生成端产出，硬拼接原样保留，不做后期混音。

#### 字幕（全片无字幕）
- [ ] 确认全片无任何内嵌字幕/外挂字幕（台词通过视频自带语音传达）
- [ ] 画面未预留字幕安全区

#### 画面一致性（跨镜）
- [ ] 同场景镜头色调/亮度无剧烈跳变（严重跳变应回模块5重生成，不靠后期调色掩盖）
- [ ] 肤色跨镜无明显偏色
- [ ] 无过曝/欠曝区域（除非是刻意的光影设计）

> **全片调色/LUT/暗角/锐化**：用户后期自理，AI 交付不做调色。

#### 合规安全
- [ ] 全片无血腥/暴力/死亡特写
- [ ] 无敏感符号/违规文字/不当着装
- [ ] 伤害/死亡画面已通过合规替换（无血液/断肢/尸体）
- [ ] 无平台违禁内容

#### 片头片尾
> **片头/片尾悬念卡/黑场字卡**：用户后期自理，AI 默认不主动加片头片尾（除非用户明确要求）。AI 交付的粗成片就是从镜01 直接到最后一镜，硬切结束。

### 1.2 终审问题处理流程

```
终审发现问题
    │
    ├─ 致命问题（影响观看/合规）→ 必须修复后重新拼接
    │   ├─ 换脸/场景跳变 → 回模块5，重生成偏差镜头
    │   ├─ 合规问题 → 立即移除/替换违规镜头
    │   └─ 音画不同步/黑帧/花屏 → 回模块6排查规格后重新拼接
    │
    ├─ 重要问题（影响体验但不致命）→ 评估处理方式
    │   ├─ 个别镜头动作略卡 → 回模块4重生成（不靠后期加速掩盖）
    │   ├─ 光影小差异/色温小偏差 → 标注给用户，用户后期自行调色统一
    │   ├─ 动效音略不同步 → 标注给用户，用户后期自行微调
    │   └─ 节奏略拖沓 → 标注给用户，用户后期自行剪辑节奏
    │
    └─ 轻微问题（不影响观看）→ 记录在交付说明里，用户后期自理
```

**原则**：致命问题零容忍，必须修；AI 能修的（重生成/重拼接）就修，AI 不做的（调色/节奏/混音）一律标注给用户自己后期处理，不要替用户做。

### 1.3 多平台交付规格

> **重要优先级（先读）**：本技能交付的是**源画质 H.264(yuv420p)+AAC、faststart 的硬拼接粗成片，不压缩画质、不降分辨率、不降帧率**——源已是 H.264+AAC 时一律流拷贝（`-c copy`）。下表的分辨率 / 帧率 / 码率是**用户后续自行发布到各平台时的"目标平台推荐规格"**，不是让 AI 把成片压到这些参数；只有源编码 / 像素格式不兼容（HEVC、非 yuv420p）才做视觉无损高码率转码（CRF≈16–18，不缩放、不降帧）。平台二次压缩 / 转码由发布端处理，AI 不预先降质。

#### 抖音 / 快手（竖屏短剧主阵地）

| 参数 | 规格 |
|---|---|
| 画幅 | 9:16（竖屏） |
| 分辨率 | 1080×1920（最低），推荐1080×1920或更高 |
| 帧率 | 30fps（推荐），60fps（高动态场景） |
| 编码 | H.264（AVC），High Profile |
| 码率 | ≥8Mbps（1080p），≥12Mbps（源素材质量高） |
| 音频 | AAC，320kbps，48kHz，立体声 |
| 文件大小 | ≤500MB |
| 封面 | 9:16，1080×1920，JPG/PNG，≤5MB |

**抖音特别注意**：上传时选择"高清发布"，避免平台二次压缩；封面图第一帧要有冲击力。

#### B站 / 视频号

| 参数 | 规格 |
|---|---|
| 画幅 | 9:16（竖屏）或16:9（横屏） |
| 分辨率 | 1080p |
| 帧率 | 30fps |
| 编码 | H.264 |
| 码率 | ≥8Mbps |
| 音频 | AAC，320kbps |
| 文件大小 | B站≤8GB，视频号≤2GB |
| 封面 | B站16:9（1920×1080） |

#### 小红书

| 参数 | 规格 |
|---|---|
| 画幅 | 9:16（竖屏）或3:4（竖版图文视频） |
| 分辨率 | 1080×1920（9:16）或1080×1440（3:4） |
| 帧率 | 30fps |
| 编码 | H.264 |
| 时长 | ≤5分钟 |
| 文件大小 | 建议≤200MB |
| 封面 | 3:4（1080×1440）效果最好 |

**小红书特别注意**：feed是3:4比例，9:16视频会被裁切显示，重要内容放在中间3:4安全区；封面图要有文字标题。

#### 通用导出参数（仅作发布参考，非交付默认）

> 再次强调：**AI 交付默认流拷贝、保持源分辨率 / 帧率，不套用下面这套固定参数去压片**。下面仅在用户需要自行导出一个多平台发布版、且源规格与目标差异需要兼容时参考；若源已是 H.264+AAC，直接 `-c copy -movflags +faststart` 即可。

```
容器：MP4
视频编码：H.264（AVC），High Profile，Level 4.1
像素格式：yuv420p
分辨率：沿用源（源为 1080×1920 即保持，不缩放）
帧率：沿用源（不转帧率、不丢帧）
码率：视觉无损优先（CRF≈16–18 或沿用源码率）
音频编码：AAC-LC（源已是 AAC 可直接 copy）
faststart：+movflags faststart（moov 前置）
```

### 1.4 封面图设计规范

> **详细封面设计规范见 [13-cover-design.md](13-cover-design.md)，以下为要点摘要。** 封面必须达到电影海报级设计——专门构图的画面+片名式大字，不是截图加字。

- **尺寸**：9:16（1080×1920）用于抖音/快手；3:4（1080×1440）用于小红书；16:9（1920×1080）用于B站
- **格式**：JPG（质量≥90%）或PNG
- **文件大小**：≤5MB
- **文字安全区**：重要文字放在画面中间60%区域

**设计要点**：
- 选全剧最有氛围感的画面（反转镜/高潮镜/场景空镜），要有电影海报级构图、光影、氛围，不是随手截图
- **人物在环境中**：中景/全景，人物和场景融为一体，用环境衬托情绪；**不要大脸特写怼镜头**
- 加剧名（大字，像电影片名，4-8字）+ 悬念句（小字），字体粗体清晰，竖排/横排在画面一侧，不挡人物面部和主体
- 色调与全片一致（电影感色调，如暖黄+暗蓝）
- 不要用模糊截图、不要加太多文字（不超过3行）

**封面图文字模板**：
```
【大字】剧名（如：《午夜来电》）
【中字】悬念句（如："她已经死了三年"）
【小字】集数/标签（如：第1集 · 悬疑反转）
```

### 1.5 文件命名与版本管理

**所有保存文件（剧本 / 资产图 / 分镜 / 视频片段 / 成片 / 封面）一律按内容命名**：见名知意、可稍详细，**长度 4–20 字、不重名，并带段落 / 镜头编号**。

```
编号_内容描述_景别/用途[_版本].扩展名

示例：
G03_农奴主鞭打农民_近景.mp4
01_女主面部特写.png
12_雨夜巷口空镜.mp4
农奴翻身_硬拼接粗成片_v1.mp4
农奴翻身_封面_第1集.jpg
```

- 编号：镜头号 / 段落号（如 `01`、`G03`），顺序清晰
- 内容描述：写清这一镜 / 这个文件是什么（人物 + 动作 + 场景）
- 景别 / 用途：近景 / 特写 / 空镜 / 成片 / 封面等
- 版本：需要时追加 `_v1 / _v2 / _final`，但**不得用版本号替代内容名**
- ❌ 禁止空泛名：`未命名`、`新建文档`、`tmp`、`视频1`、`未标题`、纯数字

**版本管理**：保留所有历史版本（不要覆盖）；终选版本单独标记 `final`；发布后保留最终发布版本（修改已发布文件时用新版本，不改旧文件）。

### 1.6 内嵌预览播放器交付 + 公共访问链接（全局铁律）

**最终成片必须以内嵌预览播放器形式交付**（用户可直接在聊天中点击播放按钮预览播放，无需跳转外部页面），同时附公共访问链接。两者缺一不可。

**交付编码与不压缩画质**：
- 成片统一为 **H.264(yuv420p)+AAC、faststart 的 MP4**；**不压缩画质、不降分辨率、不降帧率**
- 源片段已是 H.264+AAC（Seedance 通常直接输出此格式）→ **流拷贝（`-c copy`），零重编码、零画质损失**；仅 HEVC/非 yuv420p 才视觉无损高码率转码（CRF≈16–18，不缩放、不降帧）
- 上传/导出选"原画质/不压缩"，禁止交付通道默认二次压缩
- 若当前聊天预览通道必然二次压缩（预览播放器本身会压），**必须同时提供原始文件的下载链接**，并明确告知用户："预览版仅供快速看节奏，请下载原始 MP4 导入自己的后期软件"
- 全部单镜原始文件一并打包提供（zip 链接），方便用户在自己剪辑软件里逐镜处理
- 所有文件按内容命名（4–20 字、带镜头/段落编号，见 §1.5）

交付格式：

```
【硬拼接粗成片交付完成】
剧名：《XXX》
集数：第1集
时长：XX秒（=各镜头时长之和，未做修剪/调速）

[内嵌预览播放器 — 快速看节奏用，可能被聊天通道压缩]

原始粗成片下载链接：[点击下载 rough_cut.mp4](https://...)
全部单镜原始文件：[点击下载 shots.zip](https://...)
封面图链接：[点击查看封面图](https://...)

说明：本片为按分镜顺序原样硬拼的粗成片，H.264+AAC、faststart 封装，未压缩画质，保留了台词与真实环境音，未做剪辑/配乐 BGM/调色/片头片尾，可直接导入剪映/Pr/DaVinci 继续后期。

交付物清单：
- 硬拼接粗成片 MP4（H.264+AAC、faststart，流拷贝、零画质损失；按内容命名）
- 全部单镜原始文件（zip，按镜头/段落编号、按内容命名）
- 封面图（附链接，按内容命名）
- 分镜表（最终版）
- 审核报告（逐镜审核+一致性检查+终审报告）
```

> 📁 **标准项目目录归位（仅本地 Windows 模式）**：项目根目录 `D:\豆包产物\短剧项目\<项目名>\` 下建 6 个子文件夹——粗成片→`05_成片\`、逐段视频片段→`04_视频\`（按镜头编号命名）、封面图→`06_封面\`、分镜表/分镜组/调度图→`03_分镜\`、立项大纲/定稿剧本→`01_剧本\`、资产图/通用资产提示词（及按需 MJ 提示词）/三维参数→`02_资产\`。云端 / Linux 环境以实际可写工作目录为准，不强制 D 盘结构。

**禁止事项**：
- ❌ 只说"已完成"不给预览播放器
- ❌ 只给公共链接，不给内嵌预览播放器
- ❌ 只给本地文件路径
- ❌ 链接失效或无法访问
- ❌ 成片和封面图只给一个链接（每个交付物都要给预览+链接）

- [ ] 标题/话题标签已准备好

- [ ] 发布时间选择流量高峰（抖音/快手：12:00-13:00，18:00-22:00；小红书：12:00-14:00，20:00-22:00）

## 第二部分：导演决策手册

在AI短剧制作中，不是所有问题都能靠"调Prompt重生成"解决。当技术手段遇到瓶颈时，以导演的创作思维做决策。

> **说明**：本手册中涉及"后期技巧"（调速/调色/加配乐 BGM/加颗粒等）的建议，均为**给用户的后期参考方向**——AI 交付的是硬拼接粗成片，不替用户做这些操作。用户在自己的剪映/Pr/DaVinci 里可按以下思路自行处理。AI 能直接执行的只有：调 Prompt 重生成镜头、重新硬拼接。真实环境音由视频模型生成端产出并原样保留，AI 不在后期添加环境音或配乐。

### 2.1 镜头生成失败时的五种重新设计方法

**什么时候判定"生成失败"**：同一镜头重试3次仍有中重度问题；问题反复出现；Prompt已调整到极限。

#### 方法一：拆分镜头

**适用**：复杂连续动作AI无法流畅生成（如"从椅子上站起并走向门口同时说话"）

**做法**：将一个复杂镜头拆成2-3个简单镜头：
- 镜A：中景，角色从椅子上站起（2秒）
- 镜B：特写，角色的手拿起桌上的文件（1.5秒）
- 镜C：中景，角色走向门口（2秒）

**原理**：AI生成简单动作的成功率远高于复杂动作。拆分后每个镜头只有一个核心动作。

#### 方法二：换景别

**适用**：全景/远景中AI需要生成太多细节导致崩坏；或大角度面部持续融化

**做法**：
- 全景→中景：减少背景细节，聚焦人物上半身
- 中景→近景/特写：进一步聚焦，减少AI需要生成的区域
- 正侧面→3/4侧面：AI对3/4侧面的面部生成能力最强
- 俯视/仰视→平视：AI对视平角度生成最稳定

**原理**：AI生成的细节越少，出错概率越低。

#### 方法三：用替代镜头

**适用**：某个动作/场景AI完全无法生成（复杂打斗、手部精细操作、多人互动）

**做法**：
- 打斗→用反应镜（对手的表情）+ 动效音（击打声）+ 快速剪辑暗示
- 手部精细操作→用道具特写（结果展示）+ 音效（操作声）代替操作过程
- 多人互动→用单人特写+对话剪辑（正反打）代替同框互动
- 无法生成的场景→用空镜（场景细节）+ 角色画外音 + 音效暗示

**原理**：电影百年历史中，导演经常用"不直接展示"的手法——观众的想象力比AI生成的画面更有冲击力。希区柯克的"炸弹理论"：让观众知道桌子下有炸弹，比直接展示爆炸更紧张。

#### 方法四：用剪影/遮挡

**适用**：AI生成的人物/动作有明显瑕疵，但剧情需要这个镜头

**做法**：
- 剪影：强背光，人物全黑，只看轮廓（AI生成剪影的成功率极高）
- 遮挡：用前景物体（门框/窗帘/其他人）遮挡瑕疵部分
- 景深虚化：大光圈浅景深，瑕疵区域在焦外虚化
- 运动模糊：快速运动时的自然模糊，掩盖细节瑕疵

**原理**：遮挡和虚化是电影语言的常规手法，不是"偷工减料"——它们可以引导视觉重心，增强氛围感。

#### 方法五：改变调度

**适用**：当前的镜头调度导致AI生成困难

**做法**：
- 改变人物站位：从面对面改为肩并肩（减少面部同时生成的难度）
- 改变运动方向：从横向运动改为纵向运动（AI对纵深运动生成更稳定）
- 改变动作设计：从大幅度动作改为小幅度动作（如从"拍桌子"改为"握紧拳头"）
- 增加静止帧：动作之间加0.5秒静止，让AI有"锚点"

**原理**：AI生成有自己的"舒适区"——静态/小幅度/纵深运动比动态/大幅度/横向运动更容易生成。导演要了解工具的特性，在创作中扬长避短。

### 2.2 情绪强化技巧

当单镜"技术上合格但情绪不到位"时，用以下后期技巧强化：

**运镜速度调整**：
- 紧张/爆发场景：将镜头加速1.1-1.3x
- 压抑/悲伤场景：将镜头减速0.85-0.95x
- 反转时刻：先减速0.5x（慢动作）→ 骤停0.3秒 → 恢复正常速度

**光影强化**：
- 紧张场景：增加对比度（+15%），压暗阴影
- 温暖场景：加暖色调（色温+500K），降低对比度
- 恐怖/悬疑：加冷色调（色温-500K），增加暗角，降低曝光

**音效强化**：
- 加心跳声（紧张场景，逐渐加速）
- 加呼吸声（情绪爆发前，急促呼吸）
- 加低频嗡鸣（悬疑场景，持续的不安感）
- 加静音（反转前0.5秒，所有声音骤停）

### 2.3 节奏调整决策

#### 节奏拖沓时

**表现**：观众看到一半走神，觉得"进度慢"。

**诊断**：
- 单个镜头过长（超过6秒且无明确叙事目的）
- 过渡镜头太多（不必要的反应镜/空镜）
- 台词冗长（每句台词都完整说完，没有剪辑）
- 环境太平（没有层次/环境音单薄）——配乐由用户后期决定，AI 不在后期加 BGM

**解决方案**：
1. 压缩镜头时长：能3秒说完的不要用5秒
2. 删减过渡镜头：去掉不推动剧情/不展示情绪的镜头
3. 台词剪辑：长台词中间插入反应镜/动作镜
4. 加速铺垫段：开场和推进段可以略加速（1.05-1.1x）
5. 提前冲突：如果开场10秒还没进入冲突，把冲突提前

#### 节奏仓促时

**表现**：观众看不懂剧情，"太快了没反应过来"，反转没有冲击力。

**诊断**：
- 镜头太短（大量0.5-1秒的快切）
- 关键信息没有给够时间（反转的揭示只有1秒）
- 缺少"呼吸点"（全程快节奏，没有停顿）
- 台词被裁切（关键台词没说完就切了）

**解决方案**：
1. 关键镜头给够时间：反转揭示镜、情绪爆发镜至少给3-5秒
2. 加呼吸点：连续快切后加1-2秒停顿镜
3. 放慢反转前的节奏：反转前5秒开始减速，制造"暴风雨前的宁静"
4. 关键台词完整保留
5. 加反应镜：关键信息后加角色反应镜（0.5-1秒），给观众消化时间

### 2.4 视觉风格统一决策

#### 建立全片视觉基调

在开始后期之前，先确定全片的视觉基调：
- **色调**：冷色调（悬疑/恐怖/科幻）/暖色调（温情/甜宠/复古）/中性色调（都市/现实）
- **对比度**：高对比（戏剧化/冲击）/中对比（自然/叙事）/低对比（柔和/梦幻）
- **饱和度**：高饱和（活力/漫画感）/中饱和（自然）/低饱和（压抑/写实/胶片感）
- **光影**：硬光（戏剧化/noir）/柔光（自然/温馨）/混合光
- **颗粒感**：无颗粒（数字感）/轻微颗粒（胶片感）/重颗粒（复古/lo-fi）

**决策方法**：根据题材和情绪选择基调；选一个"参考片"（电影/短剧/广告），以它的视觉风格为基准；选1-2个"基准镜头"（质量最高、风格最明确的镜头），其他镜头向基准镜头对齐。

#### 偏差镜头的风格统一

当个别镜头的视觉风格与全片基调不一致时：
- **调色统一**（最常用）：将基准镜头的调色参数复制到偏差镜头
- **光影统一**：如果偏差镜头的光影方向与全片不同，用后期调整
- **质感统一**：加统一颗粒/噪点，掩盖不同镜头的质感差异
- **重生成**：如果偏差太大，重生成（光影是AI生成的核心参数，后期难以根本改变）

**统一是"基调统一"，不是"逐像素统一"**：观众感知的是整体氛围，不是每个像素的色彩。小差异可以接受。允许合理的风格变化（不同情绪段可以有不同色调，这是叙事需要）。

### 2.5 常见创作困境与解决方案

#### 困境一：AI生成的角色"没有灵魂"

**表现**：角色面部清晰、动作正确，但表情木然，感觉像"人偶"，没有感染力。

**解决方案**：
1. **用特写放大微表情**：AI在特写中生成的微表情（眼神微动/嘴角微颤）比中景更有感染力
2. **用真实环境音和细节声音"注入"情绪**：同样的画面，配合悲伤的环境音（雨声/呼吸声/物品轻响），观众会"觉得"角色在悲伤（环境音在生成端写进提示词，不用后期加配乐）
3. **用反应镜代替正面展示**：不直接展示角色的表情，而是展示其他角色对他的反应——观众会通过反应"推断"角色的情绪
4. **用画外音/内心独白**：角色不说话，但加内心独白（画外音），观众通过声音理解角色的内心
5. **Prompt中加更具体的表情描述**：不是"sad"，而是"tears in eyes, trembling lips, looking down with grief"——越具体，AI生成的表情越有细节

#### 困境二：反转没有冲击力

**表现**：反转剧情设计得很好，但生成后观众"没感觉"，反转像普通剧情推进。

**解决方案**：
1. **反转前加"假平静"**：反转前3-5秒突然放慢节奏，环境音减弱/安静，制造"一切正常"的假象——然后反转爆发，对比增强冲击
2. **反转时刻骤停**：反转揭示前0.5秒，所有画面运动和声音骤停——然后反转镜硬切切入，环境音/动效音自然进入（配乐由用户后期决定）
3. **用硬切+音效冲击**：反转帧直接硬切（全片禁用闪白/闪黑/叠化等一切非硬切转场），配合低音boom+骤停制造冲击感
4. **加低音boom**：反转时刻加一个30-60Hz的低音冲击（身体能感受到的震动）
5. **给反转足够的"释放时间"**：反转后不要立刻切走，给3-5秒展示角色反应和情绪释放
6. **用慢动作**：反转的关键动作（如转身/揭露/掉落）用慢动作（0.3-0.5x），增强仪式感

#### 困境三：90秒讲不完故事

**表现**：剧本写得很好，但90秒内塞不下——要么节奏仓促，要么砍掉关键剧情。

**解决方案**：
1. **"展示，不要讲述"**：用画面和动作代替台词解释（如角色看了一眼照片，比说"这是我去世的妻子"更有效）
2. **删减次要角色**：90秒短剧最多2-3个主要角色，多余的角色合并或删除
3. **合并场景**：如果剧情在3个场景发生，考虑合并到1-2个场景（场景切换消耗时间）
4. **用蒙太奇压缩时间**：需要展示时间流逝/多个事件时，用快切蒙太奇（5秒可以展示5个事件）
5. **开头直接进冲突**：不要用5秒"介绍背景"——直接从冲突开始，背景信息在冲突中自然展示
6. **结尾留白**：不要把所有事情都解释清楚——结尾留悬念，让观众自己脑补，同时为下集铺垫

#### 困境四：全片"AI感"太重

**表现**：每个镜头单独看都OK，但拼在一起后，观众一眼就能看出"这是AI生成的"——太完美、太光滑、没有"人味"。

**解决方案**：
1. **加颗粒/噪点**：模拟胶片质感，颗粒可以打破AI生成的"过于光滑"
2. **加轻微运动抖动**：AI生成的镜头太稳，加轻微的手持抖动（模拟手持摄影），增加"实拍感"
3. **加镜头光晕/漏光**：模拟镜头眩光和胶片漏光，增加"摄影感"
4. **加呼吸式对焦**：模拟真实镜头的轻微对焦呼吸（焦点微移），打破AI的"全画面清晰"
5. **故意保留一些"不完美"**：不要把每个镜头都修到完美——真实拍摄也有小瑕疵，保留一些自然的不完美
6. **用剪辑打破"完美"**：AI生成的镜头节奏太均匀，用剪辑制造一些"不均匀"——有的镜头长，有的短，全部硬切，靠镜头长短变化而非转场特效制造节奏
7. **环境音的"不完美"**：真实环境音（空调声/远处人声/电流声/雨声）应在生成端写进提示词做足，AI 不在后期添加；硬拼接时原样保留

## 三、导演决策检查清单

在每个关键决策点，问自己：

**创作决策**：
- [ ] 这个决策是为了"更好的叙事"，还是为了"掩盖AI的缺陷"？如果是后者，有没有更好的创作方式？
- [ ] 如果这是真人拍摄，我会这么做吗？如果不会，为什么AI生成就要降低标准？
- [ ] 观众会注意到这个问题吗？如果不会，不要过度修复（把精力放在观众会注意的地方）
- [ ] 这个决策会影响全片的节奏/情绪/风格吗？如果会，确保它是"有意为之"，不是"无奈之举"

**技术决策**：
- [ ] 已经重试3次了吗？如果没有，再试一次
- [ ] 换了Prompt/参考图/生成模式了吗？如果只调了一种参数，试试其他参数
- [ ] 这个问题是"这一个镜头"的问题，还是"这类镜头"的问题？如果是后者，在后续镜头中主动规避
- [ ] 后期能修复吗？如果能，标记后期修复，不要浪费生成资源

**最终决策**：
- [ ] 这个决策后的结果，我愿意署上自己的名字吗？
- [ ] 如果观众问"为什么这里这样处理"，我能给出一个创作上的解释吗？
- [ ] 全片看完后，整体感好吗？（不要只看单个镜头，要看全片的整体效果）
