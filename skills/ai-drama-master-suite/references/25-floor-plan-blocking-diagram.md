# 平面俯视图与调度图（Floor Plan / Blocking Diagram）——生成前先把空间、站位、机位、动线画死

> **定位**：模块2 分镜设计**之前**的「空间规划」强制步骤，是 [24-camera-plates-lock.md](24-camera-plates-lock.md) 的**上游**。24 号锁「画面层」（每个镜头长在同一张机位底图上），本文件锁「空间规划层」（人站哪、朝哪、往哪走、机位放哪、轴线在哪）。
> **适用**：同一场景含 ≥2 个镜头/片段、人物有移动、多人对话、群戏、一镜到底、复杂动作调度、复刻对齐原片。单镜头固定空镜可简化。
> **解决痛点**：人物站位乱跳、朝向错误、越轴、动线矛盾（穿墙/穿家具）、摄影机没有合理落点、每段重建房间、空间穿帮。

---

## 一、两个概念

### 1. 平面俯视图（Floor Plan / Overhead Plan）
从场景**正上方垂直俯视**的比例图，相当于这块场地的「地图」。必须画出：
- 墙体、门（含开合方向）、窗
- 家具、关键道具、障碍物
- 出入口、可通行通道、台阶/高差

作用：确立**唯一、稳定**的空间，全场镜头共享，不再每段重新想象房间。

### 2. 调度图（Blocking Diagram / Staging Plan）
在平面俯视图上叠加「人 + 摄影机 + 动线 + 光」的标注图，是这场戏的「作战地图」。必须标注：
- 每个角色的**起始位置、编号、朝向**（视线方向）
- 角色**移动路径（动线）**：起点→终点、箭头、关键停顿点
- 每个镜头的**摄影机机位、朝向、视野范围**，主机位与补拍机位，编号对应分镜
- **摄影机移动路线**（推/拉/跟/轨道/弧线）：起止位置 + 箭头
- **180° 轴线**位置
- 主光/关键光源位置（建议）

> **场面调度（Blocking/Staging）核心原则**：决定人物站哪、往哪移动、摄影机在哪看。**每次移动都必须有动机（motivated movement），绑定剧情节拍/情绪变化**，而不是为了画面花样乱动。

---

## ★ 核心用途：俯视图控制画面走位（走位锁定法）

**走位（Blocking/Movement）＝角色在场景里的站位、朝向、移动路线、停顿，以及与他人的相对位置。** 俯视图最核心的作用，就是把走位「画死」，让模型不能自由发挥。

### 为什么必须用俯视图控走位
- 视频模型对空间没有稳定记忆，只靠文字「他走到左边」常被忽略或乱执行 → 人物飘、跳位、朝向反、两角色莫名换位、静止的人自己站起来。
- 俯视图把走位变成一张**看得见的地图**，模型有明确空间锚点；多镜头共用一张，走位跨镜一致。

### 走位四要素（画在俯视图上）
1. **起点站位**：编号圆圈＋朝向箭头，标每个角色开场位置。
2. **走位路线**：实线箭头，起点→终点，关键停顿用小点；路线不穿墙、不穿家具。
3. **终点站位**：标出移动后落点与朝向。
4. **静止角色**：明确标注「保持不动」；不同角色用不同颜色，多人路线不交叉矛盾。

### 每个镜头怎么执行
1. 把**俯视走位图挂进参考图（@俯视图）**，连同角色图、场景图一起引用。
2. 提示词写死本镜走位，套用锁定句：
   > 严格按俯视走位图：角色①从〔起点〕沿〔路线〕移动到〔终点〕，面朝〔方向〕；角色②保持〔位置/朝向〕不动；机位〔固定 C1 / 沿某路线〕，不改变任何站位与朝向。
3. 一次只让该动的人动，写清「谁不动」，防止静止角色自己起身换位。

### 生成后逐镜对照俯视图查走位
- [ ] 起点、路线、终点、朝向是否与图一致？
- [ ] 静止角色有没有乱动、多人有没有换位？
- [ ] 走位是否改变人物相对位置（变了就要重建轴线、机位换到新侧）？
- 不符即重生成；废片不删，归 `废片/` 标注原因。

> 走位跨段连续：**上一段走位终点＝下一段起点**；一镜到底用一张图画完整连续走位和伴随机位。

## 二、标准符号图例（统一照此画）

| 元素 | 符号 | 说明 |
|---|---|---|
| 角色 | 圆圈＋编号 `①`，圈内小箭头 | 小箭头＝面朝方向，如 `①→` 面朝右；不同角色用不同颜色 |
| 角色动线 | **实线箭头** | 起点指向终点，终点标落点；关键停顿用小点 |
| 摄影机 | **V 形/三角形 ▶** | 尖角＝镜头朝向（指向主体），开口宽度≈视野（广角开口大、长焦开口窄）；旁标镜头号 `C1` |
| 摄影机移动 | 空心/双线箭头 | 标起止机位（C3起→C3落）；轨道用平行双线，弧线用弧箭头 |
| 轴线 | **虚线**连接两主体 `①┄┄②` | 标注「180°线，机位保持在 X 侧」 |
| 门 / 窗 | 墙留缺口＋门扇弧线；窗用双线 | 标明开合方向 |
| 灯 | 太阳/灯泡符号 | 标照射方向 |
| 家具/道具 | 简化俯视轮廓 | 桌＝矩形、椅＝小方块、床＝长矩形 |

### 示意：双人对话 + 三机位（俯视图）

```
        北（窗）
 ┌──────────────────────┐
 │                      │
 │   ①→          ←②     │   ①面朝右、②面朝左（对话）
 │   （桌在两人中间）     │
 │        ┄┄┄┄┄┄┄        │   ← 180°轴线（虚线）
 │  ▼C1      ▼C2        │   C1/C2 为过肩正反打（同在轴线南侧）
 │            ▼C3       │   C3 为侧向双人中景
 └──────────────────────┘
        南（门）
```

> 三台机位全部在轴线同一侧；`▼` 尖角朝上＝摄影机向北拍。

## 三、绘制流程（六步，先规划后生成）

1. **定空间**：取得该场景「正上方俯视、无人物」的平面图（可让 AI 出一张俯视空镜，或在场景全景基础上抽象成线稿），画齐墙、门、窗、家具、道具、通道。
2. **放人物**：标出每个角色的开场位置、编号、朝向。
3. **排动线**：按剧情节拍画出角色每次移动的起点→终点箭头；确认每次移动有动机、路径不穿墙不穿家具、多人动线互不矛盾。
4. **拉轴线**：对每组对话/对视画 180° 虚线，决定机位统一在哪一侧。
5. **放机位**：先放一个交代全局的**主机位（master）**，再按情绪/信息需要放补拍机位（中近特、过肩、主观），全部在轴线同侧；机位旁标镜头号、与分镜一一对应；需要运动就画机位移动路线。
6. **标注核对**：标主光，对照自检清单逐项核对；确认后此图即该场景所有镜头的**唯一依据**。

> **AI 落地两种标注法**：① 用修图/画图软件直接在俯视图上标站位机位（最直观，定稿推荐）；② 把俯视图喂回 AI，用文字精确描述「谁在什么位置、朝向、机位在哪」生成标注图。

## 四、在 AI 视频生成工作流中的位置

```
剧本/故事确认
   → 【25：平面俯视图 + 调度图】空间规划（本文件）
   → 【24：机位底图 Plates】画面层锁定（按调度图决定的机位制作底图）
   → 【22：分镜组】镜头序列（每镜标机位号/站位/朝向）
   → 提示词（每镜引用对应机位底图 ＋ 角色图，@ 资产）
   → 生成
   → 审核（对照调度图查站位/朝向/动线/轴线）
```

- 每个分镜/镜头都要能在调度图上找到**对应机位编号**；提示词里的站位、朝向、运动必须与调度图一致。
- **多段同场景**：调度图只画一次、全段共用；人物移动跨段时，**上段终点＝下段起点**。

> 规划层保证"应该走到哪"；上一组**实际**演到哪的图像快照锚点，见 references/33-tech-panorama-anchor.md（生成后截组末全景帧作下组参考）。本俯视图/调度图不承担该实测快照。
- **⛔ 段间衔接点（铁律31）要画进调度图**：在每两个相邻分镜组（默认 30 秒段）的边界处标注衔接点——
  - 有场景转换 / 动线跳跃 / 朝向光影不连续 / 强冲突反转后需缓冲的，在图上画出**衔接片段的动线与机位**（编号 `G03a` / `G03-G04衔接`），并保证**上段动线 / 朝向终点＝衔接起点、衔接终点＝下段起点**；跨场转场（出门—路上—到达）分段画各空间与连接动线；
  - 同机位连续、硬切自然的，在边界标「硬切连贯」，不画衔接机位 / 动线。
- **一镜到底**：在一张调度图上画出完整连续动线和摄影机伴随路线，是做复杂长镜头最有效的方法。
- **复刻**：按原片画面反推 overhead（还原原片站位/机位/动线，含原片的段间衔接），逐镜对齐；但全部资产重新制作、不搬原片。

## 五、与既有规范的关系（叠加，不冲突）

- 是 **24 机位底图的上游**：先由调度图决定「有哪几个机位」，再据此制作各机位底图。
- 服务**铁律27**（站位正常、跨镜稳定、不越轴）：调度图是该铁律的执行工具。
- 服务**铁律31**（段间必做衔接）：在图上标注相邻段的衔接点 / 衔接片段动线与机位，是衔接片段首尾对齐、不越轴、空间不漂移的规划依据。
- 服务**铁律24**（脸/服装一致）：机位与朝向稳定也减少人物崩坏。
- **真人/漫剧都适用**：流程符号不变；真人写实要求机位/动线符合物理空间（摄影机有合理落点、不穿墙）；漫剧/动画更依赖前期站位与机位规划，仅切换画面风格。
